# Паттерн «Таймлайн этапов» (T14.11)

Правила сборки повторяющейся композиции «этапы процесса» + mini-эталон из
четырёх этапов. Эталон целиком: [`timeline.html`](timeline.html) — он же стенд
`/showcase/dist/stands/patterns/timeline.html` (генерируется
`showcase/build.mjs`).

Таймлайн — «Как попасть на практику» career-portal: горизонтальный ряд
нумерованных точек с заголовками и текстами. Пилот собирал связку самодельно
(REPORT §4, PLAN P1-5); система переносит **композицию** и канонические связки.
Связки `tlp-*` — **паттерн-слой** (adoption T17.10 — перенесены из `<style>`
дока в `patterns/patterns.css` → опциональный `dist/ui-patterns.css`; вариант
A T17.1, прецедент [list/detail/form](../README.md) и лендинг-связок T17.9):
значения только токенами `--ui-*`, сайты подключают слой по желанию
(порядок в head: токены → core → patterns → сайт).

Компонент `dist/ui-timeline` не создаётся — второго потребителя нет; при
появлении решение о компоненте принимается отдельно (после EPIC-14). Анимации
шагов — за пределами матрицы (reduced-motion-осознанно — без них);
вертикальный таймлайн не переносится (в оригинале только горизонтальный,
колонка — мобильная деградация той же композиции).

## Состав

```html
<section class="ui-section" aria-labelledby="…-title">
  <div class="ui-container">
    <h2 class="ui-h2" id="…-title">Как попасть на практику</h2>
    <!-- html-validate-disable-next no-redundant-role, prefer-native-element -->
    <ol class="tlp" role="list">
      <li class="tlp__stage">
        <span class="tlp__dot">1</span>
        <h3 class="ui-h6">Заголовок этапа</h3>
        <p class="ui-small ui-text--muted">Текст этапа.</p>
      </li>
      …
    </ol>
  </div>
</section>
```

| Слой | Что | Откуда |
|---|---|---|
| Секция | `ui-section` — вертикальный ритм 32/48px | base/layout.css, T3.4 |
| Контейнер | `ui-container` — max-width + паддинги 16/24/32 | base/layout.css, T3.4 |
| Заголовок секции | роль `ui-h2` («классы, а не теги», T3.3); секция именована `aria-labelledby` | base/typography.css |
| Этапы | `ol.tlp[role="list"]` — колонка (база) / горизонтальный ряд `1fr`-колонок от 1024 | связки `tlp-*` слоя |
| Точка | `span.tlp__dot` — круг 56px, видимый номер, `--ui-color-primary` на `--ui-color-surface-hover` | связки `tlp-*` слоя |
| Заголовок этапа | роль `ui-h6` (h3 — у секции есть h2, без пропуска уровня); принятый пилот несёт `h3.ui-h6` — канон «заголовок карточки списков» T16.12 (20/500) | base/typography.css |
| Текст этапа | `ui-small` + `ui-text--muted` (fs-small/muted оригинала) | base/typography.css |
| Линия | `::after` связки этапа (кроме последнего) — 2px под точками, от lg | связки `tlp-*` слоя |

Число этапов задаёт **разметка** (`li`), а не CSS: ряд собирается
`grid-auto-flow: column; grid-auto-columns: 1fr` — колонка на каждый этап,
без inline-стилей и без счётчика в стилях. База (до 1024) — та же композиция
одной колонкой: порядок чтения = порядок DOM.

> **Примечание (батч 31.10, ревью T17.10):** мини-эталон этого дока
> (`timeline.html`) приведён к канону — заголовок этапа `h3.ui-h6` (канон
> T16.12 «заголовок карточки списков» 20/500, принятый пилот
> `build.mjs`, пин `pilot-timeline-adoption`); ранее пример показывал
> `ui-h3` — унаследовано от T14.11. Эталоны стенда пересняты
> контейнерным гейтом.

## Граница «система / сайт»

- **Система даёт**: секцию, контейнер, роли типографики (h2 → h3,
  `ui-small`/`ui-text--muted`), переносы длинных RU-слов (overflow-wrap,
  T3.3), семантические пары токенов (точка: `--ui-color-primary` на
  `--ui-color-surface-hover` — ≈12.6:1, гейт AA).
- **Сайт даёт**: контент этапов (номера, заголовки, тексты); связки `tlp-*`
  сайт получает подключением слоя `ui-patterns.css` (копировать их в
  `template_styles.css` не нужно — слой делает канон исполняемым, урок T16.5).
- **Не переносите** уникальные приёмы конкретных страниц (hover-перекраска
  точек пилота, анимации шагов) — это зона сайтов; если приём нужен
  нескольким сайтам — заявка на компонент (EPIC-2/4+), а не расширение
  паттерна.

## A11y

- **ol-семантика этапов** (WCAG 1.3.1): порядок шагов — смысловая
  последовательность, скринридер анонсирует список. `role="list"` обязателен:
  глобальный reset снимает `list-style`, а Safari/VoiceOver на
  `list-style: none` теряет роль списка (конвенция `ui-breadcrumbs`,
  `.htmlvalidate.js`); рядом — inline-директива html-validate
  (`no-redundant-role, prefer-native-element` слепы к багу).
- **Видимые номера — текстом, не `content: counter`**: скринридер читает
  текст точки; генерируемый контент хрупче (не переводится, не выделяется,
  теряется при отключении CSS). Собственная нумерация ol дублировала бы
  номер — маркеры выключены, номер несёт точка.
- **Линия — декоративная**: псевдоэлемент `::after` связки, без текста — в
  a11y-дерево не попадает, смысла не несёт (aria-hidden не требуется).
- **Иерархия заголовков**: h1 страницы (каркас сайта) → h2 секции таймлайна
  → h3 этапов — без пропусков (гейт `irao/heading-order`).
- **Контраст**: номер точки — `--ui-color-primary` на
  `--ui-color-surface-hover` = ≈12.6:1; заголовки и тексты — системные пары
  (`--ui-color-heading` T14.1, `--ui-color-text-muted` 6.19:1 на белом).

## Do / Don't

- **Do**: держите этапы в `ol[role="list"]` с видимыми номерами в точках;
  секцию — по формуле «секция → контейнер → h2 → ol».
- **Do**: число этапов меняйте разметкой (`li`), ряд пересоберётся сам.
- **Don't**: не рисуйте номера `content: counter` и не прячьте их
  `aria-hidden` — номер этапа это контент.
- **Don't**: не меняйте вид связок на сайте — канон `tlp-*` живёт в
  паттерн-слое (`patterns.css`); значение уточняется задачей эпика, а не
  правкой сайта (значения только токенами `--ui-*`).
- **Don't**: не делайте вертикальный таймлайн «вторым режимом» — в оригинале
  его нет; узкие вьюпорты обслуживает мобильная деградация в колонку.

## Bitrix-заметки

- Этапы — **элементы инфоблока** («Этапы», свойство `SORT` = порядок):
  вывод циклом `foreach ($arResult["ITEMS"] as $i => $item)`; номер точки —
  `$i + 1` (или явное свойство, если порядок не равен нумерации).
- Связки `tlp-*` (колонка/ряд, точка, линия) приходят подключением
  **`dist/ui-patterns.css`** в шаблоне сайта (опционально, после `ui-core`);
  источник значений — [`patterns.css`](../patterns.css) (в док-HTML паттерна
  стилей больше нет — adoption T17.10). Значения только токенами `--ui-*`
  (граница «система / сайт» — правило выше).
- `id` заголовка секции (`aria-labelledby`) и заголовков-якорей уникальны на
  странице: при выводе секции циклом добавляйте суффикс
  (`…-title-<?= $id ?>`).
- VI-режим (T9.1): композиция перекрашивается темами модуля как все элементы
  (цветов вне токенов в связках быть не должно — инвариант §5); проверка
  страниц в VI — README `ui-vi`.
