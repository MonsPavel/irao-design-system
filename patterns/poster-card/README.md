# Паттерн «Постерная карточка» (T17.18)

Порт постерной иллюстрированной карточки блока «Школьникам и студентам»
career-portal (`.students--illustrated`, `src/blocks/students/students.css`):
цветной постер с крупным заголовком, текстом, иллюстрацией в рост и круглой
кнопкой-действием. Эталон целиком: [`poster-card.html`](poster-card.html) —
он же стенд `/showcase/dist/stands/patterns/poster-card.html` (генерируется
`showcase/build.mjs`).

Связки `pstr-*` — **паттерн-слой** (`patterns/patterns.css` → опциональный
`dist/ui-patterns.css`; вариант A T17.1, прецеденты [лендинг-связок T17.9](../README.md)
и лендинг-композиций T17.15): значения только токенами `--ui-*`, сайты
подключают слой по желанию (порядок в head: токены → core → patterns → сайт).
Компонент `dist/ui-poster-card` не создаётся — второго потребителя нет
(прецедент tlp- T17.10); при появлении решение о компоненте отдельно.

## Состав

```html
<article class="pstr-card pstr-card--peach">
  <div class="pstr-card__body">
    <h3 class="pstr-card__title ui-h3">…</h3>
    <p class="pstr-card__text ui-body">…</p>
  </div>
  <img class="pstr-card__illu" src="…" alt="" loading="lazy">
  <a class="pstr-card__action" href="…" aria-label="Подробнее: …">
    <svg … aria-hidden="true"></svg>
  </a>
</article>
```

Карточка — `article` (или карточка-ссылка `<a class="pstr-card …">`, когда
кликабельна целиком: тогда действие — декоративный `<span aria-hidden>`).
Слоты: `__body` (заголовок-роль + текст), `__illu`, `__action`.

## API

| Класс | Назначение | Значения |
|---|---|---|
| `pstr-card` | каркас постера: колонка, `min-height` 23.75/27.5/37.5rem (380/440/600px оригинала, mobile-first), паддинг 20px, радиус карточки, клип иллюстрации | заливка — хук `--pstr-bg` (дефолт — `--ui-color-surface`) |
| `pstr-card--peach` | тон peach: `color-mix` от токенов (оригинал `#FFDDC7` вне токенов); кнопка accent/on-dark | хук `--pstr-bg` |
| `pstr-card--navy` | тон navy: `--ui-color-primary-deep`; текст on-dark; кнопка surface/text | хук `--pstr-bg` |
| `pstr-card--light` | тон light: `--ui-color-surface-muted` (surface-blue-50); кнопка primary/on-dark | хук `--pstr-bg` |
| `pstr-card__body` | тело поверх иллюстрации (z1), колонка, шаг 12px | — |
| `pstr-card__title` | заголовок: роль `ui-h3` разметки (fs-h3/fw-h3/1.3/−0.02em); цвет text | on-dark на navy — от модификатора |
| `pstr-card__text` | текст: роль `ui-body` разметки (fs-body/lh-body); цвет text | on-dark на navy — от модификатора |
| `pstr-card__illu` | иллюстрация: absolute, `pointer-events: none`; координаты по тонам «как есть» (peach left 0/top 42%/width 67%; navy left 6%/top 43%/width 56%; light right −8%/top 45%/width 63%) | — |
| `pstr-card__action` | действие: абсолют правый-низ 20px, 3.25rem (52px), круг; hover — `scale(1.08)` | пара хуков `--pstr-action-bg`/`--pstr-action-color` (дефолт accent/on-dark) |

## Тон

В отличие от nav-карточек T17.9 (тон — параметр сайта на хуках), три тона
постера — часть **одобренной композиции**: значения живут в модификаторах
слоя, сайт выбирает модификатор, а не цвет. Peach вне токенов — хук
`--pstr-bg` с `color-mix` от токенов (прецедент тон-хука `--hro-tag-bg`
T17.15: hex в ДС не едет — гейт слоя). Свои тональные варианты — через
тот же хук `--pstr-bg` в сайт-зоне (контраст пары — обязанность сайта,
прецедент таблицы контрастов лендинг-связок T17.9).

## Do / Don't

- **Do**: имя действия — на доступном имени (`aria-label="Подробнее: …"`);
  стрелка внутри декоративна (`aria-hidden="true"`).
- **Do**: иллюстрация декоративна — `alt=""` (контент постера несёт
  заголовок и текст).
- **Do**: заголовок карточки — следующий уровень иерархии страницы (секция
  h2 → карточка h3, без пропусков).
- **Don't**: не навешивайте hover-состояние на карточку целиком — в
  одобренном дизайне интерактивна только кнопка-действие.
- **Don't**: не задавайте размер/цвет кнопки руками — пара приходит от
  тона карточки (хуки `--pstr-action-bg/--pstr-action-color`).
- **Don't**: не размещайте критичный для понимания контент в иллюстрации —
  она клипается карточкой и не интерактивна (`pointer-events: none`).

## A11y

- **Действие — ссылка с доступным именем** (WCAG 4.1.2): постер кликается
  кнопкой-действием `<a class="pstr-card__action" aria-label="Подробнее: …">`;
  стрелка внутри — `aria-hidden="true"` (декоративный глиф). Если карточка
  целиком ссылка — наоборот: `aria-label` на карточке, действие-спан
  `aria-hidden` (канон nav-карточек T17.9).
- **Иллюстрация декоративна** (`alt=""`, WCAG 1.1.1): смысл постера несут
  заголовок и текст; скринридер иллюстрацию пропускает.
- **Иерархия заголовков**: h1 страницы (каркас сайта) → h2 секции →
  h3 заголовок карточки (роль `ui-h3`) — без пропусков (гейт
  `irao/heading-order`).
- **Типографика — роли**: заголовок/текст — роли `ui-h3`/`ui-body`
  (масштаб/интерлиньяж системы); тон navy красит текст `on-dark` —
  контрастная пара одобренного дизайна.
- **Hover только на кнопке**: карточка не несёт hover-состояния — фокус/наведение
  не меняют чтение контента; кнопка получает фокус по клавиатуре как обычная
  ссылка (без ловушек: `pointer-events: none` только у иллюстрации).

## Граница «система / сайт»

- **Система даёт**: каркас постера (колонка, высоты 380/440/600, паддинг,
  клип, круг кнопки, hover-масштаб), три тона с координатами иллюстраций и
  парами действия, типографические роли.
- **Сайт даёт**: контент постера (заголовок, текст, иллюстрация, href и
  текст доступного имени), выбор тона-модификатора, сборку ленты постеров
  (сетка — примитив `ui-grid` или сайт-зона; в оригинале `repeat(3, 1fr)`
  с gap 36px — вне шкалы §3.2).
- **Не переносите** тон-строки в сайт-зону: тоны — модификаторы слоя;
  свой тон — через хук `--pstr-bg` в сайт-зоне (контраст пары — обязанность
  сайта), не правкой слоя.

## Bitrix-заметки

- Карточки — **элементы инфоблока** («Школьникам и студентам»): тон —
  свойство элемента (UF-код или мнемоника в шаблоне), модификатор
  `pstr-card--{тон}` собирается в шаблоне.
- Связки `pstr-*` приходят подключением **`dist/ui-patterns.css`** в шаблоне
  сайта (опционально, после `ui-core`); источник значений —
  [`patterns.css`](../patterns.css). Значения только токенами `--ui-*`.
- Иллюстрации — файлы сайта (`alt=""` обязателен — декоративные); действие —
  ссылка на страницу раздела с `aria-label`.
