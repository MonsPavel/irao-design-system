# tests/e2e/

Playwright-сценарии поведения компонентов по стендам `showcase/dist/stands/`
(источники стендов — `showcase/pages/<name>/`, канонические паттерны
`components/<name>/`). Харнесс — `tests/helpers/harness.js`: фикстура
`stand(name)`, хелперы `a11y()`, `shot()`. Шаблон компонентного теста —
[../README.md](../README.md).

Сценарии, чья поверхность ещё не появилась (компоненты EPIC-4/5),
фиксируются здесь текстом (конвенция tests/README.md);
при появлении инфраструктуры каждый сценарий переезжает в код без изменения
сути. Запуск ручных проверок: `npm run build && npm run serve` →
`http://127.0.0.1:8080/showcase/dist/…`.

## Сценарий T2.4 (AC1, суб-часть «вид кнопок/карточек/полей»): тема меняет вид ui-компонентов без их правки

Статус: **ожидает поверхности** — стенды `ui-button`/`ui-card`/`ui-field`
появятся с EPIC-4/5, авто-гейт — с харнессом T1.4. До тех пор механизм
подтверждается на стенде «Токены» (`/showcase/dist/stands/tokens.html`),
все демо-элементы которого читают слой 2 через `var()` (пин:
`tests/unit/themes.test.js` — «промежуточная поверхность доказательства
реальна»); факт-прогон chromium 2026-10-06 — в доке «Как пользоваться
токенами» → «Темы».

Шаги (после появления стендов):

1. Открыть стенд компонента **без темы**:
   `/showcase/dist/stands/ui-button.html` (затем `ui-card.html`, `ui-field.html`).
2. Открыть тот же стенд с `?theme=test` — переключатель каркаса выставляет
   `data-ui-theme="test"` на `<html>` и подключает `dist/themes/theme-test.css`.
3. Assert computed-значения на `<html>`: `--ui-color-primary` `#002856 →
   #511d59`, `--ui-color-accent` `#f26722 → #ffab72`, `--ui-color-surface-muted`
   `#f1f5fe → #ffd3b7`, `--ui-focus-color` `#002856 → #f37131`,
   `--ui-radius-md` `1rem → 0.25rem`, `--ui-shadow-card` — геометрия md → lg.
4. Assert вид элементов компонента на странице: цвет/рамка кнопки (primary- и
   accent-модификаторы), фон и радиус карточки, рамка/фон поля — изменились
   согласно п.3; производные (`--ui-color-surface-dark`, `--ui-focus-color`
   при отсутствии явного override) следуют за цепочками слоя 2.
5. Assert неизменности: не переопределённые темой токены (`--ui-color-info`,
   `--ui-color-text` и т.д.) и слой 1 (палитра на стенде «Токены») — без
   изменений; HTML и классы компонентов на стенде побайтово те же (смена темы
   не правит разметку).
6. Фикстура совместимости: подключить `tests/lint-cases/css/themes/theme-old-compat.css`
   с `data-ui-theme="old-compat"` — переопределённые ею токены принимают её
   значения, «новые» токены core (`--ui-color-info` и др.) работают дефолтами
   `:root` (AC «старая тема + новый токен»).
7. Скриншот тестовой темы — эталон только из контейнера (ADR-0003/0004),
   локальные прогоны эталонов не пишут.

Границы сценария: значения тестовой темы синтетические (декоративные серии
палитры) и контраст-гейт AA не проходят сознательно (исключение в шапке
`tests/contrast/pairs.config.mjs`); сценарий проверяет механизм, а не
утверждённый визуал (тот — дефолтная тема career-portal).
