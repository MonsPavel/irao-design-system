Варианты

Базовая карточка

Поверхность --ui-color-surface, рамка --ui-border-color, радиус --ui-radius-md. Модификаторов нет — «тихая» основа: коробка без интерактивности.

Карточка --hover

На hover-устройствах рамка --ui-color-border-hover (#B9C6DE) и тень --ui-shadow-md. Эффект под `@media (hover: hover)`: на таче не «залипает».

Карточка --filled

Фон и рамка --ui-color-surface-muted (career-portal .card--filled): приглушённая «бесшовная» карточка.

Слоты

__media — место под ui-image (T4.6)

Слоты карточки

__media, __title, __body, __footer — на flex-колонке: карточка растёт по контенту (никаких фиксированных высот), __footer прижат к низу (margin-top: auto) — в сетке списковых страниц действия выравниваются по нижней кромке.

Типографику слотам задаёт разметка ролями base (ui-h3/ui-body) — компонент не переобъявляет шрифты. Паддинг — --ui-space-5 (24px), gap слотов — --ui-card-gap (14px .vac-card, вне шкалы §3.2 — перенос «как есть»).

Карточка-ссылка (stretched link)

__media

Вакансия: стажёр в команду разработки

Одна остановка скринридера — доступное имя = текст ссылки. Клик в любом месте карточки ведёт по ссылке, фокус-обводка проходит по всей площади (контур ::after, focus-тройка ADR-0001).

Паттерн — пара классов: ui-card--link на карточке + ui-card__link на контент-ссылке. Вложенные интерактивы (кнопка «Откликнуться») компонент поднимает над растянутой ссылкой сам — position: relative; z-index: 1 (паттерн nested-interactive): клик-зона кнопки и её остановка в Tab-порядке сохраняются. Hover перекрашивает ссылку в primary — только на hover-устройствах.

аналитик

Квадратное фото — __media--square (1/1).

Один каркас «фото + тег в углу + тело» (T17.5): пропорции фото — на слоте __media (3/2; --square — 1/1), object-fit: cover и радиус md/md 0 0 — каркас; тег — __media-tag (absolute top/left 8px), вид — готовый ui-tag, тинт варианта выбирает сайт (не --on-photo — прецедент T16.10). Типографику тела каркас не задаёт: дата ui-small+ ui-text--muted, заголовок ui-h6/ui-small (T16.12) — роли разметки. Паддинг тела (12px = --ui-space-3) поверх базового паддинга карточки (24px); __meta — лента тегов gap --ui-space-1. Источник — карточки event/article/intern пилота career-portal.
