Статические табы (канонический паттерн)

Табы — <a href="#panel">: без JS все панели видимы, ссылки работают якорями. Роли APG (tablist/tab/tabpanel), aria-selected/aria-controls, roving tabindex и скрытие неактивных панелей ставит модуль. Клавиатура: ←/→ с зацикливанием и automatic-активацией, Home/End; Tab с активного таба уходит в панель.

Пилюли — модификатор ui-tabs--pill (T14.9)

Вид навигации разделов career-portal (.tabs-pill, education.html): прозрачные пилюли без рамки на тинт-треке, активная — заливка primary; hover — подпись primary без заливки. Клавиатура и ARIA — общие с базой. aria-current="page" на третьем табе — начальный выбор из разметки: модуль выбирает его при инициализации (silent), не первый таб; дубли атрибута — первый + console.warn. Без JS все панели видимы; активная пилюля в этом состоянии красится по aria-current (T17.11), после инициализации — по aria-selected (модуль ставит его всем табам).

Навигационный набор — ссылки без панелей (T17.11)

Межстраничная навигация разделов на ui-tabs--pill: ссылки на страницы, панелей нет и data-ui-tabs не ставится — модуль такие наборы не инициализирует (контракт T13.6: табы = панели). Ролей tablist/tab и aria-selected здесь нет; активный раздел несёт aria-current="page" — модификатор красит активную пилюлю по нему (заливка primary + подпись text-on-dark, hover заливку не гасит). Раскладка страницы (сетка 5×1fr «сетка 264», маргины 24/48) — канон nvp паттерн-слоя; на стенде слой не подключён — лента остаётся flex с переносом.
