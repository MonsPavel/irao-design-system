Стенд ui-button (T4.2 — эталонный компонент): матрица варианты × размеры × состояния — default, hover, focus-visible, active, disabled, loading. Сценарии — tests/e2e/ui-button.spec.js (computed-стили, поведение disabled/loading, клавиатура Tab/Enter/Space, контраст ≥ 4.5:1 сквозной с T2.3 — известный разрыв accent зафиксирован, axe, смена темы — сценарий T2.6 «кнопочная часть»); do/don't «действие → button, переход → ui-link» — README.md компонента. Кнопка в форме управляется модулем T5.5 — на стенде состояния заданы разметкой (disabled; is-loading + aria-busy).

Варианты × размеры (default)

md — база (высота --ui-button-height, 52px); sm — компактный (--ui-button-height-sm). Без модификатора — «тихая» кнопка каркаса career-portal.

Состояние disabled (атрибут disabled)

Атрибут disabled: не фокусируется и не кликается нативно; визуал — затемнение --ui-opacity-disabled. Контраст подписи — декоративный (WCAG 1.4.3: неактивные компоненты исключены).

Состояние loading (is-loading + aria-busy)

Спиннер aria-hidden; лейбл остаётся в DOM — accessible name неизменен; повторные клики мышью игнорируются (pointer-events: none). Переключение состояния — за управляющей формой (T5.5): повторные Enter/Space перехватывает она.

С иконкой (ui-button__icon)

Иконка — инлайн-SVG на currentColor, aria-hidden (декоративная): подпись несёт имя кнопки. Icon-only кнопка — отдельное решение с обязательным aria-label (Out of scope T4.2, README.md).

Пилюля со стрелкой (ui-button--pill, T14.4)

CTA строки/карточки-ссылки (оригинал .pill-btn career-portal): h44, фон surface, рамка 1px primary, метка fs 13/uppercase/letter-spacing 0.04em (uppercase ставит CSS — текст в DOM строчный); кружок primary со стрелкой на обычном __icon, на hover свапается в accent, фон пилюли — surface-muted (T16.11, байт-канон). Обычные действия — базовые варианты; границы — README.md компонента.

Текстовая кнопка (ui-button--text, T16.7)

Действующее слово в текстовом контексте («Сбросить» фильтров оригинала, REPORT §8.2 №8): fs 14/400, подпись --ui-color-text-muted, подчёркивание — маркер действия; фона, рамки и своей высоты нет (размер по строке, не 52px); hover — primary, подчёркивание сохраняется. Это действие, а не переход — ui-link сюда не подходит (do/don't — README.md компонента).

Do / Don't: действие против перехода

Все вакансии — переход

Действие на странице (отправка, отмена, раскрытие) — ui-button; переход на другой адрес — ui-link, «переход-выглядит-как-действие» — ui-link--button. Подробнее — do/don't в README.md компонента.
