Клиентская валидация — модуль IraoUI.form (T5.5)

Прогрессивное усиление: модуль активируется на form[data-ui-form] и ставит novalidate только при инициализации — без JS форма нативно-валидна (ТЗ №14). Правила — из нативных атрибутов (required, type=email, pattern, minlength), data-ui-max-size (лимит файла в байтах) и data-ui-validate (валидатор сайта в IraoUI.form.validators — точка расширения, зарегистрирована демо-скриптом секции); текст правила переопределяет data-ui-error поля. Ошибки — по контракту T5.6 (ui-field--error + aria-invalid + aria-describedby + ui-field__error), сводная ошибка заполняется ссылками и получает фокус (без summary фокус — на первое невалидное поле). Валидный сабмит модуль пропускает (событие irao-ui:form-valid, кнопка — is-loading + aria-busy), повторный блокирует до перезагрузки (AJAX-сайты снимают IraoUI.form.unlock(form)). Сценарии — tests/e2e/ui-form-validate.spec.js; API — README.md компонента.
