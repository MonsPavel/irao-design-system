Стенд layout-примитивов (T3.4, T17.17): ui-container, ui-section, ui-grid, флекс-примитивы ui-row/ui-stack — mobile-first пересборка .container/.section/.cards-grid и флекс-строк career-portal. Колонки сеток: 1 (mobile) → 2 (md) → N (lg); сетка --4 — 3 (xl) → 4 (2xl). Сценарии — tests/e2e/layout.spec.js. Ключевые узлы размечены data-ui-check-layout — контракт гейта масштабирования T3.6 (tests/e2e/scaling.spec.js, пороги — tests/e2e/README.md).

ui-container

Центрируемый контейнер: max-width: var(--ui-container-max), горизонтальные паддинги --ui-container-pad{,-md,-lg} растут по шкале — 16 → 24 (md) → 32 (lg). Секция вокруг — ui-section: вертикальный ритм 32 (mobile) → 48 (lg) из spacing-шкалы.

Блок внутри контейнера на фоне surface-muted: видно горизонтальные паддинги контейнера на текущем вьюпорте (16/24/32) и центрирование на широких экранах.

ui-section--muted

Приглушённая секция (порт .section--gray): фон --ui-color-surface-muted, радиус --ui-radius-lg (24). Ячейки сеток ниже — те же приглушённые секции: композиция примитивов вместо отдельного «демо-стиля».

ui-section--muted — фон и крупный радиус, вертикальный ритм секции.

ui-grid — сетки --2/--3/--4

Колонки — minmax(0, 1fr): длинное слово переносится и не распирает колонку (вместе с overflow-wrap на body, T3.3). Gap — из spacing-шкалы: 24, рост 32 (lg); сетка --4 плотнее — 24 на всех ширинах. Порядок ячеек = порядок DOM (свойство order не используется).

ui-row / ui-stack — флекс-примитивы (T17.17)

Флекс-композиция средствами ДС: строка ui-row — перенос по умолчанию (защита от hscroll, гейт T3.6), вертикальное выравнивание центр (доминирующий кейс строк пилота), gap — токен --ui-row-gap; стопка ui-stack — gap — токен --ui-stack-gap (дефолты — --ui-space-4). Примитивы чисто презентационные: цвет и типографику несёт контент. «Когда строка vs сетка» — do/don't в base/README.md; отключение переноса --no-wrap — осознанное (тулбары/ пилюли, строка гарантированно влезает).
