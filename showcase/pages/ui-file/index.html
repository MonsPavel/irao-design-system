Стенд ui-file (T5.3): доступный файловый инпут — состояния пусто / выбран (демо разметки) / ошибка / disabled. Нативный input скрыт sr-only-клипом (НЕ display: none — анти-паттерн career-portal .field__file input исправлен): Tab доходит до контрола, обводку фокуса рисует кнопка-лейбл. Кнопка-лейбл — единственный label; имя полю задаёт aria-labelledby. Значение выбора — ui-file__value с role="status" (озвучивание), сброс — кнопка «Убрать файл». Сценарии — tests/e2e/ui-file.spec.js (setInputFiles); правило «без display:none на нативных контролах», do/don't — README.md компонента.
