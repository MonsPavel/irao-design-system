Скролл-зона (широкая таблица)

Колонок больше, чем помещается, — сравнение по колонкам важно, поэтому таблица сохраняет семантику, а не превращается в карточки. Зона — tabindex="0" role="region" с aria-label: Tab ставит фокус (контур — политика ADR-0001), стрелки ←/→ прокручивают нативно. Справа — градиент-индикация обрезки.

Sticky-заголовок (--sticky-head)

Опция для длинных таблиц в зоне со стеснённой высотой: шапка прилипает к верхней кромке зоны при её вертикальном прокруте. Высоту зоны задаёт сайт — здесь max-height: 20rem поставлен inline только для демонстрации. Шапке нужен непрозрачный фон, иначе строки светятся сквозь неё (компонент делает это сам).
