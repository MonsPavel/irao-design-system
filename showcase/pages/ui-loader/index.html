Стенд ui-loader (T7.5): спиннер — svg aria-hidden (декоративен), состояние загрузки объявляет текст с role="status" — правило «не голый спиннер»: текст присутствует всегда. Цвет не задаётся компонентом: кольцо на currentColor красит контекст. Анимация вращения уважает prefers-reduced-motion: спиннер остаётся статичным кольцом. Сценарии — tests/e2e/ui-loader.spec.js, aria-busy-обвязка — README.md.

Паттерн aria-busy: контейнер + оверлей

Контейнер области на время загрузки получает aria-busy="true", поверх контента — лоадер-оверлей --overlay: полупрозрачная поверхность, контент области читается сквозь. Контейнеру нужен position: relative — в бою его задаёт CSS сайта (ниже — демо, inline только на стенде). Когда данные готовы, сайт снимает aria-busy и удаляет (или прячет) лоадер.
