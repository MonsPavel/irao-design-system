Стенд ui-chip (T14.8): интерактивный фильтр-чип — пилюля 36px career-portal (.chip, pages.css:137–151: вакансии, стажировки, медиа, поиск мероприятий). Обе формы — кнопочная (aria-pressed, клиентский фильтр) и ссылочная (GET, aria-current="page" на активной); активное состояние — ARIA-атрибутом, не классом. Сценарии — tests/e2e/chip.spec.js (axe, клавиатура Tab/Enter/Space, активные состояния, контраст ≥ 4.5:1, эталоны 375/768/1280/1440). JS-модуля нет: состояние приходит из разметки/сервера, клики — нативные.

Кнопочная форма (aria-pressed)

Клиентский фильтр: переключение aria-pressed — один слушатель на группе (зона сайта, JS-модуля у компонента нет). Явный type="button" — гейт no-implicit-button-type. Активная заливка primary + подпись text-on-dark — пара chip-active гейта T2.3; дефолт — chip-default.

Ссылочная форма (GET-фильтр)

энергетика и электротехника информационные технологии экономика и финансы конструирование общие направления

Как на страницах career-portal: сервер рендерит выдачу и расставляет aria-current="page"; активная остаётся рабочей ссылкой (повторный клик перезапрашивает выдачу) — работает без JS по построению. Лента — flex-wrap: длинный набор переносится, не рвёт горизонталь на 375.

Длинные RU-подписи (перенос)

очное обучение в группе полного дня гибридный формат: часть занятий на предприятии дистанционные модули с наставником

Высота — min-height 36px (--ui-chip-height): короткая подпись даёт ровно пилюлю, длинная переносится внутри и растёт вместе с контентом (прецедент T4.2 — 32px-база T3.6). Touch-компромисс 36 против 44px пагинации зафиксирован в README компонента.
