Стенд ui-vi (T9.1): версия для слабовидящих по ГОСТ Р 52872 — панель настроек, 3 размера (zoom 1/1.2/1.45), 5 цветовых тем, режимы изображений, межбуквенный интервал, localStorage (irao-ui-vi). CSS — a11y/vi.css (отдельный dist/ui-vi.min.css), JS — window.IraoUI.vi (a11y/vi.js); канонический паттерн панели — components/ui-vi/ui-vi.html. Сценарии — tests/e2e/ui-vi.spec.js (включение/темы/размеры/персистентность/выключение, матрица «тема × стенды EPIC-4/5», axe). Чек-лист проверки страниц сайта в VI — README.md компонента.

Вход в режим

На сайтах кнопка входа живёт в шапке (header-паттерн, T7.6). Вход сбрасывает настройки к стандартным ГОСТ-панели; состояние хранится в localStorage под ключом irao-ui-vi и переживает перезагрузку; «Обычная версия сайта» полностью снимает режим.

Гарантированные пары тем (ключевая пара цветов)

Значения — константы --ui-vi-theme-* из a11y/vi.css (перенос career-portal «как есть»); контраст каждой пары ≥ 4.5:1 — контроль tests/unit/vi.test.js, соответствие computed на стендах EPIC-4/5 — e2e-матрица «тема × стенд».

Чёрным по белому (baw) #000000 на #FFFFFF — базовая, без перекраски
Белым по чёрному (wb) #FFFFFF на #000000 — инверсия корня (фильтр html)
Синим по голубому (bb) #063462 на #9DD1FF
Бежевым по коричневому (beige) #4A3728 на #F5E7CE
Зелёным на тёмно-коричневом (green) #4DFF00 на #3B2716

Контент в режиме

Перекраска !important накрывает компоненты системы (инвариант «компоненты без inline-стилей и цветов вне токенов»); изображения — обычные / чёрно-белые / выкл; слой по конвенции __photo скрывается вместе с картинками.

Карточка в VI-режиме

Фон, текст, рамки и тени перекрашиваются парой активной темы; кнопки получают контрастную пару темы.

Изображение: в режиме «выкл» скрывается вместе со слоем ниже, «чёрно-белые» — обесцвечивается.
