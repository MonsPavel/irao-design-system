FAQ-вариант (--faq)

Визуал FAQ career-portal: приглушённый фон, радиус карточки, шеврон с поворотом при раскрытии. Первый вопрос открыт нативным open. Клавиатура: Tab — к вопросу, Enter/Space — раскрыть/свернуть (нативные details/summary, без JS и без ARIA). Инстанс без JS-хука: пункты независимы.

Работает ли аккордеон без JavaScript?
Да: база — нативные details/summary, состояние и клавиатура (Enter, Space) обеспечиваются браузером. JavaScript нужен только режиму «один открыт».
Как подключить компонент к странице?
Подключите собранные ui-core.min.css и ui.min.js и используйте канонический паттерн разметки из документации компонента.
Как включить режим «один открыт»?
Добавьте data-ui-accordion="single" на корень аккордеона — модуль-усиление закроет соседей при открытии нового пункта (демо — сценарий ниже).

Список раскрытий (без --faq)

Тот же блок без модификатора: пункты без фона и радиуса — раскрывающиеся секции вне FAQ (состав поставки, требования). Содержимое ответа — зона сайта (текст, списки, карточки).

Состав поставки
ui-core.min.css, ui-vi.min.css, ui.min.js, шрифты Golos и файлы тем.
Требования к браузерам
Аккордеон работает во всех вечнозелёных браузерах; плавная анимация раскрытия — там, где есть ::details-content, иначе раскрытие мгновенное (контент не теряется).
Известные ограничения
Вложенные аккордеоны и динамическая загрузка содержимого при открытии — вне скоупа компонента.

Режим «один открыт» (single)

Единственный инстанс стенда с JS-хуком data-ui-accordion="single": открытие пункта закрывает соседей (модуль IraoUI.accordion). Без JS пункты независимы — усиление не ломает нативную базу.

Первый пункт
Откройте соседний пункт — этот свернётся: открыт ровно один.
Второй пункт
Повторный клик сворачивает и его — «все закрыты» допустимо.
Третий пункт
События irao-ui:accordion-open/accordion-close на корне — точка расширения сайта.
