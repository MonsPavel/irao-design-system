Карусель слайдов (data-ui-carousel)

Данные слайдов — JSON в разметке (<script type="application/json">); без JS виден первый слайд (продублирован в слотах), стрелки и степпер скрыты (hidden — снимает модуль). Клавиатура на табах: ←/→ с зацикливанием и automatic-активацией, Home/End; Tab уходит за степпер (roving tabindex). Событие irao-ui:carousel-select — точка расширения сайта.

Производство

Вклад каждого сотрудника на производстве — это основа нашего успеха. Нам важно, чтобы каждый чувствовал свою значимость и был уверен в завтрашнем дне.

Фото-галерея (data-ui-gallery)

Вторая форма — prev/next по JSON-массиву фото (модалка направлений career-portal). Стрелки — обычные кнопки с data-хуками: модуль вешает поведение на data-ui-gallery-prev/next, а не на класс — в светлом попапе вид стрелок несёт ui-button. Открытие — IraoUI.modal (прецедент пилота); программный выбор фото — IraoUI.carousel.select(root, index).
