Карточная трансформация (--cards)

Уже эту страницу: на экранах уже 768px таблица ниже — карточки, каждая ячейка подписана data-label (копия текста заголовка колонки), шапка скрыта. На 768px и шире — обычная таблица. Строка здесь — самодостаточная запись («Направление: …, Срок: …»), поэтому потеря table-семантики в карточном режиме допустима; для сравнения по колонкам берите скролл-зону (матрица ниже).

Направления подготовки
Направление Срок обучения Форма Ступень
Электромонтёр подстанции 2 года Очная Колледж
Мастер участка 4–5 лет Очно-заочная Переподготовка
Инженер-энергетик 5 лет Очная Университет

Как выбрать паттерн (дока-матрица)

Правило большого пальца: карточки — когда осмысленна строка; скролл — когда осмысленна колонка. Полная версия с условиями допустимости потери table-семантики — README компонента (components/ui-table/README.md).

Матрица выбора паттерна
Паттерн Когда выбирать Когда не выбирать
Базовая (.ui-table) Колонки помещаются в контейнер (2–4 короткие) Контент обрезается или не помещается
Скролл-зона (.ui-table__scroll) Колонок много, сравнение по колонкам важно (тарифы, характеристики, расписания) — семантика таблицы сохраняется полностью Строки самодостаточны — карточка подаст их удобнее без длинного горизонтального скролла
Карточки (.ui-table--cards) Строка = самодостаточная запись (имя + атрибуты); на мобиле читается сверху вниз без скролла Сравнение по колонкам, числовые сетки, десятки строк — колонка рвётся между карточками; длинную таблицу ведите скролл-зоной со sticky-шапкой
