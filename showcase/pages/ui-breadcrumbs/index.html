Стенд ui-breadcrumbs (T4.7): хлебные крошки — упорядоченный список nav > ol > li с микроразметкой schema.org BreadcrumbList (microdata по схеме Google — без JS, дружелюбна к Bitrix-шаблонам), текущая страница — span + aria-current="page". Разделитель «/» — псевдоэлемент CSS, в тексте ссылок его нет. На мобильных (≤767) цепочка — горизонтальная лента (свайп, скроллбар скрыт), на md+ — перенос. Сценарии — tests/e2e/ui-breadcrumbs.spec.js (парсер микроразметки, aria-current, Tab, лента, axe, эталоны 375/768/1280/1440); построение цепочки в Bitrix-шаблонах — bitrix/snippets/breadcrumbs.php и README.md компонента.

Базовая цепочка: 3 уровня с микроразметкой

  1. Главная
  2. Вакансии
  3. Стажировка в ИРАО

Скринридер объявляет навигацию как список («шаг 2 из 3»), текущая страница — не ссылка и не остановка Tab. Имена уровней — только в itemprop="name": разделитель в них не попадает. Позиции — в meta[itemprop="position"], у текущей страницы itemprop="item" нет (Google берёт URL самой страницы).

Длинные названия: лента на мобильных, перенос на md+

  1. Главная
  2. Программы и стажировки
  3. Производственные практики для студентов старших курсов
  4. Архив отчётов по практикам за 2025–2026 учебный год

На 375 цепочка уходит в горизонтальную ленту: overflow-x: auto — свайп на touch и колесо мыши работают, скроллбар скрыт (scrollbar-width: none), страница горизонтально не переполняется. С 768 — flex-wrap: wrap: длинные названия переносятся, скролл не активен. Усечение длинных цепочек «…» — сознательно не заведено (Out of scope T4.7), паттерн расширения описан в README.md.

Промежуточный уровень без ссылки

  1. Главная
  2. Каталог материалов
  3. Отчёты за 2025 учебный год

Случай «Главная → Раздел без ссылки → Текущая»: у промежуточного уровня нет страницы (подраздел-фильтр, якорь текущей страницы) — это span с itemprop="name" без itemprop="item". Schema.org это допускает, но Google Rich Results может выдать предупреждение «item отсутствует» для не-последнего уровня: если URL у уровня существует — давайте ссылку (правило и PHP-обработка — README.md).
