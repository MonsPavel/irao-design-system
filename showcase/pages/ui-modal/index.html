Размер --sm

Узкая модалка подтверждения (24rem). aria-labelledby ведёт на заголовок, __close — первый элемент панели: фокус при открытии приходит на него.

Подтвердить запись?

Направление «Аналитик данных»: очный формат, старт в феврале.

Размер --md (база)

Базовый размер (40rem) для контентных модалок. Закрытие — Escape, кнопка __close, программно (IraoUI.modal.close()); фокус возвращается на опенера после каждого цикла.

Направление «Аналитик данных»

Программа для тех, кто начинает карьеру в данных: SQL, Python, продуктовая аналитика и четыре проекта в портфолио. Длительность — 6 месяцев, формат — вечерние занятия онлайн.

Модалка — это <dialog> с showModal(): trap и Escape даёт браузер, фон недоступен без aria-hidden — top-layer блокирует сам (ADR-0011).

Размер --full

Полноэкранный сценарий (100vw × 100dvh, без скругления) — мобильные галереи и формы на всю высоту; пара drawer-модалке career-portal на мобиле.

Галерея направления

Полноэкранная модалка для медиа-контента: длинная прокрутка внутри панели, overflow-y: auto на диалоге, max-height не ограничивает.

Кнопка «Подтвердить» здесь не нужна — закрытие кнопкой __close или Escape; фокус вернётся на триггер.

События (точка расширения сайта)

Модуль диспетчит irao-ui:modal-open и irao-ui:modal-close на диалоге (bubbles: true) — сайты вешают аналитику и анимации. Статус-регион ниже пишет каждое событие.

Наполнитель прокрутки

Страница стенда выше вьюпорта — сценарии скролл-лока открывают модалку из прокрученного состояния и замеряют, что макет не сдвинулся (ширина шапки до/во время лока идентична: scrollbar-gutter: stable из base/reset резервирует полосу заранее).

Фоновая ссылка ниже — цель trap-сценария: при открытой модалке Tab/Shift+Tab не достигают её (нюанс К1 ADR-0011: на границе диалога фокус на один шаг уходит на body и возвращается).

Фоновая ссылка (цель trap-сценария)

Модалка — база для search-overlay (T7.6) и всех будущих диалоговых сценариев системы.

Вложенные модалки работают на стеке браузера (Escape закрывает только верхнюю) — полноценной поддержки система не обещает, см. README компонента.

Скролл-лок ставит overflow hidden на корень и компенсирует фактический сдвиг паддингом body — при стабильной полосе из base/reset компенсация нулевая и остаточного padding не бывает.

Повторные open/close циклы обязаны оставлять страницу в исходном состоянии — регресс-кейс design-qa career-portal, закрыт e2e.
