Базовый select в ui-field

Нативный select остаётся в DOM (класс скрытия ставит модуль); выбор синхронизируется и диспатчит change. Опция «Казань» — disabled: стрелки и typahead её пропускают.

Элемент после селекта (цель Tab-выхода)

Группы optgroup

optgroup переносится в список как role="group" с aria-label группы; опции остаются в документном порядке.

Модификатор «wrap»: обёртка сайта

data-ui-select="wrap" — обёртку («пилюля» фильтра) и её геометрию рисует сайт; триггер растягивается на неё. Замена хака vacancy-search__select-wrap career-portal: системный модуль не знает классов проекта (правило CONTRIBUTING).

Disabled

disabled нативного select — disabled-триггер: активация и клавиатура закрыты, значение из формы не уходит (нативное поведение).

Форма фильтра

Выбор диспатчит change (bubbles) — форма работает как с нативным контролом: статус-регион ниже ловит событие на форме; отправка — нативный POST (e2e перехватывает маршрут /submit).
