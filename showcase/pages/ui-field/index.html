Стенд ui-field (T5.1): типы input × textarea × состояния — default, focus (клавиатурой), error, disabled, readonly. Связность без JS: label for↔id, hint и error в aria-describedby, aria-invalid="true" при ошибке; required-маркер — звёздочка и текст «обязательное поле» скринридеру. Сценарии — tests/e2e/ui-field.spec.js; политика placeholder ≠ label, autocomplete-рекомендации (WCAG 1.3.5), do/don't — README.md компонента. Фокус-паттерн поля (фон + рамка) дополняет глобальный outline (ADR-0001) — проверьте с клавиатуры.

Типы input (нативные атрибуты)

Используется для уведомлений о статусе отклика

Менеджер паролей подставит сгенерированный

Высота поля — min-height (--ui-field-height, 52px): при 32px-базе (T3.6) поле растёт вместе с текстом, значение не обрезается. placeholder — пример формата, не замена label (политика — README.md).

Textarea

Фиксированной высоты нет: растёт по контенту; нижний край тянется (resize: vertical)

min-height (--ui-field-textarea-min-height) и resize: vertical одобренного .field__textarea; авто-рост — опция JS-модуля формы (T5.5), в базе не нужен.

Состояния: error / disabled / readonly

Латиница, цифры и точка; от 3 символов

Адрес неполный: добавьте домен после @

Ошибка — визуал и aria в одном паттерне: модификатор ui-field--error, aria-invalid="true" и aria-describedby на id хинта и ошибки. disabled не фокусируется; readonly фокусируется и копируется, но не редактируется.

Модификатор --wide в сетке

ui-field--wide растягивает поле на все колонки grid-родителя (здесь — layout-примитив ui-grid, T3.4); раскладка форм целиком — ui-form-grid (T5.4).
