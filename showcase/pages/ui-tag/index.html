ui-badge: счётчик

Уведомления: 3 Уведомления: 99+

Сообщения, 7 новых 7 События 0

Одна цифра — круг 24px (--ui-badge-size); «99+» растёт в pill паддингом (--ui-space-1), контент не режется. Значение в имени контрола — бейдж без aria-hidden («Уведомления: 3»); продублированное текстом рядом («Сообщения, 7 новых») — aria-hidden="true": значение остаётся в имени, дубль не озвучивается. aria-hidden без дублирующего текста запрещён — счёт не слышно (гейт e2e). При 0 бейдж не выводится — атрибут hidden (глобальная гарантия base/reset.css). Правила — README.md компонента; отдельный базовый стенд ui-badge.html — канонический паттерн components/ui-badge/ui-badge.html.
