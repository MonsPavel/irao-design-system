Базовая таблица

Колонки помещаются — трансформация не нужна. Имя таблицы — нативный <caption>; заголовки связаны нативно: th scope="col" в шапке, th scope="row" на первой колонке тела. Разделители строк — --ui-color-divider; при наведении строка подсвечивается парой --ui-color-surface-hover (только под (hover: hover)).

Полосы (--zebra)

Чётные строки тела приглушены --ui-color-surface-muted — глаз ведёт по строке wide-таблицы. Полосы — только оформление: смысл полосам не вкладывайте (Don't в README).
