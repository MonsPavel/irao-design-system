## P0 — визуальная идентичность (закрывается на уровне токенов/ролей)

### P0-1. Цвет заголовков — ✅ выполнено: T14.1
**Проблема.** Роли `ui-h1…ui-h6` наследуют `--ui-color-text` (#1F1F1F);
в career-portal все заголовки — корпоративный navy #002856 (`--color-primary`).
Каждая страница клона визуально «чернее» оригинала — крупнейший единичный
сдвиг идентичности.
**Решение.** Ввести токен `--ui-color-heading: var(--ui-color-primary)` и
назначить его ролям заголовков. Проверить контраст во всех темах
(#002856 на белом 12.4:1; на фоне surface-muted и в тёмных секциях).
**Объём.** tokens/semantic.css + base/typography.css + обновление эталонов
visual-CI (все стенды с заголовками) + строка в docs-таблице диффов.

### P0-2. Роль «заголовок страницы» — ✅ выполнено: T14.2 (роль `ui-page-title`)
**Проблема.** Внутренние страницы оригинала: h1 размером fs-h2 (60px). В ДС
единственная h1-роль — `ui-h1` 80px → заголовки страниц клона на треть крупнее.
**Решение.** Модификатор `ui-h1--page` (или роль `ui-page-title`): размер h2,
вес h2, тег — h1. Прописать в правилах типографики и паттернах list/detail/form.
**Объём.** base/typography.css + доки трёх page-паттернов + тесты вычисленных
размеров (typography.spec) + эталоны.

### P0-3. Калибровка геометрии ui-button — ✅ выполнено: T14.3 (паддинг 28px, токен `--ui-button-pad-inline`)
- паддинг 12×28 вместо 12×24 (горизонталь оригинала, токен вне шкалы
  отступов — прецедент «как есть» --ui-card-gap);
- рамка заливочных вариантов уже прозрачна — правки не требует (уточнение
  20.10 по сверке с main, см. REPORT §3.3).

### P0-4. Модификатор «пилюля со стрелкой» (pill-btn) — ✅ выполнено: T14.4 (`ui-button--pill` + `--sm`)
**Проблема.** Самый частый CTA оригинала («откликнуться», «подробнее»):
компактная пилюля h44, фон surface, рамка 1px, круглая иконка-стрелка в
акценте. В ДС аналога нет — пилот заменял `ui-button--outline` (h52, рамка 2).
**Решение.** `ui-button--pill` (+ `--sm`): высота 44, компоновка
лейбл + круглый icon-слот; иконка красится акцентом. Или паттерн в README
ui-button, если решим не множить модификаторы.

### P0-5. Вертикальный ритм ui-breadcrumbs — ✅ выполнено: T14.5 (связка в page-паттернах; в пилоте — `.cp-breadcrumbs` со значениями канона)
**Проблема.** Крошки оригинала несут ритм страницы (padding 20/24, полоса
62px); ui-breadcrumbs плоские (18px) — на клоне контент «прилипает» к шапке.
**Решение.** Спейсинг-обвязка в page-паттернах (list/detail/form-page добавляют
отступы над/под крошками), не раздувая сам компонент.

### P0-6. Калибровка полей и дифф-таблица микрорасхождений — ✅ выполнено: T14.6 (паддинг 1.25rem; карточка/модалка/тег — «принято ДС», mapping)
**Остаток закрыт:** компактный вариант полей анкет-модалок 48px —
модификатор `ui-field--compact` доставлен T14.6, пилот принял (T15.6,
REPORT §3.3). Подписи полей (серый оригинала vs text ДС) — T16.9
(muted gray-700, EPIC-16): модалки — матч; на страницах-формах оригинал
несёт тёмные подписи rgb(31,31,31) против muted ДС — новый кандидат
бэклога из пересверки T15.9 (REPORT §10.3, предложенный приоритет P3).
Pages-деплой актуален (сверка 20.10, REPORT §2 (г)):
- ui-field: базовая высота совпадает (52px); остался паддинг 24 vs 20 →
  токен 1.25rem «как есть»; в оригинале есть компактный вариант полей
  анкет-модалок 48px (.apply-form, pages.css:1208) — аналога в ДС нет,
  нужен модификатор;
- принять значения ДС (зафиксировать в tokens-career-portal-mapping.md):
  ui-card padding 24 vs 20, ui-modal padding 36 vs 40,
  ui-tag orange rgb(169,71,16) — уже AA-замена T2.3, только строка в таблице.

## P1 — новые компоненты/модификаторы (высокая частота использования)

### P1-1. Чипы фильтров (ui-chip или паттерн filter-chips) — ✅ выполнено: T14.8 (компонент `ui-chip`, кнопочная и ссылочная формы; пилот на нём с 21.10)
Интерактивные пилюли с активным состоянием: список + сетка фильтрации на
4+ страницах оригинала (vacancies, internships, media, events-search).
Сейчас README ui-tag обещает «паттерн T8.1 на базе ui-tag + button» — паттерна
нет. Нужны: вид (пилюля 36px), состояния is-active/aria-pressed, поведение
(ссылка/кнопка), a11y-гейт.

### P1-2. Табы-пилюли (ui-tabs--pill) — ✅ выполнено: T14.9 (модификатор + начальный выбор из `aria-current="page"`; пилот на нём с 21.10)
Визуальный вариант табов оригинала (`.tabs-pill`): прозрачные пилюли 20px с
подчёркиванием/заливкой активной, смешанный набор «табы + обычные ссылки»
в одной строке (навигация разделов «школьникам и студентам»).
Минимум — модификатор внешнего вида; смешение таб+ссылок — правило паттерна.
**Плюс поведение:** ui-tabs при инициализации всегда выбирает ПЕРВЫЙ таб
(`select(0, …)`); в межстраничной навигации career-portal активный таб зависит
от страницы (на «Стажировках» активна «стажировка», а не «практика»).
Сейчас решается вызовом `IraoUI.tabs.select(i)` сайтом — добавить
начальный выбор из разметки (например, `data-ui-tabs-initial`), чтобы
многостраничные наборы табов не требовали JS у потребителя.

### P1-3. Ветка «строки» в паттерне list-page — ✅ выполнено: T14.10 (в пилоте строка — сайт-зона `cp-vac-row` по образцу связки паттерна)
Список вакансий оригинала — горизонтальные строки (заголовок-ссылка, место,
описание, дата, CTA-пилюля), а не сетка карточек. Расширить
patterns/list-page: раскладка `--rows`, правила типографики строки, поведение
CTA. Компонентной новой сущности не требует (ui-card + связки).

### P1-4. Ветка «сайдбар фильтров» в паттерне list-page — ✅ выполнено: T14.10
Вертикальная sticky-панель фильтров (label + select + radio-group + checkbox
+ сброс + промо-карточка). В оригинале — на вакансиях и каталоге обучения.

### P1-5. Паттерн «таймлайн этапов» — ✅ выполнено: T14.11 (`patterns/timeline`)
Горизонтальные шаги с нумерованными точками («Как попасть на практику»,
«Как подать заявку»). Кандидат в patterns/ как чистая CSS-композиция из
токенов (аналог landing-section).
