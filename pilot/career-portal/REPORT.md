# Отчёт: career-portal (оригинал) vs пилотный клон на irao-ui

Дата: 2026-10-20 · Pilot: `pilot/career-portal/` · [План доработок](PLAN.md) · [README пилота](README.md)

## 1. Что сделано

Пилотный клон карьерного портала «Интер РАО» собран **из компонентов irao-ui**
без копирования CSS оригинала: вся разметка пересобрана на `ui-button`,
`ui-card`, `ui-field`,`ui-form`, `ui-modal`, `ui-tabs`, `ui-accordion`,
`ui-select`, `ui-dropdown`, `ui-tag`, `ui-breadcrumbs`, `ui-pagination`,
`ui-error`, `ui-vi`, `ui-file`, `ui-checkbox`, `ui-radio-group` + роли
типографики и layout-примитивы `base/`. Блоки, у которых в ДС нет аналога
(hero, карусель, направления, …), собраны как **зона сайта** (`pilot.css`,
префикс `cp-`) — ровно так, как предписывает 02-architecture §7.

Собрано 12 страниц (главная + 11 типовых внутренних; генеративные повторы
оригинала — карточки 12 вакансий и variant-2 главной — не пересобирались).

## 2. Методика сравнения

`compare.mjs`: обе версии открываются в Chromium 1440×900, страницы
прокручиваются для догрузки `loading="lazy"`-изображений, затем:

- полностраничные скриншоты обеих версий → `compare-output/{original,pilot}/`,
  просмотр парами — `compare-output/viewer.html`;
- DOM-метрики: высота документа, высоты одноимённых блоков главной,
  computed-стилы пар «класс оригинала → ui-компонент» (шрифт, цвет, геометрия).

Ограничения: (а) сайт-зона `pilot.css` — приближение вёрстки оригинала, а не
пиксель-в-пиксель пересъём, поэтому высоты блоков расходятся в том числе из-за
калибровки пилота; (б) пробы берут первый совпадающий элемент — на страницах с
модалками часть проб оригинала попала в скрытые элементы (высота 0), а проба
поля на vacancies.html попала в компактную форму модалки — см. (г); (в)
education/career-track в пилоте упрощены (меньше повторов данных), их высоты
не сравниваются напрямую; (г) **Pages-деплой актуален** (live CSS идентичен
main 8469ea6 — проверено сверкой 20.10): «48px против 52px» у поля — не
отставание, а компактный вариант форм в модалках оригинала
(`.apply-form .field__input { height: 48px }`, pages.css:1208) без аналога
в ДС — передан в T14.6.

## 3. Систематические различия компонентов

Различия, которые воспроизводятся на каждой странице — это свойства самих
ui-компонентов, а не пилотной обвязки. Вычислено по probe-парам
(`оригинал → irao-ui`), viewport 1440.

### 3.1 Цвет заголовков — главное визуальное различие

| Роль | Оригинал | irao-ui |
|---|---|---|
| Заголовок страницы (h1) | `#002856` (primary), 60px | `#1F1F1F` (ui-color-text), 80px |
| Заголовок секции (section-title) | `#002856` (primary) | `#1F1F1F` |

Роли `ui-h1…ui-h6` не задают цвет и наследуют `--ui-color-text` (`--ui-black`,
#1F1F1F). В career-portal **все заголовки — корпоративный тёмно-синий**
#002856 (`--color-primary`). На каждой странице пилота заголовки «чернее»
оригинала — самый заметный сдвиг визуальной идентичности. Контраст #002856 на
белом 12.4:1 (AA/AAA пройден), риск на стороне согласования решения.

### 3.2 Размер заголовка внутренней страницы

Внутренние страницы оригинала: `.page-title` = fs-h2 (60px desktop) при теге
h1. В ДС единственная h1-роль — `ui-h1` 80px. Пилот честно использовал `ui-h1`
→ заголовки страниц на 20px крупнее оригинала (+33% высоты строки). Нужна
роль/модификатор «заголовок страницы» между h1 и h2.

### 3.3 Геометрия компонентов (probe-цифры)

| Компонент | Оригинал | irao-ui | Примечание |
|---|---|---|---|
| ui-button | padding 12×28 | padding 12×24 | рамка заливочных прозрачна (2px видны только у outline) — реальный сдвиг только горизонтальный паддинг |
| pill-btn (пилюля со стрелкой) | h 44, фон белый, рамка 1px, стрелка в кружке | замена `ui-button--outline` h 52, фон прозрачный, рамка 2px | в ДС нет компактной пилюли — CTA «откликнуться» и «подробнее» стал тяжелее |
| ui-card | padding 20 | padding 24 (база) | проба попала в строку вакансии пилота (cp-vac-row, 16px) — артефакт; база ДС «воздушнее» оригинала на 4px |
| ui-field input | база 52px, в анкетах-модалках компакт 48px | база 52px | база совпадает; компактного варианта «поле в модалке» в ДС нет (pages.css:1208) — передано в T14.6; остался паддинг 20 vs 24 |
| ui-breadcrumbs | h 62 (padding 20/24 по вертикали) | h 18, без вертикальных отступов | крошки «прилипают» к контенту — нет ритма страницы |
| ui-modal dialog | padding 40 | padding 36 | микро |
| ui-tag orange | текст rgb(179,74,16) | rgb(169,71,16) | осознанная AA-замена T2.3 (4.78:1 на orange-50), не дефект |
| ui-tabs | «пилюли» 20px/400, прозрачные, подчёркивание активной | кнопки-капсулы 14px/500, navy-фон, рамка | визуальный вариант табов «pill» отсутствует (см. §4) |
| FAQ (ui-accordion) | summary padding 20×24 | padding 24 | близко, принято |

## 4. Чего в ДС нет (собрано как зона сайта)

Повторяющиеся сущности оригинала без аналога в системе — главные кандидаты
на доработку (детали и приоритеты — [PLAN.md](PLAN.md)):

- **Чипы-фильтры** (`.chip`) — интерактивные пилюли с активным состоянием;
  в пилоте — самодельный `cp-chip`, включающий is-active через JS пилота.
- **Табы-пилюли** (`.tabs-pill`) — смешанный набор «табы + ссылки-разделы»
  на одной строке; ui-tabs даёт только капсульный вид.
- **Строка списка** (`.vac-row`) — списки вакансий оригинала это строки, а не
  сетка карточек; паттерн list-page покрывает только сетку.
- **Сайдбар фильтров** — вертикальная sticky-панель со связкой
  label + select + radio + checkbox; list-page знает только горизонтальные пилюли.
- **Таймлайн этапов** (`.timeline`) — «Как попасть на практику».
- **Лендинг-блоки главной**: hero (стеклянная поиск-пилюля, полупрозрачные
  теги, marquee), карусель «Производство» (слайдер+степпер), «Направления»
  (сетка иконок + попап-галерея), holding (фото-фон + стеклянные статы),
  employers (лента логотипов), why-us (тёмные фото-карточки), vacancy-search
  (панель + оранжевая CTA-карточка), students (цветные карточки с иллюстрациями),
  video-block (плеер с постером), media (медиа-сетка), cta-mail.
- **Тинт-токены**: полупрозрачные цветные плашки оригинала (теги hero,
  стеклянные карточки) в пилоте собраны через `color-mix()` от базовых токенов
  — в палитре ДС нет производных оттенков.

## 5. Что сработало без доработок

- `ui-modal` на native dialog заменил сразу три самодельных оверлея оригинала
  (модалка направления, анкета, полноэкранный поиск) с лучшей
  доступностью (focus trap, Escape, инертность) без единой строки JS в пилоте.
- `ui-accordion` на `<details>` заменил JS-аккордеон faq.js.
- `ui-select` (wrap-режим) лёг в фильтры-пилюли; `ui-dropdown` — в меню шапки;
  `ui-vi` — панель VI заработала как есть (оригинальный vi.js не понадобился).
- Форма отклика целиком (`ui-form` + `ui-field` + `ui-radio-group` + `ui-file`
  + `ui-checkbox`) собирается копипастой паттернов, включая success-ветку.
- `ui-error--page` закрыл 404; `ui-breadcrumbs` — крошки всех внутренних.

## 6. Попутные находки

- **Баг serve.mjs**: в MIME-таблице не было `.jpg` — картинки отдавались как
  `application/octet-stream` и не декодировались Chromium. Исправлено в этом
  же изменении (добавлены jpg/jpeg/gif/avif).
- Пробы со скрытыми модалками оригинала показывают height 0 — артефакт
  методики, не свойство компонентов.
