# EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell (раунд 3)

## Goal

Устранить систематические визуальные расхождения клона career-portal,
зафиксированные раундом 3 (22.10, [REPORT §8](../../../pilot/career-portal/REPORT.md)):
фон страниц, подчёркивание кнопок/ссылок навигации, размеры шрифтов шапки
и футера, канон строк списка. Финальный критерий — пиксельная сверка
 zones shell (шапка, футер, крошки, строки) при side-by-side просмотре
owner'ом без видимых отличий.

## Context

Retrigер раунда 3 — ручной просмотр owner'ом:
«у нас ссылки почему-то все underline, фон не белый а голубой, хедер не
такой по размерам шрифтов». Live-замеры (Chromium, vacancies.html обеих
версий, 22.10) подтвердили показания и выявили систематику:

1. **Пилот-зона (3):**
   - `.cp-page` на `<body>` несёт `--ui-color-surface-muted` (blue-50 —
     токен «фон карточек»), у оригинала body белый
     (`rgb(255,255,255)` vs `rgb(241,245,254)`);
   - `.cp-header--static` (pilot.css:27) перебит позднейшим
     `.cp-header { position: absolute }` (pilot.css:35) — статичная шапка
     фактически абсолютная и накрывает `.cp-breadcrumbs` (rect y=0,
     h=62 за шапкой): крошки добавлены в T14.12, но визуально не видны
     ни на одной внутренней странице;
   - футер клона on-dark (`--ui-color-primary-deep`, on-dark ссылки 20px
     underline, h 290) против белого футера оригинала (ссылки 14/500
     `#1F1F1F`, nowrap, h 227).
2. **ДС (3):**
   - `a.ui-button` подчёркнут: `.ui-button` не сбрасывает
     `text-decoration` (UA-дефолт якоря), у оригинала `a.btn` — none;
     это видно на каждой кнопке-ссылке клона (CTA «узнать подробнее»,
     промо-кнопки);
   - навигационные ссылки: у ДС нет nav-варианта ui-link — все пункты
     меню (и в пилоте, и в паттерне header) наследуют 20px и глобальную
     политику «подчёркнута всегда»; оригинал — `.header__link` 14/500
     без подчёркивания (hover opacity 0.7), dropdown-пункты 16px (pad
     8/12/15 совпал);
   - ui-pagination всегда включает 2 стрелки; у оригинала (vacancies)
     пагинация без стрелок; текстовой кнопки (для «Сбросить ×» —
     fs 14/400, underline, muted) в ДС нет вовсе.
3. **Adoption строки (1):** ветка «строки» паттерна list-page (T14.10)
   канонизирует title 20/500 plain `#1F1F1F`, паддинг строки 24/28, а
   пилот собирает ui-link 28px underline navy и pad 16px — пилот отходит
   от собственного канона ДС (REPORT §8.2 №6).

Отличия a11y-политики underline ДС показаны владельцу в раунде 3 и
подтверждены (решение в T16.3): nav-вариант снимает подчёркивание в
завидном контексте `nav` (WCAG 1.4.1 исключения: структура навигации),
inline-ссылки контента остаются подчёркнутыми.

Канон визуальных значений — текущий main career-portal (8469ea6 =
Pages, свера актуальности — EPIC-15 Context).

## Scope

- T16.1: пилот — фон страницы и видимость крошек (2 правки pilot.css);
- T16.2: ДС — `a.ui-button` без подчёркивания (каскадное решение +
  эталоны + unit-пин);
- T16.3: ДС+пилот — `ui-link--nav` (fs-small, без подчёркивания,
  hover-opacity), калибровка ui-dropdown__item (16px), правка паттерна
  header (перенос фактических значений канона), adoption в
  `.cp-header`;
- T16.4: пилот — футер по оригиналу (белый фон, ссылки 14/500 plain);
- T16.5: пилот — строки/сайдбар по канону lpp-row (title 20/500 plain,
  pad 24/28, CTA пилюля primary-кружок, «Сбросить» текстовый после
  T16.7, промо `ui-card--filled`);
- T16.6: ДС — `ui-pagination--bare` (опциональные стрелки);
- T16.7: ДС — `ui-button--text` (fs-small-regular, underline, muted,
  без фона/рамки) + adoption «Сбросить» в пилоте;
- T16.8: закрывающая — расширение probe-набора compare.mjs (header-link,
  dropdown-item, footer-link, row-title, pill-icon, reset-control,
  body-bg), свежий compare на 12 страницах, обновление REPORT/PLAN;
- T16.9: ДС — цвет подписи поля ui-field (P2 из REPORT §4, ex T15.7):
  отдельный токен, AA-замена gray-700, mapping-строка;
- T16.10: ДС — модификатор «тег на фото» ui-tag--on-photo (P2 из REPORT
  §4, ex T15.8): белый на primary, высота 40px оригинала;
- T16.11: ДС — калибровка `ui-button--pill`: рамка и кружок-иконка
  primary (оранжевый — только hover), метка uppercase fs13
  letter-spacing 0.04em; находка владельца 22.10 (REPORT §8.2 №6,
  mapping §3).

## Out of scope

- P2-лендинг-блоки главной (hero, карусель, directions…) — по-прежнему
  вне (PLAN §P2, отдельный эпик);
- страничные задачи EPIC-15 (8 страниц, adoption-хвосты) — идут своим
  конвейером параллельно (только пилот, пересечений по файлам нет);
- удаление подчёркивания у inline-ссылок контентной зоны (статьи,
  form-success) — политика ДС там соответствует (ui-link default;
  REPORT §8.2 №3 в силе);
- карточка ui-card--filled (promо) условных стилей не новая —
  существующий API (is в компонентах);
- вариант-2 главной и генеративные карточки 12 вакансий — вне пилота
  (REPORT §1).

## Risks

- T16.3 может выглядеть как отказ от a11y-политики ДС: снимает
  подчёркивание только в nav-контексте со структурной маркировкой
  (`nav`), inline-ссылки не меняются; checkpoint — e2e hover и
  unit-пины текстов документов;
- T16.9 меняет цвет подписи полей на всех стендах с формами — широкий
  пересъём эталонов; значение обязано пройти AA (кандидат gray-700, не
  серый оригинала gray-600) — риск переехал из EPIC-15 вместе с задачей;
- Т16.1 (z-order) затрагивает раскладку всех внутренних страниц —
  после правки сверить каждую страницу клона на «ничего не съехало»
  (compare переснимает все 12);
- эталона паттерна header не было в раундах 1–2: правка может сдвинуть
  визуальные снапшоты паттерна (пересъём по ADR-0004, контейнер).

## Notes

Эпик заведён решением владельца 22.10 («клон должен получиться
пиксель-перфект; сравни оригинал и копию, составь план на доработку —
на примере EPIC-14»). Раунд 3 подтверждает методику: probe-набор не
покрывал shell-зоны (шапка/футер/строки), потому расхождения не
всплыли в раундах 1–2. Их закрытие даёт систематическим зонам
«компонентного уровня» финальную калибровку; допускает параллельный
конвейер EPIC-15 (страничных пересечений нет). 22.10 решением владельца
(«весь UI — в DS-эпик; EPIC-15 остаётся сборкой страниц») в эпик
перенесены DS-задачи T15.7/T15.8 → T16.9/T16.10; в STATUS конвейера
DS-батч EPIC-16 идёт раньше страничных задач EPIC-15. Находки владельца
на страницах (пример 22.10 — пилюля «откликнуться»: рамка/кружок
primary, метка uppercase) при неактивном конвейере вливаются в эпик
новыми DS-задачами, а не site-zone override в pilot.css (T16.11).
