# TASK T16.1 — Пилот: фон страницы и видимость крошек

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell](README.md)

## Priority

P0

## Type

TASK

## Goal

Две однострочные правки сайт-зоны пилота: вернуть белый фон страниц
(оригинал) и сделать крошки видимыми (сейчас они накрыты абсолютной
шапкой из-за z-order баги pilot.css).

## Context

[REPORT §8.2](../../../pilot/career-portal/REPORT.md) №1—№2, замеры 22.10:

1. **Фон страницы.** `.cp-page` на `<body>` (build.mjs:497) несёт
   `background-color: var(--ui-color-surface-muted)` (pilot.css:22).
   Токен — это blue-50 (#F1F5FE) от карьер-портала, семантика СТРОГО
   «фон карточек» (variables.css:14: `--color-surface-blue-50`
   «светло-голубой фон карточек»); фон страницы оригинала —
   `--color-surface: #FFFFFF` (variables.css:13 → DS-semantic
   `--ui-color-surface`, semantic.css:58). Замер body: оригинал
   `rgb(255,255,255)` → пилот `rgb(241,245,254)` — вся страница
   голубоватая. Показания owner («фон не белый а голубой»). Точечные
   blue-50-плашки внутри (hero-поиск `cp-hero__search-all`,
   `cp-pill`) остаются как есть.
2. **Крошки под шапкой.** `.cp-breadcrumbs` на внутренних страницах
   (добавлены ревью T14.12: vacancies/internships/practices) имеют
   rect `y=0, h=62` на скролле 0 — они в потоке `<main>` ПОСЛЕ
   `<header class="cp-header cp-header--static">`, но шапка фактически
   absolute: блок `.cp-header--static` (pilot.css:27) задаёт
   `position: static`, однако НИЖЕ идёт `.cp-header` (pilot.css:35) с
   `position: absolute` — тот класс применён вместе (build.mjs:336)
   и позже в файле, при равной специфичности (0,1,0) побеждает он.
   Итог: статичная шапка висит абсолютно над main и накрывает полосу
   крошек на всех внутренних страницах, контент съехал вверх.

## Scope

- pilot.css:22 — фон `.cp-page`: `--ui-color-surface-muted` →
  `--ui-color-surface`;
- pilot.css:27 — селектор `.cp-header--static` →
  `.cp-header.cp-header--static` (специфичность 0,2,0 побеждает
  `.cp-header` при любом порядке строк; комментарии не трогаются);
- пересборка dist (`node pilot/career-portal/build.mjs`);
- выборочная браузерная проверка: на vacancies/internships/practices
  крошки видимы под шапкой, фон страниц белый;
- после правки прогнать grep `cp-header--static` по dist — на каждой
  такой странице крошки видимы (rect y ≥ высоты шапки, h=62).

## Out of scope

- Любой другой фоновый выход в план (hero/карточки/CTA — отдельные
  слои поверх `.cp-page`);
- шрифты/underline шапки — T16.3 (отдельная задача);
- переупорядочивание CSS-Diesе pilot.css.

## Existing implementation

`--ui-color-surface` токен есть (semantic.css:58) — замена значения,
новой DS-работы нет.

## Implementation requirements

1. Правки ИСКЛЮЧИТЕЛЬНО в pilot.css (сайт-зона, не ДС).
2. После правки прогнать по всем 12 страницам `grep 'cp-header--static'`
   в дистрибьюции — каждая должна показывать крошки visible (rect y ≥
   высоты шапки, h=62).

## Technical considerations

- `.cp-header.cp-header--static` — минимальный дифф, предельно
  следующий за существующей конвенцией (qualifying selector, ADR-0005:
  без новых слоёв каскада).
- После крошки-фикса содержимое внутренних страниц опустится на 62px —
  это и есть соответствие оригиналу (полоса 62px, REPORT §3.3
  breadcrumbs T14.5).

## Dependencies

Отсутствуют. Первая в эпике — два киллера восприятия (фон + крошки)
блокируют адекватную оценку остального.

## Acceptance Criteria

- [ ] на страница с `.cp-header--static` крошки видимы (rect y > 0 под

- [ ] hero/карточки blue-50-плашки остались прежними (выборочная
  скрин-wерификация index и vacancies);
- [ ] REPORT §8.2 строки 1–2 помечены «закрыто T16.1».

## Accessibility requirements

контраста не меняется (white/…:1 15.4:1).
