# TASK T16.10 — ДС: модификатор «тег на фото» (ui-tag--on-photo)

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell (раунд 3)](README.md)

## Priority

P2

## Type

TASK

## Goal

На фотографиях (карточки событий/статей) оригинал красит тег белым на
primary, высота 40px; ДС-тег на фото — tint blue-50 28px, систематически
мельче и бледнее (REPORT §3.3 остаток раунда 1, probe education/media:
tag-blue height 40 → 28). Добавить модификатор варианта «тег поверх
фотографии».

## Context

Оригинал: тег-метка на карточках с фото (события — формат, медиа —
рубрика): `белый текст на --color-primary`, высота 40px, на тёмной
фото-подложке. Контраст пары 12.58:1 (primary/white — пара tag-blue,
уже в гейте). База ui-tag 28px остаётся для тегов на светлом фоне.

Пилот применит модификатор в T15.9-пересборке (карточки событий/медиа).

## Scope

- components/ui-tag/ui-tag.css: модификатор `--on-photo` — фон
  `--ui-color-primary`, текст `--ui-color-text-on-dark`, высота 40px
  (`--ui-tag-height-on-photo: 2.5rem` или ступень; решить по шкале —
  40 вне 8px-шкалы, перенос «как есть» по прецедентам);
- README ui-tag: правило «когда on-photo» (только поверх
  фото/тёмного), запрет на светлом фоне;
- стенд ui-tag: вариант on-photo на фото-подложке;
- mapping-строка (высота 40 + пара цветов, провенанс pages.css);
- контраст-гейт — пара уже существует (tag-blue), добавить on-photo
  алиас при необходимости;
- эталоны стенда в контейнере, CHANGELOG;
- пилот: применить на карточках событий (events) и медиа (media) —
  после задачи пересборка T15.9 подхватит.

## Out of scope

- Спец-тинты hero-тегов (violet/green/rose) — P3, бэклог;
- Другие оверлейные размеры тегов оригинала (проверить только пару
  формат/рубрика из probe).

## Existing implementation

ui-tag (T4.3): база 28px, варианты blue/orange/gray/green/navy;
модификаторов фона под фото нет.

## Implementation requirements

1. Эталоны только в контейнере (ADR-0004).
2. Контраст-гейт: пара primary/white уже зелёная — убедиться, что
   новая роль попала в покрытие (или алиас в конфиге).
3. Высота 40px: 40 вне 8px-шкалы — перенос «как есть» с комментом
   (прецедент --ui-pagination-size 44px).

## Technical considerations

- on-photo НЕ должен зависеть от цвета фото — плашка primary
  непрозрачна (не tint): иначе контраст недетерминирован;
- именование: `--on-photo` (смысл «поверх фото»), не `--overlay`
  (не путать с z-слоем);

## Dependencies
