# TASK T16.4 — Пилот: футер по оригиналу

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell](README.md)

## Priority

P0

## Type

TASK (сайт-зона пилота)

## Goal

Перестроить футер клона по оригиналу: белый фон, тёмные ссылки
14/500 без подчёркивания в nowrap-столбцах, компактная высота (227px
против 290px у клона).

## Context

[REPORT §8.2](../../../pilot/career-portal/REPORT.md) №5, замеры
(vacancies, 22.10):

| Параметр | Оригинал `.footer` | Клон `.cp-footer` |
|---|---|---|
| bg | `rgb(255,255,255)` | `--ui-color-primary-deep` `rgb(21,42,79)` |
| цвет ссылок | `#1F1F1F` (`--color-text`) | on-dark белый |
| шрифт ссылок | fs 14 / fw 500, «nowrap» | fs 20 / fw 400 (ui-link default) |
| подчёркивание | нет | есть (ui-link) |
| высота | 227px | 290px |
| контакты | «Адрес»/«Телефон»/«Email» — на-white | on-dark |

Происхождение: сайт-зона унаследовала on-dark тон паттерна footer ДС
(`patterns/footer` — DS-стилистика, «структурный перенос, не точный
клон»), но задача пилота — соответствие оригиналу (кнопки не
переопределяются, а сайт-шапка/футер — честная зона прилёга).

## Scope

- pilot.css блок `.cp-footer*`: фон → `--ui-color-surface`;
  колонки/нетто-отступы выровнять по оригиналу
  (src/blocks/footer/footer.css);
- ссылки футера → `ui-link--nav` (T16.3): fs-small/fw-small, tdl
  none, color text; `:visited` отключён по умолчанию правилами
  ссылки футера (цвет фиксирован; следить за «потемнением» visited —
  как оригинал);
- контакты (`cp-footer__contact-*`) — fs по оригиналу (label muted
  fs-small, значение fs 20/500 на-white → на-текст);
- высота/footer-pали ключевых подписей (© 1998—2026, ПАО …) —
  fs-small-regular;
- adoption не трогает `patterns/footer` — паттерн ДС остаётся on-dark
  (док-строка: для сайта «career-portal» применяется сайт-тема),
  mapping-комментарий.

## Out of scope

- Перерисовка паттерна footer ДС (вне пилота);
- логотип/соц-кнопки (стоит как есть; контент совпадает);
- перестроение raзметки сетки футера (только тона и шрифты).

## Existing implementation

- `.cp-footer*` блок pilot.css:731-805 — правка фона и типографики;
- original `src/blocks/footer/footer.css` — фактически источник
  значений (build-time файлы оригинала недоступны, см. ref
  `../career-portal-clone-ref`).

СВерка после сборки (T16.8-снапшоты на дополнительных пробах).

## Implementation requirements

1. Все значения берутся из оригинала (computed замеры §8.2 №5 или
   CSS ref), не из фантазий: paта 14/500, сегменты колонок ≡.
2. Не переопределять свойства ui-link через `.cp-footer__link` —
   использовать модификатор `--nav` (T16.3) и site-zone для размеров
   отступов, если они отличаются от ui-link--nav.
3. A11y: on-white пара (#1F1F1F/white = 15.4:1), visited не меняется.

## Technology consider >

- Каскад: `ui-link--nav` смотрит `--ui-color-primary` — на-white
  футере color переобнавливается on `.color-text` самый
  низкоходной свбz-правкой (одна строка в pilot.css);
- палилось удаление `.cp-footer__link`: белый + (НЕТ) — правится
  вместе с добавлением --nav.

## Dependencies

- T16.3 (ui-link--nav) должна поставить и запускаться до неё — иначе
  руками fs/tdl править в пилоте нельзя (правило пилота);
- файлы: только pilot.css + build.mjs footerHtml (если понадобится
  класс-модификатор).

не меняется.
