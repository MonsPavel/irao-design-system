# TASK T16.6 — ДС: пагинация без стрелок (`ui-pagination--bare`)

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell](README.md)

## Priority

P1

## Type

TASK (компонент ДС)

## Goal

Дать ui-pagination вариант без стрелок (`--bare`): оригинал career-portal
на списковых страницах рендерит только номера (`.pagination` без
стрелок), а ДС всегда включает два `ui-pagination__arrow` — расхождение
видно на каждой странице списка клона.

## Context

[REPORT §8.2](../../../../pilot/career-portal/REPORT.md) №7, замеры 22.10:

- оригинал (vacancies.html): `.pagination` содержит только
  `pagination__page` (страницы 1—3, активная без ссылки
  `span + aria-current`), стрелок в DOM нет;
- клон: `.ui-pagination` содержит 2 стрелки `BUTTON.ui-pagination__arrow`
  + страницы. Probe-набор сравнивал только стили ссылки страницы
  (`pagination-page` probe MATCH) — присутствие стрелок не сравнивалось,
  поэтому расхождение не всплыло в раундах 1—2;
- сам DS-дизайн вопроса не вызывает: компонент T6.3 задуман «1 2 … 12»
  со стрелками как структурным элементом (доступная навигация по
  страницам). Снимать стрелки дефолтом не делаем — вносим модификатором.

## Scope

- `components/ui-pagination/ui-pagination.css`: модификатор
  `.ui-pagination--bare` — стрелки скрываются (`display: none`);
  дополнительно разметка может вовсе не включать стрелки;
- `components/ui-pagination/ui-pagination.html`: документировать обе
  формы разметки (со стрелками — default; `--bare` — только страницы);
- README + do/don't (когда bare уместен: компактные списки, как в
  career-portal);
- unit: bare-разметка не содержит стрелок; стили `__page` неизменны
  (пин существующих значений);
- эталон стенда ui-pagination — пересъём (ADR-0004, контейнер).

## Out of scope

- Изменение стилей `__page`/`arrow` (совпадает, probe MATCH);
- краевые случаи «1 2 … 12» с пропуском страниц (не в оригинале);
- autopagination/js-логика — не касается.

## Existing implementation

- `components/ui-pagination/ui-popup.html` T6.3 — блок + элементы;
- css-компонент без JS.

## Implementation requirements

1. Модификатор применяется НА `.ui-pagination`; hidden стрелки не
   получают focus (ионный вариант — разметка без стрелок; display:none
   — как страховка для готовой разметки).
2. `aria-label` контейнера — неизменный.

## Technical considerations

- Прецедент структурных модификаторов: `ui-card--filled`,
  `ui-link--on-dark` — тот же стиль документирования.
- Пересъём эталонов два (со стрелками и bare) — стенд добавляет второй
  пример (по конвенции стенда «состояния компонента»).

## Dependencies

Независимая DS-задача; adoption пилота — внутри (build.mjs): убрать
стрелки из разметки пагинации клона, добавить модификатор `--bare`.
Файловых пересечений с другими задачами эпика нет.

## Acceptance Criteria

- [ ] `.ui-pagination--bare`: стрелок нет в разметке либо они
  display:none и не фокусируются (unit-пин);
- [ ] стили `__page` не изменились (снапшот диффа пуст по существующим
  парам);
- [ ] эталон стенда переснят (два примера: default и bare);
- [ ] клон (vacancies и остальные списковые страницы): пагинация без
  стрелок, стили страниц как ранее;
- [ ] гейт репозитория зелёный.

## Testing requirements

Unit-пины (2) + пересъём стенда-эталонов. e2e-клавиатура: bare-вариант
не добавляет таб-остановов (стрелки отсутствуют).

## Accessibility requirements

- Навигация по страницам сохраняет nav[aria-label] (WCAG 2.4.4 —
  смысловой контейнер);
- отсутствие стрелок не снижает доступность (ссылки страниц остаются
  целями).
