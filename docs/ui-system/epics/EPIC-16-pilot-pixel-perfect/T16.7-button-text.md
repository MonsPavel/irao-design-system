# TASK T16.7 — ДС: текстовая кнопка (`ui-button--text`)

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell](README.md)

## Priority

P2

## Type

TASK (компонент ДС)

## Goal

Добавить в ДС текстовый вариант кнопки — для контрола «Сбросить ×»
оригинала (fs 14/400, underline, muted, без фона и рамки). Сейчас
пилот вынужденно ставит на это место outline-кнопку 52px — вида
полноценного CTA, чего в оригинале нет.

## Context

[REPORT §8.2](../../../../pilot/career-portal/REPORT.md) №8, замер
(vacancies, 22.10):

- оригинал: `.vac-side__reset` — `<button>` **BUTTON** fs 14px,
  fw 400, underline, color rgb(128,128,128), подложки нет — это
  текст-кнопка, семантически действие (сброс фильтров);
- ДС: у ui-button вариантов нет текстового (`primary/accent/outline/
  light/pill/sm`); `ui-link` сюда не подходит (ссылочная семантика,
  а действия — кнопки; do/don't ui-link прямо запрещает «действие под
  видом ссылки»);
- пилот сегодня: `ui-button--outline` 52px с рамкой — визуально
  другой компонент, показания owner зафиксированы в §8.2 №6/№8.

A11y-заметка: подчёркивание у текстовой кнопки в оригинале —
визуальный маркер действия в текстовом контексте; у обычных кнопок
ДС марка фоном достаточна, но у безфонового варианта underline
остаётся осмысленным маркером — сохраняем его документированно.

## Scope

- `components/ui-button/ui-button.css`: модификатор
  `.ui-button--text` — фон/рамка прозрачные, паддинг компактный
  (как в оригинале: 0), fs-small-regular (14/400), цвет
  `--ui-color-text-muted`, `text-decoration: underline`,
  hover: цвет primary + подчёркивание сохраняется; фокус-ring по
  ADR-0001 не меняется;
- README ui-button: строка API + do/don't («действующее слово в
  текстовом контексте», отличие от `ui-link`);
- unit-пины: bg transparent, border 0, fs 14, fw 400, tdl underline,
  color text-muted, hover color primary;
- эталон стенда ui-button — пересъём с новым примером.

## Out of scope

- Поведение «Сбросить» в пилоте (сброс фильтров JS) — уже работает;
- семантика `aria`-атрибутов (plain button достаточно);
- другие размеры/цвета текстовой кнопки (мок по одному потребителю).

## Existing implementation

- модификаторы ui-button идут одним рядом (primary/accent/outline/
  light/pill/sm) — текстовый вариант встаёт в ту же линейку;
- замер оригинала — §8.2 №8 (fs/fw/colors live-computed).

## Implementation requirements

1. underline у текстового варианта осознанный — не домыслен: делаем
   от роли «маркер действия в тексте» (в README do/don't).
2. Не наследовать `text-decoration: none` из основной версии: строка
   T16.2 добавит его в `.ui-button` — модификатор переопределяет
   обратно на underline после (специфичность `.ui-button--text`
   выше, порядок в файле — после base).

## Technical considerations

- Цвет hover-подчёркивания — как текста (currentColor).
- Размер 52px не применяется (padding 0, height auto) — в отличие
  от остальных вариантов; unit-пин.

## Dependencies

- Связка с T16.2: `text-decoration: none` добавляется в базовое
  правило `.ui-button` — модификатор переопределяет обратно на
  underline (порядок правил в файле гарантирует результат);
- adoption пилота («Сбросить» → `--text`) — выполняется в задаче
  строк/сайдбара (зависимость отмечена там); в самом пилоте замена —
  одна строка build.mjs.

## Acceptance Criteria

- [ ] `.ui-button--text`: computed — bg transparent, border 0,
  fs 14px, fw 400, tdl underline, color text-muted, hover color
  primary (unit-пины);
- [ ] высота не задана (auto по строке) — не 52px;
- [ ] README + API-таблица пополнены; do/don't описывает разницу с
  ui-link;
- [ ] эталон стенда переснят (новый пример);
- [ ] гейт репозитория зелёный.

## Testing requirements

Unit-пины (названные) + снапшот стенда. e2e: клавиатурный фокус
виден (focus-ring не пропал на прозрачной кнопке).

## Accessibility requirements

- Пара контраста text-muted/white — как у muted-текста ДС; для
  мелкого текста 14px/400 ожидается ≥ 4.5:1 — проверка
  контраст-гейтом при подстановке значения токена;
- focus-ring по ADR-0001 (не color-only).
