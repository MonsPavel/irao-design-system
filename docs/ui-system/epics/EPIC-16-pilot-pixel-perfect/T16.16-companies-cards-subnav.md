# TASK T16.16 — Пилот: карточки компаний (14/500) и поднавигация ui-tabs--pill

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект (раунды 3–4)](README.md)

## Priority

P2

## Type

TASK

## Goal

Две независимые систематики раунда 4, обе — незавершённые адопции
существующих ДС-канонов:

1. **Карточки компаний** (`companies.html`): имена рендерятся 20/400
   (наследование ui-card), канон — **14/500** (`fs-small × fw-small`);
   ~50 текстовых находок;
2. **Поднавигация** разделов (career-track/education): собрана базовым
   `ui-tabs__tab` (36px, прозрачные), канон — трек-пилюли `.tabs-pill`
   (blue-50 трек, height 48, сетка repeat(5, 1fr)); ДС-вариант
   `ui-tabs--pill` (T14.9) готов, но не применён.

## Context

Канон оригинала:

- `.card--hover` (карточка компании): имя **fs-small (14) /
  fw-small (500)**, color-text (замер 14/500 `#1F1F1F`); высота
  карточки — по замеру (58px строка в grid-3);
- секционные заголовки компаний — 42/400 у оригинала, клон `ui-h3`
  42/500 — fw принимается ДС (прецедент T14.8/T14.9, фиксация в
  mapping, задача не переоткрывает);
- `.tabs-pill` (pages.css:969–1001): трек на blue-50, pad/gap 4px,
  радиус pill; табы — прозрачные пилюли без рамки, height 48,
  fs-body 20/400; активная — заливка primary + text-on-dark.
  РЕШЕНИЕ T14.9 уже описано в ДС: подпись — роль small («принято
  ДС»), высота 52 (`--ui-button-height`) в пороге ≤4px, раскладка
  страниц — flex (сетка repeat(5,1fr) — не вид модуля);

Клон сейчас: `careerTrackMain`/`educationMain` — `nav` без `ui-tabs--pill`
(база: высота 36, inline-flex, fs-small, белые с рамкой?) и карточки
компаний — `<a class="ui-card ui-card--hover cp-company-card">` без
типографской роли (замер 20/400).

## Scope

- **адопция пилота**:
  - `companiesMain`: имя компании — обёртка `ui-small` (14/500, color
    inherits) либо site-zone fs/fw на `.cp-company-card` — выбрать
    вариант, где не появляется отдельной типографской строки и не
    нарушается БЭМ-гейт;
  - `careerTrackMain`/`educationMain`: nav получает класс
    `ui-tabs--pill` (модификатор T14.9: трек blue-50, пилюли 48–52,
    активная primary); на events проверить форму поднавигации по
    замеру (если оригинал рисует тот же tabs-pill — применить и туда,
    если чипы — оставить как есть);
- **если замер покажет расхождение с T14.9-каноном** (форма трека,
  высоты) — уточнить модификатор отдельной DS-правкой до adoption;
- вертикальные отступы блока поднавигации — по замеру страниц;
- mapping §3: строки «company card», «subnav tabs»;
- REPORT §9: разделённые находки закрыты.

## Out of scope

- section-заголовки 42 fw (фиксация mapping, без работ);
- фильтр-чипы карьерного трека (`.track-chip`, 14/400 blue-50 pill)
  — как T16.14-класс фильтра, отдельное решение, вне этой задачи;
- карточки companies с логотипами (если в оригинале есть) — нет
  показаний.

## Implementation requirements

1. Две части независимы: мержить одной задачей ради одного
   пересобера dist.
2. Если замер показывает иную форму (вес, размеры, фон) — решение по
   замеру, а не по предположению.

## Technical considerations

- `ui-chip` (events) vs `ui-tabs--pill` (career-track/education) —
  разные сущности навигации; их различие фиксируется mapping, чтобы
  дальнешие страницы не путали.
- Карточка компании — ссылка с одним текстом: роль (`ui-small`)
  безопасно ставить на внутренний span — селектор ссылочной карточки
  не требует БЭМ-расширений.
