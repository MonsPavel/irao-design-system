## Goal

Промо-блок «бегущие строки» на internships.html/practices.html
(`.cp-adv-marquee`) отходит от канона по трём строкам сразу: размеры и
цвета инвертированы (клона 42/24/20 белым на тёмном, оригинал
40/18/13 uppercase primary на светлом фоне). Раунд 4 — ~24 находки на
этой зоне. Чистая сайт-зона (в ДС компонента нет) — калибровка
pilot.css по замеру.

## Context

Канон оригинала (pages.css, `.adv-marquee__*`):

- все строки: `font-weight: var(--fw-body-bold)` (500),
  `text-transform: uppercase`, `letter-spacing: 0.02em`,
  `color: var(--color-primary)`;
- базовая строка («НАЧНИ КАРЬЕРУ…»): fs 40 (замер);
- `--bar` (строки-подписи): fs 18;
- `--sm` (мелкая подпись): fs 13, fw-small (500);
- фон блока светлый (строки primary на light), фото справа.

Текущий клон: `cp-adv-marquee__line` в pilot.css — базовая 42, `--xl`
42, `--sm`-линия 24/20, цвета белым (замер: col white). Разметка
build.mjs:1446–1457 несёт классы `__line --sm --xl`, не совпадающие
с ролями оригинала (base/--bar/--sm).

## Scope

- **pilot.css**: перепривязать три размера на канон: базовая 40,
  строка-подпись 18, мелкая 13; fw 500/500/500 (fw-small для --sm),
  uppercase, ls 0.02em, color primary; фон блока светлый по скрин-замеру;
- **build.mjs**: сопоставить классы (первая 40px-строка = base,
  «оплачиваемые программы…» = --sm 13px, «опыт · наставники…» = --bar
  18px — по биркам оригинала);
- вертикальные отступы блока — по замеру высоты (в пределах порога);
- mapping §3: строка «adv-marquee (сайт-зона)»;
- REPORT §9: диффы marquee — закрыты.

## Out of scope

- Анимация бегущей строки (если в оригинале статично — замер покажет;
  без работ, если не разница);
- фото и текст-блок справа (`ui-body` уже совпадает);
- другие промо-блоки index — P2, вне эпика.
