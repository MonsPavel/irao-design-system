# TASK T16.2 — ДС: кнопки-ссылки без подчёркивания

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell](README.md)

## Priority

P0

## Type

TASK (компонент ДС)

## Goal

`.ui-button` не должен наследовать подчёркивание якоря: страницы клона
(и любые другие сайты группы) собирают `a.ui-button` для
переходов-действий — сейчас вся кнопочная поверхность клона отрисована
с underline (UA-дефолт для `a[href]`), в оригинале `a.btn` — `none`.

## Context

[REPORT §8.2](../../../pilot/career-portal/REPORT.md) №3:

- замер 22.10 (vacancies): `a.btn.btn--primary` tdl `none`;
  `a.ui-button--primary` tdl `underline` (каскад от UA `a[href]
  { text-decoration: underline }`; `components/ui-button/ui-button.css`
  не задаёт `text-decoration: none` вообще);
- показания owner («ссылки почему-то все underline») частично об этой
  находке: CTA-кнопки («узнать подробнее», промо) отрисованы
  подчёркнутыми и в строках, и в сайдбаре;
- обоснованность: `.ui-button` — кнопочный вид; WCAG 1.4.1 не требует
  подчёркивания у кнопки (фоновая марка достаточна); doc-разграничение
  ui-link (T4.1): «ссылка» = underline всегда, «кнопка-вид» = нет;
  скрин-доказательство — на всех кнопках-ссылках клона лейбл под линией.

## Scope

- `components/ui-button/ui-button.css`: в основное правило
  `.ui-button` добавить `text-decoration: none` (комментарий: сброс
  UA-дефолта якоря; кнопочный вид не несёт подчёркивания ни в одном
  состоянии, hover меняет только цвет — ADR-0010);
- unit-тест: пин `text-decoration: none` на `a.ui-button--primary` и
  `a.ui-button--outline` (tests/unit, конвенции существующих пинов);
- e2e: существующие проверки кнопок не меняются;
- эталон: пересъём стенда ui-button (контейнер, ADR-0004) — у кнопок
  `a.ui-button` на стенде уйдёт линия;
- mapping: строка в tokens-career-portal-mapping.md
  («a.btn tdl none == a.ui-button tdl none — закрыто T16.2»).

## Out of scope

- `.ui-link--button` — его документированное поведение (с underline
  опционально) не меняется;
- hover/active-подчёркивания (в ДС их нет и после — hover-производные
  colors по ADR-0010).

## Existing implementation

`components/ui-button/ui-button.css` блок `.ui-button { … }` — добавить
properties; тест tests/unit — следить за conventions (было: unit
481/481 после EPIC-4).

## Implementation requirements

1. Изменение только CSS-декларации + комментарий; API-док компонента

   гарантируется».
2. Прозрачная рамка заливочных вариантов (T14.3) не трогается.

## Technical considerations

- Прецедент сброса дефолта якоря в ДС: base/reset.css не сбрасывает
  `a`-стили полностью (generic elements — согласовано с ui-link);
  точечный сброс в классе компонента — конвенция BEM (T4.2).
- Проверить hover-рендер `a.ui-button--pill` (иконка) — там тоже был
  underline (заметено на скринах 22.10).
