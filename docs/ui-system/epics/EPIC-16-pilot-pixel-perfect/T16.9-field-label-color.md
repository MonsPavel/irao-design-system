# TASK T16.9 — ДС: цвет подписи поля (ui-field label)

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell (раунд 3)](README.md)

## Priority

P2

## Type

TASK

## Goal

Подписи полей в ДС темнее оригинала (rgb(31,31,31) `--ui-color-text` vs
серый rgb(128,128,128) оригинала, REPORT §3.3 остаток из раунда 1):
ввести отдельный токен цвета подписи поля с AA-значением и применить
его в ui-field. Единственная оставшаяся «серийная» цвет-калибровка
форм после EPIC-14.

## Context

Оригинал: `.field__label` серый `#808080` = gray-600 — на белом 3.95:1,
AA для мелкого текста НЕ проходит. Директива проекта: AA-замены по
шкале (прецедент muted gray-700 T2.3, tag-orange orange-800). Значит
токен-цель — не копия серого, а ближайший AA-стабильный серый шкалы:
`--ui-gray-700 #616161` (6.19:1 на белом) — тот же, что у text-muted.
Пара «подпись чуть тише текста, но читаема» — и визуально ближе
оригиналу, и в гейте.

Probe раунда 2 (каждая страница с формой): field-label color
rgb(128,128,128) → rgb(31,31,31).

## Scope

- tokens/semantic.css: `--ui-color-field-label: var(--ui-gray-700)`
  (слой 2, коммент-провенанс «#808080 gray-600 оригинала, AA-замена по
  прецеденту muted T2.3»);
- components/ui-field/ui-field.css: `__label` цвет — новый токен;
- components/ui-file/ui-file.css и ui-radio-group/ui-checkbox подписи:
  проверить, где подписи несут `--ui-color-text` в роли label — свести
  к токену только там, где это подпись поля (не текст чекбокса:
  согласие — контент, остаётся text; решение зафиксировать в Notes);
- доки/стенд ui-field, ui-form, ui-file (если затронуты);
- mapping-таблица: строка «label #808080 → --ui-color-field-label
  gray-700 (AA-замена)»;
- контраст-гейт tests/contrast: новая пара (gray-700 на белом и на
  surface-muted/blue-50, где стоят формы);
- эталоны затронутых стендов в контейнере (ADR-0004), CHANGELOG.

## Out of scope

- Placeholder-цвет (уже muted, отдельная пара);
- Текст чекбоксов/радио (контент согласия — text; раздувание не нужно);
- compact-textarea строка mapping (бэклог T14.6 — можно закрыть
  попутно одной строкой, не обязательно).

## Existing implementation

Подписи сейчас `--ui-color-text` (ui-field.css); muted-механика
AA-замены — T2.3 (mapping «AA-замены значений»).

## Implementation requirements

1. Новая пара обязана пройти `npm run test:contrast` (иначе — не
   сливать, вернуться к выбору ступени).
2. Эталоны ТОЛЬКО в контейнере (ADR-0004, sha-паритет).
3. Тёмные темы/тёмные секции: подписи полей в vi-контрастах — проверить
   пару на инверсии (тест контраста прогоняет темы).

## Technical considerations

- Токен слоя 2, не примитив: тема переопределяет одну точку;
  gray-700 уже несёт muted — семантика «приглушённый, но AA» уже
  существует; field-label указывает на ту же ступень (одна точка
  переопределения на тему остаётся у каждой роли отдельно);
- Формы в модалках (surface белый) и на странице (белый/surface-muted):
  пара должна держать оба фона.
