# TASK T16.5 — Пилот: строки и сайдбар по канону list-page

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект зоны shell](README.md)

## Priority

P1

## Type

TASK (adoption пилота)

## Goal

Привести строки списков (vacancies) и панель фильтров к канону ветки
«строки» паттерна list-page (T14.10): заголовок-ссылка 20/500 без
подчёркивания, тёмный текст, паддинг строки 24/28, CTA-пилюля с
primary-рамкой и primary-кружком стрелки, «Сбросить» — текстовый
контрол (после T16.7), промо-карточка — `ui-card--filled`.

## Context

[REPORT §8.2](../../../pilot/career-portal/REPORT.md) №6, замеры
(vacancies, 22.10). Пилот отходит и от оригинала, и от собственного
канона ДС (паттерн list-page, который был создан в EPIC-14 именно по
этой строке):

| Параметр | Оригинал | Канон ДС (lpp-row, T14.10) | Клон сейчас |
|---|---|---|---|
| заголовок | `.vac-row__title` h2: fs 20, fw 500, tdl none, `#1F1F1F` (pages.css) | `.lpp-row__title a`: color inherit, tdl none, ui-h4 | `ui-link`: fs 28, fw 500, tdl underline, primary |
| паддинг строки | 24px 28px r16 (`card--hover`) | `var(--ui-space-5) 1.75rem` | `var(--ui-space-4)` = 16px |
| CTA-пилюля | `.pill-btn`: border 1px primary, fs 13, w 187, кружок primary | модификатор ui-button--pill (T14.4) | pill без рамки, fs 14 (принято ДС), кружок accent `rgb(242,103,34)` |
| «Сбросить» | `.vac-side__reset`: будто кнопка fs 14/400 underline muted | нет аналога (T16.7) | `ui-button--outline` 52px |
| промо-карточка | `.vac-side__promo card--filled`: bg blue-50, pad 20, r16, fs 20 | — | без карточки (напрямую), плюс подчёркнутая primary-кнопка |
| пагинация | `.pagination`: только страницы | — | T16.6 |

Причина отклонения строки: сегментация T14.12 перенесла разметку
строки руками (ui-link в заголовке вместо ссылки канона), а не по связке
lpp-row; отклонение паддинга — ошибка калибровки блока (T14.10 указывал
«в пилоте строка остаётся сайт-зоной по образцу связки паттерна», но по
образцу заносились лишь раскладки).

Цвет заголовка: в оригинале `#1F1F1F` — заголовок-ссылка несёт цвет
текста, НЕ heading-navy. При hover строки — цвет primary (pages.css:
178); это канон ДС lpp-row (`hover строки перекрашивает ссылку в
primary`, list-page.html:145-148) — уже в каноне, не новая работа.

## Scope

- build.mjs: строка `cp-vac-row` — разметка по связке lpp-row:
  заголовок-тег (h2) с обычной ссылкой внутри; класс `ui-link` снимается,
  ссылка — plain `<a>` со стилями сайт-зоны на токенах (текстовый цвет,
  НЕ heading-navy; подчёркивания нет — как в каноне);
- полнота: `data`-атрибуты строки (region/city/spec/…) — сохраняются;
- pilot.css `.cp-vac-row`: паддинг `var(--ui-space-5) 1.75rem`
  (24/28) — как канон;
- CTA-пилюля строки: `ui-button--pill` с рамкой primary и
  primary-кружком стрелки — как у строки оригинала; сайт-зонный
  override border-color и цвета иконки через cp-класс (в ДС нет
  токена «иконка пилюли в primary»; прецедент T14.4: цвет иконки —
  отметить, что это site-zone override с комментарием в css);
- «Сбросить» → после T16.7: `ui-button--text`; до того — временный
  текстовый контрол `ui-link` на fs-small-regular (14/400, muted —
  визуально соответствует оригиналу); в css-комментарии — заметка о
  замене на `ui-button--text`;
- промо-карточка: `ui-card--filled` (blue-50 + pad 20 + r16) —
  существующий API (компоненты/ui-card/ui-card.css); CTA «узнать
  подробнее» — `ui-button--primary` (52px — как оригинал, БЕЗ
  подчёркивания при погашении T16.2);
- пагинация-строка `data_*` — вне задачи (T16.6).

## Out of scope

- ДС-правки (все уже есть: ui-card--filled, ui-button--pill, lpp-row
  канон); исключение — токен цвета иконки пилюли (см. Scope):
  принять решение-бэклог, если признают ДС-уровнем;
- поиск/сортировка: содержимое селект-пилюль («По зарплате» vs «По
  дате добавления») — мок-данные, в сверку не идут;
- hover-поведение строки — уже в каноне, не работа.

## Existing implementation

- Канон: patterns/list-page/list-page.html:129-148 (lpp-row title и
  паддинги) — прямо читается;
- оригинал: pages.css (~168-200, `vac-row`), src/blocks/…
- пилот: pilot.css:856-925 (cp-vac-row/cp-vac-side), build.mjs секция
  vacancies.

## Implementation requirements

1. Разметка строки: заголовок h2 → ссылка (кликабельная зона — поле
   заголовка, как в оригинале; большие overlay-зоны ui-card--link не
   применяются — строка требует простую ссылку по канону lpp-row);
2. `data`-атрибуты фильтра строки (region/city/spec/position/…)
   остаются в разметке — JS фильтра на них завязан;
3. Пилюля CTA: ДС-изменений не требуется — site-zone override
   border-color и цвета иконки в cp-классе pilot.css;
4. Каждый css-override в pilot.css — с комментарием о причине
   (со ссылкой на строку оригинала в pages.css).

## Technical considerations

> (замер 22.10: tdl underline), вид этой кнопки не будет финальным —
> проверку строки делать после T16.2.
