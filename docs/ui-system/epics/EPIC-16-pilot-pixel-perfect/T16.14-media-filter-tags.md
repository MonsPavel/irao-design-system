# TASK T16.14 — Пилот: фильтры медиа-каталога как ui-tag--blue (первый потребитель)

## Epic

[EPIC-16 — Пилот career-portal: пиксель-перфект (раунды 3–4)](README.md)

## Priority

P2

## Type

TASK

## Goal

Панель фильтров медиа-каталога («Тип контента», «Рубрики») собрана в клоне
`ui-chip__pill` (белые пилюли с рамкой), тогда как оригинал рисует
синие теги-пилюли `a.tag--blue` (фон blue-100, текст primary, радиус pill,
высота 40). Раунд 4 — 7 текстовых находок (замер: bg `rgb(232,238,254)`
→ белый, цвет primary → dark, радиус 100px → менее). Адаптация делает
медиа-страницу первым потребителем `ui-tag--blue` (уже есть в ДС) в роли
фильтра.

## Context

Канон оригинала (pages.css):

- `.filter-tag { height: 40px; padding: 8px 20px; font-size:
  var(--fs-small-regular) }` — поверх `.tag` (`tag--blue`: bg blue-100,
  color primary, radius pill);
- обе группы панели — «Тип контента» (Все/статьи/видео/подкасты) и
  «Рубрики» — одинаковый вид tag--blue + filter-tag.

Текущий клон (`mediaMain`, build.mjs:1621–1633): `<span class="ui-tag
ui-tag--gray">` на подписи групп + `nav.ui-chip` с `ui-chip__pill` на
самих фильтрах.

Замер раунда 4 (`.zcode/reg-4/media.json`): bg white vs blue-100,
color `#1F1F1F`/dark vs primary, radius меньше; высота не совпадает
(чип 36 / тег 28 против 40 оригинала).

Предыстория: `ui-tag--blue` поставлен в базовом составе ui-tag
(components/ui-tag/ui-tag.css:58 — bg `--ui-color-tag-blue-bg`,
color primary); «фильтр-размер» (h 40, pad 8/20, fs 14/400) в ДС нет —
базовый тегcompact и чип 36px. Решение по probe (см. Scope).

## Scope

- **решение вида** (одно на обе группы):
  - вариант A — DS: модификатор «фильтр-тег» `ui-tag--filter` (h 40,
    pad 8/20, fs-small × fw 400) поверх `--blue` — реализуем комбинацией
    `ui-tag--blue ui-tag--filter`; эталоны/unit-пины; mapping-строка;
  - вариант B — DS: размерный вариант `ui-chip--blue` (первый цветной
    вариант чипа; высота 40 против 36 — по probe «как есть» или
    «принято ДС»);
  - выбор фиксируется в mapping §3 и в README компонента;
- **адопция pilot build.mjs** (`mediaMain`): фильтры обеих групп —
  выбранным вариантом; подписи групп («Тип контента:», «Рубрики:»)
  — сохраняются `ui-tag--gray`;
- **pilot.css**: минимальный align тулбара (зазоры группы — по замеру);
- mapping §3: строка «filter-tag/media»;
- REPORT §9: диффы медиа-фильтров — закрыты.

## Out of scope

- карьерный трек `.track-chip` (blue-50 фильтр-чипы) — T16.16;
- чипы поднавигации events (ссылочная роль) — вне (нет раунд-4
  показаний на форму);
- события-теги на карточках (уже `ui-tag--*`) — не фильтры.

## Existing implementation

- ДС: `ui-tag--blue` есть; `ui-chip` (T14.8) — бесцветный;
- пилот: build.mjs:1605–1640 (mediaMain), toolbar.

## Implementation requirements

1. Фильтр остаётся ссылкой (`<a aria-current="page">` у активной) —
   состояние через ARIA, как в ui-chip; без JS-перестроек.
2. Эталоны — в контейнере (ADR-0004) для ДС-варианта.
3. Контраст: primary на blue-100 — уже в гейте (пары tag-blue).

## Technical considerations

- Высота 40px оригинала vs база тега 28 / чип 36 — расходование
  4–12px от любой базы: решение «как есть» вводит размер вне шкалы
  (прецедент pill 44px → токен); либо «принято ДС» с фиксацией.
- fs-small-regular (14/400) — DS-выражение «small × fw-body»

## Dependencies

- Не зависит от DS-батча (если вариант A/B потребует ДС-правку —
  соответствующий файл ставится в DS-батч после T16.13).
- Медиа-страница пересобирается одной правкой build.mjs.
