# TASK T12.1 — Release pipeline

## Epic

[EPIC-12 — Release & Versioning](README.md)

## Priority

P0

## Type

TASK

## Goal

Боевой релизный конвейер: тег `vX.Y.Z` → полная матрица браузеров + релизные smoke → dist-zip → GitHub Release; nightly-матрица; включение mandatory visual-гейта перед v1.0.

## Context

Каркас — T1.5. Релизные обязательства: матрица chromium/firefox/webkit, zoom/32px-сценарии (T3.6), VI-smoke (T9.1), changelog-проверка (T12.2). ADR-0004: перевод visual из advisory в mandatory — операционное действие этого пайплайна перед v1.0.

## Scope

- `release.yml`: триггер по тегу; джобы: матрица → scaling/VI-smoke → build → dist-zip (весь dist + fonts/themes) → GitHub Release (артефакт + changelog-запись);
- changelog-гейт: отсутствие записи тега в CHANGELOG.md — падение релиза;
- nightly: матрица + advisory-visual (до v1.0);
- операция «включение mandatory visual»: переключение branch protection (последний шаг перед v1.0, фиксируется в чек-листе);
- релизный чек-лист (документ): матрица зелёная 7 дней, smoke, changelog, скринридер-протокол (T9.2), эталоны актуальны.

## Out of scope

- Автодеплой showcase по тегу (main-деплой уже есть);
- подписание артефактов (нет требований ИБ на текущий момент — вопрос Phase 0 остался открытым только для домена).

## Existing implementation

Каркас release.yml (T1.5); GitHub Pages deploy career-portal — референс структуры.

## Implementation requirements

1. Артефакт = zip со структурой §6.1 architecture (проверка содержимого в джобе).
2. Тег без changelog — красный релиз (тест на демо-теге).
3. Матрица и smoke — блокирующие джобы релиза.

## Technical considerations

- Контейнер Playwright-образа для матрицы (тот же, что PR — ADR-0004);
- версия в баннерах dist = тег (T1.3).

## Acceptance Criteria

- [ ] Демо-тег проходит полный конвейер и производит корректный zip + Release;
- [ ] Тег без changelog-записи блокируется;
- [ ] Nightly стабильно зелёная;
- [ ] Чек-лист релиза опубликован; операция включения mandatory visual описана.

## Testing requirements

Tests first: демо-релиз (успешный и «без changelog») — приёмка конвейера.

## Accessibility requirements

Релизные smoke включают VI-включение и axe-прогон ключевых стендов.

## Definition of Done

- [ ] Tests added/passed (демо-релизы)
- [ ] Lint/typecheck passed

- [ ] Documentation updated if required (чек-лист)
