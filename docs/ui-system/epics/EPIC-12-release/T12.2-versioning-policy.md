# TASK T12.2 — Версионирование, changelog, deprecation

## Epic

[EPIC-12 — Release & Versioning](README.md)

## Priority

P0

## Type

TASK

## Goal

Перевести политику ADR-0007 в работающую практику: CHANGELOG с первого релиза, semver-триггеры в ревью-процессе, deprecation-цикл с алиасами, шаблон migration-guide.

## Context

Политика принята (ADR-0007): semver, N−1 (6 месяцев), major в отдельной папке, deprecation minor→alias→major. Задача создаёт механизмы, а не только тексты: CI-гейт changelog (в T12.1), dev-сборка с warnings для deprecated-алиасов, шаблон гайда миграции.

## Scope

- CHANGELOG.md (Keep a Changelog) — стартовые записи всех предрелизов;
- CONTRIBUTING: таблица semver-триггеров с примерами (вкл. «изменение канонического HTML/класса/токена = major»);
- механизм deprecation: список deprecated в доке компонента + консоль-warning в dev-режиме (`window.IraoUI.dev`) + алиас-класс работает до major;
- шаблон `docs/templates/migration-guide-template.md` (для будущих major);
- правило N−1 в README (что поддерживаем сейчас).

## Out of scope

- Codemod-скрипты миграций (P2, по факту первого major);
- автоматический бамп версий.

## Existing implementation

Политика — ADR-0007; практики нет (первый релиз впереди).

## Implementation requirements

1. Dev-вариант ui.min.js (не минифицированный или с флагом) печатает warning при использовании deprecated-имён — механизм должен существовать до первого deprecated.
2. CHANGELOG структурирован по версиям с категориями Added/Changed/Fixed/Deprecated/Removed.

## Technical considerations

- Deprecated-алиас классов: `.ui-old-name { /* deprecated since x.y */ } @extend`-эквивалент (нативный CSS — дублирование правил, допустимо для переходного периода);
- тег релиза и заголовок changelog сверяются гейтом T12.1.
