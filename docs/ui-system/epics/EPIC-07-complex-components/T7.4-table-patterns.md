# TASK T7.4 — ui-table: адаптивные паттерны таблиц

## Epic

[EPIC-7 — Complex Components](README.md)

## Priority

P1

## Type

TASK

## Goal

Три паттерна таблиц, покрывающих типовые кейсы сайтов: обычная, горизонтальный скролл (доступный), карточная трансформация на мобиле — с докой «какую выбирать».

## Context

Таблиц в career-portal нет (новый компонент). Требование — данные не теряются на мобиле, скролл-зона доступна с клавиатуры, семантика table сохраняется или сознательно трансформируется.

## Scope

- `components/ui-table/`:
  - базовая: `ui-table` (border/zebra/hover из токенов), `ui-table--compact`;
  - скролл-зона: обёртка `ui-table-scroll[tabindex=0][role=region][aria-label]` + видимая индикация прокрутки (градиент/тень);
  - карточная трансформация: на <md `display: block` + data-атрибуты заголовков (`data-label`) в ячейках — паттерн «таблица → карточки» с сохранением связности (дока: когда допустима потеря table-семантики, когда — нет);
  - sticky-заголовок (опция для длинных таблиц);
- стенды всех трёх + док-матрица выбора паттерна.

## Out of scope

- Сортировка/фильтрация в таблицах (зона сайта; хелперы — по потребности P2);
- virtual scroll больших данных (P2).

## Existing implementation

Нет (в career-portal таблиц не было).

## Implementation requirements

1. data-label-заголовки задаются в HTML (копипаст из доки); проверка html-validate: ячейки в карточном режиме обязаны иметь data-label.
2. Скролл-зона: фокус видим (T3.2), прокрутка стрелками нативная (tabindex=0).
3. Sticky-заголовок — `position: sticky` в пределах скролл-зоны.

## Technical considerations

- Карточная трансформация меняет порядок чтения: строка → карточка с парами «заголовок-значение» — проверить скринридером (протокол T9.2);
- zebra/hover — из токенов, hover под `(hover: hover)`.
