# TASK T7.1 — SPIKE: native `<dialog>` или собственный оверлей

## Epic

[EPIC-7 — Complex Components](README.md)

## Priority

P1

## Type

SPIKE

## Goal

Принять решение об основе ui-modal: native `<dialog>` (+`showModal()`) или собственный оверлей-паттерн — с доказательствами на матрице браузеров и в контексте Bitrix-страниц.

## Context

Матрица evergreen ×2 разрешает `<dialog>` (Chromium 37+, Firefox 98+, Safari 15.4+). Native dialog даёт бесплатно: focus trap, Escape, `::backdrop`, top-layer (неуязвим для z-index-войн legacy). Минусы: контроль анимации сложнее, поведение вложенных диалогов и `inert`-фона — нюансы. SPIKE обязан проверить реальные Bitrix-условия, а не только спецификацию.

## Scope

- два мини-прототипа (native / собственный) с: открытие, закрытие, trap, restore, блокировка скролла;
- проверка в контексте: страница с агрессивным legacy-CSS (z-index-стек, `position: fixed`-обёртки), Bitrix-композит/прокрутка;
- критерии сравнения (фиксируются заранее): бесплатный trap/Escape; top-layer против z-index-контекстов; анимация open/close + reduced-motion; стилизация backdrop; вложенность; объём JS; деградация без JS;
- результат: ADR в docs/adr/ (номер продолжит журнал).

## Out of scope

- Реализация ui-modal (T7.2 — сразу после ADR);
- поддержка старых браузеров (матрица решена Phase 0).

## Existing implementation

career-portal `directions.js` — собственный паттерн (div + классы + transitionend) — работает, но без trap и семантики; прототип «собственный» стартует от него.

## Implementation requirements

1. Прототипы — в песочнице showcase (не в dist), удаляются после решения.
2. Критерии измеримы (таблица в ADR), решение — однозначное (без «гибрида пополам»).

## Technical considerations

- Проверить: `dialog::backdrop` + VI-перекраска; скролл-лок и scrollbar-gutter (сдвиг макета — регресс-кейс career-portal);
- проверить поведение `<dialog>` при отправке формы (method="dialog") — для будущих форм-модалок.
