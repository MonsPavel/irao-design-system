# TASK T7.5 — ui-loader и aria-busy-паттерн

## Epic

[EPIC-7 — Complex Components](README.md)

## Priority

P1

## Type

TASK

## Goal

Компонент загрузки (спиннер + текст) и системный паттерн `aria-busy` для контейнеров в состоянии ожидания.

## Context

В career-portal loader'а нет. Нужен минимум: кнопка-loading уже есть (T4.2), здесь — индикация загрузки областей (списки, панели). Skeleton-загрузка — P2 (do-not-build).

## Scope

- `components/ui-loader/`: `ui-loader` (spinner svg, `aria-hidden`) + `ui-loader__text` (доступный текст «Загрузка…», role="status");
- паттерн `aria-busy`: контейнер получает `aria-busy="true"` на время загрузки + loader-оверлей; правило доки: текст всегда присутствует (не голый спиннер);
- reduced-motion: спиннер заменяется статичной индикацией (пульсация → точка/текст);
- стенд: inline-загрузка секции + блочная.

## Out of scope

- Skeleton-плейсхолдеры, progress-bar с процентами (P2, по потребности);
- JS-управление загрузкой (зона сайта; модуль не нужен).

## Existing implementation

Нет; паттерн кнопки-loading (T4.2) — согласован по визуалу спиннера.

## Implementation requirements

1. Спиннер — svg с `animation: rotate`; reduced-motion — отключение анимации.
2. Размеры sm/md из шкалы; цвет — currentColor (наследует контекст).
3. Дока-сниппет `aria-busy`-обвязки для сайтов.

## Technical considerations

- `prefers-reduced-motion: reduce` — двойная проверка (kill-switch base + локальное правило).
