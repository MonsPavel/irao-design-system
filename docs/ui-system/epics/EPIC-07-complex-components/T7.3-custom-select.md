# TASK T7.3 — IraoUI.select: кастомный select (listbox поверх нативного)

## Epic

[EPIC-7 — Complex Components](README.md)

## Priority

P1

## Type

TASK

## Goal

Перенос зрелого PE-паттерна career-portal: нативный `<select>` остаётся в DOM и работает, кастомный listbox строится поверх, выбор синхронизируется, диспатчится `change`; рефакторинг — отвязка от классов конкретного проекта.

## Context

`dropdowns.js` career-portal — образцовый PE (класс B аудита): нативный select жив, listbox с `role=listbox/option`, стрелки ↑↓, Escape, aria-expanded, синхронизация + `new Event('change', {bubbles:true})`. Критический рефакторинг: `inWrap = select.parentElement.classList.contains('vacancy-search__select-wrap')` — знание о чужом классе внутри общего модуля → опция через data-атрибут/модификатор.

## Scope

- `components/ui-select/`: `IraoUI.select`:
  - активация: `select[data-ui-select]`; обёртка/растяжка триггера — модификатор `data-ui-select="wrap"` (замена vacancy-search-хака);
  - listbox: `role=listbox/option`, `aria-expanded/haspopup` на триггере, отметка выбранного (is-selected + перенос паттерна «✓»);
  - клавиатура: ↑↓, Home/End, Escape, typahead-опция (по первой букве — оценить, APG рекомендует);
  - optgroup-поддержка (группировка в списке);
  - синхронизация: выбор обновляет нативный select + `change` (bubbles) — формы/фильтры сайтов работают как с нативным;
- деградация: без JS — нативный select (модуль его не прячет до инициализации).

## Out of scope

- Multi-select (нет требований);
- поиск-фильтрация внутри списка (P2, по потребности).

## Existing implementation

career-portal `js/dropdowns.js` — переносим архитектуру целиком; `.dd*` CSS → `ui-select*` с токенами.

## Implementation requirements

1. Чистая функция синхронизации (unit-тестируемая): состояние select ↔ UI-опций.
2. Клик-зона вне закрывает (переиспользование логики T6.1).
3. Мобильная стратегия: на touch можно оставить нативный select (media (pointer: coarse) — модуль не активируется; решение зафиксировать в доке и ADR-заметке).

## Technical considerations

- `custom-select-hidden`-паттерн (opacity 0 + pointer-events none) из career-portal — сохранить: нативный select остаётся в потоке для скринридера/форм;
- z-index списка — `--ui-z-dropdown`.
