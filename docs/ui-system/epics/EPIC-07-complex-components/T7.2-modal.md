# TASK T7.2 — ui-modal

## Epic

[EPIC-7 — Complex Components](README.md)

## Priority

P1

## Type

TASK

## Goal

Модальное окно с полной диалоговой доступностью: focus trap, Escape, восстановление фокуса, aria, блокировка скролла без сдвига макета — по решению ADR T7.1.

## Context

Перенос логики `directions.js` career-portal (класс B): сохранение lastFocused, открытие с фокусом на первый элемент/закрывающую кнопку, закрытие по transitionend, restore фокуса. Добавляется то, чего не было: trap, семантика диалога, регресс-защита от «остаточного padding» (кейс из design-qa career-portal).

## Scope

- `components/ui-modal/`: разметка по ADR (native `<dialog>` или ui-modal + role="dialog"/aria-modal);
  - размеры: `--sm / --md / --full`;
  - `ui-modal__close` (доступное имя «Закрыть»), `__title`, `__body`;
  - анимация open/close + reduced-motion;
- модуль `IraoUI.modal`: open(el, {…})/close(); trap (Tab/Shift+Tab цикл); Escape; restore фокуса на опенер; скролл-лок (scrollbar-gutter + padding-компенсация);
- API для сайтов: события `irao-ui:modal-open/close`; программное открытие по `data-ui-modal-target`.

## Out of scope

- Конкретные содержимые модалок (галерея направлений career-portal — контент сайта);
- вложенные модалки (проверить поведение по ADR, полноценной поддержки не обещаем — док-заметка);
- toast/alert-модалки без контента.

## Existing implementation

career-portal `src/blocks/directions/directions.js` — переносим фокус-паттерны; `.directions__modal*` CSS — визуальная база (оверлей, панель).

## Implementation requirements

1. Регресс-кейсы e2e (из design-qa career-portal): повторные open/close циклы — нет остаточного body-padding; фокус возвращается после каждого цикла; скролл-лок не сдвигает макет.
2. Инициализация статическая (data-атрибуты) — без JS модалка-триггер деградирует: контент доступен отдельной страницей/инлайн (правило доки).
3. `aria-labelledby` на диалоге → заголовок; `aria-hidden` фона — только если не native top-layer.

## Technical considerations

- Реализация по ADR T7.1 (native или собственный) — без отклонений;
- z-index (если собственный) — `--ui-z-modal`.
