# TASK T4.1 — ui-link

## Epic

## Priority

P0

## Type

TASK

## Goal

Компонент ссылок с вариантами и правилами особых случаев (внешние, файлы, анкоры), закрывающий вопрос «ссылка vs кнопка» документированным правилом.

## Context

В career-portal ссылки стилизованы глобально (`a { color: inherit; text-decoration: none }` + локальные hover) — для системы нужен явный компонент с токенами. Ссылка — семантический дефолт для навигации; кнопка — только для действий (do/don't в доке — частая ошибка интеграторов).

## Scope

- `components/ui-link/`: варианты — default (подчёркнутая при hover/всегда — фиксируется по бренду), `ui-link--on-dark` (для тёмных секций), `ui-link--button` (визуально кнопка, семантика ссылки — для «переход-выглядит-как-действие»);
- `ui-link__icon` (svg currentColor, aria-hidden);
- правила: внешние — `target="_blank" rel="noopener"` (html-validate-гейт), файлы — иконка+тип в доке, анкорные — плавный скролл опционально (reduced-motion уважается);
- стенд: варианты × состояния (default/hover/focus-visible/visited/active).

## Out of scope

- ui-button (T4.2);
- хлебные крошки (T4.7) и пагинация (T6.3) — свои компоненты, наследуют токены ссылок.

## Existing implementation

career-portal: глобальный `a` + `.breadcrumbs a:hover { color: var(--color-accent) }`, `.vac-card__company` — паттерн цветного hover; переносим идею, оформляем классом и токенами.

## Implementation requirements

1. Цвета/подчёркивание — только токены (`--ui-color-primary/accent/text-muted`, link-токены при необходимости — завести в semantic, если двумя сайтами понадобится различие).
2. `box-sizing` на корне (ADR-0002); hover — color-mix (T2.6) под `@media (hover: hover)`.
3. Ссылки без доступного имени (icon-only) — обязательный `aria-label`/визуально-скрытый текст (дока + html-validate предупреждение).

## Technical considerations

- `:visited` стилизуем минимально (только цвет) — приватность истории браузера ограничивает свойства;
- подчёркивание: `text-decoration-thickness/offset` из токенов — доступность (различимость) без магии.
