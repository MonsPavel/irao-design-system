# TASK T4.7 — ui-breadcrumbs + schema.org BreadcrumbList

## Epic

[EPIC-4 — Primitive Components](README.md)

## Priority

P0

## Type

TASK

## Goal

Хлебные крошки: перенос проверенного UX career-portal (горизонтальный скролл на мобиле), микроразметка BreadcrumbList, `aria-current="page"`, PHP-сниппет генерации в Bitrix-шаблоне.

## Context

`.breadcrumbs` career-portal: flex-wrap, fs-caption, muted-цвет, hover→accent, разделитель `/` (#C4CDDC → токен), на ≤767 — nowrap + overflow-x + скрытый скроллбар. `aria-current` в career-portal применялся в субнавигации — переносим на крошки. Schema.org BreadcrumbList — требование ТЗ №7 («там, где действительно уместно» — крошки первый кандидат).

## Scope

- `components/ui-breadcrumbs/`: разметка `nav[aria-label] > ol > li` (семантика упорядоченного списка), текущая страница — `span` + `aria-current="page"`;
- микроразметка: `itemscope itemtype="https://schema.org/BreadcrumbList"` + `itemprop position/name/item` (microdata — без JS, дружелюбно к Bitrix-шаблонам);
- адаптив: скролл-лента на md-;
- сниппет `bitrix/snippets/breadcrumbs.php` — генерация из массива `$arResult` (для `bitrix:menu` / цепочки навигации);
- дока: построение цепочки в шаблонах (вкл. случай «Главная → Раздел без ссылки → Текущая»).

## Out of scope

- Компонент `bitrix:breadcrumb` Битрикса (нативный существует) — сниппет показывает, как обернуть его вывод в ui-разметку или сгенерить свою цепочку;
- усечение длинных цепочек «…» (по потребности, паттерн описать в доке как расширение).

## Existing implementation

career-portal `components.css` `.breadcrumbs` + `build.py render_breadcrumbs` — переносим CSS-поведение и идею генерации; PHP-часть пишем с нуля.

## Implementation requirements

1. Микроразметка валидируется: автотест-парсер структуры (properties/itemtype) + разовая проверка Rich Results.
2. Разделитель — псевдоэлемент/`aria-hidden` span (не в тексте ссылок).
3. Скролл-контейнер доступен: свайп на touch, `scrollbar-width: none` с сохранением функциональности.

## Technical considerations

- ol-семантика даёт скринридеру «шаг N из M» бесплатно;
- `aria-label="Хлебные крошки"` на nav — конвенция из career-portal (его тесты её уже проверяли).
