## Goal

Карточка-основа с вариантами и паттерном «карточка-ссылка» (stretched link), доступным с клавиатуры и скринридера.

## Context

`.card` career-portal: bg surface, рамка #D6D6D6 → токен border, радиус card, `--hover` (рамка #B9C6DE + тень) и `--filled` (surface-muted). Проблема touch: hover-состояние «залипает» — переводим под `@media (hover: hover)`. Паттерн растянутой ссылки — из `.vac-card__title a:focus-visible::after` (единственный focus-паттерн career-portal).

## Scope

- `components/ui-card/`: база + модификаторы `--hover` (только hover-устройства), `--filled`;
- слоты: `ui-card__media` (место под T4.6), `__title`, `__body`, `__footer`;
- паттерн stretched link: контент-ссылка растягивается на карточку (`::after` с inset 0), фокус-обводка по всей карточке; правило: в карточке с stretched link остальные интерактивные элементы поднимаются `position: relative; z-index` (паттерн nested-interactive);
- стенд: варианты + карточка-ссылка с вложенной кнопкой.

## Out of scope

- Конкретные карточки (vac-card/event-card career-portal) — контентные, собираются сайтами из слотов (паттерны EPIC-8);
- карусели (P2).

## Existing implementation

career-portal: `.card`, `.card--hover`, `.card--filled`, `.vac-card__title a:focus-visible::after` — переносим с заменой hex на токены и hover-media-гвардом.

## Implementation requirements

1. Рамки/тени — токены (border-color, shadow-серия из T2.2).
2. Stretched link: доступное имя карточки = текст ссылки; вложенные интерактивы остаются достижимы (Tab-порядок и клик-зоны) — проверяется e2e.
3. `box-sizing` на корне и слотах с размерами.

## Technical considerations

- Тень hover — токен `--ui-shadow-md`;
- при 32px-масштабе карточка растёт по контенту (никаких фикс. высот — слоты на grid/флексе).
