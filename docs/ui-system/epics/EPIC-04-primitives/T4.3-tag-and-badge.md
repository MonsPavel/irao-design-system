# TASK T4.3 — ui-tag / ui-badge

## Epic

[EPIC-4 — Primitive Components](README.md)

## Priority

P0

## Type

TASK

## Goal

Перенос тегов career-portal (почти класс A) и добавление счётного badge с правилами доступности пустого значения.

## Context

`.tag` из career-portal: inline-flex, высота 28, pill-радиус, fs 12/fw 500, варианты blue/orange/green/gray/navy — готовая визуальная система, привязанная к hex → переводим на токены (пары bg/text уже есть в семантике статусов/тегов).

## Scope

- `components/ui-tag/`: варианты `--blue/--orange/--green/--gray/--navy` (bg+text из семантических пар токенов), слот `__icon` (точка-маркер, наследие `media__tag-dot` — как модификатор, если понадобится);
- `ui-badge` — счётчик (число в кружке): поведение при 0 (скрыт или `aria-hidden` — фиксируется докой), при переполнении (99+);
- стенд: все варианты; проверка читаемости в VI-темах (функциональная, T9.1).

## Out of scope

- Интерактивные теги-фильтры (`filter-tag` career-portal) — это чипы фильтрации, появятся с задачей списка (T8.1) как паттерн на базе ui-tag + button;
- анимации появления.

## Existing implementation

career-portal `components.css` `.tag*` и пары `--tag-*-bg/text` из `variables.css` — переносим структуру и значения (пары перепроверяет контраст-скрипт T2.3).

## Implementation requirements

1. Парные токены (bg+text) — в семантическом слое; новые пары проходят контраст-гейт автоматически.
2. `ui-badge`: `aria-hidden="true"` если значение продублировано текстом рядом; иначе — текст в имени (правило в доке).
3. `box-sizing` на корнях; размеры из шкалы.

## Technical considerations

- Тег — декоративная аннотация: не интерактивен по умолчанию (иначе это ссылка/кнопка);
- в VI-режиме перекраска `!important` накроет теги как все элементы — проверить в T9.1.
