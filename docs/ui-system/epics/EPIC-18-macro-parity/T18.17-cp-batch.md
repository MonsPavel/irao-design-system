## Priority

P2

## Type

TASK (паттерн-слой — свести cp-семейства к минимуму)

## Goal

Батч-вынос оставшихся мелких cp-семейств (после T18.10–T18.16): hero
(тон-строки поверх hro-канона), media-toolbar, offer-card, org-card,
event-card, events-feature, events-nav, article-card, intern-card,
intern-person, adv-grid, catalog-nav, vac-main, page, team, cta-mail.
Каждое семейство: вынос в слой (канон/расширение существующего) ИЛИ
аргументированная строка «тон-строка/позиция — остаётся сайт-зоне» в
судьбе семейств (REPORT §11.4-механика). Цель: allowlist ценза сократить
до позиционно-необходимого минимума.

## Context

По судьбе семейств (REPORT §11.4) часть из них — «тон-строки/позиции/
ритм поверх компонентов» (клампы, fw 400 даты, позиции сеток) — их
вынос в слой сомнителен; часть — контент-композиции (events-feature
«фича» лендинга, catalog-nav навигация каталога, offer-card целевое
обучение, org-card организация, adv-grid реклама, team секция) —
переиспользуемые. Разбивку «вынос/остаётся» решить в реализации,
каждое — одной строкой судьбы с аргументом.

## Scope

- patterns.css/доки: каноны для решённых «вынос» (имена по стыку —
  e.g. `evt-`/`ofc-`/`org-`/`cnv-`/`adv-`/`tm-`);
- build.mjs/pilot.css: cp-* → каноны (или сокращение cp-хуков);
- эталоны: по одному контейнерному на вынесенное семейство;
- ценз: allowlist сокращается, судьба каждого семейства — строкой.

## Out of scope

- production/directions/holding/company-*/why-us/tabs/page-head/
  vacancy-search/dir-modal — свои задачи (T18.10–T18.16).

## Implementation requirements

1. Тон-строки (color-mix тинты hero и т.п.) НЕ ехать в слой (прецедент
   T17.15: тон — сайт, вид — ДС) — судьба «остаётся» с аргументом;
2. Пиксель-нейтральность каждой страницы ±4px (пины по странице).

## Acceptance Criteria

- [ ] Allowlist ценза сокращён (число в примечании STATUS при
      закрытии); каждая судьба — строкой с аргументом;
- [ ] docHeight всех затронутых страниц ±4px (пины);
- [ ] Эталоны зелёные ×3; доки обновлены; гейты зелёные.
