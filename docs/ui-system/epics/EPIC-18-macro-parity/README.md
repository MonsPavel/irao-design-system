# EPIC-18 — Пиксель-паритет билда и макро-вынос ДС

## Goal

Свежий compare 04.11 (43 страницы × 2, оригинал = live Pages = локальный
D:\repositories\career-portal, все три на 8469ea6) показал: билд пилота
не даёт пиксель-паритет по двум классам причин — (1) **контентные дыры**:
целые блоки и секции не собираются `build.mjs` (company −3328px — половина
страницы; career-track −1475 — три секции; education −980; на главной нет
второй секции «Школьникам и студентам»; на index-2 лишняя секция why-us и
нет mentorship + vacancy-capsule ×2); (2) **макро-блоки не вынесены в ДС**:
30 cp-семейств сайт-зоны (pilot.css 1290 строк) живут в стыке стороны
сайта, хотя являются переиспользуемыми композициями. Эпик закрывает обе
линии: дособор билда до полной композиции оригинала и вынос макро-
компонентов в паттерн-слой/доки ДС — не только микро (кнопки/поля), но и
макро (секции, обложки, ленты, капсулы).

## Правила исполнения

- Канон значений — оригинал 1:1 (прецедент раундов 5–7: errata с
  источниками `*.css:строки`); решения-отклонения фиксировать в REPORT §8.
- В `## Dependencies` спек — только вышестоящие T-ID (урок 27.10:
  forward-упоминания создаёт ложные деп-блоки, validate-backlog циклы
  не ловит).
- После правок слоя — `npm run build` обязателен (dist/ui-patterns.css
  не пересобирается сам, урок 01.11).
- Пересъём эталонов — по списку диффов из артефакта CI, не по памяти
  (урок 31.10); docker-пересъём по протоколу sha-паритета ADR-0004.
- Ценз: новые паттерны слоя НЕ создают cp-семейств (гейт census.mjs);
  вынос семейства из сайт-зоны = строка в судьбе семейств (REPORT §11.4).
