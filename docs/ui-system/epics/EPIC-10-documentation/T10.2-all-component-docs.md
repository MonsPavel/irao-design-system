# TASK T10.2 — Доки всех компонентов по шаблону

## Epic

[EPIC-10 — Documentation](README.md)

## Priority

P1

## Type

TASK

## Goal

Довести страницы всех компонентов dist и всех паттернов до эталона T10.1; полнота — 100%.

## Context

Доки частично создаются в компонентных задачах (DoD), качество неравномерно. Задача — систематический прогон по чек-листу шаблона и закрытие пробелов (чаще всего страдают: edge-кейсы, do/don't, responsive-секция, Bitrix-заметки).

## Scope

- инвентаризация: список компонентов dist + паттернов ↔ список страниц showcase (проверка полноты);
- прогон чек-листа «страница = шаблон» по каждой; правки;
- заполнение недостающих секций (do/don't, edge-кейсы, миграционные заметки при deprecated);
- связность: перекрёстные ссылки между компонентами (button↔link, field↔form, modal↔overlay-паттерн).

## Out of scope

- Новые компоненты;
- перевод;
- туториалы для контент-менеджеров (кроме уже созданных чек-листов T4.6).

## Existing implementation

Черновики страниц — из компонентных задач; эталон — T10.1.

## Implementation requirements

1. Прогон оформить таблицей (компонент × секции) — приложить к PR.
2. Каждая правка доки — по фактическому поведению (проверка на стенде), не по памяти.

## Technical considerations

- Автопроверка полноты: сборочный скрипт «у каждого каталога components/* есть страница и наоборот».

## Dependencies

- [T10.1 — Шаблон](T10.1-docs-page-template.md)
- Компонентные эпики 3–8.

## Acceptance Criteria

- [ ] Чек-лист зелёный для 100% компонентов/паттернов; таблица прогона в PR;
- [ ] Автопроверка полноты в сборке;
- [ ] Перекрёстные ссылки работают (нет битых).

## Testing requirements

## Accessibility requirements
