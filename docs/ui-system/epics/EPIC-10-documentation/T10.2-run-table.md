# T10.2 — Таблица прогона «компонент × секции»

Приложение к PR задачи [T10.2](T10.2-all-component-docs.md) (Implementation requirements п.1).
Прогон чек-листа «страница = шаблон» (CONTRIBUTING) по всем компонентам dist
(26 компонентов + ui-vi) и паттернам. Значения колонок «Состояния / A11y / API /
Do-Dont / Extra» — README-блоки, из которых генератор showcase/docs-template.mjs
собирает секции док-страниц (один источник — README компонента). «Шаблон» —
машинная проверка сборки: selfChecks `npm run build` гоняет verifyDocPageHtml
(9 секций по порядку, сниппет = каноническому файлу, iframe 375/768/1440) и
brokenDocLinks («перекрёстные ссылки работают — нет битых») по каждой записанной
странице; полнота инвентаризации — docCompletenessProblems (юнит-пин
tests/unit/docs-completeness.test.js).
