# TASK T10.1 — Шаблон страницы компонента + 3 эталона

## Epic

[EPIC-10 — Documentation](README.md)

## Priority

P0

## Type

TASK

## Goal

Единый шаблон страницы компонента в showcase (живые примеры, копируемый HTML, состояния, responsive, a11y, API, do/don't, версия) и три эталонные страницы: button, field, modal.

## Context

Шаблон задан 02-architecture §8 (8 пунктов). Страницы рендерятся из файлов компонентов (T1.3) — дока не расходится с кодом. Эталоны выбираются так, чтобы покрыть три типа: CSS-only (button), CSS+разметка-паттерн (field), JS-компонент (modal).

## Scope

- шаблон-генератор showcase: секции страницы компонента (примеры → HTML-сниппет → состояния → responsive-стенд 375/768/1440 в iframe → a11y-заметки → API → do/don't → schema-заметка → версия/changelog);
- эталонные страницы: ui-button, ui-field, ui-modal — полное соответствие шаблону;
- чек-лист «страница = шаблон» (для T10.2 и ревью).

## Out of scope

- Доки остальных компонентов (T10.2);
- поиск по доке (нет требований; индекс-каталог достаточно).

## Existing implementation

career-portal: README-таблицы блоков — уровень «каталог», не доки; showcase-подход новый.

## Implementation requirements

1. Сниппет HTML на странице = фактическая разметка стенда (один источник — файл компонента).
2. Responsive-секция — реальные iframe-вьюпорты, не картинки.
3. A11y-секция: клавиатурная таблица + ARIA-атрибуты + чек-лист скринридера (из T9.2).

## Technical considerations

- Генерация — в build.mjs (T1.3), шаблон — декларативный (секция = блок компонентного README или метаданных);
- do/don't — подсветка «плохой» разметки (статический пример, не живой).
