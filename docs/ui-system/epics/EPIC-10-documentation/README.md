# EPIC-10 — Documentation

## Goal

Документация, по которой внешний разработчик подключает систему и собирает страницы без обращения к автору: showcase по единому шаблону, quickstart, integration guide, contribution.

## Context

Фаза 8. Доки пишутся вместе с каждым компонентом (DoD), здесь — шаблон, доведение до 100% и связность. Решение об Storybook — принято (не строим, статический showcase; пересмотр при >40 компонентах или росте команды — 02 §8). Storybook-задачи не создаются.

## Scope

- единый шаблон страницы компонента + 3 эталонные страницы;
- доведение всех компонентных док;
- quickstart + integration-guide + «Bitrix-разработчику за 30 минут»;
- contribution guide + ADR-журнал как процесс;
- incognito-тест (внешний разработчик по докам).

## Out of scope

- Storybook (решено);
- обучающие видео/воркшопы (вне репо);
- переводы (RU — рабочий язык).

## Expected outcome

100% компонентов dist имеют страницу по шаблону; quickstart воспроизводим инкогнито-тестом; contribution-процесс описан и подкреплён ADR-журналом.

## Dependencies

Компонентные эпики (3–7); T11.1 для integration-guide.

- [T10.2 — Доки всех компонентов по шаблону](T10.2-all-component-docs.md)

## Acceptance Criteria

- [ ] Чек-лист «страница = шаблон» зелёный для 100% компонентов dist;
- [ ] Incognito-тест пройден, все затыки закрыты правками доков;
- [ ] Сниппеты bitrix/ синхронны гайдам.

## Definition of Done

- [ ] Все 4 задачи закрыты
- [ ] Showcase полный: компоненты + паттерны + VI + integration
- [ ] CONTRIBUTING финализирован (процесс, чек-листы, ADR)

## Risks

- Расхождение доков и кода → дока рендерится из файлов компонентов (T10.1), ревью-гейт «изменил компонент — обнови страницу».
