# TASK T6.1 — ui-dropdown

## Epic

[EPIC-6 — Navigation & Interactive](README.md)

## Priority

P1

## Type

TASK

## Goal

Выпадающее меню двух назначений (навигация/действия) по паттерну APG menu-button: клавиатура, вне-клик, Escape с возвратом фокуса, деградация без JS.

## Context

Источник — `header.js` career-portal: toggle кнопки с aria-expanded/controls, закрытие по внешнему клику и Escape (с возвратом фокуса на триггер), простановка aria-current по URL. Система обобщает на N инстансов и два сценария: навигационное меню (ссылки) и меню действий (кнопки).

## Scope

- `components/ui-dropdown/`: `ui-dropdown` (обёртка) + `ui-dropdown__trigger` (button) + `ui-dropdown__menu` (список `role="menu"` или nav+ul — по назначению);
- модуль `IraoUI.dropdown`: открытие click/Enter/Space/ArrowDown; закрытие Escape (фокус на триггер), вне-клик, Tab-выход (закрытие — решение APG); стрелки внутри; aria-expanded/controls;
- деградация без JS: меню раскрыто (контент в DOM, `hidden` не ставится в разметке до инициализации);
- два стенда: навигационное (с aria-current по URL — хелпер в доке) и меню действий.

## Out of scope

- Комбинобокс с вводом текста (нет требований);
- подменю второго уровня (по потребности, APG submenu);
- hover-открытие (только клик/клавиатура — доступнее и проще).

## Existing implementation

career-portal `src/blocks/header/header.js` + `.header__dropdown*` CSS — переносим поведение (класс B): multi-instance, отрыв от классов шапки, generalization назначений.

## Implementation requirements

1. Инициализация по `data-ui-dropdown`; N инстансов; открытие одного закрывает другие (перенос closeAll).
2. Идентификация назначения: `role="menu"` + `menuitem` для действий; `nav > ul > li > a` для навигации (без menu-роли — правило доки: menu-роль только для командных меню).
3. `hidden` на меню ставит/снимает JS (разметка остаётся доступной без JS).

## Technical considerations

- z-index меню — `--ui-z-dropdown` из лестницы T2.2;
- позиционирование: абсолют от обёртки; коллизия с краем вьюпорта — доки-заметка (сайт решает модификатором).
