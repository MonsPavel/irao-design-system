# TASK T6.2 — ui-tabs

## Epic

[EPIC-6 — Navigation & Interactive](README.md)

## Priority

P1

## Type

TASK

## Goal

Табы по APG tabs pattern: roving tabindex, стрелки/Home/End, aria-selected/controls, панели tabpanel; без JS — все панели видимы.

## Context

Источник — `tracks.js` career-portal (карьерные треки): таб-кнопки с aria-selected и is-active, данные из `<script type="application/json">`, рендер панели. Система добавляет полный клавиатурный паттерн и деградацию.

## Scope

- `components/ui-tabs/`: `ui-tabs__list[role=tablist]` + `ui-tabs__tab[role=tab]` + `ui-tabs__panel[role=tabpanel]`;
- модуль `IraoUI.tabs`: roving tabindex (Tab у активного таба уходит в панель; стрелки/Home/End переключают, активация по Enter/Space или automatically — зафиксировать: automatic по APG-рекомендации для простых случаев);
- без JS: панели все видимы, табы — заголовки/ссылки (паттерн разметки в доке);
- стенд: статические табы + табы с данными из JSON-паттерна (Bitrix-кейс).

## Out of scope

- Вертикальные табы (модификатор — по потребности, док-заметка о стрелках ↑↓);
- swipe-жесты панелей.

## Existing implementation

career-portal `js/tracks.js` — переносим модель выбора/aria-selected; рендер из JSON оставляем как док-кейс (данные — зона сайта).

## Implementation requirements

1. Инициализация по `data-ui-tabs`; id-связки tab↔panel обязательны (html-validate).
2. Панель без активного таба — `hidden` ставит JS (не в разметке).
3. Клавиатура: ←→ (+↑↓ при вертикальном модификаторе), Home/End; цикличность.

## Technical considerations

- Активация automatic (фокус+выбор вместе) — проще для пользователей скринридеров в простых списках; выбор фиксировать в доке;
- z-index/подчёркивание активного таба — из токенов.
