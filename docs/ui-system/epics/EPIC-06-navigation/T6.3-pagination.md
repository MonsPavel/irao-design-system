# TASK T6.3 — ui-pagination

## Epic

[EPIC-6 — Navigation & Interactive](README.md)

## Priority

P1

## Type

TASK

## Goal

Перенос пагинации career-portal с доведением a11y: `aria-current="page"` на текущей, семантика disabled-стрелок, PHP-сниппет генерации в Bitrix-шаблоне.

## Context

`.pagination` career-portal: страницы 44×44 (touch-цель), стрелки, is-active текущая, disabled-стрелки через `[disabled]`. Пробел: текущая — ссылка без aria-current; disabled-стрелка — `[disabled]` на `<a>` невалиден семантически (атрибут действует только на button/input) — нужно решение: стрелка-кнопка или span + aria-disabled.

## Scope

- `components/ui-pagination/`: `ui-pagination` (nav aria-label) + `__page` + `__arrow` + `__ellipsis` («…»);
- правила: текущая — `span`/`a[aria-current="page"]` без href; стрелки недоступные — `span aria-hidden` + `aria-disabled` на обёртке или button[disabled] (решение фиксируется в доке, см. Open Questions → закрыть при реализации по APG);
- PHP-сниппет `bitrix/snippets/pagination.php` — генерация из массива страниц (для постраничной навигации Bitrix);
- стенд: полный/короткий/краевые (первая/последняя страница) варианты.

## Out of scope

- Infinite scroll/load-more (P2; load-more — тривиальный паттерн на ui-button, док-заметка);
- AJAX-пагинация (зона сайта).

## Existing implementation

career-portal `components.css` `.pagination*` — перенос (класс A): размеры 44px touch-целей, hover bg, is-active.

## Implementation requirements

1. Touch-цели ≥ 44×44 сохраняются (проверка e2e boundingBox).
2. `aria-current="page"` на текущей (тест).
3. Сниппет генерации: расчёт окна страниц с «…» — копипаст-готовый.

## Technical considerations

- nav aria-label="Пагинация" (или контекстное: «Навигация по страницам»);
- prev/next — доступные имена («Предыдущая страница»), не пустые стрелки.
