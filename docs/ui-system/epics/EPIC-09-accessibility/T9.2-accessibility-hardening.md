# TASK T9.2 — A11y hardening-спринт

## Epic

[EPIC-9 — Accessibility](README.md)

## Priority

P1

## Type

TASK

## Goal

Финальная гарантия доступности перед v1.0: ручной протокол скринридеров по каждому интерактивному стенду, forced-colors, ревизия контраста производных состояний, полный VI-прогон.

## Context

Автоматика (axe, клавиатурные e2e) работает с Iteration 0, но не покрывает: реальное поведение NVDA/VoiceOver, Windows High Contrast, контраст color-mix-производных (T2.6). Спринт закрывает разрыв между «axe=0» и «реально удобно с ассистивными технологиями».

## Scope

- forced-colors (Windows High Contrast): e2e с эмуляцией `forced-colors: active` — кнопки/поля/карточки не теряют границы (system colors / явные border);
- ручной протокол NVDA (Windows) + VoiceOver (Safari): матрица «стенд × сценарий» для всех интерактивных компонентов (dropdown/tabs/modal/select/формы/аккордеон/пагинация/VI); каждый сценарий: ожидаемое объявление vs фактическое;
- контраст-ревизия производных: hover/active color-mix ≥ 3:1 (крупные элементы) — расширение скрипта T2.3 или отдельный прогон;
- финальный VI-прогон всех стендов/паттернов (вкл. пилотные страницы, если T11.2 готов);
- отчёт с evidence (формат design-qa career-portal) + фиксы или ADR-исключения.

## Out of scope

- JAWS/Narrator (NVDA + VoiceOver — заявленный охват; расширение по потребности);
- автоматизация скринридеров (осознанно ручной протокол);
- локализация озвучки (RU-контекст).

## Existing implementation

career-portal: скринридер-тестов не было; формат evidence-отчёта — из design-qa.md.

## Implementation requirements

1. Матрица протокола заранее фиксируется (стенды × сценарии) — пустых ячеек не остаётся.
2. Каждое найденное нарушение → фикс-задача в этом же спринте или ADR-исключение с обоснованием.
3. Протокол прикладывается к релизному чек-листу (T12.1) как повторяемый артефакт.

## Technical considerations

- Эмуляция forced-colors в Playwright (`forcedColors: 'active'`) + ручная сверка на Windows;
- сценарии NVDA формулируются как «последовательность объявлений» — сравнимо между запусками.
