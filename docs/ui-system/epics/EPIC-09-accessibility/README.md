# EPIC-9 — Accessibility: VI-модуль и hardening

## Goal

VI-версия по ГОСТ Р 52872 как поставляемый модуль dist + финальный a11y-спринт: ручной протокол скринридеров, forced-colors, ревизия контраста производных состояний.

## Context

T9.1 — перенос одного из самых ценных ассетов career-portal (класс A аудита): панель настроек (размер шрифта sm/md/lg через zoom, 5 цветовых тем, картинки вкл/ч-б/выкл, межбуквенный интервал), localStorage-персистентность, агрессивная перекраска `!important`. T9.2 — hardening после закрытия всех интерактивных эпиков.

## Scope

- T9.1: порт vi.css/vi.js/vi-panel.html с префиксацией; отдельный dist-файл ui-vi.min.css; VI-страница showcase;
- T9.2: forced-colors, NVDA+VoiceOver протокол по всем интерактивным стендам, контраст-ревизия hover-производных, финальный VI-прогон.

## Out of scope

- VI-темы мульти-брендов (один бренд — Phase 0);
- автоматизация скринридеров (ручной протокол — осознанно);
- голосовая навигация.

## Expected outcome

VI-режим включается на любом стенде и на пилотных сайтах; все 5 тем × 3 размера работают; подписанный протокол скринридера; axe=0 по всем страницам.

## Dependencies

- T9.2: EPIC-6/7/8.
