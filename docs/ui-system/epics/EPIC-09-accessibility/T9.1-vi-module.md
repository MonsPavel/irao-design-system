# TASK T9.1 — Порт VI-модуля (ГОСТ Р 52872)

## Epic

[EPIC-9 — Accessibility](README.md)

## Priority

P0

## Type

TASK

## Goal

Перенести целиком (класс A аудита) версию для слабовидящих: панель настроек, режимы, localStorage — с заменой префиксов и ключа хранения; отдельным dist-файлом.

## Context

career-portal: `css/vi.css` (211 строк: панель, темы baw/wb/bb/beige/green через перекраску `!important` кроме панели и графики, zoom 1/1.2/1.45, letter-spacing, картинки off/gray, отключение анимаций), `js/vi.js` (state+localStorage 'vi-settings', apply с классами на body, aria-pressed-синхронизация всех кнопок, padding-top по фактической высоте панели), `src/blocks/vi/vi-panel.html`. Инвариант совместимости: ни один компонент системы не использует inline-стили (stylelint) — перекраска накрывает всё.

## Scope

- `a11y/vi.css` (панель → классы `ui-vi-*`; токены → `--ui-*`; темы/режимы — как есть) + `components/ui-vi/` (панель как компонент: vi-panel.html → ui-vi/);
- `IraoUI.vi` (порт vi.js): ключ localStorage → `irao-ui-vi` (career-portal не потребляет пакет — breaking допустим, зафиксировать в доке);
- сборка отдельного `dist/ui-vi.min.css` (не в ui-core — сайты подключают осознанно, кнопка входа — в header-паттерне T7.6);
- VI-страница showcase: все режимы × все темы;
- дока: как сайтам проверять свои страницы в VI (чек-лист).

## Out of scope

- Новые темы/режимы ГОСТ (переносим как есть);
- VI для мульти-брендов (Phase 0).

## Existing implementation

career-portal `css/vi.css`, `js/vi.js`, `src/blocks/vi/vi-panel.html` — перенос с рефакторингом имён; поведение — без изменений.

## Implementation requirements

1. Все поведения сохранить: сброс к дефолтам при входе, scrollTo(0) при включении, `padding-top` по offsetHeight панели, try/catch localStorage.
2. `!important`-слой остаётся единственным в системе (stylelint-разрешение только для a11y/vi.css — уже в T1.2).
3. Unit-тесты чистой логики состояния (parse/apply/save/merge-defaults).

## Technical considerations

- Порядок подключения: ui-vi.min.css последним (после core и CSS сайта) — уточнить в сниппете T11.1;
- zoom в масштабе типографики: работает (стандартизован), протокол проверки при обновлении браузеров — в чек-лист.
