# TASK T3.5 — ui-skip-link

## Epic

[EPIC-3 — Base & Typography](README.md)

## Priority

P0

## Type

TASK

## Goal

Клавиатурный переход к основному контенту («перейти к содержимому») на каждой странице системы — закрытие пробела аудита career-portal.

## Context

Аудит §6: skip-link в career-portal отсутствует — первый Tab попадает в меню. Для WCAG 2.4.1 и работы с клавиатуры на тяжёлых шапках Bitrix это первый по важности паттерн. Цель перехода — `#main` / `[data-ui-main]`.

## Scope

- компонент `ui-skip-link`: визуально скрыт до фокуса, при фокусе — фиксированная плашка (z-index из лестницы);
- включён по умолчанию в каркас showcase (T1.3) и в bitrix-сниппет header.php (заготовка T11.1);
- правило для сайтов: цель существует (валидация каркаса).

## Out of scope

- Дополнительные skip-цели (к поиску/меню) — по потребности сайтов, паттерн расширяется тривиально;
- отдельная страница showcase (стенд — часть каркаса).

## Existing implementation

career-portal: отсутствует (класс D аудита — фундамент есть в виде understanding, реализации нет).

## Implementation requirements

1. Классика visually-hidden-until-focus: вне фокуса — 1px-клип, в фокусе — видимая плашка top-left.
2. Цель: `href="#main"` + гарантия `#main` в каркасе; фокус переносится реально (tabindex=-1 на цели не обязателен, но проверить поведение браузеров — Safari-кейс).
3. Первый Tab на любой странице showcase попадает в skip-link (e2e).

## Technical considerations

- z-index плашки — `--ui-z-overlay`-уровня из лестницы T2.2;
- в VI-режиме (EPIC-9) skip-link обязан оставаться видимым и контрастным (VI перекраска его накрывает как обычный элемент).
