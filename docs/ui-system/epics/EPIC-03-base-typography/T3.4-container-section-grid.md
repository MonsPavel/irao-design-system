# TASK T3.4 — Container / Section / Grid (mobile-first)

## Epic

[EPIC-3 — Base & Typography](README.md)

## Priority

P0

## Type

TASK

## Goal

Layout-примитивы системы: контейнер с паддингами по брейкпоинтам, секция, адаптивная сетка карточек — переписанные с desktop-first career-portal на mobile-first по шкале T2.5.

## Context

Источники: `.container` (base.css: max-width 1440, pad 40/32/24/16 по max-width-медиа), `.section` + `.section--gray` (components.css), `.cards-grid--2/3/4` (pages.css: 4→3 на 1279, →2 на 1023, →1 на 734). Пересборка на min-width: базовые значения = мобильные, рост к xl/2xl.

## Scope

- `ui-container`: max-width из `--ui-container-max`, паддинги 16 → 24 (md) → 32 (lg);
- `ui-section` (+ `--muted`: фон surface-muted + радиус big) и вертикальные ритмы из spacing-токенов;
- `ui-grid` c модификаторами `--2/--3/--4`: 1 колонка на mobile → 2 на md → N на lg (поведение career-portal: 4→3 на xl);
- запрет фиксированных высот; проверка на 320px.

## Out of scope

- `form-grid` (T5.4), aside-раскладки (EPIC-8);
- CSS-Grid-утилиты общего назначения (только конкретные модификаторы сетки).

## Existing implementation

career-portal: см. Context; переносим значения (паддинги, gap 36/24, поведения колонок), инвертируя подход в mobile-first.

## Implementation requirements

1. Все размеры — только из токенов (spacing/container); gap из шкалы.
2. Поведение `--4`: 1 (mobile) → 2 (md) → 3 (xl) → 4 (2xl) — сверить с фактическим поведением career-portal на макетных вьюпортах.
3. `box-sizing` на корнях (ADR-0002).

## Technical considerations

- `minmax(0, 1fr)` в колонках (защита от переполнения длинным словом);
- проверка `scrollWidth === clientWidth` на 320/375/768/1024/1440 (перенос проверки из design-qa career-portal в автотест).

- e2e overflow-сценарии;

## Accessibility requirements

- Сетка не порождает порядок чтения, отличный от DOM (одноколоночный мобильный = порядок DOM);
- контейнер не обрезает focus-обводки (outline-offset за пределами паддинга не нужен — паддинг ≥ 16).
