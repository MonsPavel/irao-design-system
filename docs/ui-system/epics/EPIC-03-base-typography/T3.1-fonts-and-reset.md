# TASK T3.1 — Шрифты Golos и reset (порт из career-portal)

## Epic

[EPIC-3 — Base & Typography](README.md)

## Priority

P0

## Type

TASK

## Goal

Перенести проверенный в проде фундамент career-portal: 6 @font-face Golos Text с cyr/lat-сплитом и безопасный reset; довести до системных требований (box-sizing-дисциплина, preload-сниппет, лицензия).

## Context

Класс A аудита: разбивка cyr/lat через `unicode-range` + `font-display: swap` даёт скорость и кириллическую полноту; preload только 400/500 cyr (90% русской страницы). Reset-правила career-portal безопасны глобально: `[hidden] { display: none !important }`, `scrollbar-gutter: stable`, `img { display: block; max-width: 100% }`, ресет отступов, глобальный `prefers-reduced-motion` kill-switch.

## Scope

- `base/fonts.css`: 6 @font-face (перенос без изменений) + копия woff2 в `dist/fonts/` + текст лицензии Golos (SIL OFL) рядом;
- `base/reset.css`: правила выше + `*, *::before, *::after { box-sizing: border-box }` (глобально);
- preload-сниппет (golos-400-cyr, golos-500-cyr) в каркас showcase и в заготовку bitrix-сниппета;
- правило ADR-0002 в CONTRIBUTING: компонент объявляет свой box-sizing.

## Out of scope

- Фолбэк-шрифты темы (уже в стеке `--ui-font-family`: Golos Text, Arial, Helvetica Neue, sans-serif — T2.2);
- типографика-классы (T3.3), контейнер (T3.4).

## Existing implementation

career-portal: `css/base.css` (строки 1–58 — @font-face и reset) и `assets/fonts/golos-{400,500,600}-{cyr,lat}.woff2` — переносим файлы шрифтов как есть; @font-face — как есть; url() путей адаптируем под структуру dist.

## Implementation requirements

1. `font-display: swap` и `unicode-range`-значения — побайтово из career-portal (они выверены).
2. Проверить наличие/положить `OFL-LICENSE.txt` в `assets/fonts/` и `dist/fonts/`.
3. При отсутствии шрифта страница обязана быть читаемой (Arial-фолбэк) — e2e-сценарий с блокировкой шрифта.

## Technical considerations

- Относительные url() из `base/fonts.css` должны работать и из исходников, и из dist (структура повторяется — T1.3);
- `scrollbar-gutter: stable` предотвращает сдвиг сетки при появлении скролла (урок career-portal).
