# TASK T3.3 — Типографика: классы ui-h1…ui-micro и текстовый минимум

## Epic

[EPIC-3 — Base & Typography](README.md)

## Priority

P0

## Type

TASK

## Goal

Типографическая шкала как API (классы ролей), текстовые элементы и списки — в rem; SEO-правила заголовков исполняются валидатором на всех страницах showcase.

## Context

Шкала уже в токенах (T2.2, тройки fs/lh/fw + letter-spacing из макета career-portal: заголовки −0.02em). Нужны классы для контентных областей (в шаблонах Bitrix заголовки выводятся классами, т.к. теги стилизуются legacy) и element-минимум (body-шрифт/цвет). Правило: компоненты не зависят от element-стилей (ADR-0002) — base задаёт только разумный дефолт страницы.

## Scope

- `base/typography.css`: классы `ui-h1…ui-h6, ui-lead, ui-body, ui-small, ui-caption, ui-micro, ui-text--muted`;
- списки `ui-list` (маркеры/отступы), `ui-address`-минимум;
- body-дефолты (font/color/bg из токенов);
- html-validate/e2e-правило иерархии: один h1, h2→h3 без пропусков (перенос идеи `test_internship_headings.py` career-portal);
- стенд типографики (все роли × брейкпоинты).

## Out of scope

- Классы выравнивания/трансформации (утилиты общего назначения не строим — ADR-0005, анти-utility-framework);
- контентная типографика статей (EPIC-8, паттерн detail page).

## Existing implementation

career-portal: тройки из `variables.css` + media-переопределения размеров; letter-spacing заголовков −0.02em (`page-title`, `section__title`) — переносим значения, пересчитанные в rem (T2.2).

## Implementation requirements

1. Класс роли задаёт fs/lh/fw/letter-spacing целиком (не по частям).
2. Иерархия h1→h2→h3 проверяется на всех showcase-страницах (падение — ошибка валидации).
3. Стенд типографики: каждой роли — образец + значения токенов; переносы длинных слов (RU-тексты) не рвут макет.

## Technical considerations

- Классы, а не теги — главная защита от legacy `h1 { … }` сайтов (специфичность класса против тега);
- `text-wrap: pretty/balance` не используем до появления в матрице — фиксируем как потенциальное minor-улучшение.
