## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

## Type

TASK

## Goal

Закрыть эпик проверкой на живом сайте: пересобрать пилотный клон
career-portal на обновлённых компонентах, прогнать сравнение с оригиналом,
подтвердить закрытие систематических расхождений REPORT §3 (или
задокументировать остатки).

## Context

Эпик менял цвет/роли заголовков, кнопки (паддинг + пилюля), поля, крошки в
паттернах, добавлял ui-chip/ui-tabs--pill/паттерны строк-сайдбара-таймлайна.
Пилот (pilot/career-portal) собран на старых компонентах — его разметка
начнёт использовать новое API (ui-page-title, ui-chip, ui-button--pill,
ui-tabs aria-current) и сверка покажет фактический остаток расхождений.

## Scope

- pilot/career-portal/build.mjs: разметка переходит на новое API — h1 страниц
  → ui-page-title; CTA строк/деталок → ui-button--pill; чипы → ui-chip
  (cp-chip и его JS удаляются); табы стажировок → ui-tabs--pill +
  aria-current (ручной select в pilot.js снимается); тинты cp-* → токены
  T14.7 (где совпадают);
- node pilot/career-portal/build.mjs + node pilot/career-portal/compare.mjs:
  свежие compare-output (скриншоты, метрики);
- pilot/career-portal/REPORT.md: обновить §3 — по каждой probe-паре статус
  («закрыто задачей T14.x» / «принято ДС, mapping-строка» / остаток);
- pilot/career-portal/PLAN.md: пометить выполненные пункты;
- гейты: lint (pilot-исходники линтятся), npm run build ДС зелёный.

## Out of scope

- Новые калибровки (остатки расхождений фиксируются в REPORT как кандидаты
  следующего эпика/бэклога, НЕ правятся в этой задаче);
- Лендинг-блоки P2 (вне эпика);
- Коммит артефактов compare-output (gitignored — остаются локально).

## Existing implementation

pilot/career-portal (пилот 20.10): build.mjs/compare.mjs/pilot.css/pilot.js;
протокол сравнения — README пилота.

## Implementation requirements

1. Пилот требует ассетов оригинала: build.mjs --ref <путь-к-чекауту>; если
   эталонного чекаута нет рядом — сравнительная часть выполняется на
   последнем compare.json с пометкой, пересборка — blocked с причиной
   (честный blocked вместо имитации).
2. Гейты реализатора: npm run lint + npm run build (всё, что трогается —
   пилот-исходники).

## Technical considerations

- pilot.css/ds-рантайм не редактируются вручную в dist — только исходники и
  пересборка;
- cp-vac-row остаётся сайт-зоной (строки — паттерн для dist-потребителей,
  пилот может использовать связку паттерна по образцу T14.10);
- в REPORT обновить и «Ограничения», если методика изменилась.

axe-пробой одной страницы пилота (vacancies) при наличии эталонного чекаута.
