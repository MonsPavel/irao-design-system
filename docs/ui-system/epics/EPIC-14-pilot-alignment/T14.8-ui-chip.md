# TASK T14.8 — Компонент ui-chip (интерактивный фильтр-чип)

## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

P1

## Type

TASK

## Goal

Закрыть самую частую дыру компонентной базы: интерактивные пилюли-фильтры
(.chip оригинала, 4+ страниц — вакансии, стажировки, медиа, поиск мероприятий).
Сейчас README ui-tag обещает «кликабельные чипы — паттерн T8.1 на базе
ui-tag + button», но паттерна нет — пилот собрал самодельный cp-chip с JS
(REPORT §4, PLAN P1-1).

## Context

Чип — интерактивная аннотация-фильтр: кнопка (клиентская фильтрация) или
ссылка (GET-фильтр), активное состояние (выбранный фильтр). Отличия от
соседей: ui-tag — декоративный span (не интерактивен), ui-dropdown — меню.
JS-модуль не нужен: состояние active приходит из разметки/сервера (как
aria-current в ui-breadcrumbs), клики — нативные.

## Scope

- components/ui-chip/ui-chip.css: пилюля 36px (fs-small, fw-small), состояния
  default/hover/active; активный — заливка primary + text-on-dark (как
  .chip.is-active оригинала); фокус — base/focus.css;
- components/ui-chip/ui-chip.html: канонический паттерн — группа чипов:
  кнопочная форма (aria-pressed, клиентский фильтр) и ссылочная (GET,
  aria-current="page" на активной);
- components/ui-chip/README.md: API, «когда ui-chip vs ui-tag vs ui-dropdown»,
  правило активного состояния (aria-pressed у кнопки / aria-current у ссылки,
  НЕ класс без ARIA), no-JS-деградация (ссылки работают, кнопки сабмитят форму);
- showcase/build.mjs: строка в COMPONENTS (CSS в dist) — добавление компонента
  = одна строка по конвенции сборщика;
- showcase/pages/ui-chip/index.html: расширенный стенд (обе формы, группы,
  длинные RU-подписи, active-состояния);
- showcase/docs/ui-chip.mjs: метаданные док-страницы (шаблон T10.1);
- tests/unit/chip.test.js: пины классов/состояний разметки (если юнитам есть
  что пинить без JS-модуля — иначе поверхность e2e/axe);
- tests/e2e/chip.spec.js: axe, клавиатура (Tab/Enter), активное состояние;
- эталоны стенда (4 вьюпорта) в контейнере (ADR-0004);
- CHANGELOG.md: строка (новый компонент).

## Out of scope

- JS-модуль переключения (клиентская логика фильтра — зона сайта; паттерн
  list-page покажет связку в T14.10);
- Multi-select-семантика (список выбранных фильтров — потребность будущих
  паттернов; зафиксировать в README «границы»).

## Existing implementation

Компонентов-аналогов нет; ближайшие: ui-tag (декоративный), ui-pagination
(touch-цели 44px — прецедент габаритов).

## Implementation requirements

1. Контраст активного/дефолтного состояний — в гейт test:contrast (новые пары).
2. Эталоны переснимаются ТОЛЬКО в контейнере (ADR-0004).
3. Разметка паттерна проходит lint:html и axe на стенде.

## Technical considerations

- min-height 2.25rem (36px) — визуал оригинала; touch-правило: чипы в группах
  с gap — суммарная цель; при ревью зафиксировать решение (прецедент
  ui-pagination 44px vs плотный визуал — осознанный компромисс с README);
- кнопочная форма: type="button" по умолчанию (гейт no-implicit-button-type);
- именование по БЭМ ui-chip__*, модификатор активного — aria-атрибут, не класс
  (класс может дублировать для стиля: [aria-pressed="true"]-селектор).

цветом (WCAG 1.4.1); touch-цель — решение с фиксацией (см. Technical
considerations); фокус-обводка — глобальная политика ADR-0001.
