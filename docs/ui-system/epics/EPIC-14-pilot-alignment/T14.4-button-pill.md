# TASK T14.4 — ui-button--pill: пилюля со стрелкой

## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

P0

## Type

TASK

## Goal

Добавить модификатор «пилюля со стрелкой» — самый частый CTA оригинала
(«откликнуться →», «подробнее →», .pill-btn): компактная пилюля h44, фон
surface, рамка 1px, круглая иконка-стрелка в акценте. Пилот заменял её
ui-button--outline (h52, рамка 2px) — CTA тяжелее и неузнаваемее макета
(REPORT §3.3).

## Context

Оригинал .pill-btn (components.css + build.py pill_btn): label + круглый
икон-слот (32px кружок, фон accent, стрелка белая); геометрия: height 44,
padding 0 6px 0 20px, фон white, рамка 1px border, hover — фон blue-50.
Паттерн карточки-ссылки и строки списка (T14.10) ставят этот CTA.

## Scope

- components/ui-button/ui-button.css: модификатор `ui-button--pill` —
  min-height 2.75rem (44px, прецедент touch-токена пагинации), компактный
  inline-паддинг, фон surface, рамка --ui-border-width --ui-border-color;
  иконка-слот: кружок 2rem, фон --ui-color-accent, цвет text-on-dark —
  компоновка через существующий ui-button__icon (без нового элемента), hover
  фон surface-hover; совместимость с `ui-button--sm` (32px — действующий
  sm-токен --ui-button-height-sm; errata 25.10: исходная скобка писала
  «36px версия», токена 36px в системе нет — реализация шла по 32px);
- components/ui-button/ui-button.html: демо модификатора (лейбл + svg-стрелка);
- components/ui-button/README.md: раздел модификатора (когда: CTA строки/
  карточки-ссылки; границы: обычные действия — базовые варианты);
- токены: новые значения (44px, кружок) — с провенанс-комментариями в
  semantic.css (секция кнопки), вне шкалы — «как есть»;
- tests/unit/button.test.js: пины геометрии pill/base/sm (TDD);
- e2e/axe стенда кнопки зелёные; эталоны в контейнере (ADR-0004);
- CHANGELOG.md: строка (новый модификатор — расширение API).

## Out of scope

- JS-поведение (не требуется: модификатор чисто визуальный);
- Изменение базовых вариантов кнопки (T14.3);
- Иконочные кнопки без лейбла (отдельная потребность, в бэклог).

## Existing implementation

components/ui-button (T4.2): варианты primary/accent/outline/light, размеры
md/sm, слоты __label/__icon/__spinner.

## Implementation requirements

1. TDD: пины геометрии модификатора до правок CSS.
2. Эталоны переснимаются ТОЛЬКО в контейнере (ADR-0004).
3. Разметка демо — по канону слотов, иконка aria-hidden.

## Technical considerations

- Кружок иконки — на __icon (existing), не отдельный элемент: доступное имя
  кнопки остаётся «лейбл»;
- hover только на hover-устройствах (гвард компонента уже есть);
- радиус наследует --ui-radius-pill (пилюля) — не новый токен.

## Dependencies

- T14.3 — тот же компонент (css/токены/эталоны): порядок исключает конфликт
  веток и двойной пересъём.

текст pill — primary на surface (как outline), стрелка белая на accent —
проверить пин контраст-гейта (accent/text-on-dark пара уже в гейте T2.3).
