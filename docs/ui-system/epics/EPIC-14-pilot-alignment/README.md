# EPIC-14 — Калибровка и недостающие сущности по пилоту career-portal

## Goal

Закрыть систематические расхождения компонентов irao-ui с одобренным визуалом
career-portal и добавить недостающие сущности, выявленные пилотным переносом
сайта на компоненты системы (пилот 20.10: `pilot/career-portal/`,
отчёт [REPORT.md](../../../../pilot/career-portal/REPORT.md),
план [PLAN.md](../../../../pilot/career-portal/PLAN.md)).

## Context

Пилотный клон career-portal (12 страниц, только ui-компоненты + сайт-зона)
сравнили с оригиналом машинно (computed-стили probe-пар, высоты блоков,
скриншоты). Систематика различий и перечень сущностей без аналога — в REPORT;
приоритизированный план — в PLAN. Pages-деплой оригинала актуален (сверка
live-CSS с main 8469ea6, 20.10); «48px против 52px» у поля — компактный
вариант форм-модалок оригинала, не отставание (REPORT §2, ограничение (г)).

Решение владельца 20.10 («сделай эпик с задачами, чтоб ночной цикл мог
подхватить их сразу»): план становится эпиком конвейера. Канон визуальных
значений — **текущий main career-portal**; расхождения, где значение ДС
осознанное (AA-замены T2.3) или микроскопическое (≤4px), НЕ переписываются —
фиксируются в таблице диффов
[docs/ui-system/architecture/tokens-career-portal-mapping.md](../../architecture/tokens-career-portal-mapping.md).

## Scope

- T14.1: P0 — цвет заголовков: токен `--ui-color-heading` + роли ui-h1…ui-h6;
- T14.2: P0 — роль «заголовок страницы» (`ui-page-title`, вид fs-h2 при теге h1);
- T14.3: P0 — ui-button: горизонтальный паддинг 28px (токен «как есть»);
- T14.4: P0 — ui-button--pill: пилюля со стрелкой (h44, круглый icon-слот);
- T14.5: P0 — вертикальный ритм крошек в page-паттернах;
- T14.6: P0 — ui-field: горизонтальный паддинг 1.25rem + дифф-таблица микрорасхождений (карточка/модалка/тег — принято ДС);
- T14.7: P2 — тинт-токены производных primary (a10/a26) для стеклянных плашек сайт-зон;
- T14.8: P1 — компонент ui-chip (интерактивный фильтр-чип: кнопочная и ссылочная формы);
- T14.9: P1 — ui-tabs: вариант --pill + начальный выбор из разметки (aria-current на табе);
- T14.10: P1 — паттерн list-page: ветки «строки» и «сайдбар фильтров»;
- T14.11: P1 — паттерн «таймлайн этапов» (patterns/timeline);
- T14.12: закрывающая — пересборка пилота и сверка с оригиналом после калибровок (compare.mjs), обновление REPORT/PLAN.

## Out of scope

- P2 лендинг-блоки главной (hero, карусель, directions, holding, employers,
  why-us, students, video, media, cta-mail) — PLAN §P2; отдельный эпик по мере
  появления вторых потребителей (другие сайты группы), пока живут в сайт-зоне
  пилота (`pilot/career-portal/pilot.css`);
- Пересмотр AA-замен T2.3 (например, tag-orange #A94710) — design-decision
  зафиксирован, не дефект (REPORT §3.3);
- Пилоты EPIC-11 (T11.2–T11.4) — остаются `blocked` по решению владельца 10.10.

## Risks

- T14.1 меняет цвет заголовков почти на всех стендах — самый широкий пересъём
  эталонов эпика; исполнять первой, чтобы последующие задачи переснимали уже
  новый цвет;
- Токены-значения (T14.3/T14.6) меняют визуал поставки v0.1.0 — минорная
  версия: строка в CHANGELOG в каждой задаче; отдельный релиз — решение
  владельца после закрытия эпика;
- ui-chip (T14.8) — новый компонент: габарит M, риск дрейфа в «ещё один тег» —
  границы с ui-tag (декоративный) и ui-dropdown прописаны в задаче.
