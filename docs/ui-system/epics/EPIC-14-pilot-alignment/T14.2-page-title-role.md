# TASK T14.2 — Роль «заголовок страницы» (ui-page-title)

## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

P0

## Type

TASK

## Goal

Дать внутренним страницам h1 вида fs-h2: в career-portal .page-title — 60px
(fs-h2) при теге h1; в ДС единственная h1-роль ui-h1 — 80px, из-за чего
заголовки страниц клона на треть крупнее оригинала (REPORT §3.2, probe
page-title 66→88px высотой).

## Context

Оригинал: `.page-title { font-size: var(--fs-h2); font-weight: var(--fw-h2);
line-height: var(--lh-h2); letter-spacing: -0.02em; }` при семантическом h1.
Шкала ДС mobile-first: ui-h1 2.125→3→5rem; «рост к lg» T2.2 — менять лестницу
нельзя, нужна роль-псевдоним вида h2. Правило T3.3 «класс роли задаёт fs/lh/fw
целиком» — новая роль самостоятельна, не «ui-h1 + модификатор».

## Scope

- base/typography.css: новая роль `ui-page-title` — тройка fs/lh/fw от h2 +
  letter-spacing −0.02em + color: var(--ui-color-heading); mobile-first
  (значения читают те же токены --ui-fs-h2/…, media в классе нет);
- tests/unit/typography.test.js: пины тройки + letter-spacing + цвета (TDD);
- tests/e2e/typography.spec.js и стенд showcase/pages/typography/index.html:
  роль в матрице ролей (computed-пины на 4 вьюпортах);
- page-паттерны: patterns/list-page, patterns/detail-page, patterns/form-page —
  h1 page-head меняет `ui-h1` на `ui-page-title` (+ их эталоны);
- docs/ui-system/architecture/typography-roles.md: строка роли «когда какую»
  (заголовок страницы списка/детальной/формы);
- CHANGELOG.md: строка (новая роль — расширение API).

## Out of scope

- Цвет заголовков (T14.1);
- Лендинг-страницы: у главной h1 hero остаётся ui-h1 (крупный приветственный
  заголовок — так и в оригинале: hero__title 64px).

## Existing implementation

base/typography.css (T3.3): роли ui-h1…ui-micro; page-паттерны T8.1–T8.3
используют ui-h1 в page-head.

## Implementation requirements

1. TDD: юнит-пины новой роли — до правок CSS.
2. Эталоны переснимаются ТОЛЬКО в контейнере (ADR-0004): затронуты стенд
   typography и три page-паттерна.
3. Гейт irao/heading-order и один-h1 — не трогаются: роль не меняет теги.

## Technical considerations

- Имя роли `ui-page-title` (перенос .page-title как есть); альтернатива
  «модификатор ui-h1--page» отвергнута правилом «роль задаёт тройку целиком»;
- letter-spacing: −0.02em — перенос макета, как у заголовочных ролей.

## Dependencies

- T14.1 — общий файл base/typography.css и общий цвет --ui-color-heading;
  порядок исключает двойной пересъём эталонов typography-стенда.

инвертируется: на страницах с ролью секционные заголовки остаются ui-h2/ui-h3.
