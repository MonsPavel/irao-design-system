# TASK T14.1 — Цвет заголовков: токен --ui-color-heading + роли

## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

P0

## Type

TASK

## Goal

Вернуть заголовкам корпоративный тёмно-синий career-portal: роли ui-h1…ui-h6
сейчас наследуют --ui-color-text (#1F1F1F), а в одобренном макете все
заголовки — #002856 (--color-primary). Крупнейший единичный сдвиг визуальной
идентичности, найденный пилотом (REPORT §3.1).

## Context

Пилот career-portal (REPORT §3.1): на каждой странице клона заголовки
«чернее» оригинала. base/typography.css не задаёт цвет ролям — цвет наследуется
от body (--ui-color-text). Контраст #002856 на белом 12.4:1 (AAA), риска
доступности нет, но цвет обязан пройти test:contrast во всех темах и на
muted-фонах — пин гейта.

## Scope

- tokens/semantic.css: новый токен `--ui-color-heading: var(--ui-color-primary)`
  (секция «Текст», комментарий-провенанс career-portal: page-title/section__title
  color: var(--color-primary); решение владельца 20.10 — канон main);
- base/typography.css: `color: var(--ui-color-heading)` в ролях ui-h1…ui-h6
  (ui-lead/ui-body/ui-small/ui-caption/ui-micro не трогаются);
- themes/*.css: проверить темы — если тема переопределяет --ui-color-primary,
  заголовки едут за ней автоматически; контраст-гейт во всех темах зелёный
  (npm run test:contrast);
- tests/unit/typography.test.js: пины цвета ролей (до правок, TDD);
- docs/ui-system/architecture/typography-roles.md и base/README.md: правило
  «заголовочные роли несут --ui-color-heading; override — осознанный»;
- docs/ui-system/architecture/tokens-career-portal-mapping.md: строка токена;
- CHANGELOG.md: строка (визуальное изменение поставки).

## Out of scope

- Роль заголовка страницы (T14.2);
- Цвета тёмных секций (on-dark заголовки — зона сайта/лендинг-паттернов).

## Existing implementation

base/typography.css (T3.3): роли без color; tokens/semantic.css секция «Текст».

## Implementation requirements

1. TDD: юнит-пины computed-color ролей — до правок CSS.
2. Эталонные PNG переснимаются ТОЛЬКО в контейнере (ADR-0004) по протоколу
   sha-паритета: изменение затрагивает почти все стенды (заголовки везде).
3. Контраст: npm run test:contrast зелёный на дефолте и всех темах.

## Technical considerations

- Токен ссылается на --ui-color-primary (alias, не дубликат hex — гейт «hex
  только в primitives»);
- темы наследуют через alias — отдельных theme-правок не ожидается, но
  проверить тему с отличным primary (если есть) на контраст заголовков.
