# TASK T14.5 — Вертикальный ритм крошек в page-паттернах

## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

P0

## Type

TASK

## Goal

Дать хлебным крошкам вертикальный ритм страницы: в career-portal крошки несут
полосу 62px (padding 20px сверху / 24px снизу), ui-breadcrumbs плоские (18px) —
на клоне контент «прилипает» к шапке (REPORT §3.3, probe breadcrumbs
62→18px).

## Context

Компонент ui-breadcrumbs (T4.7) сознательно без внешних отступов — ритм
страницы собирал сайт. Пилот показал: без правила ритма каждый потребитель
теряет его. Page-паттерны (T8.1–T8.3) — эталонные сборки — обязаны нести ритм
сами: тогда правило «ритм крошек — у паттерна страницы» копируется вместе со
сборкой.

## Scope

- patterns/list-page/list-page.html, patterns/detail-page/detail-page.html,
  patterns/form-page/form-page.html: обвязка крошек в связках паттернов
  (padding-block от --ui-space-токенов, значения оригинала: 20/24 → 1.25rem/
  1.5rem с провенанс-комментарием в связке);
- patterns/*/README.md всех трёх: правило «крошки без обвязки — над контентом;
  ритм несёт шаблон» + сниппет обвязки;
- components/ui-breadcrumbs/README.md: Do/Don't — ритм задаёт шаблон
  (перекрёстная ссылка на паттерны), компонент отступов не получает;
- tests/e2e паттернов: пин отступов (или визуальный эталон — достаточно);
- эталоны трёх паттернов переснимаются в контейнере (ADR-0004).

## Out of scope

- Изменение CSS компонента ui-breadcrumbs (осознанно: инвариант T4.7);
- Мобильная лента крошек (уже в компоненте).

## Existing implementation

components/ui-breadcrumbs (T4.7); patterns list/detail/form-page (T8.1–T8.3):
крошки стоят в начале сборки без обвязки.

## Implementation requirements

1. Значения — токены --ui-space-*, 1.25rem вне шкалы (как T14.3/T14.6 —
   допускается перенос «как есть» с провенанс-комментарием, если на шкале
   нет 20px).
2. Эталоны переснимаются ТОЛЬКО в контейнере (ADR-0004).

## Technical considerations

- Обвязка живёт в <style> паттерна (зона сайта, как остальные связки lpp-/dpp-/fpp-*),
  НЕ в компоненте и не в dist;
- не ломает sticky/mobile-сценарии паттернов (отступы сверху/снизу, не
  overflow).

## Dependencies

- T14.2 — те же файлы трёх паттернов (page-head правится там же): порядок
  исключает конфликт веток и двойной пересъём.

## Acceptance Criteria

- [ ] Крошки в трёх паттернах несут вертикальные отступы 20/24px (computed-пин или эталон);
- [ ] README паттернов и ui-breadcrumbs содержат правило ритма со сниппетом;
- [ ] Эталоны пересняты в контейнере, visual-CI зелёный;
- [ ] npm run lint, node tools/lint-html.mjs зелёные.

## Testing requirements

Пины отступов — в e2e паттернов, если файл уже открывает крошки; иначе
поверхность — эталоны (осознанно, без новых e2e-файлов).

## Accessibility requirements

Не меняется: nav-лендмарка, aria-label, ol-семантика компонента не трогаются;
отступы не влияют на порядок обхода.

## Definition of Done

- [ ] Implementation completed
- [ ] Tests added/passed (или эталонная поверхность)
- [ ] Lint/typecheck passed
- [ ] Accessibility requirements satisfied
- [ ] Documentation updated if required
