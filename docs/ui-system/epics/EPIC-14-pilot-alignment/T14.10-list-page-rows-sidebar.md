# TASK T14.10 — Паттерн list-page: ветки «строки» и «сайдбар фильтров»

## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

P1

## Type

TASK

## Goal

Расширить эталон «Страница списка» двумя раскладками оригинала, которых в
паттерне нет: (1) список строками вакансий (горизонтальная строка: заголовок-
ссылка, место, описание, дата, CTA-пилюля) вместо сетки карточек; (2) сайдбар
фильтров (вертикальная sticky-панель: label + select-пилюли, radio-группа,
чекбокс, сброс, промо-карточка). Пилот собирал обе связки самодельно в
сайт-зоне (REPORT §4, PLAN P1-3/P1-4).

## Context

Список вакансий оригинала — строки (`.vac-row`), не сетка; фильтры — сайдбар
(`.vac-side`), не горизонтальные пилюли. Паттерн T8.1 знает только
сетку + горизонтальные фильтры. Базовые компоненты есть (ui-card, ui-select
wrap, ui-radio-group, ui-checkbox, ui-button--pill из T14.4, ui-chip из
T14.8) — паттерн собирает их в эталонные ветки без нового CSS в dist.

## Scope

- patterns/list-page/list-page.html: две новые демо-ветки рядом с
  существующими (как «пустая выдача»): (a) выдача строками — 3–4 строки
  вакансии на ui-card + связке раскладки строки, CTA — ui-button--pill с
  data-ui-modal-target на демо-модалку отклика или href-заглушку; (б) сайдбар
  фильтров — grid «aside | выдача»: группа label + select-wrap, ui-radio-group
  (опыт), ui-checkbox (доступность), кнопки Применить/Сбросить, промо
  ui-card--filled;
- patterns/list-page/README.md: разделы «когда строки vs сетка», «сайдбар vs
  горизонтальные пилюли», Bitrix-заметки (разметка строк из инфоблока,
  сохранение GET-параметров пагинации), правило ритма крошек (перекрёстная
  ссылка T14.5);
- связки раскладки — <style> паттерна (зона сайта, не dist; дисциплина
  токенов как в существующих lpp-*);
- кардинальные доступности: sticky-сайдбар — scrollable-region-focusable
  (axe), заголовок выдачи — h2, строки — article с h3-ссылкой (иерархия h1→h2→h3);
- e2e/axe паттерна зелёные; эталоны в контейнере (ADR-0004);
- docs-обновления STAND_DESCRIPTIONS в showcase/build.mjs (описание новых
  веток, если каталог показывает одну карточку паттерна — не требуется при
  том же URL).

## Out of scope

- AJAX-фильтрация (вне скоупа T8.1 — перезагрузка GET-формы);
- Мобильная трансформация сайдбара (min-width-деградация в колонку —
  связка паттерна; отдельные сценарии — зона сайта);
- Компонент «строка списка» (сознательно: связка ui-card на уровне паттерна;
  компонентизировать — по второму потребителю).

## Existing implementation

patterns/list-page (T8.1): ветки «с данными» и «ничего не найдено»;
ui-button--pill появится в T14.4, ui-chip — в T14.8.

## Implementation requirements

1. Новый CSS в системе запрещён (patterns/README): только связки в <style>
   паттерна на токенах.
2. Эталоны переснимаются ТОЛЬКО в контейнере (ADR-0004).
3. axe-гейты паттерна обязаны остаться зелёными (лендмарки, иерархия, контраст).

## Technical considerations

- Строка вакансии: article.ui-card.ui-card--hover с flex-раскладкой в связке;
  CTA-пилюля — вне карточки-ссылки (инвариант вложенных интерактивов ui-card);
- сайдбар: <aside aria-labelledby> + sticky top; select-wrap-пилюли по
  канону ui-select (label[for] рядом);
- демо-данные строк — из моков пилота не копируются дословно: 3
  правдоподобные вакансии (источник текста — data/vacancies.json пилота).

## Dependencies

- T14.4 — строки используют ui-button--pill (компонент обязан быть в dist);
- T14.8 — тулбар чипов в ветке сайдбара/выдачи (если чипы в демо — иначе dep
  не нужен; держим: чипы направлений над выдачей строк).

- [ ] Ветка «сайдбар»: aside со sticky, label у каждого контрола, radio-группа с legend, axe зелёный;
