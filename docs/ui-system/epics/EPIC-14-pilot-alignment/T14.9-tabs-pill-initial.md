# TASK T14.9 — ui-tabs: вариант --pill и начальный выбор из разметки

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Goal

Два пробела ui-tabs, найденные пилотом (REPORT §3.3, PLAN P1-2):
1. визуальный вариант «пилюль» (`.tabs-pill` оригинала — прозрачные пилюли,
   активная с заливкой) — базовый вид капсул-кнопок не совпадает с макетом
   навигации разделов;
2. начальный выбор таба из разметки: модуль всегда выбирает ПЕРВЫЙ таб
   (select(0, false, true)), а в межстраничной навигации активный таб зависит
   от страницы — потребителю приходится звать IraoUI.tabs.select(i) с сайта.

## Context

Оригинал: `.tabs-pill__tab` — прозрачные пилюли 20px/400 с hover; активная —
заливка. Многостраничные наборы («практика/стажировка» на двух страницах)
требуют разного активного таба при одинаковой разметке порядка.

## Scope

- components/ui-tabs/ui-tabs.css: модификатор `ui-tabs--pill` — прозрачные
  пилюли (fs-small-масштаб оригинала, паддинги пилюли), активная — заливка
  primary/text-on-dark; базовый вид не меняется;
- components/ui-tabs/ui-tabs.js: при инициализации таб с
  aria-current="page" выбирается вместо первого (select(index, false, true));
  без aria-current — поведение как раньше; если aria-current стоит на
  нескольких табах — первый, console.warn (контракт шаблона п.4);
- components/ui-tabs/ui-tabs.html: демо модификатора + aria-current-варианта;
- components/ui-tabs/README.md: модификатор (когда), правило начального
  выбора (aria-current="page" — семантика «текущая страница», согласовано с
  ui-dropdown/ui-breadcrumbs), no-JS-деградация (все панели видимы —
  правило не меняется);
- юнит-пины (TDD): aria-current на втором табе → выбран второй; дубли — warn;
  без aria-current — первый;
- e2e: вариант модификатора на стенде (axe/клавиатура);
- эталоны стенда ui-tabs в контейнере (ADR-0004);
- CHANGELOG.md: строка (расширение API модуля и CSS).

## Out of scope

- Смешанный набор «табы + ссылки разделов» в одной строке (навигация разделов
  оригинала — ссылкам не место в tablist; правило зафиксировать в README
  паттерна-потребителя, см. Notes);
- Автоматический выбор по URL (зона сайта).

## Existing implementation

components/ui-tabs (T6.2): APG tabs, automatic-активация, select(index,
focusTab, silent), init всегда select(0, false, true).

## Implementation requirements

1. TDD: юнит-пины начального выбора — до правок модуля.
2. Эталоны переснимаются ТОЛЬКО в контейнере (ADR-0004).
3. ARIA-инвариант: aria-current="page" на табе не конфликтует с
   aria-selected (разные семантики; ревью сверит с APG).

## Technical considerations

- select(index, false, true) — silent: стартовый выбор не диспатчит
  irao-ui:tabs-select (не смена выбора);
- модификатор меняет только вид list/tab (капсула → пилюля) — roving
  tabindex/клавиатура общие;
- пилот pilot.js использует ручной select — после задачи хак можно снять
  (попутно в T14.12).
