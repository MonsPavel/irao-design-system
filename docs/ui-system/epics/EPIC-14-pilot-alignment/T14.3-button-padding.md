# TASK T14.3 — ui-button: горизонтальный паддинг 28px

## Epic

## Priority

## Type

TASK

## Goal

Свести горизонтальный паддинг кнопки с одобренным макетом: career-portal .btn —
12×28, ui-button — 12×24 (проба REPORT §3.3: кнопки клона плотнее оригинала на
всех страницах).

## Context

Оригинал components.css:71 `padding: 12px 28px`. ДС собрала 24px из
--ui-space-5 (шкала отступов), 28px на шкале нет — прецедент переноса «как
есть» вне шкалы: --ui-card-gap (14px), --ui-pagination-size (44px). Вертикаль
совпадает (--ui-space-3 = 12px) — не трогается. Рамка заливочных вариантов
прозрачна (border-color: transparent) — правки не требует, REPORT уточнён 20.10.

## Scope

- tokens/semantic.css (секция ui-button): новый токен
  `--ui-button-pad-inline: 1.75rem` с комментарием-провенансом (career-portal
  components.css:71, вне шкалы отступов — прецедент --ui-card-gap);
- components/ui-button/ui-button.css: padding-inline читает новый токен
  (padding-block остаётся --ui-space-3); sm-вариант: проверить, что
  padding-block --ui-space-1 не сломался (токен паддинга только inline);
- tests/unit/button.test.js (или существующий файл): пины паддинга base и sm (TDD);
- components/ui-button/README.md: таблица токенов дополнена;
- docs/ui-system/architecture/tokens-career-portal-mapping.md: строка токена;
- CHANGELOG.md: строка (визуальное изменение поставки);
- эталоны: стенд ui-button + стенды, где кнопки меняют ширину заметно
  (пересъём в контейнере, ADR-0004).

## Out of scope

- Модификатор пилюли со стрелкой (T14.4);
- Высота, радиус, цвета, hover-значения кнопки — совпадают с макетом.

## Existing implementation

components/ui-button (T4.2): min-height --ui-button-height, padding
var(--ui-space-3) var(--ui-space-5), border 2px transparent (гейт эталона).

## Implementation requirements
