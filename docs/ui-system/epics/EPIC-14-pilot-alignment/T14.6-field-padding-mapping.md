# TASK T14.6 — ui-field: паддинг инпутов + дифф-таблица микрорасхождений

## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

P0

## Type

TASK

## Goal

Свести горизонтальный паддинг полей с макетом (20px против 24px ДС), добавить
компактный вариант «поле в анкете-модалке» (48px, как у оригинала) и
зафиксировать все микрорасхождения «принято ДС» в mapping-таблице — чтобы
дальше они не всплывали как дефекты (REPORT §3.3, сверка 20.10).

## Context

Базовая высота поля 52px совпадает (--ui-field-height: 3.25rem); расхождение
в горизонтальном паддинге (components.css:150 `4px 20px` против
--ui-space-5 = 24px). 20px вне шкалы отступов — прецедент «как есть»
(--ui-card-gap). Отдельный проб живого сайта (20.10): «48px» — это НЕ отставание
Pages, а компактный вариант анкет-модалок оригинала
(`.apply-form .field__input { height: 48px }`, pages.css:1208; так же
радио-строки `.apply-form .field--radios .radio`) — аналога в ДС нет.
Остальные микрорасхождения решено принять значениями ДС: карточка 24 vs 20,
модалка 36 vs 40, tag-orange — AA-замена T2.3.

## Scope

- tokens/semantic.css (секция полей): токен `--ui-field-pad-inline: 1.25rem`
  (career-portal components.css:150, вне шкалы — прецедент --ui-card-gap) и
  токен `--ui-field-height-compact: 3rem` (career-portal pages.css:1208,
  «как есть»);
- components/ui-field/ui-field.css: input/textarea padding-inline читает
  новый токен (вертикаль textarea --ui-field-textarea-padding-y не
  трогается); модификатор `ui-field--compact` — min-height
  --ui-field-height-compact на input/select (textarea — только в базовой
  высоте);
- docs/ui-system/architecture/tokens-career-portal-mapping.md: дополнить
  таблицу строками «принято ДС»: ui-card padding 24 vs 20; ui-modal padding
  36 vs 40; ui-tag orange #A94710 vs #B34A10 (AA T2.3); строки новых токенов;
- components/ui-field/README.md: таблица токенов + правило модификатора
  («когда: формы в модалках/плотные анкеты», потребитель — apply-формы
  career-portal);
- tests/unit/field.test.js (или существующий файл): пины паддинга и
  компактной высоты (TDD);
- CHANGELOG.md: строка (визуальное изменение + новый модификатор);
- эталоны: стенд ui-field + form-паттерн (в контейнере, ADR-0004).

## Out of scope

- Базовую высоту полей не менять (52px совпадает);
- Высоту радио-строк анкет (раскладка .apply-form — зона сайта; зафиксировать
  в Notes задачи фактом, не компонентом);
- Значения ui-card/ui-modal/ui-tag (приняты ДС, только строки в таблице).

## Technical considerations

- textarea: вертикальный паддинг свой (--ui-field-textarea-padding-y),
  горизонтальный — общий новый токен; compact на textarea высоту не меняет
  (многострочность важнее плотности);
- ui-select наследует ui-field__select — паддинг едет автоматически, триггер
  модуля повторяет computed (прогнать select-юниты); compact-модификатор
  ставится на обёртку .ui-field и действует на вложенный select;
- 44px touch-минимум не нарушается: 48px ≥ 44.
