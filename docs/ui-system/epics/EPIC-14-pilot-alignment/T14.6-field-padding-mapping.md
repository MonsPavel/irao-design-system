# TASK T14.6 — ui-field: паддинг инпутов + дифф-таблица микрорасхождений

## Epic

[EPIC-14 — Калибровка по пилоту career-portal](README.md)

## Priority

P0

## Type

TASK

## Goal

Свести горизонтальный паддинг полей с макетом (20px против 24px ДС) и
зафиксировать все микрорасхождения «принято ДС» в mapping-таблице — чтобы
дальше они не всплывали как дефекты (REPORT §3.3, сверка по main 20.10).

## Context

Сверка с current main career-portal (Pages-деплой отстаёт): высота поля 52px
УЖЕ совпадает (--ui-field-height: 3.25rem); расхождение осталось только в
горизонтальном паддинге (components.css:150 `4px 20px` против
--ui-space-5 = 24px). 20px вне шкалы отступов — прецедент «как есть»
(--ui-card-gap). Остальные микрорасхождения решено принять значениями ДС:
карточка 24 vs 20, модалка 36 vs 40, tag-orange — AA-замена T2.3.

## Scope

- tokens/semantic.css (секция полей): токен `--ui-field-pad-inline: 1.25rem`
  с провенанс-комментарием (career-portal components.css:150, вне шкалы —
  прецедент --ui-card-gap);
- components/ui-field/ui-field.css: input/textarea padding-inline читает
  токен (вертикаль textarea --ui-field-textarea-padding-y не трогается);
- docs/ui-system/architecture/tokens-career-portal-mapping.md: дополнить
  таблицу строками «принято ДС»: ui-card padding 24 vs 20; ui-modal padding
  36 vs 40; ui-tag orange #A94710 vs #B34A10 (AA T2.3); строка нового токена;
- components/ui-field/README.md: таблица токенов дополнена;
- tests/unit/field.test.js (или существующий файл): пины паддинга (TDD);
- CHANGELOG.md: строка (визуальное изменение поставки);
- эталоны: стенд ui-field + form-паттерн (в контейнере, ADR-0004).

## Out of scope

- Высота полей (совпадает с main — REPORT §2, ограничение (г));
- Значения ui-card/ui-modal/ui-tag (приняты ДС, только строки в таблице).

## Existing implementation

components/ui-field (T5.1): min-height --ui-field-height, padding
var(--ui-space-1) var(--ui-space-5).

## Implementation requirements

1. TDD: юнит-пины computed-паддинга input и textarea до правок CSS.
2. Эталоны переснимаются ТОЛЬКО в контейнере (ADR-0004).

## Technical considerations

- textarea: вертикальный паддинг свой (--ui-field-textarea-padding-y),
  горизонтальный — общий новый токен;
- ui-select наследует ui-field__select — паддинг едет автоматически, триггер
  модуля повторяет computed (юнит-пин селекта не должен сломаться — прогнать
  select-юниты).
