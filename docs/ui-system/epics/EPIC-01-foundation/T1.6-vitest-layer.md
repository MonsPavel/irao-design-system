# TASK T1.6 — Vitest-слой для JS-логики

## Epic

[EPIC-1 — Foundation & Tooling](README.md)

## Priority

P0

## Type

TASK

## Goal

Юнит-слой для DOM-независимой логики модулей (валидация форм, VI-состояния, синхронизация select) — быстрые детерминированные тесты без браузера.

## Context

Конвенция тестирования (06 §9): чистая логика выносится в чистые функции и тестируется Vitest+jsdom; DOM-поведение — Playwright. Без юнит-слоя логика валидации и VI оказалась бы покрыта только медленными e2e.

## Scope

- vitest + jsdom, скрипт `test:unit`, подключение в CI (шаг T1.5);
- эталонный тест на module-template (readyState-guard — оба режима);
- конвенция «чистая логика отдельно от DOM-кода» зафиксирована в README тестов.

## Out of scope

- Тесты реальной логики (появятся в T5.5, T7.3, T9.1);
- coverage-пороги (введём по факту, когда будет что мерить).

## Existing implementation

career-portal: юнит-тестов нет; вся логика замкнута в IIFE с DOM-доступом — при порте в T5.5/T9.1 её придётся выделить в чистые функции (это требование зафиксировано там).

## Implementation requirements

1. Конфиг vitest рядом с playwright (не пересекаться по glob'ам).
2. Эталонный тест module-template: DOMContentLoaded ещё не прошёл / уже прошёл — оба пути вызывают init ровно один раз.

## Technical considerations

- jsdom достаточен: чистые функции + лёгкие DOM-проверки guard'ов; полноценно DOM-поведение — только Playwright.
