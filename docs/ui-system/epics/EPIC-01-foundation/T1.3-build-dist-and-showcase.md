# TASK T1.3 — Сборка dist и showcase (esbuild)

## Epic

[EPIC-1 — Foundation & Tooling](README.md)

## Priority

P0

## Type

TASK

## Goal

Один билд-скрипт производит из одних исходников поставку (dist — то, что уезжает на сайты) и полигон (showcase — доки, тесты, visual-регрессия).

## Context

Порядок каскада критичен (урок CSS_ORDER из career-portal `build.py`): tokens → base → компоненты → (отдельный файл) vi. Showcase — единый источник правды: по тем же страницам работают Playwright-тесты и читают доку интеграторы.

## Scope

- `showcase/build.mjs` (esbuild API): конкатенация+минификация CSS → `dist/ui-core.min.css`; JS → `dist/ui.min.js`; отдельно `dist/ui-vi.min.css`; копия `fonts/`, `themes/`;
- баннер версии (из package.json) + git-sha в начало файлов;
- генерация showcase: индекс-каталог стендов + страница на компонент из `components/*/<name>.html` в каркасе (skip-link, header-заглушка, подключение dist, переключатель темы `?theme=`);
- `npm run serve` — локальный статик-сервер; `npm run build` — полный прогон.

## Out of scope

- Контент стендов конкретных компонентов (их задачи);
- минификация изображений, хэши имён файлов (версия уже в имени папки на сайте — ADR-0006).

## Existing implementation

career-portal `build.py`: концепция CSS_ORDER/JS_ORDER и cache-busting `?v={timestamp}`, preload-генерация — переносим идею, не код (Python → Node/esbuild).

## Implementation requirements

1. Порядок файлов в бандлах — явный список в build.mjs (не glob-алфавит без документации); добавление компонента = одна строка (сверить с CONTRIBUTING).
2. url() шрифтов остаются относительными: структура dist повторяет исходники (`dist/fonts/` рядом с css) — проверить подключение standalone-страницей.
3. Showcase-каркас содержит: skip-link, `<main id="main">`, подключение ui-core/ui-vi/ui.js, переключатель темы.
4. Дистрибутив должен собираться идемпотентно (дважды запущенный build даёт бинарно одинаковый результат, кроме баннера sha — зафиксировать поведение).

## Technical considerations

- esbuild — единственная сборочная зависимость (ADR-0005, анти-overengineering);
- showcase-страницы генерируются, но их тело — статический HTML компонента из его папки (не шаблонизатор).
