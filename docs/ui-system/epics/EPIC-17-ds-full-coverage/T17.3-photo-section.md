# TASK T17.3 — Фото-секция ui-section--photo

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P2

## Type

TASK (ДС, base/layout)

## Goal

Ввести модификатор «секция с фотографическим фоном» для `ui-section`:
абсолютный фон `inset: 0` под контентом + оверлей-градиент и/или
цветовое затемнение. Приём сегодня скопирован в пилоте пять раз
(hero, production, holding, why-us, company-banner) и является
фирменным композиционным средством портала.

## Context

Пилот повторяет один шаблон (pilot.css): `.cp-<block>__bg` (absolute,
inset 0, z-index −1, img object-fit cover) + оверлей (`__bg::after`
с градиентами к surface/primary-a94, или inline-оверлей `__glow`,
или `primary-a55` у баннера). Токены тинтов уже есть (T14.7:
`--ui-color-primary-a10…a94`; glass — в primitives). Различия блоков —
только параметры градиента; раскладку контента несёт существующий
`ui-section`/`ui-container`.

Канон оригинала: hero (градиент surface→transparent→primary-a94),
production (glow-градиент primary 88%→34%→transparent слева),
holding/why-us (фото + on-dark текст), company-banner (primary-a55).

## Scope

- `base/layout.css`: `ui-section--photo` + элементы `__bg` (слот img)
  и `__overlay` (модификаторы градиентов: `--fade-bottom`
  surface→transparent, `--tint` с токеном прозрачности через
  `--ui-section-overlay-tint`, кастомизируется сайтом);
- контент секции — над фоном (z-index-пара, прецедент pilot.css);
- высота фона — по контенту секции (как в пилоте); декларативные
  пропорции — сайту (`min-height`);
- пилот: пять фоновых секций переводятся на модификатор (hero,
  production, holding, why-us, company-banner), фоновые правила
  `__bg/__glow` удаляются из pilot.css;
- док: паттерн landing-section дополнен разделом «фото-фон» с примером.

## Out of scope

- параллакс/скролл-эффекты — нет в оригинале;
- `backdrop-filter`-стекло (hero-теги/поиск) — зона hero-композиции
  (T17.15), не секции;
- затемнение фотографий карточек (ui-image уже несёт cover-режимы).

## Existing implementation

- pilot.css:142–161 (hero__bg + ::after), 266–287 (production__bg +
  __glow), 418–428 (holding__bg), 491–501 (why-us__bg), 1834–1855
  (company-banner: фото + primary-a55);
- base/layout.css:79–93 (ui-section/--muted);
- tokens: primary-a55/a94 (T14.7), glass-токены.

## Implementation requirements

1. Модификатор не задаёт типографику/цвет текста — on-dark-пара
   (`ui-text--on-dark` роли) остаётся на контенте (существующие роли);
2. Оверлей — токен-хуком `--ui-section-overlay-tint` (значение по
   умолчанию — none; сайт ставит токен тинта из лестницы T14.7);
   градиентные варианты — модификаторами с фиксированными канонами;
3. `img` фона — декоративный по умолчанию (`alt=""` в каноне разметки,
   прецедент пилота);
4. Пример канона:

   ```html
   <section class="ui-section ui-section--photo">
     <div class="ui-section__bg" aria-hidden="true">
       <img src="factory.jpg" alt="" loading="lazy">
     </div>
     <div class="ui-section__overlay ui-section__overlay--fade-bottom" aria-hidden="true"></div>
     <div class="ui-container">… on-dark контент …</div>
   </section>
   ```

## Dependencies

- нет жёстких. Фото-секция — контейнер-прецедент для статов на фото и
  adoption-задач лендинга (перечислены в README эпика): они её
  используют, но исполняются независимо от неё (forward-упоминания
  T-ID в этом разделе запрещены — уроки 85f014c, 8759806).
