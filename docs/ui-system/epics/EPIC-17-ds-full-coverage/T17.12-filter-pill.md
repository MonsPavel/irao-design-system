# TASK T17.12 — Пилюля select-фильтра и find-bar

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P1

## Type

TASK (ДС-модификатор + паттерн-связка)

## Goal

Перенести в ДС геометрию «пилюля select-фильтра» (сейчас `cp-pill`:
рамка, radius pill, фон surface-muted, триггер ui-select растягивается)
— модификатором ui-select/ui-field; и канонизировать строку «найти по
списку» (find-bar: поле + кнопка) в паттерн-слое. Четыре контекста
пилота: панель «Найди свою вакансию», каталог обучения, сайдбар
вакансий, (пилюля поиска events-search остаётся сайт-зоной по решению
владельца — «по потребности = не делать»).

## Context

`cp-pill` (pilot.css:575–587 + вариации flex-basis 12rem/260px/auto) —
обёртка нативного select в режиме `data-ui-select="wrap"`: триггер
ui-select заполняет пилюлю. Обёртка несёт: border `--ui-border-width`
`--ui-border-color`, radius `--ui-radius-pill`, bg surface-muted.
Комментарий пилота: «геометрию рисует сайт (cp-pill), триггер
растягивается» — типовая связка фильтров списков, второй потребитель в
пилоте уже трижды. Find-bar (pilot.css:1197–1205) — flex-строка
«ui-field + ui-button» с margin-bottom: одна и та же панель на
vacancies и events-search (T15.5: «дублирования не плодить»).

## Scope

- ДС: модификатор `ui-select--pill` (на корневой wrap-контейнер или
  класс-обёртку — по контракту ui-select wrap-режима, решение в
  задаче): рамка/радиус/фон пилюли; ширина — раскладкой сайта
  (flex-basis 12rem в ленте фильтров / 260px в каталоге — значения
  канона list-page, уточняются probe-парой оригинала);
- README ui-select: строка API + пример фильтр-панели;
- паттерн-слой: `lpp-filters` (лента пилюль, gap 16) и `lpp-find`
  (find-bar: поле+кнопка, gap 8, ритм 8) — каноны из list-page;
- пилот: cp-pill → ui-select--pill (4 контекста), cp-find-bar/
  cp-catalog-filters → lpp-*; правила сняты;
- скрытая подпись — на ui-vh (T17.2, если идёт раньше; иначе cp-vh
  остаётся до неё).

## Out of scope

- пилюля поиска events-search 56px/r100 — закрыта решением владельца
  (a0e0d21, «по потребности = не делать»);
- поведение фильтрации — мок-слой сайта;
- мобильные селект-панели — нет потребителя.

## Implementation requirements

1. Модификатор не меняет внутренности listbox/триггера — только
   геометрия обёртки (контракт ui-select не трогается);
2. Фон пилюли — surface-muted (blue-50) канона; рамка —
   `--ui-border-color` (T16.11-канон пилюли);
3. Пример канона:

   ```html
   <label class="ui-vh" for="f-city">Город</label>
   <!-- ширина пилюли — flex-basis раскладки сайта -->
   <div class="ui-select--pill">
     <select class="ui-field__select" id="f-city" data-ui-select="wrap">
       <option>Все регионы</option>…
     </select>
   </div>
   ```

   find-bar:

   ```html
   <form class="lpp-find" action="vacancies.html" method="get" role="search">
     <div class="ui-field">
       <input class="ui-field__input" type="search" name="q"
         placeholder="Поиск по списку" aria-label="Найти вакансию">
     </div>
     <button class="ui-button ui-button--accent" type="submit">Найти</button>
   </form>
   ```
