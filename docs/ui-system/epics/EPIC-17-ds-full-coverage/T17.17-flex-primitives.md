# TASK T17.17 — Флекс-примитивы ui-row / ui-stack

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P2

## Type

TASK (ДС, layout-примитивы base — продолжение T3.4)

## Goal

Дать сайтам флекс-композицию средствами ДС: примитив `ui-row`
(горизонтальная строка с gap на токене и модификаторами выравнивания —
центрирование, по краям, прижать к концу) и `ui-stack` (вертикальная
стопка с gap — решение в задаче по замеру потребностей). Снимает
потребность, которая сегодня закрывается 59 голыми `display: flex`
сайт-зоны пилота (ценз 25.10): каждый «слева заголовок — справа
действие», каждое центрирование собираются вручную.

## Context

T3.4 заложил только контейнер/секцию/сетку: флекс не отклонялся — его
не было в scope, и дыра осталась незадокументированной. Находка
владельца 27.10: «есть грид-система в ui, но нету флекс для того чтоб
центрировать или ровнять по какому-нибудь боку» — первый потребитель по
критерию эпика (career-portal): find-bar (поле + кнопка), поднавигация,
строки списков, футерные колонки, hero-композиции. Обобщение «строки со
слотом действия» ДС уже сделала точечно дважды — `ui-card--cta --row`
(space-between, T17.8) и `lpp-row` (строка вакансии, T14.10): примитив
переносит этот приём на уровень страницы. Вариант API — семантический
примитив рядом с `ui-grid` (рекомендация оркестратора, владелец завёл
задачу 27.10); утилитный матричный набор (Bootstrap-стиль) против
философии системы — Out of scope.

## Scope

- `base/layout.css`: примитив `ui-row` — flex-строка: перенос по
  умолчанию (защита от hscroll, гейт T3.6), вертикальное выравнивание
  центр (доминирующий кейс пилота — сверить замером по инстансам),
  gap на токене `--ui-row-gap`; модификаторы: `--center`
  (justify-content: center — центрирование строки), `--between`
  (space-between — «слева/справа»), `--end` (прижать к концу),
  `--no-wrap` (перенос отключён осознанно — тулбары/пилюли);
- примитив `ui-stack` — вертикальная стопка, gap на токене
  `--ui-stack-gap`; решение «делать сейчас / отложить» — по замеру
  пилота (критерий: ≥ 3 инстансов вертикальных стопок с равным gap;
  если отложено — строка решения в задаче, задача не блокируется);
- README layout-примитивов: do/don't «когда ui-row vs ui-grid» (строка
  контента vs сетка карточек), таблица токен-хуков, правило `--no-wrap`;
- стенд layout дополнен секцией `ui-row` (матрица модификаторов +
  `ui-stack` при решении «сейчас»), эталоны 4 вьюпортов (ADR-0004);
- юнит-пины: computed-геометрия модификаторов, gap от токена
  (смена токена меняет расчётный gap), инварианты (без !important/hex).

## Out of scope

- утилитный набор «класс на значение» (ui-justify-*, ui-items-*) —
  против инварианта семантических примитивов; если adoption вскроет
  потребность — отдельное решение владельца;
- перевод 59 flex'ов пилота на примитив в ЭТОЙ задаче — adoption идёт
  задачами adoption-батча (шапка/подвал, детальные, лендинг), которые
  переводят свои блоки сами;
- правки `ui-grid` (соседний слой не трогается).

## Existing implementation

- base/layout.css:56–146 — соседний слой (ui-container/ui-section/
  ui-grid, T3.4);
- точечные «строки» ДС: components/ui-card/ui-card.css (`--cta--row`),
  patterns/list-page (`lpp-row`);
- pilot.css — 59 `display: flex` сайт-зоны (find-bar, поднавигация,
  футер, hero — ценз README эпика).

## Implementation requirements

1. Токены `--ui-row-gap` / `--ui-stack-gap` в tokens/semantic.css от
   spacing-шкалы (дефолт — `--ui-space-4`; отклонение — с
   провенанс-комментарием по прецеденту `--ui-field-pad-inline`);
2. Инварианты системы: без !important и hex; mobile-first, без
   фикс-высот; примитив — чисто презентационный `div` без роли
   (доступность не меняется);
3. wrap по умолчанию — защита от hscroll (гейт T3.6); `--no-wrap` —
   осознанное отключение, в README правило применения;
4. Пример канона:

   ```html
   <div class="ui-row ui-row--between">
     <h2 class="ui-h2">Вакансии</h2>
     <a class="ui-button ui-button--pill" href="vacancies.html">
       Все вакансии
     </a>
   </div>
   ```

5. Стенд: секция в layout-стенде — матрица `ui-row` (база/--center/
   --between/--end/--no-wrap) и `ui-stack` при решении «сейчас»;
   эталоны 375/768/1280/1440 в контейнере (ADR-0004), повторный прогон
   без update — стабилен.

## Dependencies

- нет жёстких: примитив живёт в base/layout.css — от паттерн-слоя и
  компонентов не зависит, поставляется сразу. Потребители —
  adoption-задачи эпика (шапка/подвал, детальные страницы, лендинг)
  используют примитив по усмотрению; в STATUS строка задачи стоит в
  DS-батче, до adoption-батча (forward-упоминания T-ID в этом разделе
  запрещены — уроки 85f014c, 8759806).
