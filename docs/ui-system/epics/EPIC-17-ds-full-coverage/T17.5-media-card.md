# TASK T17.5 — Медиа-карточка ui-card--media

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P1

## Type

TASK (ДС, расширение компонента)

## Goal

Ввести модификатор «карточка с медиа-зоной» `ui-card--media`: фото
(aspect-ratio 3/2, скругление сверху) + абсолютный тег на фото + тело
(дата/заголовок/мета-теги). Закрывает три копии одного вида в пилоте:
карточка события, карточка статьи, карточка стажёра — и будущие
медиа-карточки других сайтов группы.

## Context

Пилот трижды повторяет композицию «фото + тег в углу + тело»
(pilot.css): `.cp-event-card*` (тег регистрации на фото, дата, тайтл
ui-h6, мета-теги city/format), `.cp-article-card*` (тег рубрики с
точкой, мини-тайтл ui-small, дата), `.cp-intern-person*` (квадратное
фото, имя, теги, шорт). Различия — пропорции фото (3/2, 3/2, 1/1) и
набор тела; каркас один. Теги на фото — тинты вариантов (канон
T16.10-реклассификации), позиционирование тега — свойство каркаса.

Канон: фото сверху с радиусом md/md 0 0, тег absolute top/left 8px,
тело — флекс-колонка gap 8, паддинг 12; карточка — существующие
`ui-card--hover/--link`.

## Scope

- `components/ui-card/ui-card.css`: модификатор `ui-card--media`,
  элементы `__media` (слот фото, `--square` для 1/1), `__media-tag`
  (absolute-слот тега);
- канон-HTML + README (do/don't: тег на фото — тинт варианта, не
  on-photo без потребности — прецедент T16.10);
- пилот: eventCard/articleCard/internPerson (build.mjs) собираются на
  модификаторе; правила `cp-event-card*`, `cp-article-card*`,
  `cp-intern-person*` снимаются (остаётся специфика тела — мета-строки —
  на существующих утилитах);
- стенд ui-card дополняется секцией «медиа-карточка» + эталоны.

## Out of scope

- спец-сетка media главной (big+lead) — раскладка страницы (T17.15);
- теги на фото фильтров (ui-tag--filter) — готовый API ДС;
- ленивость/async-декодирование изображений — атрибуты разметки сайта.

## Existing implementation

- pilot.css:1535–1617 (cp-event-card/cp-article-card/cp-intern-person);
- build.mjs: eventCard (343), articleCard (376), internPerson (420) —
  разметка карточек;
- ui-card.css:64 (--filled), 90–143 (--link/--hover) — прецеденты
  модификаторов.

## Implementation requirements

1. Модификатор НЕ задаёт типографику тела: дата — ui-small+muted,
   заголовок — ui-h6/ui-small (каноны T16.12), несёт разметка;
2. Тег на фото — позиционирование каркасом, вид — готовый ui-tag
   (тинты вариантов; вариант тега выбирает сайт);
3. `aspect-ratio` — модификатором `__media` (3/2 база, `--square` 1/1);
   `object-fit: cover` — каркасом;
4. Пример канона (событие):

   ```html
   <article class="ui-card ui-card--hover ui-card--link ui-card--media">
     <a class="ui-card__link" href="event.html">
       <div class="ui-card__media">
         <img src="event.jpg" alt="" loading="lazy">
         <span class="ui-card__media-tag ui-tag ui-tag--green">Регистрация</span>
       </div>
       <div class="ui-card__body">
         <time class="ui-small ui-text--muted" datetime="2026-09-28">28.09.2026</time>
         <h2 class="ui-h6">День открытых дверей</h2>
         <p class="ui-card__meta">
           <span class="ui-tag ui-tag--blue">Москва</span>
           <span class="ui-tag ui-tag--gray">очно</span>
         </p>
       </div>
     </a>
   </article>
   ```
