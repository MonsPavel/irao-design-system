# TASK T17.7 — Карусель ui-carousel

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P3

## Type

TASK (ДС, новый компонент + JS-модуль)

## Goal

Ввести компонент «карусель» `ui-carousel`: слайды «фото + заголовок +
текст + CTA», стрелки prev/next и степпер-таблист; вторая форма —
фото-галерея prev/next (без степпера) для модалки направлений.
Переносит ~120 строк JS пилота (pilot.js: карусель «Производство»,
попап направлений) в модуль `dist/ui.min.js`.

## Context

«Производство» — самый сложный интерактив главной оригинала: слайдер
с JSON-данными в `<script type="application/json">`, стрелками,
степпером role=tablist (клик по табу = выбор слайда), деградация без JS
(первый слайд в разметке). Пилот повторил всё в pilot.js (ES5, ~60
строк) + разметка cp-production (17 селекторов). Галерея направлений —
та же пара prev/next по массиву фото в модалке (~55 строк).

Дизайн карусели: степпер-табы с рамкой on-dark-muted, активный —
glass-dark + белая рамка; стрелки — кнопки-стрелки on-dark. Обе формы —
on-dark-контекст фото-секций.

## Scope

- `components/ui-carousel/` (ui-carousel.css + ui-carousel.js + README):
  - `data-ui-carousel`: контейнер, `__slide-data`
    (script application/json), `__photo/__title/__text/__link`
    (слоты активного слайда), `__arrow(--prev/--next)`, `__stepper`
    (role=tablist, табы `__tab` c aria-selected);
  - API данных: массив слайдов {photo,title,text,link,count};
  - поведение: клик стрелки/таба — активный слайд; без JS — первый
    слайд из разметки (данные дублируются в слотах);
  - клавиатура: стрелки влево/вправо на табах (roving tabindex —
    прецедент ui-tabs), Home/End;
  - фото-галерея: `data-ui-gallery` — prev/next по массиву фото
    (модалка направлений), те же стрелки;
- пилот: production и попап направлений на компоненте; блоки pilot.js
  карусели/галереи удаляются; cp-production стилевой хвост сводится к
  композиции секции (glow/позиции — фото-секция + позиционирование);
- стенд + эталоны + док (do/don't: не автоплей без prefers-reduced-motion).

## Out of scope

- свайп/тач-жесты — нет в оригинале (добавка по потребности сайта);
- бесконечная лента логотипов (marquee) — не карусель, зона
  лендинг-композиций;
- ленивость фото слайдов — разметка сайта.

## Implementation requirements

1. Модуль — в реестре IraoUI (ui.min.js — счётчик модулей в баннере
   сборки обновляется); ES5-совместимость (ADR-0005) или осознанная
   оговорка о таргете браузеров в обновлении ADR;
2. Данные — JSON в разметке (как пилот): компонент не ходит в сеть;
3. Степпер — честный tablist (роль, aria-selected, стрелки клавиатуры);
   стрелки карусели — вне tablist;
4. Деградация без JS: первый слайд в слотах разметки, стрелки/табы
   скрываются CSS (`:root.js`-хук уже есть в dist — по прецеденту
   ui-select/ui-tabs);
5. Пример канона:

   ```html
   <section class="ui-section ui-section--photo" data-ui-carousel>
     <script type="application/json" data-ui-carousel-slides>[…]</script>
     <img class="ui-carousel__photo" src="slide-1.png" alt="Сотрудник" data-ui-carousel-photo>
     <div class="ui-carousel__body">
       <h2 class="ui-h2" data-ui-carousel-title>Производство</h2>
       <p class="ui-lead" data-ui-carousel-text>…</p>
       <a class="ui-button ui-button--light" data-ui-carousel-link>Подробнее</a>
     </div>
     <button class="ui-carousel__arrow" type="button" data-ui-carousel-prev
       aria-label="Предыдущий слайд">←</button>
     <ul class="ui-carousel__stepper" role="tablist" aria-label="Направления">
       <li><button class="ui-carousel__tab" role="tab" aria-selected="true">…</button></li>
     </ul>
   </section>
   ```
