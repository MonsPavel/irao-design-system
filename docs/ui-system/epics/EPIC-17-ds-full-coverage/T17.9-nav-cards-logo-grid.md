# TASK T17.9 — Nav-карточки и лента логотипов

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P2

## Type

TASK (ДС: паттерн-связки + расширение ui-card)

## Goal

Доставить два оставшихся вида лендинг-карточек: цветные
навигационные карточки «Школьникам и студентам» (3 тона: peach/navy/
light, иллюстрация в правом нижнем углу, круглая кнопка-стрелка) и
ленту карточек-логотипов работодателей (сетка рамочных плашек).
Связки — в паттерн-слой (T17.1), вид элемента «круглая кнопка-стрелка» —
модификатор ui-button.

## Context

`.cp-students__card*` (pilot.css:604–668): карточка-ссылка с тоновым
фоном (color-mix accent 24% для peach — уже замаплен; navy = primary;
light = surface+рамка), абсолютная иллюстрация, круглая кнопка
48px `--ui-control-size` трёх цветовых пар (orange=accent/on-dark,
white=surface/primary, navy=primary/surface). `.cp-employers__grid/
__card`: сетка 6 колонок (4/1 на ступенях) рамочных карт 197×108 —
логотипы «Работодатели Группы», типовой блок «партнёры/клиенты».

Тон карточки — параметр сайта (token-hook на фон), композиция — канон.
Иллюстрация — контент сайта (img absolute снизу-справа, max-height 70%).

## Scope

- паттерн-слой (или patterns/landing-связки при варианте B): связка
  `lnk-card` (nav-карточка: тон-хук `--lnk-card-bg`, слоты
  body/illustration/action; ступени 3→1 колонки);
- `ui-button--icon-round` (или модификатор `--round`): круглая
  icon-кнопка `--ui-control-size`, цветовые пары токенами
  (`--ui-button-bg/--ui-button-color` — существующие хуки), прецедент
  стрелки пилюли T16.11;
- `logo-grid`-связка: сетка рамочных плашек (граница border-muted,
  радиус md, паддинги «как есть», img растянута) на ui-grid;
- пилот: students/employers на связках, правила cp-students*/cp-employers*
  снимаются (10+2 селекторов);
- док: разделы паттерна landing-section + эталоны мини-стенда.

## Out of scope

- marquee-анимация ленты (нет в оригинале — статическая сетка);
- тон peach как токен ДС — остаётся color-mix-паттерном сайт-зоны
  (решение по спец-тинтам — T17.15, сюда не входит);
- содержание/подбор логотипов — контент.

## Existing implementation

- pilot.css:604–668 (students), 472–483 (employers);
- ui-button.css: пилюля с круглой иконкой (T16.11) — прецедент
  круглого контрола;
- ui-grid (base/layout.css:97) — каркас сеток.

## Implementation requirements

1. Тон nav-карточки — НЕ компонентным цветом: хук
   `--lnk-card-bg/--lnk-card-fg`, сайт ставит пару (navy — primary/
   on-dark; light — surface/text; peach — color-mix accent-пары);
   контраст пары — обязанность сайта, do/don't в доке с примерами
   одобренных пар;
2. Иллюстрация — слот absolute (bottom/right, max-height 70%),
   декоративна (alt="");
3. Пример канона (тон — классом сайт-зоны на токенах, инлайн-стили
   запрещены VI-инвариантом §5):

   ```html
   <!-- тон .lnk-card--navy { --lnk-card-bg: var(--ui-color-primary);
        --lnk-card-fg: var(--ui-color-text-on-dark); } — сайт-зона -->
   <a class="lnk-card lnk-card--navy" href="practices.html"
      aria-label="Подробнее: Стажировки и практики">
     <div class="lnk-card__body">
       <h3 class="ui-h4">Стажировки и практики</h3>
       <p class="ui-small">Уникальный шанс получить опыт в энергетике!</p>
     </div>
     <img class="lnk-card__illu" src="boy.png" alt="" loading="lazy">
     <span class="ui-button ui-button--round lnk-card__action" aria-hidden="true">→</span>
   </a>
   ```
