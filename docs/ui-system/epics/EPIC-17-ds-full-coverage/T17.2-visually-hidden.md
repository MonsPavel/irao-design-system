# TASK T17.2 — Базовая утилита visually-hidden

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P2

## Type

TASK (ДС, base)

## Goal

Ввести общую утилиту `.ui-vh` (visually-hidden: элемент убран из вида,
но доступен скринридерам) в `base/` и перевести на неё локальные
реализации: `cp-vh` пилота, `ui-field__req-text` (sr-only),
`ui-file__sr` — один приём в одном месте.

## Context

Техника визуального скрытия нужна каждому сайту группы (подписи
select-пилюль фильтров, пояснения обязательности, «перейти к…»). В ДС
класс размножен точечно: `ui-field.css` несёт sr-only-блок для
`__req-text`, пилот скопировал тот же набор свойств в `.cp-vh`
(pilot.css:995–1006, подписи label[for] пилюль канона ui-select T7.3),
`ui-file` дублирует для файлового инпута. Три копии одного приёма —
дрейф гарантирован (например, будущая правка под forced-colors).

## Scope

- `base/reset.css` (или отдельный блок в layout.css — по месту
  наибольшей уместности, решение по структуре base в задаче): класс
  `.ui-vh` — канонический набор (1px, clip-path inset(50%), nowrap,
  margin −1px, padding 0, border 0);
- замены локальных реализаций: `ui-field__req-text` и файловые sr-блоки
  получают `.ui-vh` в разметке канона (локальные правила снимаются);
- пилот: `.cp-vh` → `.ui-vh` в build.mjs (selectField и другие),
  правило удаляется из pilot.css;
- док: строка в README base + do/don't («не прятать фокусуемое», WCAG
  2.5.3 Label in Name — прецедент подписей пилюль).

## Out of scope

- `.ui-skip-link` — другой приём (видимая при фокусе ссылка), не трогается;
- содержание скрытых текстов (аудит имён — зона a11y-политики, не задачи).

## Existing implementation

- pilot.css:995–1006 (`.cp-vh`, перенос канона ui-select T7.3);
- components/ui-field/ui-field.css (`ui-field__req-text` sr-only);
- components/ui-file/ui-file.css (аналогичный блок).

## Implementation requirements

1. Набор свойств — ровно канон (clip-path, не clip — современный
   стандарт; пилотный `.cp-vh` уже канонический);
2. Утилита не участвует в forced-colors-особенностях (скрытие остаётся
   скрытием);
3. Пример:

   ```html
   <label class="ui-vh" for="filter-city">Город</label>
   <div class="cp-pill"><select class="ui-field__select" id="filter-city"
     data-ui-select="wrap">…</select></div>
   ```

## Dependencies

- нет; независима от решения по паттерн-слою.

## Acceptance Criteria
