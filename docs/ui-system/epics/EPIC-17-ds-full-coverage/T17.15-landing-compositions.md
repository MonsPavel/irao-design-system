# TASK T17.15 — Лендинг-композиции и спец-тинты

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P2

## Type

TASK (паттерн-слой + лендинг главной + решение по тонам)

## Goal

Собрать оставшиеся композиции главной и лендингов в паттерн-слой/доки:
hero (фото-секция + стеклянная пилюля поиска + теги-лента), типографская
adv-marquee (T16.15-канон), спец-сетка media (big+lead), cover-hero
лендингов стажировок; принять решение по спец-тинтам hero-тегов
(violet/green/rose). После задачи композиция index собирается из
ДС-сущностей с точечной связкой ритма.

## Context

Hero — «самый фирменный блок» (PLAN §P2-1): min-height 50.5rem,
фото+двойной градиент (фото-секция T17.3), центрированный ui-h1,
стеклянная пилюля поиска 50rem (glass-light + backdrop-blur 12 +
ui-field__input прозрачный + плита «Все вакансии» 72px), лента тегов
4шт с тонами: sand = primary-a26 (токен T14.7), violet #3142ff/green
#31ff76/rose #ff3134 @ 20% — color-mix сайт-зоны (P3-остаток §4).
Adv-marquee — канон 40/18/13 uppercase primary (T16.15) уже описан,
живёт в pilot.css. Спец-сетка media (big 2×2 + lead + 4 мелких) —
раскладка index. Cover-hero — колонка заголовок+lead+CTA лендингов.

Решение по спец-тинтам (владелец): (а) токены-производные в палитре
ДС (violet/green/rose как кастомные свойства сайта в доке hero —
рекомендуется: тон — бренд-слой, не система); (б) лестница тинтов ДС
расширяется — отвергнуто ранее для primary (T14.7 брал только
primary-лестницу); (в) статус-кво (color-mix в сайт-зоне).

## Scope

- паттерн-слой/доки:
  - `hro` — hero: `hro__content` (центр, паддинги 136/8/24),
    `hro__title` (max-width 56rem), `hro__search` (стеклянная пилюля:
    glass-light, blur 12, радиус pill, внутренний ui-field прозрачный,
    слот плиты-кнопки), `hro__tags` (лента flex 1:1:1:1, min-height 56);
  - `mrq` — adv-marquee: сетка 1.2fr/1fr, строки `__line(--bar/--sm/
    --xl)` — литералы 40/18/13 канона T16.15;
  - `mdl` — спец-сетка media: 4 колонки, big (row/col span 2), lead
    (col span 2), ступени 2→1;
  - `cvh` — cover-hero: колонка gap 16 start;
- спец-тинты: доке hero — блок «тон тега»: сайт-зона задаёт
  `--hro-tag-bg` custom property (примеры трёх тонов с source-
  комментариями); hex в ДС не едет (гейт);
- пилот: cp-hero/cp-adv-marquee/cp-media__grid/cp-cover-hero → каноны
  (теги — тон-строками сайт-зоны на custom properties);
- док-паттерн landing-section — разделы hero/marquee/медиа-сетка.

## Implementation requirements

1. Стеклянная пилюля — backdrop-filter в каноне (VI-инвариант §5:
   проверить отключение blur в VI-режиме img:off — прецедент
   существующих glass-поверхностей пилота);
2. Тон тега — только custom property (`--hro-tag-bg`), hex живёт в
   сайт-зоне с source-комментарием; stylelint-гейт слоя не нарушен;
3. Пример канона (hero-теги; тон — классом сайт-зоны, устанавливающим
   `--hro-tag-bg`; инлайн-стили запрещены VI-инвариантом):

   ```html
   <div class="hro__tags">
     <span class="ui-tag hro__tag">Стабильная компания</span>
     <!-- .cp-hero__tag--violet { --hro-tag-bg: color-mix(…); } — сайт -->
   </div>
   ```

4. Marquee-строки — литералы канона T16.15 (40/18/13 fw 500 uppercase
   ls 0.02em primary), не роли.
