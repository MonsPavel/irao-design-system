# TASK T17.6 — Видео-плеер ui-video

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P3

## Type

TASK (ДС, новый компонент)

## Goal

Ввести компонент «видео-постер» `ui-video`: обёртка-кнопка с постером,
градиент-оверлеем, круглой play-кнопкой и меткой времени. Потребитель
пилота — блок «Видео о работе в компании» на главной; вид — заглушка
(реального плеера в оригинале нет, клик никуда не ведёт).

## Context

Оригинал: `.video-block__player` — button с img-постером, оверлеем
(градиент к primary 72%), абсолютной play-кнопкой 88px (accent, круг) и
временем 24:23 в правом нижнем углу. Пилот повторил (pilot.css:
`.cp-video__player/poster/overlay/play/time`). Сущность типова для
медиа-каталогов группы (Rutube-эмбеды за постером).

Компонент статический (вид); поведение воспроизведения — слот сайта
(эмбед/ссылка): обёртка-кнопка или ссылка, компонент навешивает только
вид. A11y: доступное имя кнопки — параметр разметки.

## Scope

- `components/ui-video/` (ui-video.css + канон-HTML + README):
  - `ui-video` — обёртка (button/a), радиус lg, фон primary;
  - `__poster` (img, cover), `__overlay` (градиент к primary-a72),
    `__play` (круг accent, размер токеном `--ui-video-play-size`),
    `__time` (on-dark, позиция угол);
- README: do/don't — имя кнопки описывает действие («Смотреть видео
  …», не «play»); постер без alt (декоративен при наличии имени кнопки);
- пилот: блок video главной на компоненте, правила cp-video снимаются;
- стенд + эталоны.

## Out of scope

- реальный плеер/эмбед, JS-модуль — нет потребителя; при появлении —
  отдельная задача (слот data-ui-video);
- `<video>`-элемент нативный — другой контекст (контент-встройки).

## Existing implementation

- pilot.css:672–719 (cp-video: player/poster/overlay/play/time);
- оригинал: index.html видео-блок, src/blocks… (video-block).

## Implementation requirements

1. Обёртка — `<button type="button">` в каноне (кликабельный плей),
   alt постера пустой, имя — на обёртке;
2. Все размеры/цвета — токены (play — accent + on-dark, уже
   одобренная пара; градиент — primary-a72 из лестницы тинтов);
3. Пример канона:

   ```html
   <button class="ui-video" type="button">
     <img class="ui-video__poster" src="poster.jpg" alt="" loading="lazy">
     <span class="ui-video__overlay" aria-hidden="true"></span>
     <span class="ui-video__play" aria-hidden="true">▶</span>
     <span class="ui-video__time">24:23</span>
   </button>
   ```

   (play-иконка — svg-стрелка сайта; канон — слот.)
