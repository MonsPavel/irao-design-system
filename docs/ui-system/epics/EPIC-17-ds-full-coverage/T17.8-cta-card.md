# TASK T17.8 — CTA-карточка ui-card--cta

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P2

## Type

TASK (ДС, расширение компонента)

## Goal

Ввести модификатор «CTA-карточка» `ui-card--cta`: залитая поверхность
(primary или accent), центрированная композиция (заголовок + lead +
действие/ссылка). Потребители пилота: «Нет подходящей вакансии?»
(primary, email-CTA), «Все 140 вакансий» (accent, arrow-CTA) — и
баннер компании как фото-вариант (`--photo` + оверлей T17.3).

## Context

Две карточки главной + баннер компании — один приём «крупная плашка с
призывом» (pilot.css: `.cp-cta-mail__card` — primary, pad 48/20,
центр; `.cp-vacancy-search__all` — accent, flex space-between со
стрелкой-плиткой; `.cp-company-banner__body` — primary-a55 поверх
фото). CTA-плашки — стандартный блок сайтов группы («задать вопрос»,
«стать партнёром», «все новости»).

Композиция: модификатор задаёт поверхность/центрирование/ритм;
содержимое — ролями (ui-h2/ui-lead) и готовыми контролами
(ui-link/ui-button). Accent-вариант с on-dark-текстом — уже одобренная
пара исключения (T2.6/ADR-0010).

## Scope

- `components/ui-card/ui-card.css`: `ui-card--cta` + варианты
  `--primary` (surface primary), `--accent`; раскладка по умолчанию
  центр, `--row` — space-between со слотом действия (стрелка/кнопка);
- README: do/don't (один призыв на карточку; текст действия —
  действующее слово, прецедент ui-button);
- пилот: cta-mail + vacancy-search__all на модификаторе; правила
  cp-cta-mail__card/email, cp-vacancy-search__all снимаются;
- баннер компании — остаётся за фото-секцией (T17.3), CTA-модификатор
  применяется к телу баннера (центр-композиция);
- стенд ui-card: секция CTA + эталоны.

## Out of scope

- фото-фон баннера — фото-секция (T17.3);
- arrow-плитка 34px «Все вакансии» — иконка-слот разметки (svg сайта),
  компонент даёт слот, не иконку;
- hover-механики карточки (карточка — не ссылка; действие внутри).

## Existing implementation

- оригинал: index.html (cta-mail/vacancy-search), pages.css:656–674
  (banner-card);

## Implementation requirements

1. Поверхности — только токены (primary/accent); on-dark-пара текста —
   компонентом; контраст accent-варианта — исключение реестра
   (строка KNOWN_AXE_EXCEPTIONS уже покрывает пару);
2. Ритм: pad 48/24 (space-7/space-5), gap space-3; радиус lg;
3. Пример канона:

   ```html
   <div class="ui-card ui-card--cta ui-card--cta--primary">
     <h2 class="ui-h2">Нет подходящей вакансии?</h2>
     <p class="ui-lead">Расскажи о себе — возможно, мы ищем именно тебя!</p>
     <a class="ui-link" href="mailto:career@interrao.ru">career@interrao.ru</a>
   </div>
   ```

   Row-вариант (стрелка-CTA):

   ```html
   <a class="ui-card ui-card--cta ui-card--cta--accent ui-card--cta--row" href="vacancies.html">
     <span class="ui-h4">Все 140 вакансий</span>
     <svg aria-hidden="true" …arrow-up-right…></svg>
   </a>
   ```
