# TASK T17.11 — Активная пилюля по aria-current в ui-tabs

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P1

## Type

TASK (ДС-правка + adoption пилота)

## Goal

Научить `ui-tabs--pill` рисовать активную пилюлю по
`aria-current="page"` (рядом с существующим `aria-selected`) — для
межстраничных навигационных наборов без панелей. Снимает сайт-зонную
пару `.cp-subnav` (реплика правила ДС на специфичности 0,4,0 — худший
паттерн pilot.css) и сеточную обвязку поднавигации.

## Context

Поднавигация «Школьникам и студентам» (career-track/education/events) —
ссылки на страницы, собранные на `ui-tabs--pill` (T16.16). Модуль
ui-tabs.js такие наборы не инициализирует (требует панели, контракт
T13.6), а CSS ДС красит активную пилюлю только по `aria-selected` —
потому пилот реплицирует правило со специфичностью 0,4,0
(pilot.css:1057–1061: `.ui-tabs--pill.cp-subnav .ui-tabs__tab[aria-
current='page']` + `:hover`-вариант с повтором заливки — «hover пилюли
ДС гасит фон у невыбранных, его :not-исключение знает только
aria-selected»). T16.16-бэклог отмечал: «пара держалась только порядком
загрузки бандлов» — хрупкость известна.

`aria-current="page"` — каноническая семантика «текущая страница»
(прецеденты ui-chip T14.8, ui-breadcrumbs); правило в ДС делает её
первоклассной для всех nav-наборов группы.

## Scope

- components/ui-tabs/ui-tabs.css: в модификаторе `--pill` активная
  пара `[aria-selected='true']` расширяется селектором
  `:is([aria-selected='true'], [aria-current='page'])` — включая
  hover-исключения (`:not(...)`-цепочки получают обе цели);
- README ui-tabs: раздел «навигационный набор» (ссылки без панелей:
  aria-current, модуль не подключается — прецедент поднавигации);
- паттерн-слой: канон поднавигации `nvp-*` (сетка 5×1fr «сетка 264»,
  маргины 24/48 — значения pages.css:969–1001) — или при варианте B
  док-канон в patterns/list-page;
- пилот: `cp-subnav` снимается — разметка subnav() на каноне, пару
  0,4,0 удалить;
- проверка каскада: hover невибранной пилюли не гасит активную
  aria-current (кейс, ради которого пилот таскал hover-повтор).

## Out of scope

- инициализация модуля ui-tabs на наборах без панелей — сознательно
  НЕ делается (контракт T13.6: табы = панели; ссылки — навигация);
- roving tabindex на поднавигации — навигация, не табы (оговорка
  T16.16 действует).

## Implementation requirements

1. Специфичность: расширение селекторов НЕ поднимает специфичность
   существующих правил (`:is()` берёт максимум аргументов — селекторы
   атрибутные равной силы, каскад стабилен); контроль — computed-пины
   e2e обоих состояний;
2. Пример канона (навигационный набор):

   ```html
   <nav class="ui-tabs ui-tabs--pill nvp" aria-label="Разделы школьникам и студентам">
     <div class="ui-tabs__list">
       <a class="ui-tabs__tab" href="practices.html">Практики</a>
       <a class="ui-tabs__tab" href="internships.html" aria-current="page">Стажировки</a>
       …
     </div>
   </nav>
   ```
