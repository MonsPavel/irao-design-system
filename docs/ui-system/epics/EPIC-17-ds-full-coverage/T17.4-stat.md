# TASK T17.4 — Компонент ui-stat

## Epic

[EPIC-17 — Полнота ДС: карьерный портал из компонентов](README.md)

## Priority

P2

## Type

TASK (ДС, новый компонент)

## Goal

Ввести компонент «статистика» `ui-stat`: крупное значение + подпись +
опциональная сноска; варианты поверхности — `--glass` (стекло на фото),
`--filled` (primary), `--deep` (blue-deep). Потребители пилота:
статы холдинга (3 стеклянные на фото), статы компании (3 primary),
преимущества компании (4 blue-deep) — 10 инстансов трёх вариантов.

## Context

Числа-плашки — повторяющаяся сущность корпоративных лендингов группы
(«50% молодых специалистов», «60+ тысяч», «Топ-20»). Пилот собрал три
вариации руками (pilot.css: `.cp-holding__stat*` — стекло+рамка на
фото-фоне; `.cp-company-stats__*` — сплошной primary со сноской
on-dark-muted; `.cp-company-adv__*` — blue-deep с заголовком-ролей).
T15.2 уже фиксировал: «статы — вторая вариация блока статистики…
унификация дороже двух вариаций» — компонент с вариантами снимает
вопрос навсегда.

Канон значений: значение — роль ui-h2 (holding) / ui-h2 на тёмном
(company), подпись — ui-small (muted на светлом / on-dark-muted на
тёмном), сноска — fs-micro с прозрачностью 0.72 у holding (maps на
on-dark-muted), паддинги 16/24…20/24 «как есть».

## Scope

- `components/ui-stat/` (ui-stat.css + README + канон-HTML):
  - `ui-stat` — база: флекс-колонка, gap, паддинги, радиус md;
  - элементы `__value` (роль-хук ui-h2 на сайте), `__label`, `__note`;
  - варианты: `--glass` (bg glass-dark, рамка on-dark-muted — на фото),
    `--filled` (primary, текст on-dark), `--deep` (surface-blue-deep);
  - on-dark-пары цветов в компоненте, AA-гейт (on-dark-muted уже
    одобренная пара);
- пилот: holding-stats (glass на фото-секции), company-stats (filled),
  company-adv (deep, значение — роль ui-h4) — на компоненте; правила
  `cp-holding__stat*`, `cp-company-stats*`, `cp-company-adv*` (кроме
  сеток-раскладок) снимаются;
- док-страница стенда в showcase (по док-шаблону T10.1) + строка в
  индексе каталога.

## Out of scope

- сетки стат (3/4 колонки) — раскладка страницы (`ui-grid` уже есть);
- анимации счётчиков — нет в оригинале;
- photo-фон секции — фото-секция (отдельная задача эпика), компонент
  живёт внутри.

## Existing implementation

- pilot.css:440–468 (holding stats: glass-dark + рамка + сноска
  fs-micro), 1741–1769 (company stats: primary-плашки 20/24),
  1780–1804 (company adv: blue-deep);
- источники оригинала: src/pages/company.html, pages.css:796–825;
- прецедент поверхности: ui-card--filled (blue-50).

## Implementation requirements

1. Значение/подпись/сноска — семантика `<dl>`/`<li>`: канон —
   `<ul>` из `<li class="ui-stat">` (прецедент holding-списка);
2. Размер значения — НЕ компонентом: значение несёт роль (ui-h2/ui-h4),
   компонент задаёт только поверхность и ритм (урок «визуал ≠
   семантика», typography-roles);
3. Цветовые пары — только существующие токены (glass-dark,
   primary, surface-blue-deep, text-on-dark(-muted)); hex-гейт;
4. Пример канона (статы холдинга):

   ```html
   <ul class="ui-grid ui-grid--3">
     <li class="ui-stat ui-stat--glass">
       <span class="ui-stat__value ui-h2">50%</span>
       <span class="ui-stat__label">молодых специалистов получают
         карьерное продвижение</span>
       <span class="ui-stat__note">* по данным мониторинга</span>
     </li>
     …
   </ul>
   ```
