## Epic

## Priority

P2.

## Type

DS-pattern (паттерн-слой, прецедент lnk-/lgo- T17.9, hro/mrq/mdl/cvh T17.15).

## Goal

Каркас «постерной карточки» — цветной постер с крупным заголовком, текстом,
иллюстрацией в рост и круглой кнопкой-действием — в паттерн-слое ДС, чтобы
сайт-зона клона (блок «Школьникам и студентам» главной) собиралась из
канона, а не из самописных правил.

## Context

Источник — оригинал career-portal, блок `.students--illustrated`
(src/blocks/students/students.css — значения ниже, строки указаны):

- карточка: relative, flex-колонка, **min-height 600px** (440 ≤1023,
  380 ≤767 — переформулировать mobile-first), padding 20px,
  border-radius `--radius-card` 16px, overflow hidden (:84-93);
- три тона заливки (:94-96): peach `#FFDDC7` (вне токенов — завести
  тинт/хук по прецеденту `--hro-tag-bg` T17.15), navy `--color-primary-deep`
  (→ `--ui-color-primary-deep`), light `--color-surface-blue-50`
  (→ `--ui-color-surface-muted`);
- тело: relative z1, flex-колонка, gap 12px (:98-103); заголовок —
  fs-h3/fw-h3/1.3/letter-spacing −0.02em, color text (on-dark на navy)
  (:105-113); текст — fs-body/lh-body, color text (on-dark на navy)
  (:115-121);
- иллюстрация: absolute, pointer-events none, координаты по тонам
  (:124-148) — peach left 0 / top 42% / width 67%; navy left 6% / top 43% /
  width 56%; light right −8% / top 45% / width 63% («как есть», вне шкалы);
- кнопка-действие: absolute right/bottom 20px, 52×52, круглая, три тона —
  orange accent / white surface / navy primary, hover scale 1.08
  (:150-170);
- состояние наведения карточки — не диктуется (в оригинале только кнопка).

Потребитель — блок «Школьникам и студентам» главной клона (сейчас собран
на `lnk-card`, T17.9; renderDifference students 926→514 — см. compare
30.10/31.10). Второго потребителя нет — компонент dist не создаётся
(прецедент tlp- T17.10).

## Acceptance Criteria

1. Связка pstr- в паттерн-слое на токенах (без hex вне color-mix-
   комментариев; peach-тон — через хук с color-mix от токена или новый
   семантический тинт по решению ревью), гейт префиксов слоя расширен.
2. Скрин-пары 375/768/1440 канона против оригинала `.students__card`
   (эталоны спеки — из контейнера; расхождение рендера ≤4px по каркасу,
   тоны/координаты иллюстраций «как есть»).
3. Pilot adoption: блок students главной на pstr-; BLOCK_PROBE students
   compare — высота блока приближается к оригиналу 926 (порог ±4px
   недостижим из-за состава контента — осознанная оговорка в REPORT §6.2).
4. Юнит/e2e зелёные локально и в CI; эталоны — контейнерный пересъём;
   линт (stylelint BEM-паттерн pstr- под `^pstr(__[a-z-]+)?(--[a-z-]+)?$`)
   чист.
5. README паттерна: API-таблица, do/don't (доступное имя, иллюстрация
   декоративна), синхрон с DOCUMENTATION-гайдом.
