# TASK T5.2 — Нативный select, checkbox, radio

## Epic

[EPIC-5 — Forms](README.md)

## Priority

P0

## Type

TASK

## Goal

Стилизованные, но полностью нативные select/checkbox/radio: клавиатурная доступность и скринридер «из коробки», без единой ARIA-костыли.

## Context

career-portal использует нативные инпуты с `accent-color: var(--color-primary)` (класс A аудита) — правильная база. Кастомный listbox (T7.3) строится позже поверх этого нативного фундамента и обязан деградировать именно к нему.

## Scope

- `ui-field__select` — стилизация нативного select под дизайн полей (стрелка-иконка фоновой svg, appearance-none с сохранением нативного выпадающего списка);
- `ui-checkbox` — label-обёртка: нативный input + текст (вкл. вариант согласия с длинным текстом и ссылкой); групповая раскладка;
- `ui-radio` + `ui-radio-group` — группа обязана иметь `fieldset/legend` (правило доки + html-validate); раскладка `radio-row` из career-portal;
- состояния error у чекбоксов/радио (через обёртку `--error` + aria-describedby);
- `accent-color` из токена primary.

## Out of scope

- Кастомный listbox-селект (T7.3);
- switch-переключатели (нет требований; появятся — отдельный модификатор checkbox по нативному паттерну);
- многоуровневые select (нет требований).

## Existing implementation

career-portal `components.css` `.checkbox`, `.radio`, `.radio-row` и `.field__select` — переносим с токенизацией; интеграция с ui-field-обвязкой новая.

## Implementation requirements

1. Нативный select не скрывается никогда (никаких opacity-0-подмен до T7.3, который сам синхронизируется).
2. Группа radio: стрелки ↑↓←→ работают нативно; legend обязателен (html-validate).
3. Checkbox согласия: текст с вложенной ссылкой — кликабельность ссылки внутри label (паттерн: label не перехватывает клики по a).
4. `box-sizing` на корнях.

## Technical considerations

- `appearance: none` для select только вместе с явной стрелкой-индикатором (не терять аффорданс);
- `accent-color` — современный нативный путь (матрица evergreen ×2).

## Acceptance Criteria

- [ ] e2e: Space переключает checkbox; стрелки ходят по radio-группе; select открывается нативно (Alt+↓/Enter — проверка базовой нативности);
- [ ] html-validate: radio-группа без fieldset/legend — ошибка;
- [ ] axe чист; label связности зелёные.

## Testing requirements

Tests first: e2e клавиатурных сценариев (Space/стрелки), связности label; axe; visual.

## Accessibility requirements

- Полностью нативная семантика (без ARIA);
- fieldset/legend для групп;
- error-состояния связаны с группой (aria-describedby на fieldset — паттерн в доке).
