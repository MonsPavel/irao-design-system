# TASK T13.1 — destroy()-контракт: реестр instances и восстановление no-JS-состояния

## Type

## Goal

Один паттерн-дефект в трёх компонентах и одном контракте: destroy() не удаляет инстанс из module-level реестра instances — после destroy() компонент «воскресает» без слушателей. Устранить по всем четырём местам кластера A бэклога.

## Context

Кластер A триажа 10.10 ([BACKLOG.md §A](../../../process/nightly/BACKLOG.md)): реестр instances течёт в ui-modal (после destroy() + IraoUI.modal.open() диалог открывается без обработчиков, скролл-лок не снимается никогда), ui-form (документированный AJAX-сценарий с пересозданием форм накапливает отцепленные DOM-корни), ui-dropdown (closeAll() воскрешает уничтоженную разметку); в ui-select wrap-режиме destroy() не восстанавливает inline position обёртки сайта.

## Scope

- components/ui-modal/ui-modal.js: destroy() удаляет инстанс из instances (splice по indexOf) или помечает уничтоженным и пропускает в instanceOf;
- components/ui-form/ui-form.js: то же + публичный destroy в API модуля по контракту template;
- components/ui-dropdown/ui-dropdown.js: то же;
- components/ui-select/ui-select.js: запомнить прежнее inline-значение position в wrap-режиме и восстановить в destroy() (пара lock.rootOverflow в ui-modal);
- README компонентов обновить, если задекларирован destroy в API.

## Out of scope

- Поведенческие фиксы ui-modal/ui-dropdown/ui-select из T13.2/T13.6 (preventDefault, 100vw, optgroup);
- Изменение публичного API, кроме заявленного добавления destroy.

## Existing implementation

Все четыре компонента на main; паттерн instances.push при init, destroy() снимает слушатели и INIT_ATTR.

## Implementation requirements

1. TDD: сначала падающие юнит-пины («после destroy() реестр пуст», «после destroy() open(el) инициализирует заново и слушатели работают», «destroy восстанавливает inline position»).
2. Поведение destroy() в остальных аспектах не меняется (слушатели, INIT_ATTR, aria-сброс — как есть).

## Technical considerations

- Проверить, что closeAll()/unlock() не спотыкаются о пустой реестр;
- юнит-пин порядка «reopen раньше чистки» — вне этой задачи (T13.6).
