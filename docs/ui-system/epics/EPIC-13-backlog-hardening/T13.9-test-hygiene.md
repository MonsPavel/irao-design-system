## Goal

Четырнадцать замечаний к качеству тестовой базы: ассерты, которые не могут упасть, мёртвые ветки и непокрытые ветки гейтов — тесты снова становятся источником защиты, а не ритуалом.

## Context

Ревью раундов T3.2–T9.2 системно находило: тавтологические ассерты, недостижимые регэкспы, ветки чекера без единого исполняющего теста, слабые пины. Кластер E бэклога (часть).

## Scope

- tests/e2e/focus.spec.js: тавтологичный ассерт заменён проверкой уникальности последовательности (Set из tag/hasTabindex); мёртвый return в injectAttack удалён; сценарий «клик мышью → focusVisible=false, outlineStyle='none'» добавлен;
- tests/unit/focus.test.js: пин доки поленными формами селекторов (${target}:focus-visible);
- tests/e2e/scaling.spec.js: ветки hscroll (инжект body{min-width:400vw} → kind 'hscroll') и contract (снятие data-ui-check-layout → kind 'contract') покрыты; applyZoom — одна CDP-сессия на тест с session.detach(); оговорка про позиционированные маркерные узлы — в README чекера (или правило «маркерные узлы — потоковые»);
- tests/unit/layout.test.js: пин порядка gap-правила --4 через lastIndexOf обоих якорей (пинит реальную пару «top-level gap-правило после lg-media сетки»);
- showcase/pages/typography: вычисленные значения токенов мобильной базы или явная ссылка «значения — стенд tokens»;
- tests/e2e/typography.spec.js: обход иерархии сверяется с ожидаемым набором стендов (страница вне индекса — красный);
- .htmlvalidate.js: подсчёт радио-групп скоупится по ближайшему form-предку, радио без name пропускаются;
- tests/unit/forms.test.js: мёртвый регэксп fieldset-перед-legend удалён;
- tests/contrast/derived-lib.mjs: resolveColorSpec на спеке без token/mix бросает внятную ошибку → configErrors;
- tests/unit/stands.test.js: пин «для компонентных имён существует <имя>.html или pages/<имя>/index.html».
