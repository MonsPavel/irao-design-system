- components/ui-dropdown/ui-dropdown.js: пункты меню читаются в момент обработки клавиатуры (itemsOf) либо граница «снапшот при init» в README «Известные границы»; aria-haspopup="true" на триггере при init, снимается в destroy (README/API-таблица обновить);
- tests/e2e/ui-dropdown.spec.js: пин computed width меню на вьюпорте 375 после открытия (кламп);
- components/ui-dropdown/README.md: убрать --ui-color-text из перечня токенов;
- components/ui-dropdown/ui-dropdown.css:8-11 + tokens/semantic.css:332: формулировка «однослойная аппроксимация тени dropdown, заведённая в T2.2»;
- showcase/pages/ui-dropdown (или README): фраза «механизм сборки — один стенд на компонент; оба назначения — секции одной страницы»;
- components/ui-tabs/ui-tabs.js: таб вне .ui-tabs__list — Error в цикле сбора → console.warn через init() (симметрично брой id); select(index) игнорирует индексы вне диапазона;
- tests/e2e/ui-tabs.spec.js: инлайн-скрипты вырезаются из source перед регэксп-пинами;
- components/ui-modal/ui-modal.js: onDocumentClick игнорирует не-левые кнопки и модификаторы (Ctrl/Cmd/Shift/Alt);
- components/ui-modal/ui-modal.css: --full width: 100% (или inset-inline: 0 + width:auto) вместо 100vw;
- components/ui-modal/ui-modal.js:317: при входе в новый цикл с cleanedUp===false сначала отпустить резерв лока прошлого цикла; юнит-пин порядка «reopen раньше чистки»;
- components/ui-loader/README.md: смягчить формулировку live-региона (надёжно — смена текста существующего региона или снятие aria-busy);
- tests/e2e/ui-loader.spec.js:82: label «период — 0.4s сырым временем (значение --ui-transition-slow)».
