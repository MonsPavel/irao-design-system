## Goal

## Context

Линт-правила дают ложный шум (якоря без href, регистр _BLANK) и молчат об отсутствии h1; disabled-кнопка выглядит кликабельной; hover accent контраст не пиннут; стенд skip-link содержит дубль каркасного якоря. Примитивы задают эталон, который копирует вся система.

## Scope

- components/ui-button/ui-button.css: .ui-button:disabled { cursor: default };
- components/ui-button/ui-button.css:28-31: комментарий переформулирован (защитное переобъявление подписей, без утверждения о «равной специфичности»);
- tests/e2e/ui-button.spec.js: пин hover accent toBeCloseTo(2.91, 1) или пол ≥2.85 с комментарием об известном разрыве; мёртвая ветка data-ui-button-bg удалена;
- tests/unit/derived-states-handoff.test.js: нормализация пробелов секции, возврат точного сравнения color-mix-строки;
- tests/README.md: абзац о per-node исключениях KNOWN_AXE_EXCEPTIONS (id+подстрока+обоснование) + строка трёх исключений стенда ui-button;
- components/ui-link/README.md: hover-формулировка разделена (токен-гейт pairs.config.mjs vs компонентный e2e ≥ 4.5:1);
- .htmlvalidate.js: irao/link-accessible-name пропускает ссылки без href + якорь без href в позитивный контроль lint-cases; сравнение target без регистра (toLowerCase);
- .htmlvalidate.js + tests/lint-cases/html/no-h1.html: страница без h1 репортится (первый заголовок >1 при отсутствии h1 либо zero-h1 в OneH1), негативная фикстура в реестре tools/run-lint-cases.mjs;
- showcase/build.mjs (или стенд ui-skip-link): литеральный дубль каркасного skip-link-якоря на стенде исключён.

## Out of scope

- Пометка-исключение accent в файле задачи T4.2 и стратегия .prettierignore — владелец (файлы задач конвейер не редактирует, кластер П);
- Инлайн-<style>-практика стенда ui-button — правка не требуется (значения на токенах, нарушения нет).

## Existing implementation

## Implementation requirements

- репорт отсутствия h1 не должен сломать существующие страницы полигона (все начинаются с h1 — проверено прогоном в раунде ревью).
