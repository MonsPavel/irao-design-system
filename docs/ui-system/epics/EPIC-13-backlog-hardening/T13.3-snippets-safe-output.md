# TASK T13.3 — Bitrix-сниппеты и копируемые шаблоны: безопасный вывод и стык с формой

## Epic

[EPIC-13 — Backlog Hardening](README.md)

## Priority

## Type

TASK

## Goal

Все копируемые интеграторами шаблоны выводят данные безопасно и согласованно с компонентами — кластер C бэклога (4 замечания) + смежные: describedby в form-error-render и юнит-порт алгоритма пагинации.

## Context

Сниппеты и README-паттерны — источник копипасты для Bitrix-разработчиков; XSS-контракт уже проводился через T5.4 (htmlspecialchars — прецедент), но ревью нашло ещё четыре места с небезопасным/дегенеративным выводом и один недокументированный стык с формой.

## Scope

- components/ui-tabs/README.md + стенд: JSON-паттерн показывает escapeHtml-хелпер (или createElement/textContent) перед innerHTML-конкатенацией + комментарий о границе допустимости;
- bitrix/snippets/pagination.php: гвард if ($total < 2) return …; по практике README ui-pagination, правка докблока; флаги ENT_QUOTES | ENT_SUBSTITUTE в замыкании $e;
- patterns/detail-page/README.md: htmlspecialcharsbx для NAME и даты в Bitrix-сниппете, FormatDate с guard на пустое ACTIVE_FROM (без datetime="1970-01-01");
- bitrix/snippets/form-error-render.php: третий параметр $describedBy (id подсказок), вывод перед {id}-error как в каноне; в примере использования — поле с hint;
- tests/unit/pagination.test.js: JS-эталонный порт расчёта окна («…», клампинг, разрыв=номер) с краями: gap=1 → номер, gap>1 → «…», total=1/2, current вне диапазона.

## Out of scope

- Серверные рецепты Битрикса; исполняемый PHP-гейт (php недоступен) — эквивалент покрыт JS-портом;
- ui-form.js (только PHP-сниппет).

## Existing implementation

Сниппеты T5.6/T6.3, паттерны T8.1/T8.2; прецедент экранирования — form-error-render.php (T5.6).

## Implementation requirements

1. PHP-правки сверяются чтением + JS-порт; синтаксис heredoc/quoted не ломать.
2. Каждый пример остаётся копипаст-готовым (Label in Name/aria-структура не деградируют).

## Technical considerations

- ENT_SUBSTITUTE предотвращает молчаливое превращение невалидной UTF-8 в пустую строку;
- порт алгоритма пагинации — независимая реализация в тесте, не import из билда (PHP не исполняется).

## Dependencies

Отсутствуют: все компонентные задачи исходного плана закрыты.
