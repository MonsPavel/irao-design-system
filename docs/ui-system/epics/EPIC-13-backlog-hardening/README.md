# EPIC-13 — Backlog Hardening

## Goal

Обработать накопленный бэклог неблокирующих замечаний ночного ревью ([BACKLOG.md](../../../process/nightly/BACKLOG.md), триаж 10.10: 101 открытое замечание): кодовые фиксы кластеров A–F и доки-правки — задачами конвейера, процессные решения (кластер П) — владельцем вне конвейера.

## Context

Ночные циклы T3.2–T11.1 дали 101 открытое medium/low-замечание, сгруппированное триажем 10.10 в кластеры A–П (см. вводку BACKLOG.md). Решение владельца 10.10: бэклог попадает в эпик и выполняется ночным конвейером; интеграционные пилоты EPIC-11 (T11.2–T11.4) одновременно выведены из активного реестра в `blocked`. Детали каждого замечания (доказательства, воспроизведения, точные строки) — источник истины в BACKLOG.md; секции ## Scope задач ниже — компактный указатель по пунктам.
