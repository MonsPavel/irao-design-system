## Scope

- components/ui-select/ui-select.js: опция после последнего optgroup добавляется в корень списка (set индексов опций групп); disabled группы пробрасывается в disabled её опций (навигация/typeahead пропускают через существующие проверки);
- components/ui-select/ui-select.js: sync подписей построенных триггеров по событию reset формы (кластер B, замечание T8.1);
- components/ui-select/README.md: «Известные границы» — репопуляция опций существующего select не поддерживается (destroy+init или пересоздание); Do переформулировать: label[for] рядом с обёрткой, текст внутри wrap-обёртки запрещён; убрать --ui-border-width из списка токенов или пометить «для wrap-обёртки сайта»;
- components/ui-select/ui-select.css: top: calc(100% + 0.375rem) — обоснование «перенос как есть» в шапку файла либо замена на --ui-space-1 (эталоны переснимаются в контейнере).
