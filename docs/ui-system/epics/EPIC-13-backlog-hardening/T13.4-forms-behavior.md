## Goal

Поведенческие фиксы и покрытие форменного стека по пунктам бэклога (15 замечаний): Label in Name, role="list", radio-группы, aria-контракт, coverage измерение.

## Context

Формы — самый нагруженный стек системы (EPIC-5); ревью нашло краевые дефекты поведения (radio-группы, пустой override, висячие aria-ссылки) и дыры покрытия (onFormReset, radio e2e, метрика AC T5.5).

## Scope

- components/ui-file: доступное имя инпута включает видимую подпись кнопки (id span в aria-labelledby; WCAG 2.5.3) — канон, стенд, README, юнит-пин; hint канона совместим с required; юнит-сценарий onFormReset (dispatch Event('reset') → «Файл не выбран»); таутологичный пин tests/unit/file.test.js заменён пином отсутствия data-ui-file у демо-коробки;
- components/ui-form/ui-form.html + css + стенд + README + Bitrix-сниппет: role="list" на .ui-form__summary-list с inline html-validate-disable директивами по образцу ui-breadcrumbs;
- components/ui-form/ui-form.js: пустой data-ui-error="" не считается валидным override (truthy); поле без обвязки .ui-field получает реальный error-элемент рядом (без висячей aria-ссылки); pattern компилируется с 'v' при поддержке (try/catch fallback 'u') или расхождение задокументировано в README-таблице; состояние radio-группы слушает input/change на всех radio группы;
- showcase/pages/ui-form: спиннер в кнопке событийной формы; footnote внутрь свап-зоны либо правка README «Состояния»; required-radio-группа в секцию валидации стенда + e2e (сабмит с ошибкой, aria на всех radio, одна запись summary, чистка);
- components/ui-field/README.md: кросс-ссылка на ui-file-паттерн (span + aria-labelledby, второй label с for запрещён);
- showcase/pages/ui-field: текст ошибки демо-«Логина» согласован с его hint;
- components/ui-form/README.md: строка-кросс-ссылка «порядок aside/main в DOM — за страницей (см. паттерн form-page)»;
- coverage: devDependency @vitest/coverage-v8 + скрипт, измерение по components/ui-form/ui-form.js, число в отчёте задачи (файл задачи T5.5 не редактируется).

## Out of scope

- Bitrix-сниппет form-error-render (T13.3);
- файлы задач T5.5/T5.6 — не редактировать.

## Existing implementation

Стек форм на main (T5.1–T5.6), e2e ui-form-validate, стенд ui-form.

## Implementation requirements

1. TDD: падающие тесты до правок — Label in Name (юнит), onFormReset, empty override, hanging aria, radio-группы (jsdom), radio e2e.
2. Эталонные PNG — пересъёмка в контейнере при визуальных изменениях стенда.

## Technical considerations

- aria-describedby порядок hint→error сохраняется; role="alert" семантика не меняется;
- 'v'-флаг: проверка поддержки через try/catch с fallback на 'u' (старые браузеры).
