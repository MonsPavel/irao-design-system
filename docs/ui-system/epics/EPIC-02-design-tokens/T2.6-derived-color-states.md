# TASK T2.6 — Производные цвета состояний (color-mix) + ADR

## Epic

[EPIC-2 — Design Tokens](README.md)

## Priority

P1

## Type

TASK

## Goal

Единый способ hover/active-производных цветов без ручных hex-дублей; зафиксировать решение ADR (color-mix против явных hover-токенов).

## Context

Матрица браузеров «evergreen ×2» (Phase 0) разрешает `color-mix()` (Chromium 111+, Firefox 113+, Safari 16.2+). В career-portal hover-цвета захардкожены рядом с базовыми (--color-accent-light рядом с --color-accent) — при темизации такие дубли забывают переопределять.

## Scope

- hover-пары, **заданные одобренным дизайном** career-portal (`--color-blue-700` #164B89 как hover primary, `--color-accent-light` #F37131 как hover accent), переносятся как семантические токены (`--ui-color-primary-hover`, `--ui-color-accent-hover`) — одобренный визуал не пересчитывается;
- `color-mix` — стандарт для производных состояний, которые дизайн не задавал (active, hover-производные outline/light-вариантов);
- ADR: границы применения «явные hover-токены vs color-mix» + минимальные версии поддержки;
- применить в T4.2 (button): hover — из токенов-пар, active — color-mix.

## Out of scope

- Полная матрица состояний всех компонентов (делается в их задачах);
- focus-цвета (уже токены в T2.2, не производные).

## Existing implementation

career-portal: hover-пары заданы дизайн-макетом и лежат в `variables.css` рядом с базовыми (`--color-blue-700`, `--color-accent-light`) — это часть одобренного визуала, переносим пары токенами. Анти-паттерном остаётся hex в правилах компонентов (`.btn--primary:hover { background: var(--color-blue-700) }` без токена) — способ выражения меняем, значения нет.

## Implementation requirements

1. ADR фиксирует: стандарт = color-mix; исключение (если возникнет) = отдельный семантический токен через ревью-гейт.
2. Контраст производных состояний попадает в сферу T9.2 (ревизия производных) — ссылка из ADR.

## Technical considerations

- `color-mix` в `:hover` вычисляется браузером из токенов — тема меняет hover автоматически (проверить в e2e вместе с темой T2.4);
- процент смешения для производных (только не заданные дизайном состояния) — конвенция (88% базовый + black), фиксируется в ADR; hover-пары одобренного дизайна константой не заменяются.
