# TASK T2.2 — Семантический слой токенов + стенд токенов

## Epic

[EPIC-2 — Design Tokens](README.md)

## Priority

P0

## Type

TASK

## Goal

Создать слой 2 (ADR-0009) — полный смысловой API значений для всех компонентов: цвета-смыслы, focus, типографика rem, spacing, радиусы, тени, z-index, transitions, containers — и страницу-стенд, визуализирующую 100% токенов.

## Context

Состав зафиксирован 02-architecture §3.2. Отличия от career-portal: px→rem (база 16 на `html`); spacing-шкала 4/8/12/16/24/32/48/64 вместо произвольных значений; z-index-лестница 70/100/150/200/300/400 (сегодня в career-portal плавающие 70 и 200); тени-токены вместо inline rgba; focus-токены для ADR-0001. Мобильные значения типографики берутся из media-правил career-portal (1023: h1 48/h2 40/h3 30/body 18; 767: h1 34/h2 28/h3 24/h4 20/lead 18/body 16).

## Scope

- `tokens/semantic.css`: полный состав по §3.2 (цвета-смыслы, focus-тройка, типографика fs/lh/fw в rem, spacing 1–8, радиусы, border-токены, тени sm/md/lg, z-index, transitions fast/base/slow, container-max/pad);
- страница-стенд «Tokens»: сетки цветов (со значениями), шкала типографики, линейка отступов, радиусы/тени/z-index-таблица;
- правило «компонент читает только слой 2» — активировать в stylelint (запрет `var(--ui-blue-*)` вне tokens/).

## Out of scope

- Значения hover/active-производных (T2.6);
- тесты контраста (T2.3);
- брейкпоинты — константы, не переменные (T2.5, отдельная документация).

## Existing implementation

career-portal `css/variables.css` (типографика тройками, радиусы card/pill/small/big, container 1440/40, transition) — переносим структуру с пересчётом в rem и расширением.

## Implementation requirements

1. Типографика: каждая текстовая роль = тройка `--ui-fs-* / --ui-lh-* / --ui-fw-*`; значения по брейкпоинтам — через переопределение в media (mobile-first: базовые = мобильные, рост к lg).
2. Стенд токенов генерируется из файлов токенов (не ручная страница) — иначе разъедется при добавлении.
3. e2e-полнота: счётчик узлов стенда = счётчик токенов в файлах.

## Technical considerations

- rem-типографика — основа требования «не ломается при увеличении шрифта» (T3.6);
- контейнеры: `--ui-container-max: 90rem` (1440) + паддинги 16/24/32 по брейкпоинтам.
