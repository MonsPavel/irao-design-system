# TASK T2.1 — Токены-примитивы (палитра)

## Epic

[EPIC-2 — Design Tokens](README.md)

## Priority

P0

## Type

TASK

## Goal

Создать слой 1 (ADR-0009) — полный словарь «сырых» значений `--ui-*`, закрыть все hex, сейчас захардкоженные в компонентах career-portal.

## Context

Источник — `css/variables.css` career-portal: primary-deep/accent-серия, text/surface, blue-50/100, peach-серия, plum, glass-значения, статусы error/success, палитра тегов, фон внутренних страниц. В `components.css`/`pages.css` career-portal вне токенов живут hex'ы: #D6D6D6 (рамка карточки), #B9C6DE (hover-рамка), #C4CDDC (разделители крошек) — их нужно ввести в палитру.

## Scope

- `tokens/primitives.css`: перенос палитры career-portal + дополнения:
  - полные шкалы статусов (red/green/orange с производными bg);
  - нейтральная шкала серых 100–900 (для рамок/разделителей/поверхностей);
  - цвета рамок/разделителей из захардкоженных hex;
  - значения теней как сырьё для семантических shadow-токенов (цветовая составляющая);
- таблица соответствия «career-portal значение → примитив» в PR.

## Out of scope

- Семантический слой (T2.2);
- корректировки под контраст (T2.3 меняет значения семантики, не примитивов);
- VI-палитра (темы ГОСТ живут в модуле vi, не в токенах — 02 §5).

## Existing implementation

career-portal `css/variables.css` — переносим значения как есть (кроме заведомо несовместимых с AA, но правка значений произойдёт в T2.3 семантически).

## Implementation requirements

1. Каждому примитиву — комментарий с происхождением (career-portal / новый / исправлен).
2. Именование шкалами: `--ui-blue-800`, `--ui-gray-300` — без «маркетинговых» имён на слое 1.
3. stylelint (T1.2) подтверждает: hex существуют только в этом файле.
4. Таблица соответствия — инструмент контроля отклонений: значения, отличные от одобренного дизайна career-portal (не перенос, а изменение), помечаются `design-decision` и требуют подтверждения владельца дизайна до мержа.

## Technical considerations

- Файл загружается первым в ui-core (порядок T1.3);
- темы НЕ переопределяют примитивы (ADR-0009).
