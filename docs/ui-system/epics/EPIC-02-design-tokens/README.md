# EPIC-2 — Design Tokens

## Goal

Вся визуальная правда системы — в двух слоях токенов `--ui-*` (ADR-0009), с инструментально подтверждённым контрастом AA дефолтной палитры и доказанным механизмом тем.

## Context

Фаза 2 roadmap. Источник значений — `css/variables.css` career-portal (аудит §3): ~35 цветов, типографика px, 4 радиуса, container, transition. Недостающие группы (spacing, z-index, тени, focus, производные состояний) создаются с нуля. Требование «один бренд Интер РАО» (Phase 0) — мульти-брендовых тем нет, механизм тем проверяется синтетической тестовой темой.

## Scope

- примитивы (палитра со шкалами), семантика (полный состав 02-architecture §3.2);
- типографика px→rem; spacing 4–64; z-index-лестница; тени; focus-токены;
- контраст-валидация как PR-гейт (node-скрипт);
- механизм тем `data-ui-theme` + `themes/theme-test.css`;
- шкала брейкпоинтов + stylelint-правило mobile-first;
- производные цвета состояний через `color-mix` (ADR по fallback).

## Out of scope

- Реальные мульти-брендовые темы (Phase 0: один бренд; появятся minor-версиями);
- base-стили и подключение токенов к элементам (EPIC-3);
- компонентные токены слоя 3 (только по мере доказанной потребности — ADR-0009).

## Expected outcome

Стенд «Tokens» визуализирует 100% токенов; hex вне `tokens/primitives.css` невозможен (stylelint); все текстовые пары ≥ 4.5:1 (крупные ≥ 3:1); смена темы на стенде меняет вид без правок компонентов.

## Acceptance Criteria

- [ ] `ui-core.min.css` начинается с tokens; стенд токенов полный (e2e-проверка полноты);
- [ ] Контраст-скрипт зелёный в CI; отчёт прикладывается;
- [ ] Механизм тем доказан e2e (смена data-ui-theme без правок компонентов; старая тема совместима с core после добавления новых токенов);
- [ ] Все последующие CSS-задачи физически не могут использовать hex/max-width-media.

## Definition of Done

- [ ] Все 6 задач закрыты, AC выполнены
- [ ] Дока «Как пользоваться токенами» (вкл. правило «компонент не знает примитивов»)
- [ ] Диффы против career-portal задокументированы (что и почему изменилось — rem, контраст, muted-серый)

## Risks

- Расползание токенов → ревью-гейт «новый семантический токен только с потребителем»;
- color-mix на границе матрицы evergreen ×2 → ADR в T2.6 с явными версиями;
- **Дрейф от одобренного дизайна** (контраст-фиксы, генерация цветов состояний) → career-portal = эталон визуала: отклонения только через `design-decision` в таблице диффов с согласованием владельца дизайна (см. T2.1/T2.3/T2.6).
