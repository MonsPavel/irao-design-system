## Goal

Закончить с «плавающими» брейкпоинтами career-portal (1439/1365/1279/1023/767/479/359 — семь разных значений, не токенизированы): зафиксировать шкалу и включить линтер-гейт.

## Context

Media-query нельзя выразить CSS-переменной — шкала фиксируется конвенцией + stylelint. Утверждённая шкала (02 §3.2): `sm 480 / md 768 / lg 1024 / xl 1280 / 2xl 1440`, только `min-width` (mobile-first — требование ТЗ №1). Значения career-portal совместимы: 767→768-1, 1023→1024-1, 1439→1440-1 — та же сетка, инвертированная в min-width.

## Scope

- stylelint-правило: media-feature только `min-width`, значения только из шкалы (px);
- дока «Адаптивный подход»: mobile-first, критические вьюпорты для проверки (375/768/1440 + 320 smoke), правило переломов по контенту;
- механизм исключений: только через ADR (запись с обоснованием).

## Out of scope

- Переписывание существующих media (их ещё нет — гейт включает­ся до EPIC-3);
- container queries (нет требований; появятся — отдельным ADR).

## Existing implementation

career-portal: max-width desktop-first — подход осознанно не переносится (класс C аудита).

## Implementation requirements

1. Шкала — в доках и в stylelint-конфиге синхронно (один источник: константы в конфиге, дока ссылается).
2. Проверка: файл с `@media (max-width: 767px)` и с `@media (min-width: 999px)` оба красные.

## Technical considerations

- px vs em в media: фиксируем px для простоты (команда мала, дизайн-макеты в px);
- `2xl 1440` используется для широких декоративных секций (наследие макета 1440).
