# TASK T8.2 — Паттерн «Детальная страница»

## Goal

Референс детальной страницы (вакансия/статья/событие): крошки, заголовок с метаданными, двухколоночный контент+aside (sticky на десктопе), related-блоки; schema.org-кейс.

## Context

Структура `vacancy.html`/`article.html` career-portal: крошки → page-head (h1 + теги + метаданные) → `vacancy__main` + `vacancy__aside` (sticky-позиционирование, на мобиле — в конец потока) → related-секции. Sticky-aside на iOS имеет нюансы (position: sticky внутри overflow) — проверяется тестом.

## Scope

- док-страница паттерна:
  - крошки (T4.7) → page-head (h1, теги, мета) → контент (типографика T3.3, секции h2) + aside (sticky: CTA-кнопка, справочная панель — перенос `form-aside`-структуры);
  - related-блоки: заголовок h2 + сетка карточек;
  - schema.org-кейс: JobPosting-разметка эталонной вакансии как пример «когда уместно» (ТЗ №7): поля title, hiringOrganization, jobLocation, datePosted; для статей — Article;
- Bitrix-заметки: `bitrix:news.detail`, вывод свойств инфоблока в теги/мету, связные блоки.

## Out of scope

- Контентная типографика длинных статей (текст-зоны сайта; базовые роли уже в T3.3);
- new components.

## Existing implementation

career-portal `src/pages/vacancy.html` (main+aside), `article.html`, `build.py render_vacancy_detail` — переносим композицию; aside-структура `form-aside` частично.

## Implementation requirements

1. Aside: sticky только ≥md; на мобиле — после контента; проверка 32px-сценарием (не перекрывает).
2. CTA-панель aside: кнопка + дисклеймер (перенос паттерна «согласие на обработку ПД» из vacancy career-portal).
3. Schema-разметка эталона валидируется автотестом-парсером (как T4.7).

## Technical considerations

- `position: sticky` + `overflow`-контексты: док-предупреждение о wrapper'ах;
- метаданные (дата/время) — `<time>` с datetime.
