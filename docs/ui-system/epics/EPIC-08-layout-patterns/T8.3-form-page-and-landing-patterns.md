# TASK T8.3 — Паттерны «Страница формы» и «Landing-секция»

## Epic

[EPIC-8 — Layout & Page Patterns](README.md)

## Priority

P1

## Type

TASK

## Goal

Два замыкающих паттерна: страница-форма с информационной колонкой (vacancy-apply) и правила лендинг-секций (граница «система / сайт»).

## Context

`vacancy-apply.html` career-portal: двухколоночная раскладка (форма + form-aside со сводкой вакансии и возвратом), h1 «Отклик», дисклеймер ПД. Лендинг-секции (hero/holding/why-us) — контентные, принадлежат сайтам, но правила их сборки из системных примитивов фиксируются здесь.

## Scope

- паттерн «Страница формы»:
  - крошки + h1 + lead;
  - раскладка: форма (T5.4) + `ui-form__aside` (сводка: title/text/rows — перенос form-aside career-portal);
  - полный форма-цикл на паттерне (стенд T5.6 встраивается сюда);
  - Bitrix-заметки: шаблон формы отклика, сверка aside с данными элемента;
- паттерн «Landing-секция» (правила + мини-эталон):
  - секция = `ui-section` + контейнер + заголовок-роль + сетка карточек;
  - тёмные секции (on-dark-пары токенов), full-bleed-изображения внутри контейнера (правила T4.6);
  - правило границы: контент и уникальный дизайн секции — сайт; каркас (секция/сетка/типографика/карточки/кнопки) — система;
  - mini-эталон из 3 секций (светлая/тёмная/с-фоном) на showcase.

## Out of scope

- Дизайн конкретных лендингов (зона сайтов);
- новые компоненты.

## Existing implementation

career-portal `src/pages/vacancy-apply.html` + `.form-aside*` CSS — перенос композиции; лендинг-приёмы — из блоков главной (класс C, переносим только правила).

## Implementation requirements

1. Aside на мобиле — после формы (или до — зафиксировать по UX-логике: сводка вакансии до формы на мобиле; решение в доке).
2. Тёмные секции: все пары on-dark проходят контраст-гейт (T2.3).
3. Правила границы — в CONTRIBUTING (итог EPIC-8).

## Technical considerations

- full-bleed в контейнере: отрицательные margin от container-pad (паттерн доки, токенизированный);
- тёмная секция — фон `--ui-color-primary-deep`-семантика (surface-inverse-пара).
