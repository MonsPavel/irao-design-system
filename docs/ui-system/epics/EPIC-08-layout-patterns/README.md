# EPIC-8 — Layout & Page Patterns

## Goal

Типовые страницы собираются копипастой из паттернов без написания нового CSS: списки, детальные, формы, лендинг-секции.

## Context

Фаза 6 (P1). Перенос структурных решений страниц career-portal (vacancies/events/article/vacancy-apply) в паттерны-референсы: page-head с фильтрами, сетки карточек + пагинация + empty-state, контент+aside, форма с aside, лендинг-секции. Здесь же фиксируется граница «система / сайт» для контентных секций.

## Scope

- паттерн «Страница списка» (page-head + фильтры-чипы + сетка + пагинация + empty);
- паттерн «Детальная страница» (крошки + контент + sticky-aside + related);
- паттерны «Страница формы» и «Landing-секция»;
- правила контентных секций и границ системы.

## Out of scope

- Контентные блоки career-portal (hero/production/why-us — класс C, принадлежат сайтам);
- любые новые CSS-компоненты (только композиция существующих + минимальные layout-стили).

## Expected outcome

Страница списка собирается из паттернов без нового CSS; все паттерн-стенды в visual-регрессии; правила границ задокументированы.
