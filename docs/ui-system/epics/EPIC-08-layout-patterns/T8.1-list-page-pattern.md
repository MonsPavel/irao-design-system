# TASK T8.1 — Паттерн «Страница списка»

## Epic

[EPIC-8 — Layout & Page Patterns](README.md)

## Priority

P1

## Type

TASK

## Goal

Референс списковой страницы (вакансии/события/предложения): page-head с фильтрами, сетка карточек, пагинация, empty-состояние — собирается целиком из компонентов системы.

## Context

Структуры career-portal: `vacancies.html` (page-head + счётчик + фильтры-пилюли с select'ами + cards-grid + пагинация), `events.html` (группы upcoming/past), `education-catalog.html`. Фильтр-пилюли: обёртки select'ов с растяжкой триггера — именно тот кейс, который в T7.3 заменён на модификатор `data-ui-select="wrap"`.

## Scope

- док-страница паттерна: копируемая разметка всего цикла списка:
  - page-head: h1 (page-title) + счётчик результатов + lead-подзаголовок;
  - панель фильтров: чипы-обёртки select (IraoUI.select wrap-режим) + submit/reset (GET-форма — работает без JS);
  - сетка `ui-grid--3` + карточки (T4.4 с тегами T4.3);
  - пагинация (T6.3) + empty-state (T4.8) в ветке «ничего не найдено»;
- Bitrix-заметки: `bitrix:news.list` — шаблон цикла, GET-параметры фильтров, пагинация `$nav`;
- минимальные связующие стили паттерна (живут в showcase, не в dist — если связка нужна всем, поднимается вопрос о компоненте).

## Out of scope

- AJAX-фильтрация (зона сайта; паттерн работает перезагрузкой);
- новые компоненты.

## Existing implementation

career-portal `src/pages/vacancies.html`, `events.html`, `education-catalog.html` + `.vacancy-search` CSS — переносим композицию, не стили.

## Implementation requirements

1. Проверка «без нового CSS»: сборка эталонной страницы из доки на showcase.
2. Фильтры — форма GET: без JS отправляется кнопкой «применить»; с JS (IraoUI.select) — UX тот же.
3. Пустая выдача фильтра → empty-state с кнопкой сброса.

## Technical considerations

- Порядок фокуса: фильтры → результаты (после применения фильтра фокус на заголовок результатов — сниппет в доке);
- счётчик результатов обновляется (aria-live polite — сниппет).
