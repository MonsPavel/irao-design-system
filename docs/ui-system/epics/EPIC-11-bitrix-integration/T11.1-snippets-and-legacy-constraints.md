# TASK T11.1 — Сниппеты + legacy-констрейнты (hardening)

## Epic

[EPIC-11 — Bitrix Integration](README.md)

## Priority

P0

## Type

TASK

## Goal

Пакет копипаст-сниппетов подключения и правил выживания в legacy-CSS; расширенная e2e «legacy-атака», доказывающая стойкость компонентов.

## Context

Констрейнты зафиксированы (ADR-0008 + раздел 6 плана 06): порядок каскада, специфичность, box-sizing (ADR-0002), фокус (ADR-0001), запрет эскалации `!important`, запретные обёртки, минимальный base. Здесь они превращаются в проверяемые артефакты: сниппеты + тесты.

## Scope

- `bitrix/snippets/`: header-php (UI_VERSION, Asset::addCss core→vi, addJs, preload шрифтов, data-ui-theme опционально), подключение-опциональной-темы, JSON-данные-для-JS, breadcrumbs.php (T4.7), pagination.php (T6.3), form-error-render.php (T5.6), фокус-менеджмент серверных ошибок (inline-скрипт);
- `bitrix/integration-guide.md` — living doc (синхрон с T10.3);
- legacy-констрейнты как чек-лист «первое подключение к сайту» (9 пунктов раздела 6 плана 06);
- e2e «legacy-атака» (расширение T3.2): после ui-core инжект пакета токсичных правил (`a {outline:none}`, `* {box-sizing:content-box}`, `input {…}`, `h1 {…}`, `ul {list-style:none…}`) — ключевые компоненты (button/field/card/link) сохраняют геометрию, фокус и читаемость; перечень стойких исключений фиксируется.

## Out of scope

- Реальные сайты (T11.2/3);
- CI-деплой на сайты.

## Existing implementation

README career-portal «Интеграция в Битрикс» — 6 шагов, зерно гайда; сниппеты из задач T4.7/T5.6/T6.3 собираются здесь.

## Implementation requirements

1. Каждый сниппет — файл, проверенный на чистом стенде (подключение по quickstart).
2. Чек-лист подключения — исполняемый (галочки, ссылки на сниппеты).
3. Legacy-атака — параметризованный стенд (набор инжектов), переиспользуемый в регрессии.

## Technical considerations

- Порядок в header.php: preload шрифтов до `ShowHead()` (или в начало head-области шаблона);
- addJs(…, true) — в футер; readyState-guard модулей (T1.1) закрывает позднюю загрузку.
