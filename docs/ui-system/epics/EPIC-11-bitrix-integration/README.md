# EPIC-11 — Bitrix Integration

## Goal

Система на реальных сайтах: сниппеты и legacy-констрейнты выверены практикой, два пилота, отработанный процесс обновления.

## Context

Фаза 9. ADR-0006/0008 зафиксировали дистрибуцию и контракт подключения. Пилот A (рекомендованный кандидат — Bitrix-версия career-portal) — самый дешёвый win; пилот B — сайт с другой структурой (переиспользование без форка, оба в одном бренде — Phase 0). Выбор пилотов — за менеджером (открытый пункт Phase 0); нужен к Iteration 6, желательно к концу Iteration 4.

## Scope

- T11.1: пакет сниппетов + legacy-констрейнты + чек-лист первого подключения + расширенная legacy-атака e2e;
- T11.2: пилот A — подключение, 2–3 страницы (включая форму), журнал конфликтов;
- T11.3: пилот B — та же поставка, другая структура;
- T11.4: репетиция upgrade (minor-релиз на обоих пилотах).

## Out of scope

- Серверная разработка сайтов;
- форки системы под сайты (запрещены — конфликт = задача в систему или обход на сайте);
- автоматизация деплоя на сайты (ручное копирование по гайду; CI деплоя сайтов — зона ИТ сайтов).

## Expected outcome

Страницы пилотов в предпроде/проде на ui-компонентах; quickstart подтверждён реальностью; обновление сайта ≤ 0.5 дня; конфликты legacy каталогизированы.

## Acceptance Criteria

- [ ] Сниппеты работают на чистом стенде и на обоих пилотах без модификаций;
- [ ] Журналы конфликтов legacy приложены (пустые или с обходами);
- [ ] Upgrade обоих пилотов по чек-листу ≤ 0.5 дня каждый.

## Definition of Done

- [ ] Все 4 задачи закрыты
- [ ] Integration guide обновлён по итогам пилотов (реальность > теория)
- [ ] Кейсы конфликтов — в «известных ограничениях» документации

## Risks

- Задержка выбора/готовности пилотов → T11.2/3 сдвигаются, остальной план не блокируется;
- «Токсичные» legacy-страницы → правило: страница остаётся на legacy или изолируется, система не эскалирует специфичность (ADR-0008).

## Notes

MVP-граница включает стендовую репетицию (T5.6/T11.1) и подключение пилота A (07 §4, capability 10).

**10.10 — решение владельца:** T11.2–T11.4 выведены из активного реестра в статус `blocked` («интеграция: вне скоупа»): работа концентрируется на самой дизайн-системе (EPIC-13 backlog-hardening, релизная ветка T12.x). Пилоты возобновляются решением владельца при выборе площадок — файлы задач сохранены, сниппеты и гайды (T11.1, T10.3) остаются в скоупе.
