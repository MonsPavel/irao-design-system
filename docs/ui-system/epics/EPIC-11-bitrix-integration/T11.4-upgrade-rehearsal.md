# TASK T11.4 — Репетиция upgrade (minor-релиз на пилотах)

## Epic

[EPIC-11 — Bitrix Integration](README.md)

## Priority

P1

## Type

TASK

## Goal

Отработать процесс обновления системы на живых сайтах на безопасном minor-релизе; замерить трудозатраты; улучшить upgrade-гайд до v1.0.

## Context

Политика N−1 (ADR-0007) предполагает регулярные обновления сайтов. До v1.0 процесс обязан быть отрепетирован на реальных пилотах — иначе первый minor после релиза вскроет проблемы процесса на живых сайтах.

## Scope

- выпустить minor-релиз (реальный фикс или компонент из готового бэклога) через пайплайн T12.1;
- обновить оба пилота по upgrade-чек-листу: новая папка `/local/ui/{новая-версия}/`, смена UI_VERSION, smoke-тест чек-листа;
- замер трудозатрат на каждый сайт; точки трения → правки upgrade-гайда (T10.3) и чек-листа;
- кейсы — в changelog релиза.

## Out of scope

- Major-миграция (v2 не существует; процесс описан в ADR-0007 теоретически — док-заметка);
- автодеплой.

## Existing implementation

Процесс обновления описан в ADR-0006/0007; практика — новая.

## Implementation requirements

1. Обновление строго «снизить артефакт → скопировать → сменить константу → smoke» — без промежуточных ручных правок.
2. Откат: вернуть константу к старой папке — проверить фактически (папка старой версии остаётся).

## Technical considerations

- Кэш Bitrix (композит/asset) после смены версий — сброс/прогрев по чек-листу;
- неизменяемость старой папки версии — гарантия отката.

## Acceptance Criteria

- [ ] Обновление каждого пилота ≤ 0.5 дня (замер зафиксирован);
- [ ] Откат проверен фактически на одном из пилотов;
- [ ] Upgrade-гайд и чек-лист обновлены по итогам (затыки закрыты).

## Testing requirements

Tests first: smoke-чек-лист после обновления (те же проверки, что при подключении).

## Accessibility requirements

Smoke включает VI-включение и клавиатурный обход ключевой страницы.

## Definition of Done

- [ ] Implementation completed
- [ ] Tests added/passed (smoke обоих пилотов)
- [ ] Lint/typecheck passed (N/A)
- [ ] Accessibility requirements satisfied (smoke)
- [ ] Documentation updated if required (upgrade-гайд)
