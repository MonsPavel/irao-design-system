# TASK T11.2 — Пилот A: интеграция (рекомендуемый кандидат — Bitrix-версия career-portal)

## Epic

[EPIC-11 — Bitrix Integration](README.md)

## Priority

P0

## Type

TASK

## Goal

Подключить UI-систему к первому реальному сайту и перевести 2–3 страницы (обязательно форму) на ui-компоненты; выверить сниппеты и quickstart реальностью.

## Context

Рекомендованный кандидат — Bitrix-версия career-portal (вёрстка уже на компонентах-предках — самый дешёвый win; критерии выбора переданы менеджеру, Phase 0). Пилот A — единственная MVP-задача на реальном сайте (07 §4, capability 10). Журнал конфликтов legacy — обязательный артефакт (кормит «известные ограничения»).

## Scope

- Stage 0–1 миграции (план 06 §6): аудит legacy-веса страниц, alongside-подключение (`/local/ui/{version}/`, сниппет T11.1);
- перевод 2–3 страниц: списковая (паттерн T8.1), детальная (T8.2), форма отклика (T8.3/T5.6) — разметка на ui-, данные из инфоблоков;
- VI-режим на реальном сайте (ui-vi + кнопка в шапке);
- чек-лист страницы (axe локально, клавиатура, VI, 375/768/1440, консоль чистая, 200% zoom) — по каждой странице;
- журнал конфликтов: симптом → причина → решение/обход.

## Out of scope

- Полный перевод сайта (остальные страницы — по плану сайта после MVP);
- изменение серверной логики;
- темы (один бренд).

## Existing implementation

career-portal (статика) — источник контента/структуры страниц; его Bitrix-инкарнация — потребитель пакета.

## Implementation requirements

1. Подключение строго по quickstart: каждое отклонение = баг гайда (фиксится в T10.3).
2. Никаких правок в `/local/ui/` на сайте (копия read-only — ADR-0006); потребности → задачи в систему.
3. Конфликтные страницы не форсируются: остаются на legacy + запись в журнале.

## Technical considerations

- Bitrix-объединение CSS (`Asset`-оптимизации) совместимо: файлы уже минифицированы;
- композит-кэш: проверка работы JS-модулей после композитной загрузки.

## Accessibility requirements
