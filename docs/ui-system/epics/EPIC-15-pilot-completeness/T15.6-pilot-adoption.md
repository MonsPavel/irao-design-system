## Context

Раунд 2 зафиксировал три adoption-расхождения:

1. **Анкеты-модалки**: оригинал красит поля анкет в модалках компактно
   (`.apply-form .field__input { height: 48px }`, pages.css:1208); ДС
   доставила `ui-field--compact` + `--ui-field-height-compact: 3rem`
   (T14.6, components/ui-field/ui-field.css:136, mapping:154) — пилот
   собирает модальные анкеты (vacancy.html, internships/practices) с
   базовыми полями 52px: 4px систематическое расхождение на каждом
   поле каждой модалки.
2. **education.html**: внешняя ссылка «сайт „Работа России"» собрана
   `ui-button--accent ui-button--sm` (32px) — оригинал несёт базовую
   accent-кнопку 52px (probe раунда 2: height 52 → 32 при прочих
   совпадающих стилях; тот же текст, та же сущность).
3. **REPORT §3.3/§4**: «компактный вариант полей модалок, 48px — P1
   (остаток, аналога в ДС нет)» — неверно: модификатор есть с T14.6;
   строка должна переехать в «закрыто T14.6 + принято пилотом в T15.6».
   Попутно: формулировка §3.1 «Единственный остаток — career-track
   section-title» противоречит строке таблицы выше (второй остаток —
   vacancy-apply) — бэклог-пункт от ревью T14.12 (BACKLOG.md).
