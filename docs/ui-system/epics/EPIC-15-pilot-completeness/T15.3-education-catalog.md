# TASK T15.3 — Пилот: каталог обучения (education-catalog.html)

## Epic

[EPIC-15 — Пилот career-portal: полнота страниц и хвосты раунда 2](README.md)

## Priority

P1

## Type

TASK

## Goal

Закрыть мёртвую ссылку «Все предложения» с education.html: в оригинале
это каталог предложений целевого обучения с панелью фильтров-селектов и
пагинацией. Для клона страница ценна дополнительно: первый реальный
потребитель связки list-page «сайдбар фильтров» (T14.10) за пределами
vacancies.

## Context

Оригинал (src/pages/education-catalog.html): панель
`vacancy-search__select-wrap` (6 нативных select), список предложений
(организация/программа/город), `pagination`. Крошки: Главная/Целевое
обучение/Каталог предложений. Данные — data/educat.json.

В клоне education.html уже ссылается на education-catalog.html
(«Все предложения», ui-button--outline).

## Scope

- build.mjs: страница education-catalog.html;
- разметка: крошки, заголовок, панель фильтров — `ui-select` (wrap-режим
  пилюлями, прецедент вакансий) по образцу связки list-page сайдбар/панель;
  список предложений — строки или карточки по данным educat.json
  (как в оригинале: компактные строки-предложения);
  `ui-pagination` как на vacancies;
- compare.mjs: страница в PAGES;
- сайт-зонные стили — pilot.css при необходимости.

## Out of scope

- Клиентская логика фильтрации (select-ы в оригинале — GET/перезагрузка;
  клон оставляет нативный сабмит, JS не пишем — прецедент vacancies);
- Ветка «строки» на этой странице — если строки оригинала ложатся на
  cp-vac-row, переиспользовать; отдельного паттерна не заводить.

## Existing implementation

Связка list-page (T14.10) в паттернах, ui-select wrap (T7.3),
ui-pagination (vacancies клона), строки вакансий cp-vac-row.

## Implementation requirements

1. Только ui-компоненты + `cp-*`; данные из educat.json байт-в-байт.
2. Крошки: один aria-current, «Целевое обучение» — ссылка.
3. Если композиция выявила дыру связки list-page (сущность без правила)
   — найти её в REPORT как вход для бэклога, НЕ расширять паттерн в
   этой задаче (границы T14.10).

## Technical considerations

- 6 select оригинала — групповая панель: проверить, как wrap-режим
  ui-select ведёт себя в количестве 6 (перенос строк, ширина) —
  прецедент «фильтры-пилюли» вакансий был 3-4.
