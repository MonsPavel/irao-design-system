# TASK T15.5 — Пилот: поиск мероприятий (events-search.html) и пагинация events.html

## Epic

[EPIC-15 — Пилот career-portal: полнота страниц и хвосты раунда 2](README.md)

## Priority

## Type

## Goal

Дособрать страницу поиска мероприятий (events-search.html — «Все
мероприятия» в навигации оригинала, «Поиск» в крошках) и закрыть пропуск
в собранной странице: на events.html клона нет пагинации, в оригинале
есть (5 вхождений .pagination).

## Context

Оригинал events-search.html: секция с полем поиска (field__input) и
результатами-карточками событий; крошки Главная/Мероприятия/Поиск.
Страница — аналог списка с поиском: в клоне прецедент — панель поиска
вакансий (vacancies) + карточки событий (events).

Пагинация: events.html оригинала несёт pagination (карточки событий на
несколько страниц); клон собрал все карточки одной страницей без
ui-pagination — probe раунда 2: `pagination-page 44×44 → not found`.

## Scope

- build.mjs: страница events-search.html (поиск-панель + список
  карточек событий по data/events.json);
- events.html: добавить `ui-pagination` по образцу vacancies (ссылки
  страниц 1..N, aria-current на текущей);
- compare.mjs: events-search в PAGES; events — probe pagination
  возвращается (44px пара).

## Out of scope

- Клиентский поиск (JS фильтрации) — нативный сабмит, прецедент
  vacancies (панель с кнопкой «Найти»);
- Реальное разбиение на страницы данных — мок-пагинация по образцу
  vacancies (ссылки ?page=N без бэкенда).

## Existing implementation

Карточки событий (events.html клона, ui-card), панель поиска вакансий,
ui-pagination (vacancies), ui-chip (рубрики, при необходимости).

## Implementation requirements

1. Только ui-компоненты + `cp-*`; данные events.json.
2. Крошки: один aria-current, «Мероприятия» — ссылка.
3. Пагинация — тот же паттерн разметки, что vacancies (единый вид).

## Technical considerations

- events-search в оригинале — единственный потребитель «поиск по
  карточкам»: если поиск-панель повторяет панель vacancies — вынести
  переиспользуемую cp-функцию, дублирования не плодить.
