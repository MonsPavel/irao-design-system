# EPIC-15 — Пилот career-portal: полнота страниц и хвосты раунда 2

## Goal

Довести пилотный клон career-portal до полноты оригинала: пересобрать 8
неперенесённых страниц (4 из них — мёртвые ссылки из собранных страниц),
принять уже существующие API ДС, которые пилот не использует, и закрыть
P2-остатки сверки по компонентам. Пилот остаётся инструментом проверки
полноты системы на живом сайте.

## Context

Раунд 2 проверок (21.10, вечер) — пересборка пилота на текущем main ДС
(17beefd) и свежий compare-прогон против оригинала. Предпосылки проверены
и подтверждены фактическими проверками:

- **Pages-деплой оригинала актуален**: live CSS байт-в-байт идентичен
  main 8469ea6 (sha256, свера raw-блоба и live; последний deploy workflow
  зелёный на финальном коммите 12.10); все 20+ страниц оригинала, включая
  8 неперенесённых, отвечают 200. Опасение «Pages не актуальный» не
  подтвердилось.
- **Регрессий по компонентам нет**: probe-пары compare.json
  (21.10 вечер) соответствуют задокументированному состоянию REPORT §3.3
  после EPIC-14 — все «закрыто T14.x» остались MATCH, систематика
  «принято ДС» на месте (контейнерный паддинг 32 vs 40 — решение-отклонение
  №4 mapping-таблицы; ширины/text-дифы проб — артефакты выборки).
- **Новые находки раунда 2**:
  1. 8 страниц оригинала не пересобраны; 4 из них — мёртвые ссылки из
     собранных страниц клона: `article.html` (← index, media, career-track),
     `company.html` (← companies), `education-catalog.html` (← education),
     `event.html` (← events, internships, practices); ещё 4 достижимы из
     неперенесённых: `internship.html`, `internship-apply.html`,
     `events-search.html`, `event-apply.html`. На events.html клона нет
     пагинации (в оригинале есть).
  2. Adoption-хвосты: `ui-field--compact` (доставлен T14.6, есть в
     ui-field.css/README/mapping) не применён в анкетах-модалках клона —
     поля 52px против 48px оригинала; на education кнопка «сайт „Работа
     России"» собрана как `--sm` (32px) вместо базовой accent (52px).
     REPORT §3.3/§4 при этом устарел: «компактный вариант… аналога в ДС
     нет» — неверно, T14.6 его доставил.
  3. DS-остатки раунда 1 с предложенными приоритетами (REPORT §4, решение
     за владельцем): цвет подписи ui-field — P2, «тег на фото» — P2
     включаются в эпик; P3 (заголовок vacancy-apply fs-h3, спец-тинты
     hero) — остаются в бэклоге (Out of scope).

Канон визуальных значений — текущий main career-portal (8469ea6 = Pages).

## Scope

- T15.1: пилот — детальные «мероприятие» (event.html) и «статья»
  (article.html): закрывает мёртвые ссылки с 6 собранных страниц;
- T15.2: пилот — страница компании (company.html): закрывает мёртвую
  ссылку с companies.html;
- T15.3: пилот — каталог обучения (education-catalog.html): закрывает
  мёртвую ссылку с education.html, первый потребитель ветки «сайдбар»
  list-page (T14.10);
- T15.4: пилот — детальная стажировки (internship.html) и анкеты
  (internship-apply.html, event-apply.html) по паттерну vacancy-apply;
- T15.5: пилот — поиск мероприятий (events-search.html) + пагинация
  на events.html (в оригинале есть, клон пропустил);
- T15.6: пилот — adoption-хвосты: `ui-field--compact` в анкетах-модалках,
  кнопка education без `--sm`, актуализация REPORT §3.3/§4 (compact уже
  в ДС) и формулировки «единственный остаток» (бэклог-пункт от T14.12);
- T15.7: ДС — цвет подписи поля ui-field (P2 из REPORT §4): отдельный
  токен, AA-пара, mapping-строка;
- T15.8: ДС — модификатор «тег на фото» ui-tag--on-photo (P2 из REPORT §4):
  белый на primary, высота 40px оригинала;
- T15.9: закрывающая — пересверка всех 20 страниц (compare.mjs), гейт
  мёртвых ссылок dist, обновление REPORT/PLAN.

## Out of scope

- Заголовок страницы-формы vacancy-apply (оригинал fs-h3 42px vs
  ui-page-title 60px) — P3, лендинг-специфика одной страницы; остаётся
  в бэклоге (REPORT §4);
- Спец-тинты hero-тегов (violet/green/rose) — P3, только лендинг;
  остаются в бэклоге;
- P2 лендинг-блоки главной (PLAN §P2) — без изменений, отдельный эпик
  по мере появления вторых потребителей;
- Главная варианта 2 (index-2) и генеративные карточки 12 вакансий —
  принципиально вне пилота (REPORT §1);
- Компактный textarea оригинала (pages.css:1209, 96px/12px 16px) — уже
  задокументирован «принято ДС» (бэклог-пункт от T14.6, одна строка в
  mapping — допустимо закрыть попутно в T15.7, отдельной задачей не является).
