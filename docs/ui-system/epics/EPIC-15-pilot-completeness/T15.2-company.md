# TASK T15.2 — Пилот: страница компании (company.html)

## Epic

[EPIC-15 — Пилот career-portal: полнота страниц и хвосты раунда 2](README.md)

## Priority

P1

## Type

TASK

## Goal

Закрыть мёртвую ссылку с companies.html: карточки-компании клона ведут
на company.html, которого нет. В оригинале это детальная страница
компании группы (первая из data/companies.json).

## Context

Оригинал (src/pages/company.html): `company-hero` (фото + название +
описание), `company-stats` (3 факта: значение/подпись), `company-adv`
(4 преимущества: заголовок/текст), `where-we-work` (география,
подписи), `banner-card` (CTA-баннер «смотреть вакансии» фото+текст),
секции с section-title. Крошки: Главная/Компании группы/АО «Интер РАО –
Электрогенерация».

Данные компании — data/companies.json (в пилоте уже есть, карточки
companies.html из него собираются).

## Scope

- build.mjs: страница company.html (первая компания из companies.json,
  как в оригинале);
- разметка: крошки, заголовок-имя компании по канону детальной,
  `company-stats` — сайт-зона на токенах (числа `ui-h*` + подписи),
  преимущества — список/сетка сайт-зоны, `banner-card` — CTA-панель с
  фото (`ui-image`) и `ui-button` на vacancies.html;
- compare.mjs: страница в PAGES;
- недостающие сайт-зонные стили — pilot.css (`cp-` префикс).

## Out of scope

- Остальные компании группы (генеративные повторы — одна типовая
  страница, как решено для 12 вакансий);
- Сетка «где мы работаем» с картой — приближение подписями (в оригинале
  карта-иллюстрация, интерактива нет).

## Existing implementation

Карточки companies.html клона уже размечены ссылками на company.html
(build.mjs). CTA-панели/фото-баннеры — прецедент cp-cta-mail, holding.

## Implementation requirements

1. Только ui-компоненты + `cp-*`; классы оригинала не копируются.
2. Крошки: один aria-current, промежуточная «Компании группы» — ссылка.
3. Контент — из data/companies.json, без выдумывания.

## Technical considerations

- `company-stats` — кандидат в переиспользование статистики holding
  (cp-holding статы на тёмном vs светлый фон здесь): унифицировать
  сайт-зонный блок статов, если цена низкая (иначе две вариации).
