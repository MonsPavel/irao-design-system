# TASK T15.4 — Пилот: детальная стажировки и анкеты (internship.html, internship-apply.html, event-apply.html)

## Epic

[EPIC-15 — Пилот career-portal: полнота страниц и хвосты раунда 2](README.md)

## Priority

P2

## Type

TASK

## Goal

Дособрать семейство «школьникам и студентам»: детальная стажировки
(карточки-направления internships/practices ссылаются на internship.html)
и две анкеты-заявки — internship-apply.html и event-apply.html (CTA
с event.html после T15.1).

## Context

Оригинал:

- internship.html — тот же шаблон `internship__main/aside`, что event
  (T15.1 вынесет общий шаблон): теги `vacancy__tags`, «зарплата»
  `vacancy__salary`, компания `vacancy__company`, мета-aside, CTA →
  internship-apply.html;
- internship-apply.html — полная анкета: `form-card__title` (fs-h3 —
  та же пара, что vacancy-apply, см. REPORT §3.1 остаток P3), ~15 полей
  (ФИО, дата рождения, телефон, e-mail, гражданство, вуз, специальность,
  курс-select, последнее место/должность, период, textarea), success-ветка,
  aside с данными заявки;
- event-apply.html — короткая форма (e-mail + ошибка + success) + aside.

В клоне уже есть: полная форма отклика vacancy-apply (ui-form + ui-field
+ ui-radio-group + ui-file + ui-checkbox + success), модалки анкет
(vacancy, internships). Крошки оригинала: Главная/Стажировки/…, Главная/
Мероприятия/Заявка.

## Scope

- build.mjs: три страницы;
- internship.html: общий шаблон детальной из T15.1 (main+aside), теги,
  зарплатная вилка, компания, CTA на internship-apply.html;
- internship-apply/event-apply: формы по паттерну vacancy-apply клона
  (страница-форма — базовые поля 52px; compact — только модалки, T15.6);
  поля по составу оригинала (select курса — ui-select или ui-field
  select-вариант по канону формы вакансии); aside — мета заявки;
- compare.mjs: страницы в PAGES.

## Out of scope

- Заголовок form-card__title fs-h3 42px (остаток P3, REPORT §4) —
  клон несёт ui-page-title 60px по канону; задача не меняет решение;
- Остальные стажировки (генеративные повторы — одна типовая).

## Existing implementation

Шаблон детальной (T15.1), паттерн формы отклика (vacancy-apply),
модалки анкет, ui-form/ui-field/ui-file/ui-radio-group/ui-checkbox.

## Implementation requirements

1. Только ui-компоненты + `cp-*`; данные из data/internships.json,
   events.json.
2. Крошки: один aria-current на цепочку.
3. Поля формы — обязательные/необязательные по оригиналу; required
   маркировка каноном ui-field (звёздочка + sr-only пояснение).

## Technical considerations

- internship-apply несёт select «курс»: сверить с формой вакансии,
  есть ли там select-прецедент (ui-field select-вариант) —
  переиспользовать, не заводить вторую форму select;
- success-ветка: копия паттерна vacancy-apply (мок, без бэкенда).

## Dependencies

- T15.1 (общий шаблон `internship__*` детальной) — выполнить после
  или вместе; CTA event.html → event-apply.html осмысленен после T15.1.
