# TASK T15.1 — Пилот: детальные «мероприятие» (event.html) и «статья» (article.html)

## Epic

[EPIC-15 — Пилот career-portal: полнота страниц и хвосты раунда 2](README.md)

## Priority

P1

## Type

TASK

## Goal

Закрыть самые цитируемые мёртвые ссылки клона: `event.html` — на него
ссылаются events, internships, practices (карточки мероприятий);
`article.html` — index, media, career-track (карточки статей). Сейчас
клик по любой карточке события/статьи в клоне — 404.

## Context

Обе страницы — детальные контентные. Оригинал (src/pages/event.html,
article.html + сборка build.py из data/events.json / articles.json):

- event: layout `internship__main/internship__aside` (общий шаблон с
  internship), заголовок, `vacancy__tags` (теги формата), мета-строки
  `form-aside__row` (дата/место/формат), фото, текст-секции, CTA
  «зарегистрироваться» → event-apply.html (собирается в T15.4);
- article: `article-page__title/meta`, тег рубрики `media__tag`, дата,
  галерея `article-page__gallery`, текст, секции «материалы по теме»
  (section-title + карточки).

Пилот собирает страницы генератором `pilot/career-portal/build.mjs` из
`data/*.json` (байт-в-байт копия данных оригинала); правила — README
пилота (только ui-компоненты + сайт-зона `cp-*` на токенах `--ui-*`).

## Scope

- build.mjs: две функции-страницы + включение в массив собираемых;
- event: `ui-breadcrumbs` (крошки как в оригинале: Главная/Мероприятия/
  «День открытых дверей»), заголовок по канону детальной (см. как
  собран vacancy.html — h2-тройка), `ui-tag` (формат), мета-aside
  (сайт-зона по образцу aside вакансии), `ui-button` CTA на
  event-apply.html, `ui-image` для фото;
- article: крошки Главная/Медиа/«Студенты приступили к практике»,
  заголовок, тег рубрики + дата (мета), галерея на `ui-image`/
  `ui-figure`, текстовые секции `ui-h3`, блок «материалы по теме» —
  карточки `ui-card` как на media;
- данные: из data/events.json, articles.json уже в пилоте (копия
  оригинала) — контент не выдумывается;
- compare.mjs: обе страницы в PAGES;
- при необходимости — недостающие сайт-зонные стили в pilot.css
  (`cp-` префикс, mobile-first, токены `--ui-*`).

## Out of scope

- event-apply.html (T15.4) — CTA ссылается, страница собирается там;
- спец-сетки «материалов» (перенос 1:1 сеток оригинала не требуется —
  правило сайт-зоны: приближение, расхождения фиксируются в compare).

## Existing implementation

Общие шаблоны уже есть в клоне: aside-мета вакансии (vacancy.html),
карточки media, крошки всех внутренних, теги. Новых сущностей ДС не
требуется — задача пилотная.

## Implementation requirements

1. Разметка — только ui-компоненты + `cp-*` сайт-зона (README пилота);
   классы оригинала не копируются.
2. Страницы проходят lint:html (если распространяется на dist пилота —
   по правилам T14.12) и ручной axe-пробой в T15.9.
3. Крошки: ровно один `aria-current="page"` на цепочку, промежуточные
   «Мероприятия»/«Медиа» — ссылки (канон T14.5/оригинал).

## Technical considerations

- Заголовок детальной: оригинал event несёт `internship__title` —
  сверить по pages.css, какой тройке fs соответствует (прецедент vacancy
  `.vacancy-page__title` fs-h2 60px); взять тот же паттерн, что vacancy.
- event и internship в оригинале — один шаблон `internship__*`:
  в клоне разобрать переиспользуемую функцию, чтобы T15.4 не дублировал.
