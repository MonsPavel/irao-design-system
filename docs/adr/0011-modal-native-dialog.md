# ADR-0011: ui-modal — основа native `<dialog>` (+`showModal()`), собственный оверлей отвергнут

- **Дата:** 2026-10-08
- **Статус:** принято (задача T7.1 — SPIKE)
- **Влияет на:** T7.2 (ui-modal — реализует решение), T7.6 (search-overlay — тот же выбор), T9.1 (vi.css — правило `::backdrop`), base/reset (kill-switch — дополнение `*::backdrop`, задача T7.2)

## Context

Спека T7.1: выбрать основу ui-modal — native `<dialog>` (`showModal()`) или собственный оверлей-паттерн (старт от career-portal `src/blocks/directions/directions.js`: div + классы + transitionend, без trap и семантики) — с доказательствами на матрице браузеров и в контексте Bitrix-страниц. Критерии сравнения зафиксированы ДО прогонов (12 критериев К1–К12, `showcase/spike-dialog/README.md` в истории git). Матрица evergreen ×2 (Phase 0) старые браузеры исключает.

Доказательства: песочница `showcase/spike-dialog/` (зонд техники, два мини-прототипа на равном чек-листе, legacy-стенд «z-index-стек 2147483647, sticky-шапка, чат-виджет, transform/filter-обёртки, content-box») и сценарии `tests/e2e/spike-dialog.spec.js`; прогоны Playwright 1.63, chromium 153 / firefox 155 / webkit 26.6, локально 2026-10-08 (коммиты `7fa4944`…`4680b9d`; песочница и сценарии выброшены после решения — восстанавливаются из истории git).

## Decision

**Основа ui-modal — native `<dialog>` с `showModal()`.** Собственный оверлей не берём ни в каком виде (не «гибрид пополам»): он проигрывает в каждом измеренном критерии, где разница есть, и не выигрывает нигде. Итог по зафиксированным критериям (chromium/firefox/webkit, на обоих прототипах и legacy-стенде):

| Критерий | Native `<dialog>` | Собственный оверлей |
|---|---|---|
| К1 trap | бесплатно (браузер; нюанс — транзит через body, фон недостижим) | руками: Tab-цикл ~15 строк JS |
| К2 Escape | бесплатно (`cancel` шлётся верхнему) | слушатель документа + стек руками |
| К3 restore | браузерный, но Safari не фокусирует кнопку кликом → нужна строка `focus(opener, preventScroll)` | `lastFocused` — то же ограничение Safari (явный опенер обязателен) |
| К4 top-layer | выше z-index 2147483647 (elementFromPoint = dialog, клик в баннер не доходит) на всех трёх | z-войну проигрывает: `--ui-z-modal: 300` < 2147483647 — баннер рисуется поверх затемнения; спасает только перенос в body при init (и то лишь с позиционированием) |
| К5 анимация | открытие @starting-style — все три; закрытие — только JS-delayed (is-closing → transitionend/timeout → `close()`): pure-CSS (allow-discrete + overlay) на chromium 153 даёт ≥2 промежуточных кадра, на firefox 155/webkit 26.6 — мгновенно (сэмплы {0}); reduced-motion — kill-switch base/reset гасит | та же техника закрытия; открытие — класс + rAF (directions.js: force reflow) |
| К6 backdrop | `::backdrop { background: var(--ui-color-overlay) }` резолвится и перекрашивается оверрайдом токена на корне на всех трёх (механика тем ADR-0009 / VI T9.1); прямой селектор `dialog::backdrop` в vi.css тоже возможен | оверлей — обычный элемент, перекрашивается элементными правилами |
| К7 вложенность | стек ведёт браузер (cancel/close — верхнему топ-слоя; проверено: Escape закрывает только верхнюю) | стек руками |
| К8 объём JS на равный чек-лист | **85 строк** (и из них ~30 — анимация/лок/кнопки, не чек-лист) | **139 строк** |
| К9 деградация без JS | `dialog[open]:not(:modal)` → static инлайн (UA display:none для закрытого); модуль снимает open при init | разметка без hidden + оверлейная механика только под init-атрибутом (контракт dropdown T6.1) |
| К10 скролл-лок | свой для обоих (showModal скролл НЕ лочит): overflow hidden + padding-компенсация; сдвига нет и от `scrollbar-gutter: stable` — уже в base/reset (T3.1): ширина fixed-шапки до/во время лока идентична (замер) | тот же лок |
| К11 method="dialog" | бесплатно: submit закрывает, `returnValue` = value кнопки, без навигации (формы-модалки T7.2+) | руками: preventDefault + close |
| К12 инертность фона | поведение top-layer (main.inert остаётся false, клики/фокус всё равно заблокированы) | `inert` обходом детей body (~12 строк; неаккуратный пересчёт инертит страницу и ломает restore — поймано на прогоне) |

Обязательный слой модуля (T7.2, поверх бесплатного): анимация закрытия JS-delayed (остаточный класс закрывающего состояния снимать на `close` — первый прогон поймал замирание повторного цикла: класс зажимал opacity и блокировал повторное закрытие; это регресс-кейс career-portal «повторные циклы — без остаточных эффектов», e2e на него обязателен); `focus(opener, preventScroll)` до `showModal()`; скролл-лок; PE-деградация; `aria-labelledby`; `box-sizing: border-box` на корне (ADR-0002 — legacy content-box распирает панель, замерено). aria-hidden на фоне НЕ ставить — top-layer блокирует сам (T7.2 п.3 подтверждён замером).

Сопутствующие обязательства: (а) в kill-switch reduced-motion (base/reset) добавить `*::backdrop` — сейчас `*`, `::before`, `::after` псевдоэлемент не накрывают, и на всех трёх движках backdrop анимируется при reduced-motion (14 промежуточных кадров в chromium) — изменение base/ делает T7.2 как часть модалки; (б) нюанс К1 в доку ui-modal: native Tab-цикл на границе диалога отдаёт фокус на body на один шаг (следующий Tab возвращает; фоновые элементы недостижимы) — тестам и доке учитывать «не достигает фоновых элементов», а не «строго внутри»; (в) вложенные модалки — поведение браузерное, полноценной поддержки не обещаем (док-заметка T7.2, как в спеке); (г) мобильный Safari-профиль (02-architecture §10, nightly smoke) — не прогонялся, webkit-факты получены на desktop-движке.

## Alternatives considered

- **Собственный оверлей как основа** — +54 строки JS на равном чек-листе, проигранная z-война (единственный способ «победить» потолок 2147483647 — свой потолок, что ломает интерфейс с виджетами сайта), ручной стек/trap/инертность с реальным полем ошибок (две из них пойманы первыми же прогонами). Выгоды кастома — full-контроль анимации и никаких нюансов UA — не стоят этого: анимация решается JS-delayed закрытием (переносимый приём), нюансы (body-транзит, Safari-фокус) — по одной строке/строке доки.
- **Гибрид «native + JS-фолбэк на старых браузерах»** — матрица Phase 0 старые браузеры исключила (dialog: Chromium 37+/Firefox 98+/Safari 15.4+); фолбэк-ветка была бы мёртвым кодом и вторым код-путём для каждого сценария e2e.
- **Pure-CSS закрытие (allow-discrete + overlay)** — принятая было техника для chromium, отброшена как основа: firefox/webkit закрывают мгновенно (замер сэмплами). Остаётся в доке как chromium-прогрессия (пересмотреть при появлении в firefox/webkit).

## Why

Top-layer — единственный из двух подходов, который переживает реальный Bitrix-контекст (z-index-войны с виджетами сайта не выигрываются ничем, кроме top-layer); trap/Escape/инертность/restore/метод-диалог бесплатно; JS только на то, чего в платформе нет (анимация закрытия, скролл-лок, PE-состояние) — меньше кода, меньше поверхность ошибок (подтверждено: обе ошибки первых прогонов случились в JS кастомного оверлея, ни одной — в native-слое).

## Consequences

**Плюсы:** диалог-чек-лист закрывается платформой; top-layer изолирует от legacy-CSS сайта (замерено на стенде с z-index 2147483647, transform/filter-обёртками и content-box); объём модуля T7.2 сокращается до анимации/лока/PE; формы-модалки получают method="dialog" бесплатно.
**Минусы/цена:** анимация закрытия — JS-delayed-слой с контрактом «класс снимается на close» (иначе повторные циклы ломаются — зафиксировано e2e); Safari требует явного focus(opener); Tab-транзит через body — особость в тестах/доке; kill-switch reduced-motion нужно дотянуть до `::backdrop` (T7.2); «бесплатность» нативного restore условна — она держится на фокусе до showModal, который в Safari надо ставить самому.
