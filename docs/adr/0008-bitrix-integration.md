# ADR-0008: Интеграция с Bitrix — сниппеты, HTML-паттерны и границы ответственности

- **Дата:** 2026-10-05
- **Статус:** принято (фиксирует решение из 02-architecture §6)
- **Влияет на:** T11.1–T11.3, T5.6, T6.3, T4.7

## Context

Bitrix-сайты — server-rendered PHP без Node. Интеграторы копируют разметку из документации. Legacy-CSS подключается после системы и содержит tag-правила и `!important`. Нужен контракт подключения, использования и сосуществования.

## Decision

1. **Подключение:** версионированная папка `/local/ui/{version}/` (ADR-0006); в `header.php` шаблона — `Asset::addCss` (core → тема → vi) и `addJs` через константу `UI_VERSION`; preload шрифтов 400/500 cyr до прочего CSS; порядок каскада: ui-core первым, `template_styles.css` сайта последним.
2. **Использование:** компонент = копируемый HTML-паттерн из showcase; данные для JS — `<script type="application/json">` (заполняется `json_encode` из инфоблоков); PHP-хелперы рендера не делаются до доказанной боли.
3. **Сосуществование с legacy:** namespace `ui-` + односелекторная специфичность; box-sizing и focus-политика по ADR-0001/0002; система не отвечает на legacy `!important` своим (кроме vi); ui-компоненты не вкладываются в legacy-контейнеры с фиксированной высотой/`overflow: hidden`; смешение на странице — только целыми компонентами; миграция по стадийной модели (аудит → alongside → новые страницы → построчная замена → удаление legacy).
4. **Граница:** система — токены/примитивы/a11y/поведение/доки; сайт — контент, шаблоны страниц, бизнес-компоненты, интеграция данных.

## Alternatives considered

- **Bitrix-модуль с настройками в админке** — отдельный продукт с другой стоимостью поддержки; MVP — библиотека вёрстки.
- **PHP-хелперы рендера (`IraoUI::button()`)** — удобнее, но добавляют связку версий PHP-кода и паттернов; отложено до боли копипасты.
- **Общий header-компонент системы** — шапки сайтов слишком различаются; система даёт паттерн, не код.

## Why

Копипаст-паттерны не требуют сборки на сайте и читаются интеграторами; сниппеты подключения тривиальны; контракт каскада и ограничения защищают от типовых конфликтов, подтверждённых аудитом legacy-подходов.

## Consequences

**Плюсы:** нулевая сборка на сайте; предсказуемое сосуществование; простые обновления.
**Минусы/цена:** разметка живёт в двух местах (дока и шаблон сайта) — закрывается версионной дисциплиной ADR-0007 и upgrade-чек-листами.
