# ADR-0009: Design Tokens — два слоя, темы только на семантическом

- **Дата:** 2026-10-05
- **Статус:** принято (фиксирует решение из 02-architecture §3 и Phase 0)
- **Влияет на:** T2.1–T2.4, все компонентные задачи

## Context

Нужна единая визуальная правда, пригодная для потенциального мульти-бренда в будущем, при решении Phase 0 «в MVP один бренд Интер РАО». Аудит career-portal: ~35 цветов и типографика px в одном `:root`, часть визуала захардкожена hex'ами в компонентах; отступов/теней/z-index/focus-токенов нет вовсе.

## Decision

1. **Слой 1 — примитивы** (`tokens/primitives.css`): «сырая» палитра (`--ui-blue-800`, `--ui-gray-300`…). Единственное место, где допустимы hex (stylelint-гейт). Темы их не переопределяют.
2. **Слой 2 — семантика** (`tokens/semantic.css`): смысловые значения (`--ui-color-primary`, `--ui-focus-color`, типографика в rem, spacing 4–64, радиусы, тени, z-index, transitions, containers). Компоненты читают только этот слой.
3. **Слой 3 — компонентные токены** (`--ui-button-height`…) — только при доказанной потребности двух сайтов в разных значениях; по умолчанию не заводятся (анти-overengineering).
4. **Тема** = файл переопределения семантических токенов под `[data-ui-theme="…"]`. В MVP — дефолт Интер РАО + одна синтетическая тестовая тема для проверки механизма; реальные темы будут minor-версиями.
5. Обратная совместимость: новый семантический токен = minor с дефолтом в `:root`; переименование/удаление = major (ADR-0007).

## Alternatives considered

- **Один плоский список токенов** (как в career-portal) — темизация перезапишет «сырьё» и сломает производные значения; нет контроля контраста по смыслам.
- **Токены в JS/JSON с генерацией CSS** — build-шаг без выгоды: рантайм-темизация всё равно через custom properties.
- **Токены per-компонент по умолчанию** — взрыв сущностей при 1–2 потребителях.

## Why

Два слоя дают контролируемую точку темизации (семантика) и инструментальный контроль контраста (пары «смысл → фон»), оставляя компоненты стабильными: API классов не меняется, меняются значения.

## Consequences

**Плюсы:** дешёвые темы, машинный контраст-гейт, ясное правило «где можно менять».
**Минусы/цена:** дисциплина «компонент не знает примитивов» держится stylelint; слой 3 требует ревью-гейта от раздувания.
