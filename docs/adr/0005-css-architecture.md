# ADR-0005: CSS-архитектура — нативный CSS + custom properties + БЭМ с namespace `ui-`

- **Дата:** 2026-10-05
- **Статус:** принято (фиксирует решение, ранее описанное в 02-architecture §2)
- **Влияет на:** все CSS-задачи (T2.x–T8.x)

## Context

Стилизация UI-системы должна работать в server-rendered HTML из PHP-шаблонов Bitrix, сосуществовать с legacy-CSS сайтов, поддерживаться интеграторами без глубокого frontend-бэкграунда, темизироваться per-site без пересборки и жить несколько лет при команде 1–2 человека. Аудит career-portal показал жизнеспособность подхода «нативный CSS + БЭМ без зависимостей» (4881 строка CSS/JS в продакшн-режиме).

## Decision

Собственный нативный CSS на custom properties, БЭМ-нейминг с namespace `ui-` (`ui-button__icon--primary`), специфичность одного класса, состояния `is-*`, JS-хуки только через `data-ui-*`, токены `--ui-*`. Без препроцессоров; PostCSS-обработка только на сборке dist. `@layer` не используется для изоляции (непослойный legacy-CSS сайта его «переигрывает»).

## Alternatives considered

- **Bootstrap** — тянет свою нормализацию и вид, конфликтует с brand-дизайном, избыточен (~нужно 25 компонентов), исторически ломается на мажорах; в legacy-Bitrix часто уже есть второй Bootstrap.
- **Tailwind (utility-first)** — «каша» утилит в PHP-шаблонах, build на каждом сайте или CDN-байткод, темизация через конфиг, невозможно версионировать компонентный API.
- **CSS Modules** — требуют JS-сборки у потребителя, генерируют имена классов, бесполезны без компонентного фреймворка.
- **@layer для изоляции** — legacy-стили всегда побеждают слоистые; изоляция через namespace + порядок подключения надёжнее.

## Why

Нативный CSS работает без сборки вообще (dist подключается как есть), предсказуем, темизируется переменными в рантайме, HTML-паттерны копируются в шаблоны, поддерживается дёшево. Все альтернативы проигрывают по критериям Bitrix/legacy/интеграторы/годы поддержки.

## Consequences

**Плюсы:** ноль runtime-зависимостей; переносимость; предсказуемый каскад; дешёвая поддержка.
**Минусы/цена:** дисциплина нейминга и специфичности держится stylelint-гейтами; нет «бесплатных» готовых компонентов фреймворков — пишем сами (осознанно, ~25 компонентов).
