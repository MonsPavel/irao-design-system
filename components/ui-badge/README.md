# ui-badge

Счётчик-кружок: число рядом со ссылкой/заголовком. В career-portal бейджа
нет — компонент новый (T4.3), значения — ступени шкалы §3.2 и тройка тегов
одобренного дизайна. Одна цифра — круг 24px, «99+» — pill.

## API

| Что | Значение |
|---|---|
| Блок | `.ui-badge` на `<span>` — внутри ссылки, заголовка, кнопки |
| Контент | число («3») или переполнение «99+» (текстом; логика переполнения — за приложением) |
| Пара цветов | `--ui-color-primary` / `--ui-color-text-on-dark` (та же, что у `.tag--navy`; ~12.6:1) |
| Круг | `min-width`/`min-height` = `--ui-badge-size` (1.5rem), `--ui-radius-pill` |
| Переполнение «99+» | горизонтальный паддинг `--ui-space-1` — растёт в pill, контент не режется |
| Типографика | `--ui-fs-micro` (12px) × `--ui-fw-caption` (500) × `--ui-lh-micro` — тройка тегов |
| JS | не требуется (CSS-компонент; счёт, скрытие при 0 и «99+» — за приложением) |
| Токены | `--ui-badge-size`, `--ui-radius-pill`, `--ui-space-1`, пара primary/text-on-dark |

```html
<a class="ui-link" href="/notifications">
  Уведомления: <span class="ui-badge">3</span>
</a>
```

## Правило при 0 (AC)

Бейдж при значении 0 **не выводится** — атрибутом `hidden` в разметке
(счёт ведёт приложение: компонент CSS-only и «0 в кружке» — ложная
информация). Скрытие исполняет глобальная гарантия `base/reset.css`:
`[hidden] { display: none !important }` (T3.1) — сильнее display-правил
компонента; собственное правило бейдж не заводит. Не оставляйте видимый
`0`: axe и скринридер его озвучат, пользователь прочитает ложный счётчик.

```html
<span class="ui-badge" hidden>0</span>
```

## Правило дублирования значения (Implementation requirements п.2)

- **Значение продублировано текстом рядом** («Уведомления, 3 новых») —
  бейдж декоративен: `aria-hidden="true"`, иначе скринридер прочитает
  число дважды.
- **Значение только в бейдже** — `aria-hidden` НЕ ставится, число обязано
  войти в доступное имя контрола: текстом содержимого (`Уведомления: 3`)
  или `aria-label`. Бейдж вне имени (пустая иконка-кнопка с кружком) —
  нарушение: имя контрола не содержит счёт.

## Клавиатура и a11y

- Не интерактивен: фокус/клавиатура — у контрола-родителя (ссылки/кнопки).
- Контраст пары ≥ 4.5:1 — гейт T2.3 (пара `on-dark-on-surface-dark`) и
  e2e стенда.
- VI-режим (T9.1): перекраска `!important` накроет бейдж как все элементы —
  цветов вне токенов нет (инвариант §5); функциональная проверка — T9.1.

## Do / Don't

- **Do**: `<a href="…">Уведомления: <span class="ui-badge">3</span></a>` —
  значение в доступном имени ссылки.
- **Do**: `<span class="ui-badge" aria-hidden="true">3</span>` рядом с
  текстом «3 новых уведомления» — дубль скрыт.
- **Do**: `<span class="ui-badge" hidden>0</span>` — нулевой счётчик
  скрыт разметкой.
- **Don't**: видимый `<span class="ui-badge">0</span>` — ложный счётчик.
- **Don't**: `<button aria-label="Уведомления"><span class="ui-badge">3</span></button>`
  — имя кнопки не содержит число; `aria-label="Уведомлений: 3"`.
- **Don't**: больше трёх знаков без переполнения — приложение обязано
  приводить к «99+» (форму «9999» бейдж не держит: Pill растянется, но
  смысл счётчика теряется).

## Bitrix (шаблоны)

`<span class="ui-badge">N</span>` в шаблоне элемента списка/меню; при 0 —
`hidden`. Счёт считает PHP/JS шаблона, бейдж только показывает. Цвета —
из токенов: тема перекрашивает бейдж без правки разметки.

## Известные границы

- Форма «круг ↔ pill» автоматическая: любой контент длиннее двух знаков
  растянет pill — переполнение до «99+» обязано считаться приложением.
- Цвет один (primary/text-on-dark): вариативность цветов — новое решение
  по потребности (и каждая пара — через контраст-гейт T2.3).
- VI-перекраска бейджа не проверялась в этой задаче — за T9.1.
