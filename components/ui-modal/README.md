# ui-modal

Модальное окно на нативном `<dialog>` с полной диалоговой доступностью:
focus trap, Escape, восстановление фокуса, блокировка скролла без сдвига
макета. Задача T7.2, реализация решения [ADR-0011](../../../docs/adr/0011-modal-native-dialog.md)
(SPIKE T7.1): **основа — native `showModal()`, собственный оверлей отвергнут** —
top-layer единственный переживает z-index-войны реальных Bitrix-страниц
(виджет с z-index 2147483647 не перекрывает диалог), а trap/Escape/инертность
фона/restore даёт платформа бесплатно. Источник поведения — `directions.js`
career-portal (класс B): сохранение опенера, фокус на закрывающую кнопку,
закрытие по завершении перехода, restore фокуса.

## API

| Что | Значение |
|---|---|
| Блок | `.ui-modal` — на `<dialog>`; JS-хук — `data-ui-modal` |
| Модификатор `.ui-modal--sm` | узкая модалка 24rem (подтверждения) |
| Размер по умолчанию | `--md` 40rem (база, модификатор не нужен) |
| Модификатор `.ui-modal--full` | весь вьюпорт (100vw × 100dvh, без скругления) |
| Элемент `.ui-modal__close` | `<button type="button" aria-label="Закрыть">` — первый элемент панели: модуль даёт ей фокус при открытии (перенос career-portal `closeButton.focus`; нативные dialog focusing steps ставят фокус на сам диалог) |
| Элемент `.ui-modal__icon` | декоративный × внутри `__close`: `aria-hidden="true"`, `currentColor` |
| Элемент `.ui-modal__title` | заголовок; цель `aria-labelledby` диалога (id генерирует модуль, если нет) |
| Элемент `.ui-modal__body` | содержимое |
| Хук триггера | `data-ui-modal-target="<id диалога>"` — на кнопке или ссылке |
| JS | `IraoUI.modal`: `init()`, `selector`, `open(el, {…})`, `close()` |
| `open(el, options)` | `el` — `<dialog>` или его id; `options.opener` — куда вернуть фокус (по умолчанию активный элемент) |
| `close()` | закрыть верхнюю открытую модалку |
| События | `irao-ui:modal-open` / `irao-ui:modal-close` на диалоге (`bubbles: true`) |
| Токены | `--ui-color-overlay` (фон `::backdrop`), `--ui-color-{surface, surface-muted, text}`, `--ui-shadow-lg`, `--ui-radius-{md, pill}`, `--ui-space-{2,3,4,6}`, `--ui-transition{,-fast}`; **`--ui-z-modal` не используется** — top-layer выше любых z-index (К4 ADR-0011) |

```html
<!-- Триггер: кнопка или ссылка на страницу контента (деградация) -->
<button class="ui-button ui-button--primary" type="button" data-ui-modal-target="ui-modal-demo">
  Открыть модалку
</button>

<!-- Диалог: open в разметке — деградация без JS (К9 ADR-0011); модуль снимает -->
<dialog
  class="ui-modal ui-modal--md"
  id="ui-modal-demo"
  open
  data-ui-modal
  aria-labelledby="ui-modal-demo-title"
>
  <button class="ui-modal__close" type="button" aria-label="Закрыть">
    <svg class="ui-modal__icon" aria-hidden="true" focusable="false" width="24" height="24"
         viewBox="0 0 24 24"><path d="M6 6l12 12M18 6L6 18" fill="none" stroke="currentColor"
         stroke-width="2" stroke-linecap="round"></path></svg>
  </button>
  <h2 class="ui-modal__title ui-h3" id="ui-modal-demo-title">Заголовок модалки</h2>
  <div class="ui-modal__body">
    <p>Содержимое диалога.</p>
  </div>
</dialog>
```

## Деградация без JS

В разметке диалог **открыт** (`open`): без JS он показан статичным инлайном
(UA-правило `dialog:not([open]) { display: none }` не действует), весь контент
доступен — правило доки «контент доступен отдельной страницей/инлайн».
Триггер-кнопка без JS ничего не делает; если важен доступ без JS — сделайте
триггер **ссылкой** на страницу с содержимым (`<a href="/directions/analytics/"
data-ui-modal-target="…">`): без JS сработает переход, с JS модуль снимет его
и откроет модалку. При инициализации модуль снимает статичный `open`
(К9 ADR-0011) и дальше управляет показом сам — разметка остаётся правдивой.

## Клавиатура — dialog-чек-лист (проверено e2e)

| Действие | Поведение |
|---|---|
| Клик / `Enter` по триггеру | открыть; фокус **внутри** диалога — на `__close` (перенос career-portal `closeButton.focus`) |
| `Tab` / `Shift+Tab` | цикл внутри диалога ведёт браузер (top-layer). Нюанс К1 ADR-0011: на границе диалога фокус на один шаг уходит на `body`, следующий `Tab` возвращает; **фоновые элементы недостижимы** — проверяйте сценарии «не достигает фона», а не «строго внутри» |
| `Escape` | закрыть (событие `cancel` → модуль перехватывает и закрывает анимированно) |
| Закрытие любым способом | фокус возвращается на опенера (нативный restore + явный `focus(opener)`) |
| Фон при открытой модалке | недоступен без `aria-hidden`: top-layer блокирует клики и фокус сам (К12; `aria-hidden` фону не ставится — п. 3 требований) |

## Поведение модуля (что платформа не даёт)

- **Анимация закрытия JS-delayed** (К5): открытие — `@starting-style` (все
  три движка матрицы), закрытие — класс `is-closing` → `transitionend`
  transform панели → `dialog.close()`, со страховочным таймером 500ms.
  Контракт ADR-0011: **остаточный класс снимается на событии `close`** —
  иначе он зажимает opacity и ломает повторные циклы (регресс-кейс
  design-qa career-portal, закрыт e2e).
- **Скролл-лок** (К10): `overflow: hidden` на корне + padding-компенсация
  **по факту сдвига**. С `scrollbar-gutter: stable` из base/reset сдвига
  нет — padding не ставится вовсе, «остаточный body-padding» исключён по
  построению (регресс-кейс design-qa; e2e замеряет ширину шапки до/во время).
  Счётчик локов: вложенные модалки лочат страницу один раз.
- **`aria-labelledby`**: указанный в разметке не трогается; при отсутствии
  модуль ставит его на `.ui-modal__title` (генерируя id).
- **`prefers-reduced-motion`**: анимации гасит глобальный kill-switch
  base/reset — с T7.2 он накрывает и `::backdrop` (обязательство (а)
  ADR-0011).

## A11y

- Роль `dialog` и `aria-modal` — нативные свойства `<dialog>` + `showModal()`;
  ARIA не дублируется.
- `aria-labelledby` → заголовок: скринридер объявляет «диалог, Заголовок».
- `aria-hidden` фону **не ставится** — при top-layer он бесполезен, а с
  ручной простановкой по детям body ломает restore (поймано в T7.1).
- Видимый фокус рисует глобальная политика `base/focus.css` (ADR-0001).
- Контраст подписи на поверхности и на `surface-muted` (hover `__close`) —
  гейт T2.3; e2e axe чист закрытым и с открытой модалкой.

## Вложенные модалки (док-заметка)

Стек ведёт браузер (К7 ADR-0011): второй `showModal()` ложится поверх
первого, Escape закрывает только верхнюю, скролл-лок снимается после
закрытия последней. Это работает, но **полноценной поддержки система не
обещает**: сценарии «модалка из модалки» не покрыты чек-листом и визуальными
эталонами. Если нужен вложенный сценарий — сначала пересмотрите композицию.

## Do / Don't

- **Do**: `data-ui-modal` — на `<dialog>`; на любом другом элементе модуль
  предупредит в консоли и не инициализирует.
- **Do**: `__close` — первым элементом панели (фокус при открытии придёт на
  него — паттерн career-portal).
- **Do**: заголовку — роль типографики (`ui-h3`…), диалогу — `aria-labelledby`.
- **Don't**: не ставьте `aria-hidden` на фон — top-layer блокирует сам.
- **Don't**: не держите диалог `open`-менее скрытым своими классами —
  скрытие это отсутствие `open` (ставит/снимает браузер и модуль).
- **Don't**: `z-index` модалке не нужен — top-layer выше любых значений;
  переопределение позиции/размера — модификатором или стилем сайта.
- **Don't**: модалки без контента (toast/alert) — не этот компонент (Out of
  scope T7.2).

## Bitrix (шаблоны)

Разметка копируется в include-файл или шаблон компонента; `ui.min.js`
инициализирует все `data-ui-modal` на странице. Диалог удобно держать в
подвале шаблона, триггеры — в контенте; для «контент без JS» триггер-ссылка
ведёт на отдельную страницу (модуль снимет переход при JS). События
`irao-ui:modal-open/close` — точки интеграции аналитики.

## Известные границы

- Конкретные содержимые модалок (галерея направлений career-portal) — контент
  сайта, не компонента (Out of scope).
- Вложенные модалки — поведение браузера без гарантий системы (см. выше).
- Toast/alert-модалки без контента — не этот компонент (P2 backlog'а).
- Формы внутри модалки: `method="dialog"` закрывает её без навигации,
  `returnValue` = value кнопки (К11 ADR-0011) — очистка (класс/лок/фокус)
  происходит по событию `close` так же, как при анимированном закрытии.
- Мобильный Safari-профиль (02-architecture §10) не прогонялся: webkit-факты
  получены на desktop-движке (ADR-0011, обязательство (г)).
