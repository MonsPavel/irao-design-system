# ui-card

Карточка-основа: базовый вид, `--hover`, `--filled`, CTA-плашка `--cta`,
медиа-карточка `--media` (фото + тег на фото + тело), слоты
`__media`/`__title`/`__body`/`__meta`/`__footer` и паттерн **карточка-ссылка** (stretched link):
контент-ссылка растягивается на карточку, фокус-обводка проходит по всей площади, вложенные
интерактивы остаются достижимыми. Ключевой компонент списковых страниц — паттерн [«Страница
списка»](stand:patterns/list-page).

## API

| Что | Значение |
|---|---|
| Блок | `.ui-card` на `<article>` (или `<div>`) — коробка: фон surface, рамка `--ui-border-color`, радиус `--ui-radius-md` (16px, career-portal `--radius-card`) |
| Модификатор `.ui-card--hover` | hover-эффект: рамка `--ui-color-border-hover` (#B9C6DE) + тень `--ui-shadow-md` (0 12px 32px blue-800-10). **Только под `@media (hover: hover)`** — на таче не «залипает» |
| Модификатор `.ui-card--filled` | фон и рамка `--ui-color-surface-muted` — приглушённая «бесшовная» карточка (career-portal `.card--filled`) |
| Модификатор `.ui-card--cta` | CTA-карточка (T17.8): центр-композиция (дети по крест-оси, `text-align: center`), ритм — pad 48/24 (`--ui-space-7`/`--ui-space-5`), шаг `--ui-space-3`, радиус `--ui-radius-lg`. Поверхность — вариантом ниже; босой `--cta` остаётся на базовой surface (тело фото-баннера, фон — за `ui-section--photo` T17.3) |
| Вариант `.ui-card--cta--primary` | заливка `--ui-color-primary`, текст — on-dark-пара компонентом (заголовочные роли `ui-h1…h5`/`ui-page-title` внутри перекрашиваются тоже: цвет роли heading = primary — на заливке невидим) |
| Вариант `.ui-card--cta--accent` | заливка `--ui-color-accent`, on-dark-пара; контраст 3.12:1 — одобренное исключение (T2.6/ADR-0010, пара `on-dark-on-accent`; axe — строка реестра `KNOWN_AXE_EXCEPTIONS`) |
| Вариант `.ui-card--cta--row` | горизонтальная плашка `space-between` со слотом действия (стрелка/кнопка); ритм плитки — pad `--ui-space-5`; применяется к `<a>`-карточке |
| Модификатор `.ui-card--link` | включает паттерн карточки-ссылки (в паре с `.ui-card__link` на контент-ссылке) |
| Модификатор `.ui-card--media` | медиа-карточка (T17.5): фото-зона + тег в углу + тело; типографику тела не задаёт — роли разметки |
| Элемент `.ui-card__link` | контент-ссылка паттерна: растягивается на карточку (`::after` c `inset: 0`), доступное имя остановки — её текст |
| Слот `.ui-card__media` | место под изображение — `ui-image` (T4.6); под `--media` — фото-зона: `aspect-ratio: 3/2`, тег-слот, img растягивается (`cover`, радиус md/md 0 0) |
| Модификатор `.ui-card__media--square` | квадратное фото `1/1` (карточка стажёра) — в паре с `--media` |
| Элемент `.ui-card__media-tag` | тег на фото (только под `--media`): `absolute top/left 8px` (`--ui-space-2`); вид — готовый `ui-tag`, тинт варианта выбирает сайт |
| Слот `.ui-card__title` | заголовок; типографику задаёт разметка ролями base (`ui-h3` и т.п.) — компонент шрифты не переобъявляет |
| Слот `.ui-card__body` | основной контент; под `--media` — флекс-колонка: gap 8px (`--ui-space-2`), паддинг 12px (`--ui-space-3`) |
| Элемент `.ui-card__meta` | лента мета-тегов (город/формат события; под `--media`): flex wrap, gap 4px (`--ui-space-1`) |
| Слот `.ui-card__footer` | действия/мета; прижат к низу (`margin-top: auto`) — в сетке списковых страниц действия выравниваются по нижней кромке |
| JS | не требуется (CSS-компонент) |
| Токены | `--ui-border-width`, `--ui-border-color`, `--ui-color-border-hover`, `--ui-radius-md`, `--ui-color-surface(-muted)`, `--ui-shadow-md`, `--ui-space-5` (паддинг 24px), `--ui-card-gap` (14px), `--ui-focus-*`, `--ui-transition`; CTA: `--ui-space-7`/`--ui-space-5`/`--ui-space-3`, `--ui-radius-lg`, `--ui-color-primary`, `--ui-color-accent`, `--ui-color-text-on-dark`; media: `--ui-space-1`/`--ui-space-2`/`--ui-space-3`, `--ui-radius-md` |

```html
<article class="ui-card ui-card--hover ui-card--link">
  <div class="ui-card__media"><!-- ui-image (T4.6) --></div>
  <h3 class="ui-h3 ui-card__title">
    <a class="ui-card__link" href="vacancy.html">Должность</a>
  </h3>
  <p class="ui-body ui-card__body">Короткое описание.</p>
  <div class="ui-card__footer">
    <button class="ui-button ui-button--primary" type="button">Откликнуться</button>
  </div>
</article>
```

## CTA-карточка (`--cta`, T17.8)

Один приём «крупная плашка с призывом»: «Нет подходящей вакансии?» (primary, email-CTA),
«Все 140 вакансий» (accent, стрелка-CTA) главной career-portal. Модификатор задаёт
поверхность/центрирование/ритм; содержимое — ролями base (`ui-h2`/`ui-lead`) и готовыми
контролами (`ui-link`/`ui-button`) — компонент шрифты не переобъявляет:

```html
<div class="ui-card ui-card--cta ui-card--cta--primary">
  <h2 class="ui-h2">Нет подходящей вакансии?</h2>
  <p class="ui-lead">Расскажи о себе — возможно, мы ищем именно тебя!</p>
  <a class="ui-link ui-link--on-dark" href="mailto:career@interrao.ru">career@interrao.ru</a>
</div>
```

Row-вариант — плитка-ссылка со слотом действия (svg-иконка — разметке сайта, компонент даёт
слот, не иконку):

```html
<a class="ui-card ui-card--cta ui-card--cta--accent ui-card--cta--row" href="vacancies.html">
  <span class="ui-h4">Все 140 вакансий</span>
  <svg aria-hidden="true" width="34" height="34" viewBox="0 0 34 34" fill="none"><!-- arrow-up-right --></svg>
</a>
```

- **On-dark-пара — компонентом**: на заливке заголовочные роли перекрашиваются сами
  (`ui-h1…h5`/`ui-page-title` → `--ui-color-text-on-dark`) — цвет роли heading равен primary и
  на primary-заливке невидим. Ссылкам внутри ставьте `ui-link--on-dark` (готовый контрол).
- **Контраст on-dark на accent** — 3.12:1: одобренное исключение (T2.6/ADR-0010, пара
  `on-dark-on-accent`); axe-прогон опирается на строку реестра `KNOWN_AXE_EXCEPTIONS`
  (`tests/helpers/harness.js`).
- **Босой `--cta`** (без варианта поверхности) — центр-композиция на базовой surface: так
  применяется к телу фото-баннера компании, чей оверлей несёт `ui-section--photo` (T17.3).

## Медиа-карточка (`--media`, T17.5)

Один каркас «фото + тег в углу + тело»: карточка события, карточка статьи/медиа-каталога,
карточка стажёра career-portal (закрытые копии `cp-event-card`/`cp-article-card`/
`cp-intern-person`). Каркас задаёт **геометрию и слоты**, содержимое — разметка:

- фото-зона `__media` — `aspect-ratio: 3/2` (`__media--square` — 1/1), img внутри растягивается
  каркасом: `object-fit: cover`, радиус `md`/`md 0 0` (канон «фото сверху»);
- тег на фото `__media-tag` — позиционирование каркаса (`absolute`, top/left 8px); **вид тега —
  готовый `ui-tag`**, тинт варианта выбирает сайт (`ui-tag--green` «Регистрация», `ui-tag--blue`
  рубрика с точкой `ui-tag__icon` и т.д.);
- тело `__body` — флекс-колонка: gap 8px, паддинг 12px; типографику не задаёт — дата `ui-small` +
  `ui-text--muted`, заголовок `ui-h6` (канон карточки списков T16.12, 20/500) или мини-тайтл
  `ui-small` — роли разметки;
- мета-теги события — `__meta`: лента flex wrap с gap 4px.

```html
<article class="ui-card ui-card--hover ui-card--link ui-card--media">
  <a class="ui-card__link" href="event.html">
    <div class="ui-card__media">
      <img src="event.jpg" alt="" width="600" height="400" loading="lazy">
      <span class="ui-card__media-tag ui-tag ui-tag--green">Регистрация</span>
    </div>
    <div class="ui-card__body">
      <time class="ui-small ui-text--muted" datetime="2026-09-28">28.09.2026</time>
      <h2 class="ui-h6">День открытых дверей</h2>
      <p class="ui-card__meta">
        <span class="ui-tag ui-tag--blue">Москва</span>
        <span class="ui-tag ui-tag--gray">очно</span>
      </p>
    </div>
  </a>
</article>
```

Мини-тайтл статьи (media-каталог) и квадратное фото стажёра — тот же каркас с другим набором
тела и `__media--square`:

```html
<article class="ui-card ui-card--hover ui-card--link ui-card--media">
  <a class="ui-card__link" href="article.html">
    <div class="ui-card__media">
      <img src="article.jpg" alt="" width="600" height="400" loading="lazy">
      <span class="ui-card__media-tag ui-tag ui-tag--blue"><span class="ui-tag__icon" aria-hidden="true"></span>статья</span>
    </div>
    <div class="ui-card__body">
      <h3 class="ui-small">Модернизация Киришской ГРЭС</h3>
      <time class="ui-small ui-text--muted" datetime="2026-02-18">18.02.2026</time>
    </div>
  </a>
</article>

<article class="ui-card ui-card--hover ui-card--media">
  <div class="ui-card__media ui-card__media--square">
    <img src="intern.jpg" alt="" width="480" height="480" loading="lazy">
  </div>
  <div class="ui-card__body">
    <p class="ui-h6">Анна Смирнова</p>
    <p><span class="ui-tag ui-tag--blue">аналитик</span></p>
    <p class="ui-small ui-text--muted">Стажировка в команде данных.</p>
  </div>
</article>
```

- **Пропорции — на слоте, не на img**: `aspect-ratio` живёт на `__media`, поэтому смена
  `<img>` на `ui-image` (T4.6) сохраняет композицию; атрибуты `width`/`height` у img — гейт
  `irao/img-dimensions` (CLS-страховка, CSS их перекрывает).
- **Тег на фото — тинт варианта `ui-tag`, не `--on-photo`**: тинты — одобренные пары T16.10;
  модификатор `ui-tag--on-photo` («белый на primary») остаётся API ДС без пилотного применения —
  применение поверх фото без потребности не дублируйте (прецедент реклассификации T16.10).
- **Ссылочная карточка**: `__media` и `__body` внутри `ui-card__link` — вся медиа-зона кликабельна
  (паттерн выше); тег на фото не интерактивен и клик не перехватывает.
- Паддинг тела (12px) — **поверх** базового паддинга карточки (24px): композиция канона
  career-portal (тело плотнее коробки).

## Геометрия и значения

- Паддинг — `--ui-space-5` (24px), gap слотов — `--ui-card-gap` (14px,
  `.vac-card` pages.css:42–43; значение вне 4px-шкалы §3.2 — перенос «как
  есть», пересмотр — design-decision владельца).
- Никаких фиксированных высот: карточка — flex-колонка, растёт по контенту
  вместе с 32px-базой T3.6. Слоты в растянутой сетке (T8.1) тянутся по высоте
  строки, `__footer` прижимается `margin-top: auto`.
- `position: relative` на корне — точка позиционирования растянутой ссылки
  (`::after` разрешается в паддинг-бокс карточки).
- Тень hover — `--ui-shadow-md` (= `--ui-shadow-card`, ступень лестницы теней
  §3.2, источник — тень карточки career-portal components.css:124).
- Hover-рамка — `--ui-color-border-hover` → `--ui-slate-300` (#B9C6DE,
  components.css:123); семантическое имя заведено T4.4 (решение №1 таблицы
  диффов: примитив существовал с T2.1).

## Паттерн «карточка-ссылка» (stretched link)

Включается **парой классов**: `.ui-card--link` на карточке + `.ui-card__link`
на контент-ссылке (обычно в `__title`). Класс ссылки без модификатора ничего
не растягивает; модификатор без ссылки — no-op.

Как работает:

1. `::after` ссылки (`inset: 0`, `border-radius: --ui-radius-md`) покрывает
   всю карточку: клик в любом месте ведёт по ссылке — одна кликабельная
   зона вместо «заголовок-да-остальное-нет».
2. **Доступность**: одна карточка-ссылка = одно остановочное место
   скринридера; доступное имя = текст ссылки. Поэтому текст ссылки обязан
   быть самодостаточным («Вакансия: стажёр…», не «подробнее»).
3. **Фокус**: контур по всей карточке — `:focus-visible::after` на
   focus-тройке токенов (`--ui-focus-color/width/offset`, career-portal
   pages.css:52). Локальная обводка ссылки заменена контуром `::after`
   (`outline: none` с inline-disable — разрешённая замена по
   [focus-policy.md](../../docs/ui-system/architecture/focus-policy.md),
   «Правило для компонентов»; видимый индикатор остаётся и пинится e2e).
4. **Вложенные интерактивы** (паттерн nested-interactive): кнопки и ссылки
   внутри карточки компонент поднимает над растянутой ссылкой —
   `position: relative; z-index: 1` (career-portal pages.css:69/83). Их
   клик-зоны не «съедаются» `::after`, Tab-порядок остаётся осмысленным
   (ссылка → вложенные интерактивы в DOM-порядке). Правило действует на
   `a` и `button`; другой интерактивный элемент поднимайте теми же двумя
   объявлениями в разметке сайта.

## Клавиатура и a11y

- Сама карточка (`article`) не интерактивна: в Tab-порядок попадают только
  ссылка и вложенные интерактивы.
- `Enter` на растянутой ссылке — переход; фокус-обводка видна по всей
  площади карточки (проверено Tab-обходом, `tests/e2e/ui-card.spec.js`).
- Контраст текста на surface/surface-muted ≥ 4.5:1 — гейт T2.3 (пары
  `text-on-surface`, `text-on-surface-muted`) и e2e стенда; hover-рамка —
  осознанное исключение контраст-гейта (декоративная, состояние несёт и
  тень).
- VI-режим (T9.1): перекраска накроет карточку как все элементы — цветов вне
  токенов в файле нет (инвариант §5).

## Do / Don't

- **Do**: список вакансий/статей — карточки-ссылки в `ui-grid` (T8.1), у
  каждой самодостаточный текст ссылки.
- **Do**: `<button class="ui-button">` в `__footer` карточки-ссылки —
  действие поверх перехода (компонент поднимает его сам).
- **Don't**: `<div class="ui-card" onclick="…">` — «кликабельная» карточка
  без ссылки: ни клавиатуры, ни скринридера. Оберните заголовок ссылкой
  с `.ui-card__link` и включите `--link`.
- **Don't**: `.ui-card__link` с текстом «подробнее» — имя остановки
  скринридера обязано описывать назначение (п. 2 паттерна).
- **Don't**: фиксировать высоту карточки inline-стилем или site-CSS —
  карточка растёт по контенту; выравнивание футеров — сеткой + `margin-top:
  auto` слота.
- **Don't**: вкладывать интерактив внутрь самой `.ui-card__link` — вложенный
  в ссылку интерактив недоступен; все интерактивы — сиблинги ссылки внутри
  карточки.
- **Do**: CTA-карточка — один призыв на карточку: заголовок + lead + одно
  действие (`ui-link`/`ui-button`). Две competing цели размывают фокус плашки —
  разбейте на две карточки.
- **Do**: текст действия CTA — действующее слово («написать нам», «смотреть
  вакансии»), прецедент ui-button: доступное имя описывает назначение, а не
  «подробнее»/«жми».
- **Don't**: наливать `--cta--accent`/`--cta--primary` без содержимого ролями —
  on-dark-пару компонент применяет к заголовочным ролям и наследованию; текст
  вне ролей/наследования (например, «серые» утилиты сайта) проверяйте на
  заливке отдельно.
- **Do**: тег на фото медиа-карточки — тинт готового `ui-tag` (`--green`/
  `--blue`/…); вид тега выбирает сайт, каркас даёт только слот-позицию.
- **Don't**: типографику тела медиа-карточки задавать компонентом/модификатором
  — дата `ui-small`+`ui-text--muted`, заголовок `ui-h6`/`ui-small` (T16.12)
  несёт разметка; каркас фиксирует только ритм тела (gap 8, паддинг 12).
- **Don't**: добавлять тегу на фото `ui-tag--on-photo` без потребности — тинты
  вариантов уже одобренные пары (T16.10); белый на primary — отдельный случай
  и решение владельца дизайна.
- **Don't**: задавать пропорции фото inline-стилем или site-CSS — `aspect-ratio`
  3/2 (`--square` 1/1) несёт слот `__media`; site-CSS поверх слота ломает
  единственный источник геометрии.

## Bitrix (шаблоны)

Карточка собирается в `result_modifier`/шаблоне компонента списка: классы на
`<article>`, ссылка заголовка получает `.ui-card__link`, карточка —
`ui-card--link` (и `ui-card--hover` по дизайну). Цвета и геометрия едут из
токенов: смена темы перекрашивает варианты и фокус без правки разметки.

## Известные границы

- Конкретные карточки (vac-card/event-card career-portal) — контентные
  паттерны EPIC-8 (T8.1): собираются из слотов ui-card, компонент их дубликат
  не содержит (Out of scope T4.4).
- `__media` — место под `ui-image` (T4.6): нейтральный слот; изображение и его
  атрибуты (alt/width/height/lazy, модификаторы `--cover`/`--ratio-*`)
  добавляет интегратор — паттерн и чек-лист: README ui-image. Под `--media`
  слот сам несёт пропорции (3/2, `--square` 1/1), cover и радиус фото —
  bare-img-канон T17.5; `ui-image` со своими `--ratio-*`/`--cover` в слоте
  тоже легален (его геометрия совпадает со слотом).
- Список видов медиа-карточки открыт: related-блоки детальных страниц и
  лендинг-композиции эпика полноты ДС собираются из тех же слотов — новые
  дубликаты каркаса не заводить.
- Подъём вложенных интерактивов покрывает `a`/`button`; другой интерактивный
  элемент (например, `input`) поднимайте вручную (`position: relative;
