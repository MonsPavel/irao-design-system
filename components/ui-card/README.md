# ui-card

Карточка-основа: варианты одобренного дизайна career-portal (`.card`,
components.css:115–127) — база, `--hover`, `--filled` — плюс слоты
`__media`/`__title`/`__body`/`__footer` и паттерн **карточка-ссылка**
(stretched link) из `.vac-card` (pages.css:38–83): контент-ссылка растягивается
на карточку, фокус-обводка проходит по всей площади, вложенные интерактивы
остаются достижимыми. Задача T4.4. Ключевой компонент списковых страниц.

## API

| Что | Значение |
|---|---|
| Блок | `.ui-card` на `<article>` (или `<div>`) — коробка: фон surface, рамка `--ui-border-color`, радиус `--ui-radius-md` (16px, career-portal `--radius-card`) |
| Модификатор `.ui-card--hover` | hover-эффект: рамка `--ui-color-border-hover` (#B9C6DE) + тень `--ui-shadow-md` (0 12px 32px blue-800-10). **Только под `@media (hover: hover)`** — на таче не «залипает» |
| Модификатор `.ui-card--filled` | фон и рамка `--ui-color-surface-muted` — приглушённая «бесшовная» карточка (career-portal `.card--filled`) |
| Модификатор `.ui-card--link` | включает паттерн карточки-ссылки (в паре с `.ui-card__link` на контент-ссылке) |
| Элемент `.ui-card__link` | контент-ссылка паттерна: растягивается на карточку (`::after` c `inset: 0`), доступное имя остановки — её текст |
| Слот `.ui-card__media` | место под изображение — `ui-image` (T4.6) |
| Слот `.ui-card__title` | заголовок; типографику задаёт разметка ролями base (`ui-h3` и т.п.) — компонент шрифты не переобъявляет |
| Слот `.ui-card__body` | основной контент |
| Слот `.ui-card__footer` | действия/мета; прижат к низу (`margin-top: auto`) — в сетке списковых страниц действия выравниваются по нижней кромке |
| JS | не требуется (CSS-компонент) |
| Токены | `--ui-border-width`, `--ui-border-color`, `--ui-color-border-hover`, `--ui-radius-md`, `--ui-color-surface(-muted)`, `--ui-shadow-md`, `--ui-space-5` (паддинг 24px), `--ui-card-gap` (14px), `--ui-focus-*`, `--ui-transition` |

```html
<article class="ui-card ui-card--hover ui-card--link">
  <div class="ui-card__media"><!-- ui-image (T4.6) --></div>
  <h3 class="ui-h3 ui-card__title">
    <a class="ui-card__link" href="vacancy.html">Должность</a>
  </h3>
  <p class="ui-body ui-card__body">Короткое описание.</p>
  <div class="ui-card__footer">
    <button class="ui-button ui-button--primary" type="button">Откликнуться</button>
  </div>
</article>
```

## Геометрия и значения

- Паддинг — `--ui-space-5` (24px), gap слотов — `--ui-card-gap` (14px,
  `.vac-card` pages.css:42–43; значение вне 4px-шкалы §3.2 — перенос «как
  есть», пересмотр — design-decision владельца).
- Никаких фиксированных высот: карточка — flex-колонка, растёт по контенту
  вместе с 32px-базой T3.6. Слоты в растянутой сетке (T8.1) тянутся по высоте
  строки, `__footer` прижимается `margin-top: auto`.
- `position: relative` на корне — точка позиционирования растянутой ссылки
  (`::after` разрешается в паддинг-бокс карточки).
- Тень hover — `--ui-shadow-md` (= `--ui-shadow-card`, ступень лестницы теней
  §3.2, источник — тень карточки career-portal components.css:124).
- Hover-рамка — `--ui-color-border-hover` → `--ui-slate-300` (#B9C6DE,
  components.css:123); семантическое имя заведено T4.4 (решение №1 таблицы
  диффов: примитив существовал с T2.1).

## Паттерн «карточка-ссылка» (stretched link)

Включается **парой классов**: `.ui-card--link` на карточке + `.ui-card__link`
на контент-ссылке (обычно в `__title`). Класс ссылки без модификатора ничего
не растягивает; модификатор без ссылки — no-op.

Как работает:

1. `::after` ссылки (`inset: 0`, `border-radius: --ui-radius-md`) покрывает
   всю карточку: клик в любом месте ведёт по ссылке — одна кликабельная
   зона вместо «заголовок-да-остальное-нет».
2. **Доступность**: одна карточка-ссылка = одно остановочное место
   скринридера; доступное имя = текст ссылки. Поэтому текст ссылки обязан
   быть самодостаточным («Вакансия: стажёр…», не «подробнее»).
3. **Фокус**: контур по всей карточке — `:focus-visible::after` на
   focus-тройке токенов (`--ui-focus-color/width/offset`, career-portal
   pages.css:52). Локальная обводка ссылки заменена контуром `::after`
   (`outline: none` с inline-disable — разрешённая замена по
   [focus-policy.md](../../docs/ui-system/architecture/focus-policy.md),
   «Правило для компонентов»; видимый индикатор остаётся и пинится e2e).
4. **Вложенные интерактивы** (паттерн nested-interactive): кнопки и ссылки
   внутри карточки компонент поднимает над растянутой ссылкой —
   `position: relative; z-index: 1` (career-portal pages.css:69/83). Их
   клик-зоны не «съедаются» `::after`, Tab-порядок остаётся осмысленным
   (ссылка → вложенные интерактивы в DOM-порядке). Правило действует на
   `a` и `button`; другой интерактивный элемент поднимайте теми же двумя
   объявлениями в разметке сайта.

## Клавиатура и a11y

- Сама карточка (`article`) не интерактивна: в Tab-порядок попадают только
  ссылка и вложенные интерактивы.
- `Enter` на растянутой ссылке — переход; фокус-обводка видна по всей
  площади карточки (проверено Tab-обходом, `tests/e2e/ui-card.spec.js`).
- Контраст текста на surface/surface-muted ≥ 4.5:1 — гейт T2.3 (пары
  `text-on-surface`, `text-on-surface-muted`) и e2e стенда; hover-рамка —
  осознанное исключение контраст-гейта (декоративная, состояние несёт и
  тень).
- VI-режим (T9.1): перекраска накроет карточку как все элементы — цветов вне
  токенов в файле нет (инвариант §5).

## Do / Don't

- **Do**: список вакансий/статей — карточки-ссылки в `ui-grid` (T8.1), у
  каждой самодостаточный текст ссылки.
- **Do**: `<button class="ui-button">` в `__footer` карточки-ссылки —
  действие поверх перехода (компонент поднимает его сам).
- **Don't**: `<div class="ui-card" onclick="…">` — «кликабельная» карточка
  без ссылки: ни клавиатуры, ни скринридера. Оберните заголовок ссылкой
  с `.ui-card__link` и включите `--link`.
- **Don't**: `.ui-card__link` с текстом «подробнее» — имя остановки
  скринридера обязано описывать назначение (п. 2 паттерна).
- **Don't**: фиксировать высоту карточки inline-стилем или site-CSS —
  карточка растёт по контенту; выравнивание футеров — сеткой + `margin-top:
  auto` слота.
- **Don't**: вкладывать интерактив внутрь самой `.ui-card__link` — вложенный
  в ссылку интерактив недоступен; все интерактивы — сиблинги ссылки внутри
  карточки.

## Bitrix (шаблоны)

Карточка собирается в `result_modifier`/шаблоне компонента списка: классы на
`<article>`, ссылка заголовка получает `.ui-card__link`, карточка —
`ui-card--link` (и `ui-card--hover` по дизайну). Цвета и геометрия едут из
токенов: смена темы перекрашивает варианты и фокус без правки разметки.

## Известные границы

- Конкретные карточки (vac-card/event-card career-portal) — контентные
  паттерны EPIC-8 (T8.1): собираются из слотов ui-card, компонент их дубликат
  не содержит (Out of scope T4.4).
- `__media` — место под `ui-image` (T4.6): сейчас это нейтральный слот без
  встройки изображения.
- Подъём вложенных интерактивов покрывает `a`/`button`; другой интерактивный
  элемент (например, `input`) поднимайте вручную (`position: relative;
  z-index: 1`) — кард-паттерны с полями форм — EPIC-5/EPIC-8.
- Карусели карточек — P2 (Out of scope T4.4).
- VI-перекраска карточек не проверялась в этой задаче — функциональная
  проверка читаемости за T9.1 (Scope T4.4).
