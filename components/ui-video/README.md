# ui-video

Видео-постер «кадр + play-кнопка + метка времени» — обёртка-кнопка (или
ссылка) с постером, градиент-оверлеем к primary 72%, круглой play-кнопкой
accent и временем в правом нижнем углу. Потребитель — блок «Видео о работе в
компании» на главной карьерного портала; вид — заглушка (реального плеера в
оригинале нет, клик никуда не ведёт). Задача T17.6; значения перенесены из
одобренного вида пилота (`.cp-video__*`, pilot.css:653–700).

Компонент **статический (вид)**: поведение воспроизведения — слот сайта.
Обёртка — `<button type="button">` (кликабельный плей) или `<a href="…">`
(Rutube-эмбеды за постером): класс навешивает только вид, клик ведёт
потребитель.

## API

| Что | Значение |
|---|---|
| Блок | `.ui-video` на `<button>`/`<a>` — блок relative с `overflow: hidden`, радиус `--ui-radius-lg`, фон `--ui-color-primary` (страхует кадр до загрузки постера); сброс нативной кнопки (padding 0, border 0) |
| Токен-хук | `--ui-video-play-size` (дефолт `5.5rem` = 88px одобренного дизайна): размер play-кнопки; потребитель переопределяет на блоке без fork'а |
| Элемент `.ui-video__poster` | `img` с `alt=""` + `loading="lazy"`: `object-fit: cover` во всю ширину; высоту ведёт кадр (фиксированные высоты оригинала 720/420/240 — сайт-зона) |
| Элемент `.ui-video__overlay` | градиент `transparent 40% → --ui-color-primary-a72` к низу кадра — тёмная подложка метки времени на светлых постерах; `aria-hidden="true"` |
| Элемент `.ui-video__play` | круг `--ui-color-accent` размером `--ui-video-play-size`, on-dark-стрелка (слот: svg-стрелка сайта или глиф), центр кадра; `aria-hidden="true"` |
| Элемент `.ui-video__time` | метка времени «24:23» — `--ui-color-text-on-dark`, правый нижний угол с отступом `--ui-space-4` |
| JS | не требуется (CSS-компонент; реальный плеер/эмбед — Out of scope, при появлении отдельная задача) |
| Токены | `--ui-video-play-size`, `--ui-color-primary`, `--ui-color-primary-a72`, `--ui-color-accent`, `--ui-color-text-on-dark`, `--ui-space-4`, `--ui-radius-lg` |

```html
<button class="ui-video" type="button" aria-label="Смотреть видео о работе в компании">
  <img class="ui-video__poster" src="poster.jpg" alt="" loading="lazy">
  <span class="ui-video__overlay" aria-hidden="true"></span>
  <span class="ui-video__play" aria-hidden="true">▶</span>
  <span class="ui-video__time">24:23</span>
</button>
```

## Геометрия и значения

- Play-кнопка 88px (`5.5rem`) — значение одобренного дизайна пилота;
  переопределяется токен-хуком: `--ui-video-play-size: 4rem` на блоке
  (плотные медиа-каталоги).
- Градиент-оверлей — ступень лестницы тинтов `--ui-color-primary-a72`
  (T17.6): производная следует за primary в темах автоматически.
- Высоту кадра ведёт постер (`width: 100%`, высота авто): фиксированные
  высоты оригинала (720/420/240) не переносились — раскладка и ритм секции
  остаются сайт-зоной.
- Hover/переходы не перенесены: в одобренном виде пилота их нет (клик —
  заглушка); состояний компонент не диктует.

## Клавиатура и a11y

- Обёртка-кнопка — нативный `<button>`: Tab/Enter/Space из платформы,
  фокус — глобальная политика ADR-0001 (`:focus-visible` с outline).
- Ссылочная форма — нативный `<a>`: Enter переходит по `href` (эмбед или
  страница видео — решает сайт).
- Доступное имя — параметр разметки: `aria-label` на обёртке. Скринридер
  читает «Смотреть видео о работе в компании, кнопка» — одно действие,
  без «24:23 ▶ постер».
- Постер декоративен: `alt=""` — при наличии имени обёртки дублировать
  alt не нужно (иначе скринридер читал бы «постер видео» перед именем).
- `overlay`/`play` — `aria-hidden="true"`: декоративные слои вне потока
  доступности; метка времени остаётся в потоке (читается после имени).
- Контраст: пара play `accent` + on-dark-стрелка — уже одобренная
  (3.12:1 как графика WCAG 1.4.11 ≥ 3:1) — исключение реестра axe
  (`KNOWN_AXE_EXCEPTIONS`, как `ui-button--accent`, ADR-0010); метка
  времени on-dark на градиенте к primary-a72 — гейтит axe на живом стенде
  (эффективный фон с альфой).

## Do / Don't

- **Do**: имя кнопки описывает действие — `aria-label="Смотреть видео о
  работе в компании"` («Смотреть видео …», не «play» и не «видео»).
- **Do**: постер без alt (`alt=""`) + `loading="lazy"` — постер декоративен
  при наличии имени обёртки.
- **Do**: ссылочная форма — `<a class="ui-video" href="https://rutube.ru/…">`:
  переход на эмбед/страницу видео несёт сайт, вид тот же.
- **Do**: плотный медиа-каталог — `--ui-video-play-size: 4rem` на блоке:
  масштаб play без fork'а.
- **Don't**: `aria-label="play"` / `"видео"` / `"24:23"` — имя кнопки
  описывает действие, а не картинку.
- **Don't**: `alt="Видео о работе"` на постере — дубль имени обёртки;
  постер декоративен.
- **Don't**: вешать JS-плеер на класс компонента — поведение
  воспроизведения вне компонента (Out of scope T17.6); при появлении —
  отдельная задача (слот data-ui-video).
- **Don't**: фиксированная высота кадра классом компонента — высоту ведёт
  постер; нужен кроп/ритм секции — сайт-зона.

## Bitrix (шаблоны)

Видео-блок собирается в шаблоне секции главной/медиа-каталога: обёртка —
button (открытие модалки с эмбедом) или ссылка на Rutube-канал, постер и
длительность — свойства инфоблока (`POSTER`, `DURATION`). Доступное имя —
параметр шаблона («Смотреть видео «{Название}»»). Цвета и геометрия едут из
токенов: смена темы перекрашивает оверлей и play без правки разметки.

## Известные границы

- Реальный плеер/эмбед и JS-модуль — нет потребителя; при появлении —
  отдельная задача (слот `data-ui-video`).
- Нативный `<video>`-элемент — другой контекст (контент-встройки), не
  покрывается.
- Hover-масштаб play из старого оригинала (112px, `rgba`-фон) не
  переносился: одобренный вид пилота статичен; интерактивные состояния —
  задача будущего плеера.
