# ui-empty

Паттерн пустого состояния: раздел/список без контента — декоративная иллюстрация
(медиа-слот), заголовок-роль, пояснение и обязательный CTA. Задача T4.8. В
career-portal пустых состояний нет — паттерн новый: минимальный CSS (структура
слотов) поверх существующих примитивов — типографика ролями, CTA из
`ui-button`/`ui-link` (анти-overengineering: 02-architecture §4 «Empty state /
Error state — доки + разметка, CSS-минимум»).

## API

| Что | Значение |
|---|---|
| Блок `.ui-empty` | корень паттерна — центрированная колонка слотов (gap `--ui-space-5`, `text-align: center`) |
| Элемент `.ui-empty__media` | на `<svg aria-hidden="true">` или `<img alt="">` — декоративная иллюстрация; **необязателен** |
| Элемент `.ui-empty__title` | на `<h2>` — заголовок состояния; вид даёт роль `ui-h3` в разметке |
| Элемент `.ui-empty__text` | на `<p>` — пояснение; роль `ui-body` + `ui-text--muted` |
| Элемент `.ui-empty__actions` | лента CTA (переносится на узких экранах); **обязателен** — хотя бы одно действие |
| CTA | действие (повторить/сбросить/отправить) — `ui-button`; переход (смотреть все/на главную) — `ui-link` или `ui-link--button` |
| JS | не требуется |
| Токены | `--ui-space-5` (шаг колонки), `--ui-space-3` (шаг CTA), `--ui-color-text-muted` (тон слота) |

```html
<div class="ui-empty">
  <svg class="ui-empty__media" aria-hidden="true" focusable="false" width="48" height="48" viewBox="0 0 24 24">
    <circle cx="10.5" cy="10.5" r="6.75" fill="none" stroke="currentColor" stroke-width="1.5"></circle>
    <path d="M7.75 13.25h5.5" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round"></path>
    <path d="m15.5 15.5 4.75 4.75" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round"></path>
  </svg>
  <h2 class="ui-empty__title ui-h3">Вакансии не найдены</h2>
  <p class="ui-empty__text ui-body ui-text--muted">
    Под выбранные фильтры ничего не подошло. Попробуйте смягчить условия — или посмотрите все вакансии.
  </p>
  <div class="ui-empty__actions">
    <button class="ui-button ui-button--primary" type="button">Сбросить фильтры</button>
    <a class="ui-link" href="/vacancies/">Посмотреть все вакансии</a>
  </div>
</div>
```

## Правило заголовков

**Заголовок пустого состояния — `h2`**: страница, внутри которой появляется
состояние, уже имеет свой `h1` (заголовок страницы/раздела списка). Пустое
состояние — часть содержимого, а не страница. Проверка сквозная:
`html-validate` (`irao/one-h1`, `irao/heading-order`) гоняется по каноническим
паттернам и стендам в `npm run lint` (`npm run lint:html`). Вид заголовка —
роль `ui-h3` (одобренный размер заголовков состояний — от референса
`.page-404` career-portal, pages.css:683).

## Правила текстов

Спека T4.8 сжимает правила в две строки: **нет вины пользователя** и **есть
следующее действие**. Тон — референс `career-portal/404.html`: «Такой страницы
нет или она была перемещена. Начните с главной — там всё на месте.»

1. **Нет вины пользователя.** Никаких «вы ошиблись», «неверный запрос»,
   «нажмите правильную кнопку». Формулировки от состояния мира: «ничего не
   нашлось», «здесь пока пусто».
2. **Есть следующее действие.** Пустое состояние без CTA — тупик: текст
   обязан подсказывать выход («смягчите фильтры», «посмотрите все вакансии»),
   и хотя бы одно действие обязано стоять в `.ui-empty__actions`
   (Implementation requirements T4.8 п.3).
3. **Коротко.** Пояснение — одна фраза; долгие объяснения читают только
   в документации, не в состоянии.

## Слот иллюстрации

- **Система — только слот и правила** (Out of scope T4.8: иллюстрации сайты
  подставляют свои). Размер не навязывается: геометрию задают атрибуты
  `width`/`height` разметки (svg или img) — те же правила, что у ui-image
  (T4.6): без зафиксированного места — CLS; для retina — запас ×2 в атрибутах.
- **Декоративно и необязательно**: `svg aria-hidden="true"` / `img alt=""` —
  состояние объясняется текстом (Accessibility requirements), иллюстрация не
  попадает в a11y-дерево. Слот можно не выводить вовсе (пример «Здесь пока
  пусто» на стенде).
- Тон по умолчанию — `--ui-color-text-muted` (`currentColor` из разметки):
  декоративный элемент не спорит с текстом; своя иллюстрация — свои цвета
  сайта.

## A11y

- Состояние появляется **в потоке страницы** и не ловит фокус программно
  (Technical considerations T4.8): скринридер читает его при обходе контента,
  `tabindex`/`aria-live` в разметке не нужны. Если состояние появляется
  динамически (замена списка по фильтру), объявление о смене — задача
  контейнера списка (`aria-live="polite"` на области результатов, T8.1), не
  самого паттерна.
- CTA доступны с клавиатуры нативно (кнопка/ссылка); фокус-обводка —
  глобальная политика `base/focus.css` (ADR-0001).
- axe на стенде чист, известных исключений нет.

## Bitrix

Паттерн собирается в шаблоне компонента списка: ветка «нет элементов»
(`$arResult['ITEMS']` пуст) рендерит `.ui-empty` вместо сетки карточек.
Тексты состояний — из языковых файлов/инфоблоков, экранируйте
`htmlspecialchars`. Полный пример пустой ветки списка — задача T8.1.

## Do / Don't

- **Do**: заголовок состояния — `h2`; пояснение + хотя бы один CTA.
- **Do**: для единственного действия-перехода — просто ссылка (пример «Ничего
  не найдено» на стенде); кнопка — для действий, меняющих данные/состояние.
- **Don't**: не выводите пустое состояние с пустым `.ui-empty__actions` —
  тупик для пользователя (п.2 правил текстов).
- **Don't**: не делайте иллюстрацию единственным носителем смысла (без
  `aria-hidden`/с осмысленным alt она попадёт в a11y-дерево как картинка без
  контекста) — смысл несёт текст.
- **Don't**: не ставьте `tabindex`/фокус/`aria-live` на само состояние —
  оно появляется в потоке (объявление о смене — задача области результатов,
  T8.1).
- **Don't**: не используйте пустое состояние для ошибок загрузки — это
  паттерн `ui-error` (граница — в его README.md).

## Известные границы

- Шаг колонки `--ui-space-5` (24px) — маппинг gap 20px одобренного
  `.page-404` на шкалу §3.2 (T3.4: «размеры только из шкалы»); точные 20px —
  только через design-decision владельца дизайна.
- Иллюстрации/анимации в слоте — вне системы (Out of scope T4.8).
- Динамическое появление состояния без перезагрузки страницы — поверхность
  T8.1 (область результатов с `aria-live`).
