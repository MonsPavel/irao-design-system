# ui-link

Ссылки: варианты, состояния и правила особых случаев (внешние, файловые,
анкорные). Задача T4.1. В career-portal ссылки стилизованы глобально
(`a { color: inherit; text-decoration: none }` + локальные цветные hover) —
система даёт явный компонент на токенах. Ссылка — семантический дефолт для
навигации; кнопка — только для действий (см. do/don't ниже — частая ошибка
интеграторов).

## API

| Что | Значение |
|---|---|
| Блок | `.ui-link` на `<a>` |
| Модификатор `.ui-link--on-dark` | для тёмных секций: пара `--ui-color-text-on-dark` / фон секции |
| Модификатор `.ui-link--button` | визуально кнопка, семантика ссылки («переход-выглядит-как-действие») |
| Модификатор `.ui-link--nav` | пункты навигации (меню/шапка/футер): `fs-small`/`fw-small` (14/500), без подчёркивания, hover — opacity 0.7 (T16.3) |
| Элемент `.ui-link__icon` | инлайн-SVG иконки: `aria-hidden="true"`, `focusable="false"`, цвета — `currentColor` в атрибутах `fill`/`stroke`; размер 1em (растёт с текстом) |
| JS | не требуется (CSS-компонент) |
| Токены | `--ui-color-primary`, `--ui-color-text-muted`, `--ui-color-text-on-dark(-muted)`, `--ui-color-primary-hover`, `--ui-link-underline-{thickness,offset}`, focus-тройка ADR-0001 |

```html
<a class="ui-link" href="/vacancies/">смотреть вакансии</a>

<a class="ui-link" href="https://example.com" target="_blank" rel="noopener">
  справочник соискателя
  <svg class="ui-link__icon" aria-hidden="true" focusable="false" width="16" height="16"
       viewBox="0 0 16 16"><path d="…" fill="none" stroke="currentColor" stroke-width="1.5"></path></svg>
</a>
```

## Варианты и состояния

- **default** — подчёркнута всегда, цвет `--ui-color-primary`. Подчёркивание —
  осознанный фикс бренда (спека: «при hover/всегда — фиксируется по бренду»):
  ссылка обязана различаться без цвета (WCAG 1.4.1). Толщина/отступ — токены
  `--ui-link-underline-thickness/offset` в em: линия масштабируется вместе с
  ролью текста (32px-база T3.6 делает её толще).
- **`--on-dark`** — внутри тёмных секций (фон секции — контекст страницы, не
  компонента). Visited — `--ui-color-text-on-dark-muted` (пара AA с тёмным).
- **`--button`** — вид кнопки одобренного дизайна (pill, `--ui-color-primary`,
  подпись `--ui-color-text-on-dark`, padдинги .btn career-portal) без
  фиксированной высоты; hover — пара одобренного дизайна
  `--ui-color-primary-hover` (ADR-0010). Демо «переход-выглядит-как-действие»;
  системная кнопка — [ui-button](doc:ui-button) (T4.2).
- **`--nav`** — пункты навигации (пункты меню, шапки, футера): `fs-small`/
  `fw-small` (14/500 — пара `.header__link` career-portal), подчёркивание
  снято, hover — **только opacity 0.7** (под `@media (hover: hover)`) —
  одобренный дизайн `.header__link:hover`; цветных hover-значений у nav нет.
  Подчёркивание у навигации снимается осознанно: WCAG 1.4.1 «Use of Color»
  обязывает различать ссылку без цвета у **inline-ссылок контента**, а пункт
  навигации в структурном контексте (`<nav[aria-label]>`, список меню)
  различим самим положением — система переносит это исключение из оригинала
  (T16.3). `:visited` — общее с default: nav-ссылки переходят между
  страницами одного сайта, посещённые меняют цвет (`--ui-color-text-muted`),
  правило не отключается. Focus-ring — глобальная политика ADR-0001, как у
  default. Размер наследуемо переопределяем узкими сайт-случаями —
  модификатор его задаёт, но сайт может сузить (пример: кнопка VI шапки
  пилота).

Состояния: default → visited (только цвет — приватность истории браузера
ограничивает свойства) → hover (только под `@media (hover: hover)` — на таче
hover не «залипает») → focus-visible (глобальная политика ADR-0001) → active.
Hover/active ссылок одобренным дизайном не заданы — color-mix 88% + black
(T2.6, ADR-0010); смена темы пересчитывает их сама. Исключения одобренного
дизайна: hover кнопочного вида — пара `--ui-color-primary-hover`; hover
nav-варианта — opacity 0.7 (обе — производные состояния ADR-0010, парами
токенов не гейтятся).

## Клавиатура и a11y

- **Tab** — фокус; **Enter** — переход. Focus-visible рисует глобальная
  политика `base/focus.css` (outline focus-тройки) — компонент не запрещает и
  не заменяет его.
- Известный разрыв: outline-цвет (`--ui-focus-color` = primary) не читается на
  тёмных секциях — замена производных состояний на тёмном зафиксирована за
  T9.2 (`tests/contrast/pairs.config.mjs`).
- Различимость без цвета: подчёркивание всегда (в т.ч. в заголовках и на
  малых ролях).
- **icon-only ссылка обязана иметь доступное имя**: `aria-label` или
  визуально-скрытый текст. Гейт — html-validate `irao/link-accessible-name`
  (предупреждение). Имя должно описывать назначение («Инструкция для
  соискателя», не «ссылка»).
- Контраст всех вариантов и состояний ≥ 4.5:1 — e2e сквозной с T2.3
  (`tests/e2e/ui-link.spec.js` читает computed-цвета и считает его той же
  библиотекой, что контраст-гейт токенов).

## Правила особых случаев

- **Внешние ссылки** — `target="_blank"` **обязательно** с `rel="noopener"`:
  без него целевая страница получает `window.opener` и может управлять
  исходной (tabnabbing). Гейт — html-validate `irao/link-external-noopener`
  (ошибка, `npm run lint`).
- **Файловые ссылки** (PDF, DOCX…) — иконка типа + тип и размер в доступном
  имени: «Скачать прайс-лист (PDF, 2 МБ)». Если файл открывается в новой
  вкладке — те же `target="_blank" rel="noopener"`.
- **Анкорные ссылки** (`href="#…"`): плавный скролл — опция сайта,
  `html { scroll-behavior: smooth; }` в его CSS; пользователям с
  «уменьшить движение» скролл мгновенный — глобальный kill-switch
  `base/reset.css` (T3.1) выставляет `scroll-behavior: auto !important`.
  Цель якоря существует на странице; для переноса фокуса — цель с
  `tabindex="-1"` (паттерн skip-link, T3.5).

## Do / Don't: ссылка vs кнопка

- **Do**: `<a class="ui-link" href="/vacancies/">Вакансии</a>` — навигация на
  другой адрес (страница, якорь, файл, внешний сайт). Браузер даёт бесплатно:
  открытие в новой вкладке, копирование адреса, среднюю кнопку.
- **Do**: `<a class="ui-link ui-link--nav" href="/vacancies/">Вакансии</a>`
  внутри `<nav aria-label>` — пункты навигации: меню, шапки, футера
  (T16.3). Подчёркивание не нужно: WCAG 1.4.1 «Use of Color» не требует
  различать ссылку подчёркиванием при выраженной навигационной структуре —
  пункт различим самим положением (исключение из политики «подчёркнута
  всегда», решение владельца 22.10).
- **Don't**: `ui-link--nav` на inline-ссылках текста контента (статья,
  «подробнее», юридические ссылки в формах) — у текста нет навигационной
  структуры, различимость без цвета обязательна: inline-ссылки остаются на
  default `ui-link`, подчёркнутыми всегда (политика T4.1).
- **Do**: `<a class="ui-link ui-link--button" href="/vacancies/apply/">Откликнуться</a>`
  — переход, который по макету выглядит как действие.
- **Don't**: `<a class="ui-link ui-link--button" href="#">Отправить</a>` —
  действие под видом ссылки: без JS оно не работает, скринридер объявит
  «ссылку», Enter/пробел ведут себя по-разному. Для действий —
  `<button class="ui-button" type="button">` (дока: [ui-button](doc:ui-button)).
- **Don't**: «нажмите здесь» / голый URL текстом — имя ссылки описывает
  назначение («Скачать прайс-лист (PDF)»), это слышно в списке ссылок
  скринридера.
- **Don't**: класть блок-контент внутрь ссылки ради большой кликабельной зоны
  — ссылка остаётся инлайновой семантикой; карточная схема «заголовок-ссылка»
  (паттерн `.vac-card__title a` career-portal) закрывается ui-card (T4.4).

## Bitrix (шаблоны)

Класс ставится на `<a>` в `template.php`-шаблонах компонентов; внешние
адреса из инфоблоков — вместе с `rel="noopener"`. Цвет ссылок едет из токенов:
смена бренда (тема) перекрашивает ссылки и их hover без правки разметки.

## Известные границы

- `:visited` — только цвет (ограничение приватности браузеров); e2e факт
  посещения не проверяет — правило пинит `tests/unit/link.test.js`.
- Hover-производные (color-mix 88% + black) не гейтятся контраст-гейтом
  ТОКЕНОВ-ПАР (`tests/contrast/pairs.config.mjs` гейтит пары значений макета,
  а не производные; «не гейтятся контрастом вовсе» — неверно: производные
  закрыты ревизией T9.2 — `tests/contrast/derived.config.mjs`, level text) —
  компонентный e2e проверяет hover ≥ 4.5:1 на стенде
  (`tests/e2e/ui-link.spec.js`: hover default/on-dark/button). Nav-hover —
  opacity 0.7: цвет не меняет, контраст computed-цвета сохраняется
  (производное состояние ADR-0010, парами не гейтится).
- Цветных link-токенов в слое 2 нет сознательно (правило «слой 3/новые токены
  — когда двум сайтам понадобится различие»): используются смысловые
  `--ui-color-*`; введение link-токенов — minor с дефолтом в `:root`.
