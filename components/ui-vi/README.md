# ui-vi

Версия для слабовидящих по **ГОСТ Р 52872** (задача T9.1): панель настроек, три размера
шрифта, пять цветовых тем, режимы изображений, межбуквенный интервал, персистентность в
localStorage. Порт класса A аудита career-portal (`css/vi.css`, `js/vi.js`,
`src/blocks/vi/vi-panel.html`) — поведение без изменений, кроме зафиксированных ниже дельт.

Состав модуля:

| Файл | Что |
|---|---|
| `a11y/vi.css` | панель (`ui-vi-*`) + режимы (классы на `<body>`); собирается **отдельным** `dist/ui-vi.min.css` — не в `ui-core` |
| `a11y/vi.js` | модуль `window.IraoUI.vi` — состояние, применение, хранение; в составе `dist/ui.min.js` |
| `ui-vi.html` (этот каталог) | канонический паттерн панели — источник стенда и копипасты |

## Подключение

```php
// Порядок каскада: ui-core → тема → CSS сайта → ui-vi ПОСЛЕДНИМ.
$asset->addCss('/local/ui/' . UI_VERSION . '/ui-vi.min.css');
```

`ui-vi.min.css` подключается **последним** — перекраска `!important` обязана быть последним
словом каскада (после core и CSS сайта). JS уже в `ui.min.js`. Кнопка входа в режим — в
шапке сайта (header-паттерн, T7.6): `<button type="button" data-ui-vi-toggle>`.

## Breaking против career-portal

- **Ключ localStorage: `irao-ui-vi`** (career-portal: `vi-settings`). career-portal пакет не
  потребляет; сохранённые на старом сайте настройки **не переносятся** — посетитель выберет
  режим заново. Осознанное решение T9.1 (общесистемное пространство ключей).
- **JS-хуки**: `data-ui-vi-panel` / `data-ui-vi-set="ключ:значение"` / `data-ui-vi-toggle`
  (были `data-vi-*`) — правило `data-ui-*` (ADR-0005).
- **Классы панели** — `ui-vi-*` (были `vi-bar`, `vi-seg__btn`, …). Классы **режимов** на
  `<body>` не менялись: `vi`, `vi-size--*`, `vi-theme--*`, `vi-img--*`, `vi-kern--*`.
- **Выключение снимает классы полностью** (AC T9.1): в career-portal семейства
  `vi-size--*`/`vi-theme--*` оставались на `<body>` инертными; наблюдаемое поведение то же
  (все селекторы режимов требуют `body.vi`), состояние DOM чище.

## API

### Классы панели

| Класс | Элемент |
|---|---|
| `.ui-vi-bar` | фиксированная панель (`position: fixed; z-index: var(--ui-z-vi)`) |
| `.ui-vi-bar__inner` | контентная строка панели |
| `.ui-vi-group` / `.ui-vi-group__label` | группа настроек и её подпись (подпись скрыта `<1024px`) |
| `.ui-vi-seg` / `.ui-vi-seg__btn` | сегмент кнопок; `--sm/--md/--lg` — размеры кнопок «Шрифт» |
| `.ui-vi-swatch` + `--baw/--wb/--bb/--beige/--green` | предпросмотр темы |
| `.ui-vi-exit` | кнопка «Обычная версия сайта» |

### Data-атрибуты (JS-хуки)

| Атрибут | Где | Что делает модуль |
|---|---|---|
| `data-ui-vi-panel` | корень панели | `hidden` снимается/ставится при входе/выходе; по нему же считается `padding-top` страницы |
| `data-ui-vi-set="size:sm\|md\|lg"` | кнопки размера | клик — установить и применить; модуль синхронизирует `aria-pressed` всех кнопок |
| `data-ui-vi-set="theme:baw\|wb\|bb\|beige\|green"` | кнопки темы | то же |
| `data-ui-vi-set="img:on\|gray\|off"` | кнопки изображений | то же |
| `data-ui-vi-set="kern:normal\|wide"` | кнопки интервала | то же |
| `data-ui-vi-toggle` | кнопка входа/выхода (в шапке и в панели) | вход — сброс к стандартным настройкам ГОСТ-панели; `aria-pressed` отражает состояние |

### `window.IraoUI.vi`

| Член | Назначение |
|---|---|
| `init()` | слушатели кнопок + первичное применение; идемпотентен (readyState-guard — Bitrix `addJs(..., true)`) |
| `apply()` | применить текущее состояние (классы, aria, padding-top, сохранение) |
| `set(key, value)` | задать настройку (`on/size/theme/img/kern`) и применить |
| `toggle()` | вход/выход из режима (сброс к дефолтам при входе, `scrollTo({top: 0})`) |
| `state` | живое состояние `{ on, size, theme, img, kern }` |
| `DEFAULTS` | `{ on: false, size: 'md', theme: 'baw', img: 'on', kern: 'normal' }` |
| `STORAGE_KEY` | `'irao-ui-vi'` |
| `parseSaved(raw)` / `mergeState(defaults, saved)` | чистая логика (поверхность `tests/unit/vi.test.js`) |

Чтение и запись localStorage — в `try/catch`: приватный режим/запрет хранилища переводят
модуль в режим без сохранения, страницу не роняют.

## Состояния и режимы

- **Размер** — `zoom` на `body`: sm 1, md 1.2 (по умолчанию), lg 1.45. Масштабируется вся
  вёрстка; zoom стандартизован — протокол перепроверки при обновлении браузеров ниже.
- **Темы** — гарантированные пары ГОСТ (константы `--ui-vi-theme-*` в `a11y/vi.css`,
  единственный осознанный hex вне `tokens/primitives.css`; контраст каждой ≥ 4.5:1 —
  `tests/unit/vi.test.js`):

| Тема | Класс | Пара |
|---|---|---|
| Чёрным по белому | `vi-theme--baw` | базовая, без перекраски (дизайн уже «тёмное на светлом») |
| Белым по чёрному | `vi-theme--wb` | инверсия корня: фильтр `invert(1) grayscale(1)` на `<html>`, фото возвращается фильтром на `img/video` |
| Синим по голубому | `vi-theme--bb` | `#063462` на `#9DD1FF` (7.76:1) |
| Бежевым по коричневому | `vi-theme--beige` | `#4A3728` на `#F5E7CE` (9.21:1) |
| Зелёным на тёмно-коричневом | `vi-theme--green` | `#4DFF00` на `#3B2716` (10.5:1) |

- **Изображения** — обычные / чёрно-белые (`grayscale(1)`) / выкл (прячутся `img`, `video` и
  декоративные слои по конвенции классов `__bg`, `__photo`, `-photo`; svg-иконки остаются).
- **Интервал** — обычный / широкий (`letter-spacing: 0.06em`).
- В режиме отключаются анимации и переходы; плейсхолдеры перекрашиваются `currentColor`.

## Клавиатура и a11y

- Сегментные кнопки — `aria-pressed`, группы — `role="group"` + `aria-label`; визуальные
  «Аа»/«A» — декоративные (`aria-hidden`), имена кнопок — текстовые (`aria-label`).
- Панель — фиксирована сверху; кнопка «Обычная версия сайта» — **escape-путь** из режима,
  доступен с клавиатуры (e2e: Shift+Tab из кнопки входа → Enter).
- `padding-top` страницы = фактическая высота панели (модуль измеряет `offsetHeight`),
  до JS — CSS-резерв `body.vi`.
- Контраст тем — гарантированные пары ГОСТ; обычный контраст-гейт T2.3 на них не действует
  (не токены — исключение с обоснованием в `tests/contrast/pairs.config.mjs`).
- axe-гейт стенда в обоих состояниях (обычный и режим) — `tests/e2e/ui-vi.spec.js`;
  NVDA/VoiceOver-протокол — T9.2.

## Do / Don't

- **Do**: подключать `ui-vi.min.css` последним; панель — первым элементом `<body>`; кнопку
  входа (`data-ui-vi-toggle`) — в шапке на каждой странице; держать компоненты без
  inline-стилей и цветов вне токенов (инвариант §5 — иначе перекраска ляжет неровно).
- **Don't**: не стилизуйте `ui-vi-*` из CSS сайта (панель — зона модуля); не полагайтесь на
  инертные классы при выключенном режиме (их больше не будет); не вводите новые темы/режимы
  (ГОСТ-набор зафиксирован, Phase 0 — один бренд).

## Чек-лист: как проверить страницы сайта в VI

Прогонять после каждой новой страницы/секции (стенд модуля — `stands/ui-vi.html` в showcase;
матрица «тема × стенды» системы — `tests/e2e/ui-vi.spec.js`).

1. **Включение на каждой странице сайта**: кнопка в шапке работает; панель раскрыта;
   `padding-top` равен её высоте (контент не уехал под панель); настройки пережили
   перезагрузку; «Обычная версия сайта» снимает режим полностью.
2. **Все 5 тем × страницы**: текст читаем на каждой теме (пары гарантированы — искать
   просадки не из пар, а из локальных перекрытий); кнопки — контрастная пара темы;
   фокус-обводка видна.
3. **Размеры sm/md/lg**: вёрстка не разваливается (zoom масштабирует всё — сетки, модалки,
   fixed-элементы), горизонтального скролла нет.
4. **Картинки «выкл»**: контент остаётся понятен без растровых фото и декоративных фонов;
   иконки-интерфейсы (svg) на месте; «чёрно-белые» — фото обесцвечены.
5. **Инвариант перекраски** (почему он исполняется сам): компоненты системы не используют
   inline-стили (stylelint-гейт) и цвета вне токенов — проверьте, что в **своих** связках
   (`template_styles.css`) нет inline-`style` и что секции читают токены `--ui-*`:
   перекраска `!important` накрывает только то, что выражено каскадом.
6. **Фото-секции (приёмы career-portal — допишите в CSS сайта при необходимости)**:
   - слой-композиция с абсолютами внутри растянутого контейнера: в режиме задайте ей
     `position: relative` ломает геометрию — верните раскладку по образцу
     `@media (min-width: 1280px) { body.vi section.ХХХ .ХХХ__body { position: absolute; inset: 0; … background-color: transparent !important; } }`;
   - полупрозрачные оверлеи на фото (`::after` с `rgba`) перекрасятся непрозрачным пятном
     темы — замените фон оверлея в режиме: `body.vi.vi-theme--bb .ХХХ__bg::after { background: rgba(157, 209, 255, 0.55) !important; }` (и т.п. для beige/green);
   - тонировка фото под тему (фильтры `sepia/hue-rotate`) — образцы в `a11y/vi.css`
     (конвенционные селекторы `[class*='__bg'] img`, `[class*='__photo'] img` уже действуют);
   - декоративные свечения называйте `ХХХ__glow` — модуль скрывает их в режиме.
7. **Протокол zoom** (при обновлении браузеров): на стенде `stands/ui-vi.html` проверить
   отрисовку 100px-пробы в sm/md/lg (100/120/145px, e2e-сценарий `ui-vi.spec.js`) и
   отсутствие горизонтального скролла на самой узкой странице; при изменении поведения
   `zoom` — design-decision с записью в доку модуля.
8. **Тёмные/фото фоны**: фокус цветом primary на тёмных секциях — известное ограничение,
   ревизия производных состояний — T9.2; до него проверяйте вручную видимость фокуса на
   своих тёмных секциях в режиме.
