# ui-radio

Радио-кнопка: label-обёртка нативного `input[type="radio"]` и текста —
повторяемая единица группы. Задача T5.2. Источник — `.radio` career-portal
(components.css:212–227): inline-flex ярлык, инпут 20px по центру, шаг 10px.
Точку рисует браузер (`accent-color` — токен primary); подмены инпута
запрещены — стрелки и скринридер работают нативно (принципы ТЗ №16/17).

## API

| Что | Значение |
|---|---|
| Блок `.ui-radio` | `label`-корень: inline-flex, инпут по центру (`align-items: center`), шаг `--ui-radio-gap` (10px одобренного `.radio`, components.css:215 — вне шкалы §3.2, перенос «как есть») |
| Элемент `.ui-radio__input` | нативный инпут: 20px (`--ui-control-size`), `accent-color: var(--ui-color-primary)`; `appearance`/`opacity` не трогаются |
| Группа | ≥2 радио с общим `name` оборачивает **ui-radio-group** (fieldset/legend) — одиночное радио вне группы не используйте |
| JS | модуля нет — выбор нативный (клик, стрелки) |
| Токены | `--ui-control-size`, `--ui-radio-gap`; `accent-color` — `--ui-color-primary` |

```html
<!-- одиночный ярлык — элемент группы (полную группу см. ui-radio-group) -->
<label class="ui-radio">
  <input class="ui-radio__input" type="radio" name="employment" value="full" required checked>
  Полная занятость
</label>
```

## Состояния

- **default / checked** — состояние выбора нативное: точку рисует браузер
  (`accent-color` — токен primary), скринридер объявляет «включена/выключена»;
  ARIA-эмуляции у блока нет.
- **checked обязателен в разметке одного из вариантов** (`checked`), когда
  значение по умолчанию предусмотрено: у группы без выбранного варианта
  нет нативного «пустого» состояния — вернуться в него после выбора нельзя.
- **disabled** — нативный атрибут на инпуте: вариант не фокусируется и не
  выбирается; приглушение рисует браузер (своего визуала одобренным
  дизайном не задано — см. «Известные границы»).
- **error/required** — семантика живёт на уровне группы: обвязка
  `ui-field--error` + `required` (README ui-radio-group и ui-checkbox).

## Клавиатура и a11y

- **Стрелки ←→↑↓** ходят по группе нативно: выбор и фокус переходят к
  следующему/предыдущему варианту без JS и tabindex (e2e-пин —
  `tests/e2e/ui-forms.spec.js`).
- Клик по тексту выбирает вариант — label-обёртка нативна.
- Общий `name` — нативная группа: выбор взаимоисключающий.
- Доступное имя ярлыка — его текст; имя группы даёт legend (ui-radio-group).
- required — нативный атрибут на инпутах группы.
- VI-режим: цветов вне токенов нет (§5); `accent-color` перекрашивает
  vi.css (T9.1).

## Do / Don't

- **Do**: всегда внутри `ui-radio-group` (fieldset/legend) вместе с
  остальными вариантами группы.
- **Do**: одинаковый `name` у всех вариантов группы, разные `value`.
- **Don't**: прятать инпут и рисовать свою точку — теряется нативная
  клавиатура и скринридер.
- **Don't**: tabindex — нативный roving фокуса уже работает.

## Известные границы

- предпросмотр «выбран и недоступен» (disabled-вариант в группе) одобренным
  дизайном не задан — нативное приглушение браузера; пересмотр —
  design-decision владельца;
- кастомный список вариантов (address-подбор и т.п.) — вне задачи; нативный
  фундамент обязателен для деградации T7.3.
