# ui-loader

Индикация загрузки области: спиннер (svg, `aria-hidden`) + доступный текст
(`role="status"`) и лоадер-оверлей для `aria-busy`-паттерна. Задача T7.5. В
career-portal loader'а нет — компонент новый; визуал спиннера согласован с
кнопкой-loading [T4.2](../../docs/ui-system/epics/EPIC-04-primitives/T4.2-button.md)
(кольцо на `currentColor`, период вращения — 0.4s). JS не требуется:
состояние загрузки ставит/снимает код сайта (Out of scope T7.5).
Skeleton-плейсхолдеры и progress-bar с процентами — P2, не строились.

> Примечание (ревью T7.5): duration вращения — сырым временем (`0.4s linear
> infinite`), не `var(--ui-transition-slow)`: токен перехода несёт «0.4s
> ease», и в шорткате `animation` рядом с явным `linear` даёт два
> easing-значения — декларация невалидна целиком (спиннер перестаёт
> вращаться). Прецедент сырого duration — `ui-dropdown` (0.18s).

## API

| Что | Значение |
|---|---|
| Блок `.ui-loader` | inline-строка «спиннер + текст» (gap `--ui-space-3`); цвет не задаётся — `currentColor` наследует контекст |
| Элемент `.ui-loader__spinner` | слот спиннера на `<svg aria-hidden="true">`; md-диаметр `--ui-space-5` (24px); вращение `ui-loader-spin` 0.4s linear (значение `--ui-transition-slow`; duration сырым временем — см. примечание выше) |
| Элемент `.ui-loader__text` | **обязателен**: доступный текст с `role="status"` («Загрузка…»); правило доки — текст всегда присутствует |
| Модификатор `.ui-loader--sm` | малый размер: диаметр спиннера `--ui-space-4` (16px) — в потоке текста |
| Модификатор `.ui-loader--block` | блочная загрузка секции: строка по центру, шаг `--ui-space-6` |
| Модификатор `.ui-loader--overlay` | оверлей `aria-busy`-паттерна: покрывает контейнер (`position: absolute; inset: 0`), полупрозрачная поверхность `--ui-color-surface-translucent` |
| JS | не требуется |
| Токены | `--ui-space-3` (шаг строки), `--ui-space-4`/`--ui-space-5` (диаметры sm/md), `--ui-color-surface-translucent` (фон оверлея) |

```html
<span class="ui-loader">
  <svg
    class="ui-loader__spinner"
    aria-hidden="true"
    focusable="false"
    width="24"
    height="24"
    viewBox="0 0 24 24"
  >
    <circle
      cx="12"
      cy="12"
      r="10"
      fill="none"
      stroke="currentColor"
      stroke-width="2.5"
      pathLength="100"
      stroke-dasharray="75 25"
      stroke-linecap="round"
    ></circle>
  </svg>
  <span class="ui-loader__text" role="status">Загрузка…</span>
</span>
```

## Паттерн aria-busy: загрузка области (сниппет для сайтов)

Контейнер области (список, панель, секция) на время загрузки получает
`aria-busy="true"`, поверх контента — лоадер-оверлей `.ui-loader--overlay`.
Контейнеру нужен `position: relative` — его задаёт CSS сайта:

```css
/* CSS сайта */
.vacancies {
  position: relative;
}
```

```html
<div class="vacancies" aria-busy="true">
  <div class="ui-loader ui-loader--overlay">
    <!-- спиннер + текст как в каноническом паттерне выше -->
    <span class="ui-loader__text" role="status">Загружаем вакансии…</span>
  </div>
  <!-- прежний контент области: читается сквозь полупрозрачный оверлей -->
</div>
```

Когда данные готовы, сайт снимает `aria-busy="true"` (или удаляет атрибут) и
удаляет/прячет лоадер (`hidden`). JS-модуля в системе нет — управление
загрузкой зона сайта.

**Правило доки: текст всегда присутствует (не голый спиннер).** Спиннер
декоративен (`aria-hidden`) — состояние загрузки скринридеру объявляет только
текст-живая-область. Правило исполняется машинно: гейт `html-validate`
`irao/loader-text-status` (гоняется по паттернам и стендам в `npm run
lint:html`) требует при каждом `.ui-loader` ровно один `.ui-loader__text` с
`role="status"` и непустым текстом.

## Размеры и цвет

- **md** — база: диаметр спиннера `--ui-space-5` (24px) — самостоятельная
  строка, оверлей, блочная загрузка.
- **sm** (`.ui-loader--sm`) — `--ui-space-4` (16px) — внутри строки текста;
  типографику задаёт контекст (например, роль `ui-small`).
- **Цвет — `currentColor`**: компонент не задаёт ни одного цвета; кольцо
  (`stroke="currentColor"` в разметке) и текст наследуют контекст — роль
  `ui-text--muted`, цвета варианта сайта и перекраска VI-режима работают без
  правок компонента (инвариант §5).

## Reduced motion

`prefers-reduced-motion: reduce` — двойная проверка (Technical considerations
T7.5): глобальный kill-switch `base/reset.css` (T3.1) и локальное правило
`animation: none` в `ui-loader.css`. Вращение отключается на любом движке;
спиннер остаётся видимым статичным кольцом (точка-индикатор), а текст
«Загрузка…» присутствует всегда — состояние читается и без анимации.

## A11y

- **Состояние объявляется**: `role="status"` на тексте — неявная
  `aria-live="polite"`: появление и смена текста («Загрузка…» → «Готово»)
  озвучивается вежливо, без прерывания.
- **Текстовая альтернатива обязательна** — правило «не голый спиннер» (выше,
  гейт `irao/loader-text-status`).
- **Спиннер вне a11y-дерева**: `aria-hidden="true"` + `focusable="false"` —
  декоративная графика (WCAG 1.1.1).
- **Анимация уважает reduced-motion** (раздел выше).
- Лоадер не ловит фокус и не содержит интерактивных элементов: `tabindex`
  не нужен; клавиатурный доступ — к элементам контента после загрузки.
- axe на стенде чист, известных исключений нет. Ручной чек-лист скринридера —
  протокол T9.2.

## Bitrix

Лоадер вставляется в шаблон компонента списка/панели: статичная разметка
(например, ветка «загрузка» аякс-компонента) или включение до получения
данных. Снимайте `aria-busy` и удаляйте лоадер в обработчике успеха; текст
«Загрузка…» — из языковых файлов. Полный паттерн страницы списка с зоной
результатов — задача T8.1.

## Do / Don't

- **Do**: всегда давайте лоадеру осмысленный текст («Загружаем вакансии…»,
  «Обновляем список…») — «Загрузка…» из канонического паттерна подходит, когда
  контекст и так очевиден.
- **Do**: для области контента используйте `aria-busy` + `--overlay`, для
  строки текста — `--sm`, для секции без контента — `--block`.
- **Don't**: не выводите голый спиннер (без `.ui-loader__text`) — гейт
  `irao/loader-text-status` ловит это в разметке системы, на сайте это
  страница без объявления состояния.
- **Don't**: не анимируйте текст лоадера (мигание, «прыгающие» точки) —
  объявление уже делает `role="status"`, а движение — WCAG 2.2.2 (пауза
  анимаций) и reduced-motion.
- **Don't**: не ставьте `aria-live` дополнительно к `role="status"` — роль
  уже несёт неявную `aria-live="polite"`; двойная область даёт повторное
  озвучивание.
- **Don't**: не используйте лоадер для сообщений об ошибке загрузки — это
  паттерн `ui-error`/`ui-alert` (граница — их README).

## Известные границы

- Значения геометрии — новые (одобренного дизайна лоадера в career-portal
  нет): диаметры — ступени шкалы §3.2 (16/24px), период вращения — 0.4s
  (значение токена кнопки `--ui-transition-slow`; сырым временем — см.
  примечание выше), шаг строки — `--ui-space-3`; пересмотр — design-decision
  владельца дизайна.
- Оверлей перекрывает только собственных потомков контейнера (локальный
  стек); для подложек уровня страницы — `--ui-z-overlay` (§3.2), компонент
  его сознательно не тратит.
- Skeleton-плейсхолдеры, progress-bar с процентами — P2 (Out of scope T7.5).
