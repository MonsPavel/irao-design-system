# ui-tag

Тег-аннотация: 5 цветовых вариантов одобренного дизайна career-portal
(`.tag`, components.css:96–112), точка-маркер `__icon` (наследие
`media__tag-dot`). Задача T4.3. Тег — **не интерактивен**: это визуальная
метка рядом с контентом, скринридер читает её как обычный текст.

## API

| Что | Значение |
|---|---|
| Блок | `.ui-tag` на `<span>` (или другом строчном контейнере) — аннотация рядом с контентом |
| Без модификатора | «тихая» база: прозрачный фон, цвет текста (в career-portal не использовался — оставлен предсказуемым, как база ui-button) |
| Модификатор `.ui-tag--blue` | пара `--ui-color-tag-blue-bg` / `--ui-color-primary` (career-portal `.tag--blue`, components.css:108; токен пары заведён T4.3) |
| Модификатор `.ui-tag--orange` | пара `--ui-color-tag-orange-bg` / `--ui-color-tag-orange-text` (AA-замена T2.3: 4.78:1) |
| Модификатор `.ui-tag--green` | пара `--ui-color-tag-green-bg` / `--ui-color-tag-green-text` |
| Модификатор `.ui-tag--gray` | пара `--ui-color-tag-gray-bg` / `--ui-color-text-muted` (AA-замена T2.3) |
| Модификатор `.ui-tag--navy` | пара `--ui-color-primary` / `--ui-color-text-on-dark` |
| Элемент `.ui-tag__icon` | точка-маркер 8px, круг; **обязателен `aria-hidden="true"`**; красится `currentColor` — цвет подписи варианта |
| JS | не требуется (CSS-компонент) |
| Токены | `--ui-tag-height` (28px, min-height), `--ui-tag-gap` (6px), `--ui-tag-letter-spacing` (0.02em), `--ui-radius-pill`, отступы `--ui-space-1`/`--ui-space-3`; цвета — пары «Цветов-смыслов: теги» |

```html
<span class="ui-tag ui-tag--orange">горячая вакансия</span>

<span class="ui-tag ui-tag--blue">
  <span class="ui-tag__icon" aria-hidden="true"></span>
  статья
</span>
```

## Варианты и геометрия

- Высота — `min-height: var(--ui-tag-height)` (28px), не `height`:
  32px-база T3.6 растит тег вместе с текстом (прецедент ui-button).
- Типографика — тройка `--ui-fs-micro` (12px) × `--ui-fw-caption` (500,
  career-portal задаёт `var(--fw-caption)`) × `--ui-lh-micro`,
  letter-spacing `0.02em` — значения одобренного `.tag`.
- Отступы 4/12px — ступени `--ui-space-1`/`--ui-space-3`; gap 6px —
  токен `--ui-tag-gap` (значение макета не на шкале §3.2 — перенос «как
  есть», пересмотр — design-decision владельца).
- Точка-маркер: 8px из шкалы (`--ui-space-2`), круг (pill-радиус в
  квадратном боксе). Цветные модификаторы точки одобренного
  `media__tag-dot` (primary/accent/podcast) не переносились — «как
  модификатор, если понадобится» (Scope T4.3); сейчас точка наследует
  цвет подписи варианта (`currentColor`).

## Клавиатура и a11y

- Не интерактивен: не фокусируется, не попадает в Tab-порядок — фокусная
  политика ADR-0001 к тегу неприменима.
- Текст тега читается скринридером как обычный текст (контент обязателен —
  не оставляйте пустой `span`); точка-маркер — `aria-hidden="true"`.
- Контраст всех пяти пар ≥ 4.5:1 — гейт T2.3 (`npm run test:contrast`,
  пары `tag-orange`/`tag-green`/`tag-blue`/`muted-on-tag-gray`/
  `on-dark-on-surface-dark`) и e2e стенда; orange и gray — AA-замены
  значений T2.3 (исходные 4.40:1 и 3.49:1 на своём фоне).
- VI-режим (T9.1): перекраска `!important` накроет теги как все элементы —
  цветов вне токенов в файле нет (инвариант §5); функциональная проверка
  читаемости — за T9.1.

## Do / Don't: аннотация против интерактива

- **Do**: `<span class="ui-tag ui-tag--green">идёт набор</span>` — статус
  рядом с заголовком карточки.
- **Do**: `<a class="ui-link" href="…">Все статьи</a>` — переход; метка,
  ведущая на страницу, — ссылка со стилем, а не интерактивный тег.
- **Don't**: `<span class="ui-tag" onclick="…">Фильтр</span>` —
  «интерактивный» span: без клавиатуры, фокуса и роли. Чипы фильтров —
  паттерн T8.1 на базе ui-tag + `<button>`/`<a>`.
- **Don't**: пустой `<span class="ui-tag ui-tag--gray"></span>` —
  «пустышка»: скринридер не объявит ничего; тег без текста не имеет смысла.
- **Don't**: `<span class="ui-tag ui-tag--orange" style="color: …">` —
  inline-стили ломают темы и VI-режим (инвариант §5); цвет — выбор
  модификатора + токены.

## Bitrix (шаблоны)

Класс ставится на `<span>` в `template.php`-шаблонах; варианты —
модификатором, точка — `<i>`/`<span>` c `aria-hidden="true"`. Цвета едут
из токенов: смена темы перекрашивает все варианты без правки разметки.
Значение тега — текст разметки; счётчики — `ui-badge`.

## Известные границы

- Тег не интерактивен по умолчанию: интерактивные метки (чипы фильтров
  career-portal `.filter-tag`, 40px) — паттерн T8.1, не расширение этого
  компонента.
- `--ui-tag-gap` 6px вне 4px-сетки шкалы отступов §3.2 — значение
  одобренного дизайна, изменение — design-decision владельца.
- VI-перекраска тегов не проверялась в этой задаче — функциональная
  проверка читаемости в VI-темах за T9.1 (Scope T4.3).
- Пять вариантов = пять пар одобренного дизайна; новых цветов без пары
  контраст-гейт T2.3 не пропустит (новый цвет — сначала пара/исключение).
