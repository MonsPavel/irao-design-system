# ui-carousel

Карусель «фото + заголовок + текст + CTA» со степпером-таблистом и вторая
форма — **фото-галерея** prev/next. Данные слайдов — JSON в разметке
(`<script type="application/json">`), компонент не ходит в сеть. Без JS
показывается первый слайд (данные продублированы в слотах), стрелки и
степпер скрыты. Обе формы рассчитаны on-dark-контекст фото-секций:
степпер-табы с рамкой on-dark-muted, активный — glass-dark + белая рамка,
стрелки — белые кнопки-стрелки; раскладку и перекраску слотов несёт
композиция секции (стенд показывает полный вид блока «Производство»).

## API

| Что | Значение |
|---|---|
| Блок | `.ui-carousel` — корень инстанса (типично секция фото-композиции) |
| Хуки форм | `data-ui-carousel` — карусель со степпером; `data-ui-gallery` — фото-галерея prev/next (степпера нет) |
| Данные карусели | `<script type="application/json" data-ui-carousel-slides>` — массив `{photo, title, text, link, count}`; `link` опционален (CTA-подпись: `slide.link`, иначе строка пилота «Подробнее: count»), `count` — только для этой подписи |
| Данные галереи | `<script type="application/json" data-ui-gallery-photos>` — массив строк-URL |
| Слот карусели | `[data-ui-carousel-photo]` (img), `[data-ui-carousel-title]`, `[data-ui-carousel-text]`, `[data-ui-carousel-link]` — активный слайд; слоты опциональны (рендер по наличию), типографика — ролями в разметке (`ui-h2`, `ui-lead`, `ui-button`) |
| Слот галереи | `[data-ui-gallery-photo]` (img, обязателен); `alt` не меняется модулем — фото попапа декоративны (`alt=""`) |
| Стрелки | `[data-ui-carousel-prev]` / `[data-ui-carousel-next]` (галерея: `data-ui-gallery-prev/next`) — кнопки `.ui-carousel__arrow` вне tablist, `aria-label` обязателен; вид — только класс, модуль вешает поведение на data-хуки (попап направлений может оставить `ui-button`) |
| Степпер | `.ui-carousel__stepper` (`ul role="tablist" aria-label`) в разметке, табы `.ui-carousel__tab` (`button role="tab" aria-selected`); модуль ставит roving tabindex, нормализует `aria-selected` |
| Состояние | активный слайд — `aria-selected="true"` таба + содержимое слотов; CSS активного таба — `:where([aria-selected='true'])`, класса-дубля нет |
| JS | `IraoUI.carousel`: `init()`, `selector` (`[data-ui-carousel], [data-ui-gallery]`), `select(root, index)` — программный выбор (root — элемент или id; ленивая инициализация, как `IraoUI.modal.open`) |
| Событие | `irao-ui:carousel-select` на корне (`bubbles: true`, `detail.index`) — на смене слайда/фото после инициализации (стартовый выбор события не диспатчит) |
| Токены | `--ui-border-width`, `--ui-color-{text-on-dark, text-on-dark-muted, glass-dark, surface, font-family}` (семейство шрифта таба), `--ui-space-2` |

## Деградация без JS

Первый слайд **продублирован в слотах разметки** (как в каноне): без JS
посетитель видит первый слайд с полным контентом. Стрелки и степпер в
разметке несут `hidden` — модуль снимает его при инициализации (симметрично
атрибуту `open` в ui-modal: разметка остаётся правдивой без JS, мёртвых
контролов нет). Скрытие делает CSS (`[hidden]` из base/reset сильнее любых
display-правил + display:none по умолчанию у `.ui-carousel__arrow/
__stepper`); показ — класс `is-initialized` на корне, который ставит модуль.

> **Почему не «:root.js-хук»**: спека T17.7 упоминала хук `:root.js` «уже
> есть в dist» — фактически его в системе нет, а селекторы по data-атрибутам
> не проходят БЭМ-гейт stylelint (прецедентов нет ни в одном компоненте).
> Принят системный приём «состояние ставит модуль» (is-open ui-dropdown,
> is-open/is-closing ui-modal): hidden в разметке — начальное состояние,
> модуль переводит разметку в рабочее.

Данные — зона разметки: без клиентского рендера сайт обязан отдать слоты
первого слайда сервером (PHP-шаблон) — паттерн JSON-данных ui-tabs
(02-architecture §6.3) применим как есть.

## Клавиатура — чек-лист (проверено e2e)

Клавиатура на табах степпера — паттерн APG tabs с **automatic-активацией**
(прецедент ui-tabs):

| Действие | Поведение |
|---|---|
| `→` / `←` | фокус и выбор переходят вместе, с зацикливанием |
| `Home` / `End` | первый / последний таб |
| `Tab` / `Shift+Tab` | не перехватываются — roving tabindex (0 у активного таба, −1 у остальных) уводит Tab за степпер |
| Клик по стрелке | предыдущий/следующий слайд (зацикливание) |
| Клик по табу | выбор слайда |

Стрелки prev/next — обычные кнопки **вне tablist** (Implementation
requirements п.3): в таб-порядок встают как обычные таб-стопы. Программный
выбор — `IraoUI.carousel.select(root, index)`; событие
`irao-ui:carousel-select` позволяет сайту синхронизировать свои тексты
(пилот так обновляет заголовок/подзаголовок/текст попапа направлений при
перелистывании фото).

## A11y

- Степпер — честный tablist **в разметке** (канон спеки): `role="tablist"`
  с `aria-label` → `role="tab"` с `aria-selected`; ровно один выбранный
  поддерживает модуль.
- Стрелки — кнопки с `aria-label` («Предыдущий слайд», «Следующий слайд»)
  вне tablist.
- Roving tabindex: в Tab-порядке один таб; `Tab` не перехватывается.
- Фокус табов и стрелок рисует глобальная политика ADR-0001
  (`base/focus.css`) — компонент outline не гасит и не заменяет.
- Фото карусели: `alt` = заголовок слайда (ставит модуль при переключении,
  как пилот); фото галереи — `alt=""` (декоративные, контент — тексты
  попапа).
- Собственных анимаций и переходов **нет** — AC prefers-reduced-motion
  выполнен конструктивно (пин — tests/unit/carousel.test.js); смена слайда
  мгновенная, как в пилоте.
- Отказ инициализации (нет/битый/пустой JSON, таб вне степпера, галерея без
  фото-слота) — `console.warn`, инстанс не инициализируется, соседние живы
  (контракт шаблона п.4); разметка остаётся в no-JS-состоянии (контролы
  скрыты).

## Do / Don't

- **Do**: дублируйте первый слайд в слотах разметки — это деградация без JS
  и контент для SEO.
- **Do**: раскладку фото-секции (фон, glow, позиции фото/стрелок/степпера)
  несите композицией сайта — компонент не позиционирует элементы (собственных
  absolute/z-index нет).
- **Do**: обновляйте свои тексты подпиской на `irao-ui:carousel-select`
  (bubbles) или вызовом `IraoUI.carousel.select(root, index)` при открытии.
- **Don't**: не ставьте `hidden` на слоты/секцию — `hidden` в каноне только
  на контролах переключения (стрелки/степпер); модуль снимает именно их.
- **Don't**: не ставьте roving `tabindex` в разметку — его ставит модуль;
  роли `tablist`/`tab` и `aria-selected` первого таба — наоборот, часть
  канона (честный tablist без JS-скрытого степпера не врёт: без JS он
  невидим).
- **Don't**: не делайте автоплей. Автопрокрутка без управления пользователем
  недоступна (WCAG 2.2.2 «Pause, Stop, Hide») и в одобренном дизайне её нет;
  если когда-нибудь появится — только с уважением к prefers-reduced-motion и
  явным управлением (отдельное design-решение).
- **Don't**: не вкладывайте интерактив в табы степпера; таб — точка выбора
  слайда. Содержимое таба (номер, подпись, счётчик) типографирует разметка
  сайта.
- **Don't**: не ходите в сеть из разметки инстанса — данные только через
  `<script type="application/json">` в нём же.

## Скрин-пара production (AC T17.7)

Пара «прежний пилот → компонент» для блока «Производство» содержит **ровно
два видимых отличия** — оба осознанные (errata AC4, эскалация
dwfq-e2d04771-1, решение владельца 27.10): снятие артефактов прежнего
пилота в пользу одобренного оригинала career-portal.

1. **Стрелки**: «до» — UA-подложка ButtonFace (rgb(240,240,240), рамка 2px,
   бокс 45×70 — светло-серые плашки на фото; следствие отсутствия
   button-ресета в пилоте), «после» — прозрачные on-dark-иконки
   (`border: 0; background-color: transparent`, бокс 41×66). Одобренный
   оригинал: `button { background: none; border: none }` (base.css) —
   «кнопки-стрелки on-dark» по спеке; воспроизведение подложки запрещено
   инвариантом эпика «одобренный дизайн career-portal не меняется».
2. **Табы степпера**: «до» — UA-шрифт Arial (тот же отсутствующий
   button-ресет), «после» — "Golos Text" (`font-family:
   var(--ui-font-family)` — системный стек ДС, как ui-tabs/ui-button).
   Одобренный оригинал — Golos. Размер не задан (контент таба
   типографирует разметка) — UA-размер 13.33px сохранён.

Остальная раскладка пары идентична (relative-метрики probe до/после
совпадают); высота секции 649→651px (Δ2px — в пороге ±4px соседних задач
T17.4/T17.6). Отступление от оригинала не вносится — наоборот, миграция
повысила соответствие одобренному дизайну; буквальная формулировка AC4
относительно прежнего пилота — брак формулировки (errata в файле задачи),
не работы.

## Известные границы

- Свайп/тач-жесты — Out of scope спеки (нет в оригинале; добавка по
  потребности сайта).
- Автоплей — не предусмотрен (см. Do/Don't).
- Слайд с полем `fit` (cover/contain оригинала) не поддерживается: API
  данных спеки — `{photo,title,text,link,count}`; object-fit фото — зона
  композиции сайта.
- Шрифт таба: компонент задаёт только семейство (`--ui-font-family`) — без
  него нативная кнопка рендерит UA-семейство; размер/вес контента таба
  типографирует разметка сайта (в пилоте — `cp-production__tab-*`).
- Вертикальные карусели, RTL, ленивость фото слайдов — зона сайта (Out of
  scope спеки).
- Бесконечная лента логотипов (marquee) — не карусель: зона лендинг-
  композиций (T17.15).
