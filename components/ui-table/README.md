# ui-table

Адаптивные паттерны таблиц (задача T7.4). Компонент — **паттерны, не «умная
таблица»**: JS-модуля нет, вся адаптивность — CSS + разметка. Три паттерна
покрывают типовые кейсы: обычная таблица, доступная горизонтальная прокрутка
и карточная трансформация на мобиле. Таблиц в career-portal не было — значения
из токенов и шкал системы (пересмотр — design-decision владельца).

## API

| Что | Значение |
|---|---|
| Блок `.ui-table` | на `<table>`: разделители строк `--ui-color-divider`, `border-collapse: separate` + `border-spacing: 0` (collapse ломает `position: sticky`), `width: 100%` |
| `.ui-table__caption` | на `<caption>` — нативное имя таблицы (доступное имя без ARIA) |
| `.ui-table__head` / `.ui-table__body` | на `<thead>` / `<tbody>` |
| `.ui-table__row` | на `<tr>` |
| `.ui-table__col` | на `<th scope="col">` — заголовок колонки |
| `.ui-table__rowhead` | на `<th scope="row">` — заголовок строки (первая колонка тела) |
| `.ui-table__cell` | на `<td>` |
| Обёртка `.ui-table__scroll` | на `<div>` вокруг таблицы: `overflow-x: auto`, индикация прокрутки — градиент правой кромки. **Атрибуты обязательны**: `tabindex="0" role="region" aria-label="Имя данных"` — фокусируемый именованный регион (WCAG 2.4.1/4.1.2); прокрутка стрелками — нативная с фокуса, контур фокуса — глобальная политика ADR-0001 |
| `.ui-table--zebra` | полосы по чётным строкам тела — `--ui-color-surface-muted` |
| `.ui-table--compact` | плотные отступы ячеек (ступени 8/12 вместо 12/16) |
| `.ui-table--sticky-head` | sticky-заголовок: `position: sticky; top: 0` в пределах скролл-зоны, непрозрачный фон `--ui-color-surface`, `z-index: --ui-z-sticky` |
| `.ui-table--cards` | карточная трансформация: на <md (768px) таблица → карточки-строки с парами «заголовок–значение» из `data-label`; на ≥md — обычная таблица |
| `data-label` на ячейках | **обязателен** в `--cards` для каждой `td` и `th` тела — текст заголовка колонки (копипаст); исполняет гейт html-validate `irao/table-card-data-label` (error) |
| JS | не требуется (CSS-компонент) |
| Токены | `--ui-space-1..4`, `--ui-color-divider`, `--ui-color-surface(-muted/-hover)`, `--ui-border-width`, `--ui-border-color`, `--ui-radius-md`, `--ui-z-sticky`, `--ui-fw-body-bold`, `--ui-fs-caption`, `--ui-fw-caption`, `--ui-color-text-muted` |

```html
<div class="ui-table__scroll" tabindex="0" role="region" aria-label="Направления подготовки">
  <table class="ui-table ui-table--cards">
    <caption class="ui-table__caption">Направления подготовки</caption>
    <thead class="ui-table__head">
      <tr class="ui-table__row">
        <th class="ui-table__col" scope="col">Направление</th>
        <th class="ui-table__col" scope="col">Срок обучения</th>
      </tr>
    </thead>
    <tbody class="ui-table__body">
      <tr class="ui-table__row">
        <th class="ui-table__rowhead" scope="row" data-label="Направление">Электромонтёр подстанции</th>
        <td class="ui-table__cell" data-label="Срок обучения">2 года</td>
      </tr>
    </tbody>
  </table>
</div>
```

## Матрица выбора паттерна

| Ситуация | Паттерн | Почему |
|---|---|---|
| Колонки помещаются в контейнер (2–4 короткие) | базовая `.ui-table` | нативная семантика без трансформаций; ничего не включается |
| Колонок много, сравнение **по колонкам** важно (тарифы, характеристики, расписания) | скролл-зона `.ui-table__scroll` | table-семантика сохраняется полностью: скринридер ведёт по заголовкам колонок, данные сравнимы; прокрутка доступна с клавиатуры |
| Строка = **самодостаточная запись** (имя + атрибуты), на мобиле не помещается | карточная трансформация `.ui-table--cards` | карточка читается сверху вниз без горизонтального скролла; пары «заголовок–значение» сохраняют связность данных |
| Данные сравниваются по колонкам (сопоставить «Срок» у нескольких направлений) | **не** `--cards` | карточка рвёт колонку: значения одной колонки разнесены по разным карточкам, сравнение требует памяти |
| Числовые сетки, выравнивание по разрядам, большая таблица (десятки строк) | **не** `--cards`; длинную — со `--sticky-head` внутри зоны | сетка и sticky-шапка держат контекст; лента из десятков карточек нечитаема |

Правило большого пальца: **карточки — когда строка осмысленна сама по себе;
скролл — когда осмысленна колонка.**

## Потеря table-семантики (паттерн `--cards`)

`display: block` на table-элементах меняет их представление в дереве
доступности — **движко-зависимо** (зонд chromium 153, 2026-10): chromium
сохраняет table-дерево (роли cell/row остаются, а `data-label` из `::before`
дополнительно входит в доступные имена ячеек); firefox/webkit исторически
роли table-элементов при изменённом display снимают. Компонент в любом случае
**не опирается** на table-навигацию в карточном режиме:

- **Допустима потеря**, когда каждая строка — самодостаточная запись: пары
  «заголовок–значение» (`data-label` + значение) читаются подряд, связность
  данных внутри карточки полная.
- **Не допустима**, когда данные табличны по природе — сравнение по колонкам,
  числовые сетки, зависимость значения от колонки И строки: в движках со
  снятыми ролями колонка рвётся между карточками. Тогда — скролл-зона
  (семантика таблицы сохраняется всегда).
- `data-label` обязан повторять **текст заголовка колонки** (копипаст) —
  гейт `irao/table-card-data-label` ловит отсутствующий и пустой; ячейка шапки
  (`thead`) data-label не требует — она и есть имя колонки.
- Функциональная проверка чтения пар скринридером (порядок чтения меняется:
  строка → карточка) — протокол T9.2 (Hardening, Technical considerations
  задачи); поведение firefox/webkit — матрица nightly.

## Геометрия и значения

- Паддинги ячеек — ступени шкалы §3.2: `--ui-space-3`/`--ui-space-4`
  (12/16px), compact — `--ui-space-2`/`--ui-space-3` (8/12px). Разделители —
  `--ui-color-divider` (slate-200), рамка 1px `--ui-border-width`.
- Заголовки (колонок и строк) — вес `--ui-fw-body-bold`, выравнивание влево.
- `border-collapse: separate` + `border-spacing: 0`: при `collapse` рамки
  sticky-заголовка уезжают при прокрутке (баг Chrome) — отдельная модель
  рисует разделители на ячейках и дружит со sticky.
- Индикация прокрутки — статический градиент правой кромки от
  `--ui-color-surface` (ширина `--ui-space-5`): фон контейнера не прокручивается
  вместе с контентом. Градиент виден всегда, скрывать у края (scroll-событие) —
  зона сайта: паттерн не умнеет. Под zebra-заливкой градиент приглушён (фон
  ячейки рисуется над фоном контейнера) — второй сигнал: обрезка контента и
  нативный скроллбар.
- sticky-заголовок прилипает **в пределах скролл-зоны** (она — scroll-контейнер:
  `overflow-x: auto` вычисляет `overflow-y` в auto). Работает, когда сайт
  ограничил высоту зоны (`max-height` на `.ui-table__scroll`); к вьюпорту
  страницы из overflow-контейнера sticky не прилипает — платформа.

## Клавиатура и a11y

- Скролл-зона — Tab-стоп (`tabindex="0"`) с доступным именем (`aria-label`);
  стрелки прокручивают её нативно; фокус рисует политика ADR-0001
  (`[tabindex]:focus-visible`). Без aria-label регион был бы безымянным —
  WCAG 4.1.2.
- Заголовки связаны нативно: `th scope="col"` / `th scope="row"` — без ARIA;
  имя таблицы — `<caption>`.
- Контраст текста/подписей на surface и surface-muted — гейт T2.3
  (`npm run test:contrast`); axe стендов чист (e2e), осознанных исключений нет.
- VI-режим (T9.1): цветов вне токенов нет (§5) — перекраска накроет компонент.

## Do / Don't

- **Do**: `data-label` = точный текст заголовка колонки (копипаст) — расхождения
  читаются скринридером как ложные имена.
- **Do**: именуйте каждую скролл-зону (`aria-label="Расписание смен"`).
- **Do**: длинную таблицу в зоне со стеснённой высотой дополняйте
  `--sticky-head`.
- **Don't**: `--cards` для сравнимых по колонкам данных (см. матрицу).
- **Don't**: таблица «для layout» — раскладку дают сетка (T3.4) и списки.
- **Don't**: опускать классы ячеек (`__cell`/`__col`/`__rowhead`) — гейт БЭМ
  не пропускает селекторы по голым тегам, без классов таблица останется
  нестилизованной.

## Bitrix (шаблоны)

Таблица собирается в шаблоне компонента списка: классы на все части (см.
Do/Don't), `data-label` генерируется из описателя колонок
(`$arResult['COLUMNS'][$code]['NAME']`), скролл-зона и `--cards`/`--sticky-head`
— по матрице выбора. Токены едут из темы: смена бренда перекрашивает таблицу
без правки разметки.

## Известные границы

- Сортировка/фильтрация — P2 (Out of scope T7.4, зона сайта).
- Virtual scroll больших данных — P2 (Out of scope T7.4).
- SR-протокол чтения карточек — T9.2 (см. «Потеря table-семантики»).
- Градиент кромки статический; под zebra приглушён (см. «Геометрия»).
- sticky только в пределах зоны с заданной высотой (см. «Геометрия»).
