# ui-image

Паттерн изображений: базовый класс `.ui-image` + модификаторы фиксации места
`--ratio-*` (aspect-ratio из шкалы `--ui-ratio-*`) и кадрирования
`--cover`/`--contain` (object-fit). Задача T4.6. В career-portal системной
политики не было — width/height стояли только на лого, lazy на карточных img,
retina ограничивалась PNG @2x логотипами; медиа секций фиксировались
магическими высотами (pages.css:455/632/697). Паттерн закрывает требования
ТЗ №11 (alt/a11y), №12 (Retina), №20 (работа при отсутствующих изображениях).

## API

| Что | Значение |
|---|---|
| Блок | `.ui-image` на `<img>` — база: `display: block`, `max-width: 100%`, `height: auto` (атрибутная пропорция не искажается при сжатии). box-sizing на корне (ADR-0002) |
| Модификаторы `.ui-image--ratio-*` | фиксация места: `width: 100%` + `aspect-ratio` из шкалы слоя 2 — `--ui-ratio-1-1` (1/1), `--ui-ratio-3-2` (3/2), `--ui-ratio-4-3` (4/3), `--ui-ratio-16-9` (16/9). Без кадрирования пропорция файла обязана совпадать с пропорцией бокса |
| Модификатор `.ui-image--cover` | `object-fit: cover` — файл заполняет бокс, излишек обрезается (без искажения) |
| Модификатор `.ui-image--contain` | `object-fit: contain` — файл вписывается целиком (поля по бокам) |
| Атрибуты `width`/`height` | **обязательны в разметке всегда** (гейт `html-validate irao/img-dimensions`): CLS-страховка до загрузки CSS и intrinsic-пропорция. Второй легитимный путь зафиксировать место — класс `--ratio-*` (спека: «width/height или aspect-ratio») |
| Атрибут `loading="lazy"` | **обязателен для изображений вне первого экрана**; на первом экране — не ставится (нативный eager). JS-библиотеки лени не нужны (Out of scope T4.6) |
| Атрибут `alt` | **обязателен** (гейт `wcag/h37` из T1.2): пустой — для декоративных, осмысленный — для информативных; для complex — краткое описание + `aria-describedby` |
| JS | не требуется (CSS-компонент, единственный элемент — img) |
| Токены | `--ui-ratio-{1-1,3-2,4-3,16-9}` (шкала пропорций, новая — T4.6) |

```html
<!-- Информативное изображение -->
<img class="ui-image" src="/upload/news/ceremony.jpg"
     alt="Церемония награждения победителей программы стажировок"
     width="640" height="360" loading="lazy">

<!-- Media-паттерн (слот ui-card__media): место из шкалы + кадрирование -->
<img class="ui-image ui-image--cover ui-image--ratio-16-9"
     src="/upload/vacancy/cover.jpg"
     alt="Команда разработки за совместной работой над проектом"
     width="640" height="480" loading="lazy">
```

Модификаторы ортогональны: `--ratio-*` фиксирует место, `--cover`/`--contain`
кадрируют поверх бокса. Без зафиксированного бокса object-fit — no-op.

## Три вида изображений (alt-семантика, WCAG 1.1.1)

| Вид | Alt | Пример |
|---|---|---|
| Декоративное | `alt=""` (скринридер пропускает) | оформление рядом с текстом, фоновые фото |
| Информативное | осмысленный alt — **что на картинке**, не имя файла и не «картинка»/«фото» | «Церемония награждения победителей программы стажировок» |
| Complex (инфографика, диаграммы, схемы) | краткий alt + длинное описание через `aria-describedby` | диаграмма: alt «Столбчатая диаграмма: заявки по месяцам», описание — выводы |

Complex-кейс: короткая версия в `alt`, детали — в видимом элементе рядом,
`img[aria-describedby]` ссылается на его `id`; скринридер объявляет их вместе.
Alt и подпись (`ui-figure`, если она есть) решают разные задачи: alt — что на
картинке, подпись — что она значит в контексте страницы.

## Fallback: сломанный src не рушит сетку (ТЗ №20)

Место зарезервировано до и независимо от загрузки файла (атрибуты `width/height`
или модификатор `--ratio-*`), поэтому при ошибке загрузки:

- бокс не схлопывается — соседи и сетка не смещаются (проверено e2e
  boundingBox'ами, `tests/e2e/ui-image.spec.js`);
- вместо картинки рендерится **alt-текст** — потому alt информативного
  изображения обязан быть полезным текстом (это правило — часть fallback, а не
  только a11y-формальность);
- JS не нужен: деградация чисто браузерная. Обработчики `onerror`-подмен —
  не паттерн системы.

## Чек-лист «как готовить изображения» (контент-менеджерам Bitrix)

- [ ] **Вид и alt**: декоративное → `alt=""`; информативное → alt описывает
      содержание; диаграмма/схема → краткий alt + `aria-describedby` на
      полное описание (описание готовится вместе с картинкой, из инфоблока).
- [ ] **Размеры в разметке**: у каждого `<img>` есть `width`/`height`
      (реальные пропорции файла) — иначе место не зафиксировано (CLS).
- [ ] **Файл по ширине места**: экспортируйте картинку в ширину контейнера
      (или в 2× — для ретины, см. ниже), не в «как получится»: файл 4000px в
      слоте 300px — трафик и лаги, файл 200px в слоте 300px — мыло.
- [ ] **Формат**: фото — JPEG; логотипы, графика с прозрачностью — PNG;
      иконки, схемы, диаграммы — **вектор SVG** (инлайном с `aria-hidden` —
      паттерн иконок ui-button/ui-alert: красятся `currentColor`, темы и
      VI-режим работают сами).
- [ ] **Retina (ТЗ №12)**: вектор — для иконок; растр — `srcset` 1x/2x
      (пример ниже); растровые SVG не нужны — SVG масштабируется сам.
- [ ] **Вес** (ориентир, не гейт): обложки/hero — до 200–300 КБ, контентные
      изображения — до 100–150 КБ, иконки — вектор. Тяжёлые фото сжимайте
      (JPEG quality ~80) перед загрузкой в медиабиблиотеку.
- [ ] **Lazy**: всё, что ниже первого экрана, — `loading="lazy"` в разметке
      шаблона (для списков Bitrix — в `template.php` карточки).
- [ ] **Подпись**: если у изображения есть подпись — это `ui-figure`
      (`figure/figcaption`), а не соседний абзац (README ui-figure).
- [ ] **Fallback-тест**: проверьте страницу с отключённым файлом — сетка не
      должна ехать, вместо картинки читается осмысленный alt.

### Retina: srcset 1x/2x (кейс Bitrix — генерация из инфоблоков)

Логотипы career-portal — PNG @2x (`logo.png` + `logo@2x.png`): браузер сам
выбирает файл по плотности экрана. В Bitrix 2x-версия — второе свойство
инфоблока (заполняется контент-менеджером или генерируется при сохранении):

```php
<!-- template.php компонента списка -->
<img class="ui-image"
     src="<?= $item['DISPLAY_PROPERTIES']['PHOTO']['FILE_VALUE']['SRC'] ?>"
     srcset="<?= $item['DISPLAY_PROPERTIES']['PHOTO_2X']['FILE_VALUE']['SRC'] ?> 2x"
     alt="<?= $item['NAME'] ?>"
     width="640" height="360" loading="lazy">
```

Для адаптивной ширины добавляется `sizes` (браузер выбирает файл по ширине
слота, а не по плотности): `srcset="photo-400.jpg 400w, photo-800.jpg 800w"
sizes="(min-width: 1024px) 400px, 100vw"` — ширины файлов готовятся заранее.

## Клавиатура и a11y

- Изображение не интерактивно: в Tab-порядок не попадает. Обернув его в
  ссылку, дайте ссылке осмысленное имя (текст или aria-label) — паттерн
  `irao/link-accessible-name`.
- Декоративное (`alt=""`) исключается из a11y-дерева целиком — подписи у него
  быть не может (и `ui-figure` не имеет смысла).
- VI-режим (T9.1): у изображений нет цветов в CSS — перекраска и «картинки
  выключить» (паттерн `vi-img--off` career-portal) накрывают компонент без
  правок.
- Контраст: компонент цветов не задаёт — гейт T2.3 не применяется.

## Do / Don't

- **Do**: media-слот карточки — `ui-image--cover ui-image--ratio-16-9` +
  `width/height` + `loading="lazy"` (единая геометрия списков T8.1).
- **Do**: `alt=""` для декоративных — пустого alt НЕ бывает только у
  сломанной разметки: отсутствие атрибута ≠ пустой атрибут (гейт `wcag/h37`).
- **Don't**: `<img class="ui-image" src="…">` без `width/height` и `--ratio-*`
  — красный на `irao/img-dimensions`: загрузка сдвинет контент (CLS).
- **Don't**: сжимать пропорцию (файл 4:3 в бокс 16:9 без `--cover`) —
  искажение; кадрируйте модификатором.
- **Don't**: alt «фото», «картинка», «image123.jpg» — имя остановки
  скринридера обязано описывать содержание.
- **Don't**: инлайн-стили и фиксированные высоты (`style="height: 280px"`,
  паттерн career-portal pages.css:632/697) — место фиксирует `--ratio-*`,
  высоты из контентной вёрстки не переносятся.
- **Don't**: JS-библиотеки lazy-loading — нативного `loading="lazy"`
  достаточно (Out of scope T4.6).

## Bitrix (шаблоны)

Паттерн копируется в `template.php`: `width`/`height` — из свойств файла
(`getimageSize`) или константы макета, `alt` — из поля/названия элемента,
`loading="lazy"` — статично в разметке карточки. 2x-версии для `srcset` —
вторым свойством инфоблока (пример выше). Конверсия форматов (WebP/AVIF) и
`<picture>`/art-direction — инфраструктура контента сайта, не системы
(Out of scope T4.6): браузер берёт WebP в `<img>` нативно, если сайт его
отдаёт.

## Известные границы

- Шкала `--ui-ratio-*` — четыре типовые пропорции (1/1, 3/2, 4/3, 16/9).
  Новая ступень — minor-токен (дефолт в `:root`, запись в таблице диффов
  `docs/ui-system/architecture/tokens-career-portal-mapping.md`).
- В `--ratio-*` зашита ширина `100%`: для изображения в обёртке не на всю
  ширину ограничивайте контейнер/слот, а не сам img.
- До загрузки CSS бокс равен атрибутам `width/height`; при кадрировании
  (пропорция файла ≠ пропорции бокса) полный откат без CSS невозможен —
  это осознанный компромисс в пользу CLS = 0 при включённом CSS.
- `<picture>`/art-direction, AVIF/WebP-конверсия, JS-lazy — Out of scope
  T4.6 (заметка выше).
- VI-перекраска изображений функционально не проверялась в этой задаче —
  за T9.1.
