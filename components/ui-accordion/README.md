# ui-accordion

Аккордеон на нативных `<details>/<summary>`: **полностью работает без
JavaScript** (раскрытие, Enter/Space, клик, состояние — браузер), с плавной
анимацией высоты и вариантом FAQ. Задача T6.4. Источник — `.faq` + `faq.js`
career-portal (класс A): визуал и grid-rows-техника анимации перенесены,
управление `div/button` + класс `is-open` заменено на нативное (`[open]`).

## API

| Что | Значение |
|---|---|
| Блок | `.ui-accordion` — корень (flex-колонка с gap 16px); вариант `--faq` — визуал FAQ career-portal (фон `--ui-color-surface-muted`, радиус `--ui-radius-md`) |
| Элемент `.ui-accordion__item` | пункт — `<details>`; состояние — нативный атрибут `open` (можно задать в разметке: стартово раскрытый пункт) |
| Элемент `.ui-accordion__q` | вопрос — `<summary>`: имя скринридеру — **текст** (без ARIA), маркер disclosure снят (`list-style: none`); индикатор — шеврон |
| Элемент `.ui-accordion__icon` | шеврон svg 16×16 `aria-hidden` (декоративный); поворот 180° при `[open]` |
| Элемент `.ui-accordion__a` | ответ — grid-item слота `::details-content` (`min-height: 0` + `overflow: hidden` — контракт усадки трека 0fr) |
| Элемент `.ui-accordion__a-inner` | внутренний блок ответа: паддинги, роль small |
| JS (опция) | `IraoUI.accordion`: `init()`, `selector`; хук разметки — `data-ui-accordion` на корне; режим single — `data-ui-accordion="single"` |
| События | `irao-ui:accordion-open` / `irao-ui:accordion-close` на корне (`bubbles: true`) — на каждом toggle инициализированного инстанса (точка расширения сайта) |
| Токены | `--ui-color-surface-muted`, `--ui-radius-md`, `--ui-color-primary`, `--ui-color-text`, `--ui-fs-body`, `--ui-fw-body-bold`, `--ui-fs-small`, `--ui-lh-small`, `--ui-space-4/5/6`, `--ui-transition`; focus-тройка ADR-0001 |

```html
<div class="ui-accordion ui-accordion--faq">
  <details class="ui-accordion__item" open>
    <summary class="ui-accordion__q">Работает ли аккордеон без JavaScript?
      <svg class="ui-accordion__icon" aria-hidden="true" width="16" height="16"
           viewBox="0 0 16 16" fill="none"><!-- шеврон career-portal --></svg>
    </summary>
    <div class="ui-accordion__a">
      <div class="ui-accordion__a-inner">Да: база — нативные details/summary…</div>
    </div>
  </details>
</div>
```

**Без ARIA** (Accessibility requirements): `details/summary` объявляют
раскрыватель и состояние сами; имя вопроса — текст summary, глиф —
`aria-hidden`. Разметка правдива без JS: режим single — единственное
JS-зависимое поведение, и оно чистое усиление (без JS пункты независимы).

## Деградация без JS

Полная: раскрытие/сворачивание (клик), клавиатура (Enter, Space), состояние
(`open`) — нативные. Модуль `IraoUI.accordion` не ставит ни атрибутов, ни
ролей и не трогает начальные состояния — он только слушает `toggle`.

## Режим «один открыт» (single)

```html
<div class="ui-accordion ui-accordion--faq" data-ui-accordion="single">
```

Открытие пункта закрывает соседей; повторный клик закрывает единственный
открытый («все закрыты» допустимо). Значение атрибута, отличное от `single`,
поведение не меняет (пункты независимы), но события open/close диспатчатся в
любом режиме. Без JS атрибут — просто неиспользуемый хук.

## Клавиатура — чек-лист (нативная, проверено e2e)

| Действие | Поведение |
|---|---|
| `Tab` / `Shift+Tab` | вопрос — обычный таб-стоп; из открытого ответа фокус идёт по его содержимому |
| `Enter` | раскрыть/свернуть вопрос |
| `Space` | раскрыть/свернуть вопрос |
| Клик | раскрыть/свернуть вопрос |

Фокус-обводка — глобальная политика ADR-0001 (`base/focus.css` содержит
`summary:focus-visible`); компонент outline не гасит и не заменяет.

## Анимация `<details>` — зафиксированное решение (AC)

Проблема: `details` раскрывается мгновенно — слот содержимого начинает
рендериться в момент `[open]`, поэтому классический grid-rows-переход
career-portal (0fr→1fr на обёртке ответа) в Chromium не стартует (переходу
не с чего начинать). Решение выбрано эмпирическим зондом (2026-10-08,
`chromium 153 / firefox 155 / webkit(«Safari 26.6»)`, все три — Playwright-матрица репозитория):

| Техника | Chromium | Firefox | WebKit |
|---|---|---|---|
| grid-rows на обёртке (career-portal «как есть») | мгновенно | анимация | анимация |
| `height 0→auto` + `interpolate-size` на `::details-content` | анимация | мгновенно (нет `interpolate-size`) | мгновенно (нет) |
| **grid-rows на `::details-content` (выбрано)** | **анимация** | **анимация** | **анимация** |

```css
.ui-accordion__item::details-content {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows var(--ui-transition);
}
.ui-accordion__item:where([open])::details-content { grid-template-rows: 1fr; }
```

Почему это работает: `::details-content` (Chrome 131+, Safari 18.4+, Firefox
150+) — **постоянный** бокс слота содержимого, он существует и в закрытом
состоянии — переходу есть между чем идти. `interpolate-size` не нужен
(0fr↔1fr интерполируется сам). `content-visibility` c `allow-discrete` в
переходе (согласование с UA-правилом
`details:not([open])::details-content { content-visibility: hidden }`)
проверена тем же зондом и **отброшена**: плавности закрытия она не даёт
(закрытие мгновенно во всех движках и с ней), а сочетание остаётся
экзотическим — UA переключает скрытие слота дискретно, что и есть
наблюдаемое поведение.

Границы решения:

- **Закрытие — мгновенное во всех движках** (проверено зондом при любой
  чисто CSS-технике) — осознанная деградация по ТЗ: контент не теряется,
  плавности закрытия нет. JS-компромиссы (задержка снятия `[open]`) не
  принимаются — база обязана работать без JS.
- Движок без `::details-content`: правила не применяются, аккордеон работает
  нативно без анимации — деградация, не поломка.
- **reduced-motion**: `transition: none` на `::details-content` в компоненте
  внутри `@media (prefers-reduced-motion: reduce)` — kill-switch
  `base/reset` бьёт `*::before/*::after`, но не произвольный псевдоэлемент
  слота. Поворот шеврона гасит глобальный kill-switch (реальный элемент).

Значения переноса (одобренный дизайн): паддинги 20px → `--ui-space-5` (24px,
ступень шкалы §3.2; прецедент ui-card 28→24, ui-tabs); длительность 0.3s →
`--ui-transition` (0.25s — шкала движений; career-portal сам держит
`--transition: 0.25s`); `line-height: 1.45` ответа → роль small
(`--ui-lh-small` 1.35 — career-portal расходился с собственной
`--lh-small-regular: 1.35`). Пересмотр значений — design-decision владельца
дизайна.

## schema.org FAQPage — когда уместно

FAQ-вариант — визуальный паттерн, а не «канонический потребитель» микроразметки
FAQPage: schema.org/Google требуют, чтобы всё содержимое вопросов и ответов
было **доступно пользователю**, и не рекомендуют разметку, служащую рекламе
видимости, а не содержанию. Разметить `FAQPage` уместно, когда блок —
действительный FAQ (вопрос-ответ одной тематики), разметка отражает видимый
контент 1:1 и ответы не прячутся от пользователя (раскрытие по действию
допустимо). Решение о разметке — зона сайта, компонент её не несёт.

## Do / Don't

- **Do**: один вопрос — один пункт; текст вопроса — прямой текст summary.
- **Do**: содержимое ответа — зона сайта (текст, списки, `ui-card`);
  компонент стилизует только коробку.
- **Do**: стартово раскрытый пункт — нативный `open` в разметке (демо и
  паттерн: первый вопрос FAQ).
- **Don't**: не добавляйте ARIA (`aria-expanded`, роли) — нативная семантика
  полна; дубли только путают скринридеры.
- **Don't**: не кладите интерактив внутрь summary (кнопки, ссылки) — summary
  сам интерактив, вложенное недоступно с клавиатуры до раскрытия.
- **Don't**: не используйте аккордеон для контента, критичного без JS
  (контакты, цены) — по умолчанию он скрыт; для «все видно без JS» есть
  статичные секции.
- **Don't**: не стилизуйте `is-open` — состояния нет в CSS: источник правды —
  нативный `[open]`.

## Известные границы

- Деревья/вложенные аккордеоны — по потребности (Out of scope спеки).
- Динамическая загрузка содержимого при открытии — зона сайта; после
  клиентского рендера новых инстансов вызовите `IraoUI.accordion.init()`
  повторно (guard повторной инициализации разрешает).
- Плавность закрытия не обеспечивается чистым CSS (см. «Анимация») — если
  закроется, то мгновенно.
- Глубокие ссылки на раскрытый пункт (`#hash`) не обрабатываются — зона
  сайта (сайт может выставить `open` до загрузки скрипта: модуль состояние
  не трогает).
