# ui-chip

Интерактивный фильтр-чип: пилюля-контрол с активным состоянием (`.chip`
career-portal, pages.css:137–151 — вакансии, стажировки, медиа, поиск
мероприятий; 4+ страницы). Задача T14.8. Чип — **кнопка** (клиентская
фильтрация) или **ссылка** (GET-фильтр): активное состояние приходит из
разметки/сервера — как `aria-current` в ui-breadcrumbs, JS-модуля у компонента
нет, клики — нативные.

## API

| Что | Значение |
|---|---|
| Блок `.ui-chip` | **группа чипов** — flex-лента с переносом и gap 8px (`.chip-row` pages.css:135, ступень шкалы `--ui-space-2`); ставится на `<nav>` (ссылочная форма) или на контейнер с `role="group"` (кнопочная) — **доступное имя обязательно** (`aria-label`) |
| Элемент `.ui-chip__pill` | пилюля-контрол: `<button type="button" aria-pressed="…">` (клиентский фильтр) или `<a href="…" [aria-current="page"]>` (GET-фильтр) |
| Активное состояние | только ARIA-атрибутом: `aria-pressed="true"` у кнопки / `aria-current="page"` у ссылки — CSS-селектор `[aria-pressed='true'], [aria-current='page']` (класс-дубль не нужен; `is-active` оригинала не переносится) |
| JS | не требуется (CSS-компонент; переключение `aria-pressed` — зона сайта: один слушатель клика на группу) |
| Токены | `--ui-chip-height` (36px, min-height), рамка `--ui-border-width` × `--ui-border-color`, радиус `--ui-radius-pill`, типографика — роль small (`--ui-fs-small` × `--ui-fw-small` × `--ui-lh-small`), паддинг `0 var(--ui-space-4)`, переход `--ui-transition`; цвета — пары surface/text, primary/text-on-dark |

```html
<nav class="ui-chip" aria-label="Направления">
  <a class="ui-chip__pill" href="?topic=energy" aria-current="page">энергетика и электротехника</a>
  <a class="ui-chip__pill" href="?topic=it">информационные технологии</a>
</nav>

<div class="ui-chip" role="group" aria-label="Формат занятости">
  <button class="ui-chip__pill" type="button" aria-pressed="true">полная занятость</button>
  <button class="ui-chip__pill" type="button" aria-pressed="false">стажировка</button>
</div>
```

## Активное состояние: ARIA-атрибут, не класс

Состояние «фильтр выбран» обязано быть express АРИА-атрибутом — `aria-pressed`
у кнопки, `aria-current="page"` у ссылки — а не только классом или цветом
(WCAG 1.4.1: состояние не только цветом; скринридер объявляет «нажата» /
«текущая страница»). CSS держит селектор атрибута
(`.ui-chip__pill:where([aria-pressed='true'], [aria-current='page'])` —
`:where()` сохраняет специфичность одноклассовой, прецедент aria-selected
ui-tabs): класс-дубль для стиля не нужен, а стилизованный «класс без ARIA» —
антипример (состояние невидимо ассистивным технологиям). Канон — одна активная
на группу (одиночный выбор, как на страницах career-portal).

- Кнопка: `aria-pressed` всегда со значением `true`/`false` — «голой»
  `aria-pressed` без значения быть не должно (логика выбран/не выбран).
- Ссылка: активная остаётся рабочей ссылкой (`aria-current="page"` — не
  `disabled` и не `span`): повторный клик перезапрашивает выдачу — это не
  «текущая страница» пагинации, а выбранный фильтр.
- hover — рамка и подпись primary (pages.css:149, пара `primary-on-surface`
  гейта T2.3) только у **неактивных** и только под `(hover: hover)` (EPIC-4):
  у активной подпись primary на заливке primary была бы нечитаема.

## Границы: ui-chip / ui-tag / ui-dropdown

| | Что это | Интерактив | Семантика |
|---|---|---|---|
| `ui-tag` | декоративная аннотация-метка рядом с контентом («горячая вакансия») | **нет** — не фокусируется | `<span>` без роли |
| `ui-chip` | фильтр: выбор значения выдачи («энергетика») | кнопка/ссылка, активное состояние | ARIA-состояние |
| `ui-dropdown` | меню действий/переходов, открывается по клику | кнопка + всплывающее меню (APG menu-button) | `aria-expanded`/`menu` |

- «Похожее на тег, но по клику фильтрует/переходит» — ui-chip, не ui-tag
  (do/don't ui-tag: «интерактивный span» запрещён).
- «Клик открывает список вариантов» — ui-dropdown: чип выбирает одно значение
  сразу, dropdown показывает меню.
- Счётчик результатов внутри чипа — `ui-badge` (следить за дублированием
  значения — правило ui-badge).

## Клавиатура и a11y

- Кнопки и ссылки — нативные контролы: попадают в Tab-порядок в DOM-порядке
  группы; Enter (кнопка и ссылка) и Space (кнопка) активируют нативно.
- Фокус-обводка — глобальная политика ADR-0001 (`base/focus.css`):
  `:focus-visible`, компонент outline не переопределяет.
- Активное состояние озвучивается атрибутом («нажата» / «текущая страница»),
  не цветом (WCAG 1.4.1) — см. раздел выше.
- Контраст состояний — гейт T2.3 (Implementation requirements T14.8 п.1):
  пары `chip-default` (текст на surface, 16.48:1) и `chip-active`
  (text-on-dark на primary, 14.60:1 — значения отчёта
  `npm run test:contrast`, dist/contrast-report.md); hover-пара —
  существующая `primary-on-surface`. Рамка #D6D6D6 — декоративная (исключение
  `--ui-border-color` гейта). Синхронность чисел с отчётом — юнит-пин
  `tests/unit/chip.test.js` (evaluateContrast поверх pairs.config.mjs).
- Группа несёт доступное имя (`aria-label` у `nav` / `role="group"`):
  без него скринридер читает набор пилюль без контекста «это фильтры».

## Do / Don't

- **Do**: `<button class="ui-chip__pill" type="button" aria-pressed="true">`
  в группе `role="group"` — клиентский фильтр; переключение атрибута — один
  слушатель на группе (зона сайта).
- **Do**: `<a class="ui-chip__pill" href="?topic=it" aria-current="page">` —
  GET-фильтр, состояние из серверной разметки.
- **Don't**: `<span class="ui-chip__pill" onclick="…">` — «чип» без
  клавиатуры, фокуса и роли: контрол — кнопка или ссылка.
- **Don't**: `class="is-active"` (или любой класс) без ARIA-атрибута —
  состояние невидимо скринридеру; визуал вешается на селекторы атрибутов.
- **Don't**: чип вне группы без имени контекста И чип как «метка статуса» —
  статус без действия это ui-tag.

## Touch-цели: компромисс 36/44

Высота чипа — 36px (`--ui-chip-height`, визуал оригинала), а не 44px как
touch-цель ui-pagination. Это осознанный компромисс, зафиксированный решением
T14.8: чипы живут в группах с gap 8px и плотной лентой фильтров (визуал
одобренного дизайна менять нельзя — design-decision владельца). 36px ≥ 24px —
минимум WCAG 2.5.8 (AA) выполняется; требование 2.5.5 (AAA, 44px) сознательно
не преследуется. Держите группы чипов вне зон частых промахов (рядом с
критичными действиями) — соседние цели через 8px-зазор читаются лентой как
суммарная область.

## Деградация без JS

- Ссылочная форма работает без JS по построению: обычные GET-ссылки — сервер
  рендерит выдачу и расставляет `aria-current="page"` (как career-portal).
- Кнопочная форма: `type="button"` — канон клиентского фильтра; для страниц,
  где фильтрация обязана работать без JS, делайте кнопки чипов
  `type="submit"` внутри `<form method="get" action="…">` — сабмит унесёт
  выбранные значения в query-строку. Правило то же: состояние —
  `aria-pressed`, CSS не меняется.

## Bitrix (шаблоны)

Классы ставятся в `template.php`: группа — на `nav`/контейнер, чипы — на
`<a>`/`<button>`; активное состояние выставляет сервер (`aria-current="page"`
/ `aria-pressed="true"` по выбранному фильтру в query-строке). Цвета и
геометрия едут из токенов: смена темы перекрашивает чипы без правки разметки;
VI-перекраска (EPIC-9) накрывает компонент — цветов вне токенов в файле нет.

## Известные границы

- Мульти-выбор (список выбранных фильтров, «сбросить всё») — вне компонента
  (Out of scope T14.8): семантика группы выбранных значений — потребность
  будущих паттернов (заявка на компонент/паттерн, не расширение ui-chip).
  Канон компонента — одиночная активная на группу.
- Сама логика фильтрации (переключение `aria-pressed`, запросы) — зона сайта;
  эталонная связка чипов со строками списка — паттерн list-page (T14.10).
- Touch-цель 36px — компромисс с фиксацией (раздел выше); пересмотр в 44px —
  design-decision владельца одобренного дизайна.
