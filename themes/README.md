# themes/

Темы: `theme-test.css` (синтетическая, T2.4), `theme-<company>.css` (реальные
бренды — minor-версиями, ADR-0007/0009; Phase 0 — один бренд Интер РАО).
**Только переопределение токенов `--ui-*`.**

## Механизм (ADR-0009, 02-architecture §3.3)

Каскад: `ui-core.min.css` (дефолты слоя 2 в `:root`) → тема → CSS сайта.

- **Атрибут темы** — `data-ui-theme` на `<html>` (фиксация T2.4; переключатель
  `?theme=` каркаса showcase делает так же, сниппет T11.1 повторит). Значение —
  имя файла без префикса `theme-` и суффикса `.css`.
- **Тема подключается после core** — файл из `dist/themes/`, ссылка рядом с
  `ui-core.min.css` (порядок подключения: core → theme → `template_styles.css`).
- Переключение может быть без перезагрузки: смена атрибута + `<link>` (так
  делает showcase); декларативно — атрибутом в шаблоне сайта, в т.ч. по разделам.

## Правила файла темы (исполняет stylelint-гейт `irao/theme-semantic-overrides`, T2.4)

- Можно: перекрывать значения **семантических токенов** (слой 2,
  `tokens/semantic.css`) в одном блоке `[data-ui-theme="…"]`. Значения
  (исполнимая форма, ревью T2.4): цветовые токены — ровно один `var()`-токен;
  теневые (`--ui-shadow-*`) — целый `var()`-токен или `none`; остальные
  неколоровые — значения без сырых цветов (длины/числа, например
  `--ui-radius-md: 0.25rem` в theme-test.css).
- Нельзя: селекторы компонентов/тегов (ни одного), обычные свойства кроме
  custom properties, примитивы слоя 1 (не переопределяются темами), новые
  имена токенов (в т.ч. опечатки — гейт сверяет имена со слоем 2), сырые
  цвета (hex/rgb/hsl — нигде, включая не-цветовые токены: цветовые имена
  закрывает declaration-property-value-allowed-list, тени — гейт тем),
  `!important`.
- Проверки: `npm run lint` (гейт themes/ + hex-гейты) и
  `npm run test:lint` (фикстуры `tests/lint-cases/css/themes/`: негативная
  `theme-invalid.css`, позитивная `theme-old-compat.css`).

## Обратная совместимость тем (правило доки)

Новые семантические токены вводятся **только с дефолтом в `:root`** слоя 2
(= minor-версия, ADR-0007/0009): старая тема просто не знает новый токен и
работает дефолтом. Переименование/удаление токена — major. Проверено
фикстурой «старая тема + новый токен» (`theme-old-compat.css`: тема знает три
токена, core содержит более поздние `--ui-color-info*` — визуал валиден;
исполнение: `tests/unit/themes.test.js`, факт: computed-проверка на стенде —
см. «Темы» в docs/ui-system/architecture/tokens-usage.md).

## Контраст

Контраст-гейт AA (T2.3) проверяет слой 2 и на темы **не действует**:
`theme-test.css` — синтетическая и не поставляется (исключение зафиксировано
в шапке `tests/contrast/pairs.config.mjs`). Реальная брендовая тема при
введении проходит те же пары против своих значений (minor-версия — с отчётом).
